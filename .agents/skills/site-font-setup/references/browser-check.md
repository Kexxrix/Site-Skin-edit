# 폰트 적용 검수

설치 완료 뒤 페이지를 실행하고 실제 브라우저에서 확인한다.

1. 폰트 파일이 정상 응답하는지, `document.fonts.load('400 16px "Pretendard JP"', '가나다 ABC 0123')`가 해당 font face를 반환하는지 확인한다. 굵은 텍스트가 있으면 700/800도 확인한다.
2. 본문·헤더·버튼·input의 computed font-family를 확인한다. 가능한 브라우저에서는 실제 사용 글꼴 표시도 확인한다. 폰트 로딩 결과와 computed style을 함께 평가한다.
3. `가나다라마바사 ABC abc 0123456789`와 실제 서비스 문구를 렌더링하고 스크린샷으로 결손 글리프, 어색한 대체 글꼴, 잘림·줄바꿈을 본다.
4. 명시적으로 사용한 Adobe family는 별도로 로딩 확인한다. 서체가 제공되지 않으면 Pretendard UI 성공과 Adobe 실패를 나누어 기록한다. 계정의 kit를 다른 도메인에서 사용할 수 있다고 추측하지 않는다.
5. 모바일과 데스크톱에서 메뉴·숫자 폭을 확인한다. 텍스트 크기와 역할별 서체는 사이트 디자인 단계에서 결정하며 설치기가 임의로 확대하지 않는다.

정적 사이트는 하위 URL에서도 상대경로 `./fonts/...`와 `./typography.css`가 동작해야 한다. 앱 빌드는 공개 URL의 base 설정도 확인한다. 브라우저 검증이 불가능하면 파일·해시 검사까지만 완료했다고 보고한다.
