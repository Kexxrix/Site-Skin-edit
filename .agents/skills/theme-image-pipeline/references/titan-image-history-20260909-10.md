# TITAN 사진·영상 제작의 문제와 개선 이력

기록 범위: 2026-09-09~10, 한국 시간. 현재 상태: 개발·기획 / 상담 / 기술 회의 / 아이디어 회의 사진 네 장을 로컬 사이트에 적용했고, 이후 미감 개선 제안은 아직 재생성하지 않았다. 영상은 첫 프레임 제작과 일부 실제 MP4 검토까지 진행했으며 최종 12초 편집본·사이트 영상 교체는 완료하지 않았다.

이 문서는 [누적 교훈](site-image-lessons.md)의 근거다. 새 사이트에서는 [장면 기획과 목적 검수](scene-intent-and-review.md)를 적용하고 [검토 기록 양식](../assets/generation-review.template.md)으로 해당 사이트의 이력을 이어간다. 아래 경로는 당시 증거를 찾기 위한 링크이며 다른 컨셉 제작의 필수 입력이 아니다.

## 작업의 성격과 기준 명세

사용자는 이전에는 직접 임시로 만든 사이트에서 일관된 테마 리소스의 생성·적용 파이프라인을 준비했고, 앞으로는 프로그래머가 만든 사이트의 명세와 정해진 규칙 아래 이미지·레이아웃 등을 지정된 컨셉에 맞추는 방식으로 작업한다고 설명했다. TITAN은 그 실제 방식의 첫 시험이며, 아래 사진·영상 제작은 맡은 첫 작업의 이력이다.

- [프로젝트 지침](../../../../titan_promotion/AGENTS.md)은 디자인 참조의 우선순위와 Titan의 콘텐츠·기능 보존, 사용자 수정 지시의 우선 적용을 정한다.
- [첫 화면 미디어 제작 의뢰서](../../../../titan_promotion/docs/briefs/hero-media-brief.md)는 왼쪽 영상과 오른쪽 사진의 납품 분량·전달 메시지·제품/기기 관계·반응형 구도와 담당 구분을 명시한다. 원문은 약 15초 영상과 사진 3~4장, 주요 한국어 메시지이며 예시 콘티의 조정을 허용한다.
- 이후 사용자 지시로 사진 네 장, 영상 첫 프레임의 영문 문구, 세 장면에서 4초씩 사용하는 12초 편집 계획을 따랐다. 원문 의뢰서는 보존하고 이 이력에 후속 조건을 기록한다. 편집 계획과 실제 영상 납품 완료는 구분한다.

이 기록은 어떤 입력과 생성 방식을 사용했고 무엇을 왜 수정했는지, 실제로 어떤 결과를 확인했는지를 추적한다. 다음 사이트에서는 해당 명세와 작업 경계를 먼저 확인하고 필요한 사례를 참조해 개선 방향을 정한다. 이번 미디어 제작 범위를 사이트 전체의 레이아웃 변경 권한으로 확대하지 않는다.

## 읽는 기준

- **관찰 확인 / 수정 후 확인 / 사용자 선택·적용 / 제안·미검증 / 원인 추정**을 구분한다. 적용 요청이 있었다고 최종 미감 만족까지 승인된 것으로 쓰지 않는다.
- 초기 `run.json`의 상태와 후속 기록이 다르면 날짜가 늦은 적용·영상 검수 기록으로 현재 상태를 판단한다. 초기 상태도 당시 기록으로 보존한다.
- 아래 평가는 당시 이미지·페이지·영상 검수 및 사용자 피드백의 기록이다. 비교 조건이 다른 결과로 프롬프트 길이, 캐스팅 집단, 생성 경로 하나의 효과를 증명하지 않는다.
- 기존 원본·실제 프롬프트·결과를 이 문서 작성 때문에 수정하거나 옮기지 않았다. 임시 폴더에 있던 적용 QA 8개만 프로젝트에 복사해 해시 일치와 원본 보존을 확인했다.

### 짧은 사용자 브리프가 실제로 제공한 정보

사용자는 사이트 오른쪽 아래 회색 영역이라는 위치, 스톡사진처럼 보이지 않는 세련된 실제 사진·화보라는 표현, 개발자·기획자/상담원/기술 회의/아이디어 회의라는 사건, 동양계 인물, 네 개의 독립 출력을 지정했다. 또한 사이트 상단 이미지를 참조로 보냈다고 설명했다. [원문과 확인 한계](../../../../generated-images/titan-generation-audit-20260909-194559/AUDIT.md)에 전문을 보존했다.

이 요청은 짧아도 사용 목적과 장면 정보가 충분했다. 반면 일부 기존 프롬프트는 미소·머리·원단·광원을 세밀하게 적으면서 장면을 업무 직후의 초상으로 바꿨고, 업무 단서까지 금지했다. 수정 기준은 ‘무조건 네 줄’이 아니라 원래 사건과 참조를 보존하고 필요한 조건만 더하는 것이다.

[사용자의 비교 자료](../../../../generated-images/titan-generation-audit-20260909-194559/sources/user-four-scene-reference.png)는 네 장면이 들어간 한 PNG다. 품질·역할 구분을 볼 자료이며 네 개의 독립 원본 파일이 생성됐다는 증거는 아니다. 19:27에 적용한 별도 네 파일과 동일한 세트로 기록하지 않는다.

이어 12초 타이포 구성 중 가장 긴 `PARTNER EARNINGS / AUTO-CALCULATED & RECORDED`의 [첫 프레임과 6초 프롬프트](../../../../generated-images/titan-grok-partner-earnings-test-20260910-152728/README.md)를 제작했고, 사용자가 제공한 MP4 2개를 [실제 의도 비교](../../../../generated-images/titan-grok-partner-earnings-test-20260910-152728/qa/video-review-20260910/README.md)로 검토했다. 선명한 후반 문구와 리본·링·패널의 움직임은 확인했으나 중앙 본문이 남은 채 글자 조각과 잔상이 움직였고, 후반에도 링이 RECORDED를 일부 가렸다. 장문이 읽힌다는 사실을 단어별 퇴장·재조립 성공으로 취급하지 않는다. 두 파일의 모션은 매우 유사해 같은 기초 영상의 다른 저장본일 가능성으로 기록했으며 생성 이력은 미확인이다.

이 사이 사용자가 확정한 [장면별 독립 디자인과 Grok 필수 편집 구조](titan-solution-brief.md)는 이후 모든 타이탄용 Grok 제작에 적용한다. 기존 정산 프롬프트 작성 뒤 추가된 완전 퇴장·전면 가림 후 재등장은 아직 검증되지 않았다. 다음 프롬프트는 이 구조, 본문과 추가 장식의 구분, 판독 구간의 도형 가림 방지를 함께 참조해 작성한다. 이번 검토에서는 과거 프롬프트와 원본 영상을 보존했으며 새 프롬프트·완성 편집본·사이트 적용은 만들지 않았다.

후속 V2 검정 가림 시험에서는 완전 검정과 재등장이 구현됐으나 시작 화면 유지가 빠지고 하단 문구가 복제됐다. 사용자는 암전 시작이 불안정과 관련될 수 있다는 가설을 제시하며 실제 요소의 화면 밖 퇴장·복귀를 요청했다. [V3 실제 결과와 채택 기록](../../../../generated-images/titan-grok-partner-earnings-test-20260910-152728/qa/video-review-offscreen-v3-20260910/README.md)에서는 원래 구성이 먼저 보이고 문구·도형이 빠져 배경만 남았다가 돌아오는 동작을 확인했다. 사용자는 이 방식이 편집하기 편리하고 자연스럽다고 채택했다. 이 제작 방식은 이후 기본으로 유지한다. 요소·이미지별 정밀 진입 방향 제어는 후속 연구로 남기며, 이번 한 사례로 독립 방향 제어나 암전의 인과관계를 확인했다고 주장하지 않는다. 원본과 프롬프트는 보존했고 새 생성·편집·사이트 적용은 하지 않았다.

그다음 사용자가 낱글자 하단 낙하·자석 복귀와 도형 상단 확산·복귀를 결합한 V4를 요청했다. [V4 실제 실패와 제어 범위](../../../../generated-images/titan-grok-partner-earnings-test-20260910-152728/qa/video-review-gravity-magnet-v4-20260910/README.md)에서 원본문구 잔류·추가 글자 낙하·자석 복귀 미구현을 확인했다. 사용자는 배경 액션은 훌륭하지만 의도는 실패했다고 평가했다. 큰 시각적 액션의 매력과 원래 요소의 수·형태·경로·시간을 따르는 능력을 분리한다. V3 제작 기준은 유지하고 V4는 실패 사례로 보존했으며, ‘낱글자 제어는 보편적으로 불가능’이라는 결론은 내리지 않았다.

확인된 변경은 사진의 밝기·표현을 사이트 팔레트와 분리한 것, 장면과 실제 참조를 되살려 네 업무가 읽히게 한 것, 실제 슬롯의 정렬을 조정한 것, 와이드 첫 프레임과 실제 MP4를 구분해 검수한 것이다. 모든 사진의 품질이 충분해졌거나 영상 고정 문제가 해결됐다는 뜻은 아니다.

현재 사이트는 09-10에 적용한 네 사진을 사용한다. 더 가까운 업무 구도·자연스러운 작업 순간·반복 소품 축소는 다음 비교의 제안으로 남아 있다. 영상의 문구·UI 고정, 최종 12초 편집, 사이트 영상 교체도 완료하지 않았다. 다른 컨셉 작업은 이 미완료 상태나 TITAN의 인물·색·비율을 그대로 이어받지 않고 현재 사용자의 목적과 자료로 시작한다.
