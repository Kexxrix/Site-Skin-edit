# 근거와 범위

이 패키지는 Sites-Skill-pipeline에서 2026-09-07~09에 진행한 사용자 확인 사례와 최신 실행 지시를 일반화했다. 다른 프로젝트 경로·GPT 대화·개인 이미지 폴더를 실행 의존성으로 포함하지 않는다.

| 항목 | 근거와 범위 |
| --- | --- |
| 폰트 먼저 설치 | 기존 casino-typography의 Pretendard JP v1.3.9, 5개 굵기 해시, CSS 변수와 Adobe kit 계약을 재사용. 정적 HTML도 같은 초기 단계를 적용. 새 패키지는 다운로드 대신 번들 검증을 사용 |
| 테마·UI 계보 | HellFire 및 후속 사이트에서 배경·캐릭터·로고·패널·아이콘 생성과 배치가 사용자 기준 사용 가능으로 확인됨. 모든 새 테마의 성공률을 보장하지 않음 |
| 편집 분기 | 사용자 직접 편집과 에이전트 편집을 구분. HellFire 캐릭터+가구 원경 제거와 지각적 크롭은 개별 사례에서 사용 가능 판정. 자동 분할의 보편 성능이나 무인 스케줄러 검증은 아님 |
| 3슬라이스 | 기존 도구로 패널 끝 장식을 보존하면서 폭 조절, 브라우저 조절/저장 확인. 가운데 무늬 변형은 남고 9슬라이스는 미구현 |
| 인물 체형 | 2026-09-08 얼굴/상체와 의상 참조 역할 수정 후 전신·무릎 앉기에서 상체 볼륨 개선 확인. 정확한 치수·동일 바닥 접점은 보장하지 않음 |
| 방향 | 2026-09-09 여섯 조건의 시계/화면 방향 비교에서 일부 시계 조건이 유리. 사용자는 시계 좌표를 약간 높은 타율의 기본값으로 채택. 고개·시선·각도 오차는 남음 |
| 내장 생성 | 같은 문구와 참조 3장으로 웹 결과와 내장 결과 한 쌍 비교. 사용자 확인 후 내장 도구를 기본 경로로 변경. 내부 모델 버전 동일성이나 모든 입력에서의 품질 동등성은 확인하지 않음 |
| 사이트 사진·영상 첫 프레임 | [TITAN 2026-09-09~10 이력](titan-image-history-20260909-10.md): 사진의 밝기·캐스팅·업무 표현, 참조·제약·검수 수정, 와이드 첫 프레임과 실제 영상 불일치, 네 사진의 로컬 적용을 기록. 최신 구도·동작 개선 제안은 아직 재생성으로 검증하지 않음 |

패키지에 포함된 [실제 제출 프롬프트](tested-prompts/README.md)는 당시 입력 역할과 실패/보정 과정을 남긴다. 현재 변수형 템플릿은 개선·일반화된 작업 지침이므로 모두 같은 문구로 반복 검증됐다고 주장하지 않는다.

## 출처 모듈

- `skills/casino-typography`: 폰트 설치기·CSS. 새 설치기는 오프라인 번들 및 여러 JS/TS 엔트리, 선택적 Adobe embed를 지원하도록 조정했다.
- `skills/casino-asset-prompt-pipeline/references`: 테마, 역할, 공유 DNA, 편집 분기. 예전 외부 생성 전용·10장 의무·매번 사용자 승인 규칙은 최신 지시에 맞춰 바꿨다.
- `docs/character-image-generation`: 참조 권한, 전신 마스터와 독립 자세 생성, 보정 원문.
- `tools/asset-panel-slicer`: `slice_panel.py`, `app-template.html` 원본을 변경 없이 포함.
- 새 `prepare_asset.py`: 검수된 마스크·명시적 크롭·알파 경계·비교 배경을 다루는 소형 도구. 의미 기반 자동 분할기가 아니다.

Pretendard JP의 원본 바이너리와 라이선스를 유지한다. Adobe 바이너리, 사용자 생성 얼굴, 의상 쇼핑몰 사진, 사이트의 파트너 로고는 재배포하지 않는다.
