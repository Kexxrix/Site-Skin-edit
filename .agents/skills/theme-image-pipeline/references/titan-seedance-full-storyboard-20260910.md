사용자의 최신 방향은 개별 글자 낙하 실험의 여섯 중간 상태가 아니라, 처음 기획한 MEET TITAN부터 TITAN SOLUTION까지의 전체 이야기다. 실제 웹 화면과 인물을 주요 소재로 사용하고 필요한 중간 이미지를 추가한다. 아래는 그 요청에 맞춘 이미지 제작 사양과 모션 연출안이다.

## 전체 방향

이야기: 타이탄을 만난다 → 만드는 사람과 시스템을 본다 → 실제 제품을 확인한다 → 운영 제어 역량을 본다 → 수익금 계산·기록의 정리를 본다 → 브랜드를 기억한다.

- 기존 후속 지시의 **12초·영문 문구**를 유지하는 안으로 기획한다. 원래 약 15초·한글 예시로 되돌리지 않는다.
- **주요 장면 6장 + 연결 상태 2장 = 독립 이미지 8장**을 제작한다. 02→03→04와 06→07은 각각 한 메시지 안의 연속 상태다.
- Seedance 2.5에서 전체 12초를 **한 번의 생성으로 사용할 수 있는 클립**으로 만드는 것이 목표다. 여기서 원샷은 생성 1회라는 의미이며 카메라 한 대의 물리적 롱테이크를 뜻하지 않는다. 장면 전환·레이아웃 교체는 연출의 일부다.
- 장면별로 배경·재질·구도를 바꾸되 굵은 산세리프 타이포, 명확한 전경·중경·배경, 빠른 이동 뒤의 판독 구간을 공유한다.
- 사이트 UI의 주황색을 영상 전체 테마로 적용하지 않는다. 제품 원본 안의 색은 그 제품의 시각 요소로 유지한다.
- 사람·제품·타이포를 연결하는 모션그래픽으로 설계한다. 인물은 업무 행동을 하고, 실제 제품 화면은 깊이와 움직임을 가진 주요 피사체가 된다.

반복 경계는 별도 동작으로 계획한다. 마지막 약 0.2초에 SOLUTION이 아래로 빠지기 시작하고 다음 시작 약 0.2초에 MEET가 위에서 들어온다. 중앙 TITAN은 같은 자리에 남는다. 금속판의 위치·진행 방향·속도와 배경 밝기·조명도 끝과 시작에서 이어지도록 지시한다. 01·08은 각각 읽히는 대표 구도이며 모든 중간·끝 프레임의 픽셀 일치를 보장하는 자료는 아니다. 완성 브랜드를 읽는 구간과 경계 연결 구간을 나누어 검수한다.

## 이미지별 제작 설정

- **공통 비율:** 이미지와 영상 모두 자연스러운 16:9. 실제 왼쪽 미디어 영역에 비율을 맞추려고 위아래 블랙 레터박스를 넣지 않는다. 주요 문구·얼굴·기기는 여유 있게 배치하고, 위아래도 공간·배경이 자연스럽게 이어진다. 정확한 출력 픽셀 크기는 고정하지 않는다.
- **독립 파일:** 8개 프레임은 각각 독립된 한 장이다. 콜라주 한 장을 참조 이미지 8장으로 취급하지 않는다.
- **글자 포함:** 각 프레임에 해당하는 최종 문구를 이미지 자체에 넣는다. 이미지 번호·시간표·화살표 설명·제작 메모는 화면에 출력하지 않는다. `/`는 위 표의 줄바꿈 표시이며 실제 문자가 아니다.
- **주요 피사체:** 01·08은 브랜드 글자, 02는 개발자의 행동, 04는 실제 제품, 05는 움직임이 정리되는 제어 구조, 07은 정확한 정산 문구와 정돈된 기록이다.
- **밝기 변화:** 밝은 소개 → 개발 현장의 차콜·자연광 → 밝은 제품 스튜디오 → 어두운 제어 장면 → 깊은 청록 정산 장면 → 밝은 브랜드. 전체를 같은 파란 리본·링 배경으로 통일하지 않는다.
- **움직일 여유:** 문구·얼굴·제품의 핵심 부분은 가장자리에서 여유를 둔다. 가로형 화면에서 제품 두 개가 서로의 내용을 가리지 않게 하고, 예상 회전·이동 상태도 확인한다.
- **연결되는 이미지의 일관성:** 02·03은 같은 인물과 공간, 03·04는 같은 제품·기기, 06·07은 같은 글자 위치·카드 구조, 01·08은 같은 TITAN 크기·위치를 공유한다. 모든 장면을 같은 공간이나 같은 도형 세트로 만들 필요는 없다.

여덟 장은 장면과 전환의 의도를 전달하는 참조다. 각 이미지가 지정한 시각의 출력 프레임과 반드시 일치한다고 취급하지 않는다. 새 방식에는 Grok 시험의 장면마다 초반을 버리는 6초 개별 클립 구조를 적용하지 않는다. 전체 원샷에서 필요한 연출과 판독을 구성한다.

## 제작 순서와 확인 기준

1. 01을 먼저 만들어 타이포·재질·와이드 구도의 기준으로 삼는다.
2. 02·04·05·07·08의 주요 장면을 제작한다. 장면의 표현력과 메시지를 우선하며 01의 배경·소재를 모든 컷에 반복하지 않는다.
3. 주요 장면을 참조해 연결 상태 03·06을 제작한다. 각각 실제 02·04와 05·07의 구성에 맞춘다.
4. 여덟 장을 시간순으로 놓고 문구, 인물의 행동, 제품 구분, 밝기 변화와 전환의 연결을 확인한다.
5. 확인된 이미지들을 사용해 Seedance 전체 영상 프롬프트를 작성한다. 현재 요청의 납품 범위는 이미지와 프롬프트이며, 실제 영상 생성은 그 후 실행하는 별도 단계다.

생성 후에는 첫 화면의 MEET TITAN, 개발·운영·정산 메시지, CAT VILLAGE 태블릿과 COBALT 휴대폰의 구분, 마지막 TITAN SOLUTION을 확인한다. 판독 구간의 철자·가림, 인물·제품의 연속성, 실제 12초 길이와 루프 경계도 검수한다. 이번 문서 작성은 그 검수를 통과한 상태가 아니다.
