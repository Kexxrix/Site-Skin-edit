# TITAN 12초 타이포그래피 영상: 텍스트 검토안

2026-09-10 최초 작성 상태: 원본 분석과 문구 제안 완료, 사용자 검토 전. 당시 첫 프레임 이미지·영상 생성 프롬프트·새 영상은 만들지 않았다. 이후 진행 상태는 마지막의 후속 기록을 따른다.

## 이번 단계와 제작 순서

현재 사용자 요청은 원본의 구조를 타이탄 내용으로 바꾸고, 먼저 들어갈 텍스트를 정리하는 것이다. 이전의 영문 방향을 유지하며 최종 편집 길이는 12초다. 원래 의뢰서의 약 15초·한글 예시보다 후속 사용자 지시를 우선한다.

1. 원본 분석 → 전체 이야기와 화면 문구 검토: 이번 단계.
2. 문구가 정해진 뒤 각 타이포 장면의 첫 프레임 이미지와 개별 Grok 영상 프롬프트 제작.
3. 각 영상을 생성하고 사용자가 필요한 부분을 골라 12초로 편집 → 한 세트 검수.
4. 그 결과를 근거로 사이트 소개용 소재와 타이포를 결합한 첫 프레임·프롬프트를 제작해 추가 시험.

첫 세트는 타이포와 추상 도형 중심이다. 복잡한 실제 사이트 UI·기기 목업·제품 소재는 후속 시험에서 다룬다. C 시험의 강한 움직임을 활용하되, 새 문구의 생성 성공이나 최종 편집 적합성이 검증됐다고 간주하지 않는다.

## 원본에서 확인한 구성

대상: [현재 삽입된 원본 영상](https://www.youtube.com/watch?v=-jokuknAtu8). 플레이어 표시 약 20초. 이번에 브라우저에서 구간별로 탐색하고 서비스명·마무리 일부는 정지 후 프레임을 전진시켜 확인했다. 시간은 대략적인 구간이며 정밀 컷 경계나 박자 측정값이 아니다. 무음 시각 분석으로, 오디오 동기화는 검토하지 않았다.

| 원본의 전개 | 확인한 화면·레터링 | 타이탄 첫 세트에 가져올 역할 |
| --- | --- | --- |
| 약 0~4초: 인사와 정체 소개 | 짧은 인사·소개 문구, 흰색과 짙은 배경의 교체, 큰 원과 작은 선·원, 로고 | 짧은 소개 뒤 브랜드를 읽게 하는 시작 |
| 약 4~8초: 강점과 가치 | 트로피와 큰 문구, 이후 발광 도형과 문구 | 큰 글자·형태 변화로 핵심 강점 강조. 트로피 자체는 이번 세트에 넣지 않음 |
| 약 8~11초: 서비스명 교체 | `Branding`에서 `Web Design`으로 교체, 다음 문구가 글자별로 나타남 | 짧은 정보 단위의 등장·교체, 문구별 속도 변화 |
| 약 11~13초: 제작물 소개 | 여러 제품·인쇄물 이미지 패널이 모인 화면 | 화면 밀도 변화. 실제 소재 결합은 두 번째 시험으로 넘김 |
| 약 13~17초: 경험과 연락 유도 | 경력 문구, 짧은 단어 전개, 연락 유도 문구 | 마지막 강점에서 브랜드로 빠르게 수렴 |
| 약 17~20초: 브랜드 마무리 | 로고와 주소 | TITAN SOLUTION으로 마무리하고 루프 연결 |

관찰에서 도출한 연출 판단: 한 문장을 오래 두기보다 문구·배경·도형의 변화를 연결하고, 빠른 등장 뒤에는 읽을 수 있는 순간을 둔다. 타이탄의 첫 12초에는 원본의 모든 컷을 같은 비율로 압축하지 않고 소개 → 핵심 역량 → 운영 역량 → 정산 역량 → 브랜드의 흐름을 적용한다.

## 전체 이야기와 화면 문구

전달할 이야기: 타이탄을 소개한다 → 핵심 시스템을 직접 만든다 → 실전에서 운영 제어를 다듬는다 → 파트너 수익금을 자동 계산하고 기록한다 → TITAN SOLUTION을 기억하게 한다.

아래는 하나의 권장안이다. `/`는 줄바꿈이며 실제 화면에 출력할 문자가 아니다. 한국어 설명은 의미 확인용이며 영상에는 넣지 않는다. 시간은 최종 편집 배분 제안이고 생성 모델에 보장된 길이가 아니다.

| 장면 | 최종 편집 구간 | 영문 화면 문구 | 전달 의미 | 레터링·도형 전개의 개념 |
| --- | --- | --- | --- | --- |
| 01 소개 | 0~2초 | **MEET / TITAN** | 타이탄을 소개합니다 | 짧은 첫 단어에서 큰 TITAN으로 강조점 이동. 원·선이 글자 주변을 빠르게 통과 |
| 02 직접 개발 | 2~4.5초 | **CORE SYSTEMS / BUILT IN-HOUSE** | 핵심 시스템을 직접 개발 | 두 줄이 서로 다른 방향에서 들어와 정렬. 블록이 모여 하나의 구조를 이룸 |
| 03 운영 제어 | 4.5~7초 | **CONTROLS / REFINED IN PRACTICE** | 실전에서 다듬은 운영 제어 | 움직이던 선·도형이 정해진 위치에 맞춰지고 문구가 선명하게 정착 |
| 04 자동 계산·기록 | 7~10초 | **PARTNER EARNINGS / AUTO-CALCULATED & RECORDED** | 파트너 수익금을 자동 계산하고 기록 | 흩어진 요소가 정렬된 묶음으로 모임. 읽을 문구가 가장 길어 3초를 배분 |
| 05 브랜드 마무리 | 10~12초 | **TITAN / SOLUTION** | 브랜드 각인 | 앞 장면의 요소를 활용해 두 줄 브랜드가 크게 등장. 짧은 판독 구간 뒤 시작 화면과 연결 |

합계: 2 + 2.5 + 2.5 + 3 + 2 = **12초**. 별도 CTA를 더 넣지 않고 마지막 브랜드에 시간을 준다. 새 숫자·실적·수익 보장은 추가하지 않는다.

문구의 기능 근거는 [제작 의뢰서의 세 가지 메시지](../../../../titan_promotion/docs/briefs/hero-media-brief.md)다. 직접 개발의 대상은 핵심 시스템이며, 운영 문구는 실전에서 다듬은 제어 기능을 뜻한다. 정산은 파트너 수익금의 계산과 백오피스 기록 범위다. `AUTO-CALCULATED & RECORDED`는 그 범위를 짧게 표현한 초안이며 자동 송금 완료를 뜻하지 않는다.

## 다음 단계의 확인점

- 장면 5개를 독립 영상 후보로 만들고 각 결과의 후반 재등장 구간에서 약 2~3초를 선택하는 구성이다. 기존 6초 생성 방식을 이어갈 경우 명목 원본 분량은 5 × 6 = 30초지만, 실제 생성 길이와 사용할 구간은 결과 파일로 확인한다. 초반 퇴장·가림과 후반 재등장에 관한 후속 필수 규칙을 함께 적용한다.
- 장면마다 글자 등장·정렬·퇴장 방식에 차이를 준다. 모든 컷을 같은 분해·재조립 효과로 반복하지 않는다.
- 운영·정산 문구는 앞선 TITAN SOLUTION 시험보다 길다. 실제 결과에서 철자·글자 형태·판독 시간·크롭을 따로 검토해야 한다.
- 영상 내내 정지시키는 조건 대신, 편집에 쓸 구간 안에서 정확히 읽히는 문구와 충분한 움직임이 함께 있는지 평가한다.
- 무음으로 이어 보았을 때 세 가지 역량이 구분되는지 확인한 뒤 소재 결합 시험으로 넘어간다.

## 후속 확정: 장면별 디자인과 편집용 재등장 구조

이후 사용자는 장면마다 배경·도형·소재·배치가 다른 독립 디자인으로 제작하도록 정했다. 정산 문구의 기존 이미지는 시험용으로 두되 같은 배경 요소를 모든 장면에 반복하지 않는다.

또한 첫 프레임에 완성된 문구와 요소가 보이는 상태를 초반 약 1~2초에 완전히 퇴장시키거나 전면 가림으로 숨긴 뒤, 후반 약 4초에 다시 등장시키는 기법을 **타이탄용 Grok 영상의 필수 조건**으로 정했다. 초반은 제외하고 후반을 속도 조절·편집하는 목적이다. 상세 적용과 실제 컷 선택 기준은 [타이탄 전용 제작 규칙](titan-solution-brief.md)을 따른다.

위 정산 시험 프롬프트는 이 규칙이 지정되기 전에 작성된 기록이다. 기존 파일을 덮어쓰지 않았으며, 다음 제작·재사용 시에는 필수 퇴장·가림 후 재등장을 반영한 새 프롬프트가 필요하다. 이번 기록 갱신에서는 새 이미지·영상·프롬프트를 생성하지 않았다.
