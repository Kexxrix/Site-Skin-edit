# 프로젝트 지침

## 최우선 디자인 레퍼런스

- 이 프로젝트의 최우선 레퍼런스는 [Dizora Home](https://kits.roxthemes.com/dizora/template-kit/home/?storefront=envato-elements)이다.
- 화면 구성, 타이포그래피, 색상, 여백, 카드·버튼, 모션 등 디자인·UI를 결정하거나 수정할 때 해당 레퍼런스를 먼저 확인하고 우선 기준으로 삼는다. 다른 레퍼런스는 보조로 활용한다.
- Titan Solution의 콘텐츠와 기능 요구사항을 유지하며 적용한다. 레퍼런스와 사용자의 구체적인 수정 지시가 충돌하면 사용자 지시를 우선한다.
