# BIT365 라이브 카지노 1차 시리즈

- 범위: Figma 74:567의 공급사 이미지 10장. 원본 사이트/Figma 편집 및 배포는 수행하지 않음.
- 기준: 사용자가 준 예시 두 화면의 시리즈 구성, 지정 폴더에서 직접 확인한 사진의 실사 품질, 현재 Figma의 카드와 로고 배치.
- 공통 방향: 검정·브라스 공간, 따뜻한 샹들리에 조명, 딥그린 테이블, 실사 인물 및 새틴 의상.
- 첫 시도는 이미지 도구 출력 안전 필터 sexual 분류로 거절됨. 노출이 적은 의상으로 수정 후 생성 성공.
- 초기 아시아 게이밍/아스타는 얼굴·포즈가 첫 이미지와 지나치게 비슷했음. 한 번씩 새로 생성하여 v2 선택; 초기본은 qa/not-selected에 보존.
- 총 시도 13회, 생성 성공 12장, 실패 1회, 최종 선택 10장, 미선택 2장, 건너뜀 0. 사용자 승인 0, 사이트/Figma 채택 0.
- 검증: 선택본 모두 PNG·1086×1448·디코딩 성공, 이동 전후 SHA-256 일치. 카드 시트와 개별 결과를 직접 시각 확인.
- 브라우저: 카드 10개, 이미지 21개, 로드 실패 0. 카드 외곽 180px, 내부 이미지 178×238, 기존 로고 156×58의 별도 레이어.
- 남은 점: 일부 얼굴·정면 자세의 유사성은 남음. 로고가 주변 손·허리 일부에 겹치지만 얼굴은 가리지 않음. 최종 미감 승인과 실제 Figma/사이트 적용은 별도 단계.
- 보존: 품질 기준 폴더·사용자 첨부·기존 사이트·Figma·이전 생성물 수정 없음. 이번 성공 출력만 프로젝트 규칙에 따라 결과 폴더로 이동.

최종 결과와 실제 프롬프트·참조·해시는 ../run.json 참조. 미리보기는 review.html과 series-card-preview.png.
