# 라이브 카지노 세로 카드 화보 시리즈 수정

- 사용자 품질 프롬프트의 16:9까지 이전 결과에 적용한 것은 목적 해석 오류였음. 원래 라이브 카지노 세로 카드 용도로 다시 제작.
- 품질이 좋다고 사용자가 평가한 가로 결과를 각 인물의 미형·의상·피부/원단 질감·밝기 참조로 사용. 첨부된 카드 시트는 세로 구도·표시 영역 참조로만 사용.
- 독립 세로 이미지 10장, 네이비 숄 1회 출력 필터 거절 후 의상 드레이프 명확화 재시도 성공. 시도 11, 생성 10, 실패 1, 건너뜀 0, 선택 10, 사용자 승인 0, 사이트/Figma 채택 0.
- 생성 원본 모두 PNG 1086×1448, 정확한 3:4. 코드로 기존 가로 사진을 크롭한 파일이 아니라 내장 이미지 도구에서 다시 구성한 출력.
- 실제 Figma 카드 외곽 폭 180px, 내부 이미지 178×238, 공급사 로고 156×58·하단 12px 조건으로 검토 시트·HTML 제작. 기존 로고는 QA에서 별도 중첩하며 생성 원본에는 포함되지 않음.
- 개별 원본·전체 카드 시트·브라우저 표시를 시각 확인. 얼굴/헤어 주요 부분이 잘리지 않고 로고가 얼굴을 가리지 않음. 하단 의상 또는 주변 손 일부에는 로고가 겹침.
- 브라우저: 카드 10개, 이미지 21개, 로딩 실패 0. 파일 읽기 및 이동 전후/최종 SHA-256 일치. 이전 세트 30장의 해시도 이전 기록과 일치.
- 남은 범위: 최종 미감 승인, 실제 Figma·사이트 교체. 소스·로고 원본·이전 가로/세로 결과는 변경하지 않음.
- 사용자 후속 요구: 생성 결과 안내 시 실제 저장 경로 항상 표시. 이번 결과는 ../results, 프롬프트와 참조·원래 도구 경로·최종 경로·해시는 ../run.json.
