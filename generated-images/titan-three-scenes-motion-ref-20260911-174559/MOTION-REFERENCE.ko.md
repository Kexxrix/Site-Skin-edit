새 3씬의 추가 카피는 사용자 표기대로 `CAT VILLAGE`와 `Casino Slot`입니다. 이전 문서의 `Casino & slots`는 이번 이미지의 카피로 사용하지 않았습니다. 제품 화면 속 일본어는 제공된 CAT VILLAGE 화면 정체성에 속하며, 새 한국어 문구를 추가하지 않았습니다.

새 생성 경로와 화면 구성 제안만 만들었습니다. 기존 승인 영상·AEP·3D 모델·사이트를 수정하거나 외부 프리셋을 설치·실행하지 않았습니다.

## 화면비 검증

- 요청한 목표: 현재 AE 작업의 75:32. 프롬프트 요청 크기: 2400×1024.
- 실제 도구 출력: 세 장 모두 **1920×819 PNG**.
- 폭 1920에서 목표 높이는 `1920 × 32 ÷ 75 = 819.2px`. 실제 높이와 차이는 `|819 − 819.2| = 0.2px`.
- 따라서 정수 픽셀 반올림 수준에서 같은 와이드 비율입니다. 2400×1024 파일을 받았다고 기록하지 않았으며, 별도 자르기·리사이즈는 하지 않았습니다.
- 각 이미지가 독립 파일 한 장입니다. 내부 비교판·콜라주가 아닙니다.

## AE에서 구성할 모션 — 제안, 아직 미실행

아래는 정지 이미지를 그대로 확대하는 방식이 아니라, Text·Shape·3D 기기로 재구성할 때 사용할 설계입니다. PNG 자체에 편집 레이어·프리셋·시간 정보가 들어 있지는 않습니다. 이미지 생성 당시 컷별 길이는 정하지 않았으며, 후속 제작 지시서에서 01은 0–1.3초, 02는 1.3–3.8초, 03은 3.8–5.7초로 원래 콘티 시간을 반영했습니다.

### 01 — 낱글자 등장과 큰 아웃라인의 역할 교대

1. 작은 `Meet`와 채움 `TITAN`을 별도 Text로 두고, 문자별 시간차·스케일·회전·이징을 조정합니다.
2. 큰 아웃라인 `TITAN`은 같은 텍스트의 별도 사본입니다. 글꼴·자간은 고정하고 배율·위치·획 또는 채움의 가시성을 움직일 수 있습니다.
3. 원호와 도트는 독립 Shape로 재구성합니다. 도트가 이동한 경로가 수평선으로 이어지고, 선의 끝이 02의 밑줄·프레임 출발점이 되도록 연결합니다.
4. 본문이 읽히는 동안 큰 아웃라인이나 도형이 움직이게 하면 글자와 배경의 움직임을 분담할 수 있습니다.

### 02 — 문구 누적과 밑줄에서 프레임으로

1. `Core systems` → `Built` → `in-house`의 의미 순서를 유지합니다.
2. 문자별 등장과 자간·스케일 변화를 만든 뒤 한 구절의 기준선에 정착시킵니다. 큰 `BUILT` 아웃라인 사본은 다른 깊이감·배율로 움직입니다.
3. 밑줄은 Built 아래에서 시작해 우측으로 이동하고, 열린 직사각 프레임으로 확장합니다.
4. 03 진입 시 이 프레임이 새 배경과 레터링의 입장 경계를 열고, 이후 태블릿 외곽과 시각적으로 연결됩니다. CAT VILLAGE와 Casino Slot 자체도 이 경계를 따라 시간차를 둔 위치·마스크 모션으로 등장합니다. 프레임의 모양·이동 방향·속도가 컷 연결의 기준입니다.

### 03 — 먼 거리의 회전 태블릿 → 정면 도착 → Fill에서 Outline

1. 중앙의 채움 `CAT VILLAGE` / `Casino Slot`은 02의 선·프레임에서 이어지는 등장 모션으로 만들어집니다. 씬 시작부터 완성된 Fill 문구를 미리 노출하지 않습니다. 제작 지시서의 F114–F124에서 제목·설명이 순차 진입하여 Fill 상태로 정착하고, 동시에 태블릿은 뒤쪽 공간에서 작게 나타나 접근을 시작합니다.
2. 태블릿은 하나의 온전한 3D 물체로 회전하면서 전진합니다. 최종 도착점은 이미지처럼 중앙·정면입니다. 실제 축·각도·시간·가속은 AE 시험에서 결정합니다.
3. 중앙 문구는 위치·글꼴·자간·크기를 유지한 채 같은 모양의 **채움 Text 사본과 아웃라인 Text 사본**의 가시성을 교대합니다. 새로운 글자로 바꾸거나 획 형태를 임의 변형할 필요가 없습니다.
4. 태블릿이 정면에 도착할 때 채움이 사라지고 획만 남아, 앞의 문구 너머로 제품 화면이 드러납니다. 이미지 03은 이 도착 상태만 나타냅니다.
5. 아웃라인 획이 제품 화면과 겹치는 영역에서는 밝은 획이나 얇은 대비 보조가 필요할 수 있습니다. 고양이 얼굴·제품 브랜드·게임 화면과의 가독성을 실제 움직임에서 검수해야 합니다.
6. 마지막에는 기기 자세와 문구를 읽을 시간을 확보합니다. 회전·진입이 끝나도 화면 영상은 독립적으로 유지할 수 있습니다.

## 조사한 프리셋·코드와의 연결

[무료 모션 리소스 조사](../titan-ae-two-cuts-20260911-114818/free-motion-resources-research-20260911.md)에서 확인한 도구를 기준으로 한 활용 제안입니다.

| 구성 | 활용할 후보 / 현재 MCP 경로 | 아직 필요한 확인 |
| --- | --- | --- |
| 낱글자·단어 등장 | aftr의 `charScale`, `bunchRotate`, `wordReveal` 정의를 `text.add_animator`·`property.set`·키프레임 작업으로 변환 | 현재 글꼴에서의 자간·선택자·가독성과 Beta 동작 |
| 윤곽선 사본의 확대·반복 | 네이티브 Text 사본 또는 파생 Shape, 위치·크기 키프레임 | 레이어 순서, 본문 가림, 글자 크기와 장면 텐션 |
| 공통 속도·반동 | Rebound / DuAEF의 베지어·스프링 계산을 검토해 `expression.set` 또는 키프레임으로 적용 | 컷 사이 연속성, 과한 바운스, 정착 시간 |
| 원호·밑줄·프레임 | 독립 Shape와 경로 공개·도트 위치 제어 | 실제 경로 연결, 도트 정렬, 불필요한 경로 점프 |
| .ffx 비교 | `timeline.set_time` → `layer.apply_preset` | 선택 프리셋의 실제 결과·의존 효과·기존 키프레임 영향 |
| 03 Fill→Outline | 같은 텍스트의 채움/획 레이어 가시성 교대 | 고정된 글자 외곽, 화면이 실제로 드러나는 시점 |
| 태블릿 | 실제 3D 기기 + 별도 화면 소스 | 원거리 회전부터 정면 도착까지 기기·화면의 보존 |

새 외부 패널이 이미 설치됐거나 특정 프리셋을 실제 적용했다는 뜻은 아닙니다. 완성 영상의 텐션·동작 수·연결성은 실제 AE 제작·렌더에서 따로 검증합니다.
