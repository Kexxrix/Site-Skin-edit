## 현재 기준

사용자가 기존 3씬의 다른 화면비를 지적하고 1·2·3씬을 모두 재생성하도록 요청했습니다. 새 요구는 같은 와이드 비율, 한국어 제거, K/DA 연구에서 참고한 타이포·전환 표현, 프리셋으로 많은 움직임을 만들 수 있는 구도, 3씬의 회전 태블릿과 중앙 Fill→Outline 문구입니다.

작업 경계는 세 정지 참조 이미지입니다. 이전 영상·3D 모델을 수정하거나 새로운 모션 영상을 만들지 않았습니다. 기존 타이포의 정확한 문구와 제품 화면 정체성을 참조하되, 새 구도는 현재 지시로 다시 설계했습니다.

참조 근거: [THE BADDEST 분석](../../titan-ae-two-cuts-20260911-114818/motion-language-reference-review-20260911.md), [리소스 조사](../../titan-ae-two-cuts-20260911-114818/free-motion-resources-research-20260911.md), [누적 교훈](../../../.agents/skills/theme-image-pipeline/references/site-image-lessons.md). 참조 영상의 원본 제작 플러그인을 확인했다는 의미는 아닙니다.

세 장을 도구가 표시한 전체 이미지로 직접 검수했습니다. 의도한 큰 배경 아웃라인과 그래픽의 화면 밖 잘림은 주 문구·기기 잘림과 구분했습니다. 03의 태블릿은 프롬프트 배치 목표보다 크게 생성됐지만 모든 모서리가 보이고 요청한 중앙 화면·아웃라인 겹침을 전달하여 후보로 선택했습니다.

01→02→03을 순차 생성했습니다. 02는 새 01을, 03은 새 01·02와 실제 CAT VILLAGE 화면을 참조했습니다. 중간 후보의 다음 참조 사용은 에이전트 선택이며 사용자 승인으로 기록하지 않았습니다.

## 기술·원본 보존

- 독립 PNG 3개, 모두 1920×819.
- 75:32 기준 높이 반올림 오차 0.2px. 2400×1024 요청과 실제 출력 크기를 분리 기록.
- 이동 전후 파일 SHA-256 동일, 최종 파일은 이미지 라이브러리로 읽음.
- 기존 01·02·03 참조와 제품 원본 캡처의 해시 재확인 결과는 run.json의 source_preservation에 저장.
- 자르기·리사이즈·외부 합성 없음. 기본 생성 폴더의 이번 세 출력만 이동.
- 도구 내장 생성 3회, 성공 3회, 실패·재시도·거절·건너뜀 0회.

## 상태와 다음 단계

이번 요청에 맞춘 정지 구도 후보 세 장으로 검수 통과했습니다. 사용자 선택과 새 AE 영상 제작은 아직 진행하지 않았습니다. PNG 자체가 네이티브 AE 레이어 또는 실제 프리셋 적용 결과라는 뜻은 아닙니다.

후속 영상에서는 주 문구의 읽기 시간, 아웃라인 대비, 선과 프레임의 이동 접점, 03의 태블릿 정면 도착 시점과 채움 제거 시점, 실제 제품 화면 보존을 확인해야 합니다. 이 검수 기록을 정지 참조 이미지의 성공 범위로 한정합니다.
