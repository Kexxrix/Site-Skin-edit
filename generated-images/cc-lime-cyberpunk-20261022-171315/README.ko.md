## 현재 요청과 변경 경계

CC Lime · 24 기본형 고정 · 1920의 녹색 테마를 살려 사이버펑크 배경과 캐릭터들을 적용했다. 기존 레이아웃 고정 조건과, 알아볼 수 있으면 캐릭터가 커지고 일부가 페이지 밖으로 잘려도 좋다는 최신 사용자 방향을 적용했다.

배경·헤더·사이버 러너·정찰 로봇을 독립 생성했다. 원본 사진·문구·폰트·버튼·간격·카드·파트너 로고·공유 컴포넌트는 수정하지 않았다. 웹 코드·서버·배포도 변경하지 않았다.

장면은 비 내리는 미래 도시, 젖은 금속과 녹색 네온, 짙은 흑연색으로 구성했다. 러너는 라임색 머리와 테크웨어·기계 팔을 가진 성인 오리지널 캐릭터이며, 정찰 로봇은 고양이 형태의 금속 몸체와 라임색 눈으로 같은 세계관을 공유한다. 광원은 상단 왼쪽의 차가운 중성광과 상단 오른쪽의 녹색 림 라이트다.

원본 파일을 추가 크롭·리사이즈·재압축하지 않았다. 이번 성공 출력만 프로젝트 폴더로 이동했고 전후 SHA-256 일치, 실제 PNG 형식·치수·읽기, 두 캐릭터의 실제 투명 알파를 확인했다. [자산 검증 기록](qa/asset-moves.json).

| 헤더 | 803:1335 | 기존 단색 위 IMAGE 채움 75%, 기존 인스턴스 유지 |
| 러너 | 911:7504 | x-240 y1082 / 800×1066.6667, FIT |
| 로봇 | 911:7505 | x1680 y1595 / 260×260, FIT |

러너는 사이드바 아래 왼쪽에 크게 배치했다. 로봇은 하단 오른쪽의 파트너 로고 바깥 여백에 배치했다. 캐릭터 일부는 페이지 가장자리와 하단에서 의도적으로 잘리며, 얼굴과 주요 특징을 남겼다. 원래 UI 위로 배치하지 않아 카드·버튼·로고를 가리지 않는다.

기존 프레임의 clipsContent=false 설정은 그대로 두고 새 장식 컨테이너만 클리핑했다. 원본 프레임 밖의 기존 페인트 범위도 임의로 변경하지 않았다. 헤더의 기존 이미지 오버레이와 fade는 삭제하지 않고 현재 인스턴스에서만 숨겼다.

실제 1920px 프레임의 전체 렌더에서 헤더·본문의 분위기 연결, 제목·사진·버튼의 구별, 캐릭터의 얼굴 식별, 의도한 크롭, 파트너 로고의 비가림을 확인했다. 기존 프레임 밖 페인트가 렌더에 포함돼 최종 PNG는 1935×1821이다. 원래 프레임 크기는 1920×1819.199951로 유지된다.

의도한 헤더 채움·구 오버레이 visibility와 신규 장식 컨테이너를 제외한 원본 UI 해시는 전후 d76d92f4로 동일하다. 인스턴스 94개를 유지했다. 기존 이미지 포함 노드 101개를 보존하고 신규 4자산을 적용해 이미지 노드가 105개가 됐다. 노드는 630→634, 신규 장식 컨테이너와 사각형 세 개만 추가했다. 다른 화면 11개와 공유 마스터 44개의 해시·캔버스 위치도 동일하다.

## 상태 및 후속

시도 4 / 생성 4 / 실패 0 / 건너뜀 0 / 작업자 검수 통과 4 / Figma 적용 4 / 거절 0.
이번 결과의 사용자 최종 승인과 웹 채택·배포는 아직 기록하지 않는다.

캐릭터는 첫 1080px 아래에서 노출되는 현재 고정 레이아웃의 배경 장식이다. 실제 웹의 반응형·스크롤 동작은 구현하거나 검증하지 않았다. 이 위치와 캐릭터 크기는 다른 테마의 고정 규칙으로 자동 재사용하지 않는다.

복구 시 911:7502를 숨기고, 기준선에 저장된 헤더 fills 및 두 구 오버레이 visibility를 복원한다. 새 이미지는 별도 파일과 독립 레이어로 남아 있어 각각 교체할 수 있다.
