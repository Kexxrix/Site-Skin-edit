## What changed

### 연결과 06 Sportsbook

F164–170의 기존 경로 끝을 반지름 80의 곡선으로 바꾸고, F171–180에 CAT과 새 장면을 같은 공간에서 위로 1024px 이동했습니다. F164 이전 경로 식은 그대로 분기 보존했고, 도트는 기존 선의 실제 끝점을 따라 최종 (2240,856)에 도착합니다. 새 Sportsbook에 왼쪽 아래 커브를 반복하지 않았습니다.

관리 중인 iPhone17 GLB를 실제 3D로 사용했습니다. 정면 축은 렌더로 확인하여 Orientation (90,0,0), 균일 Scale 1165%, Position (682,512,0)으로 맞췄습니다. 불필요한 홀드 중 흔들림은 넣지 않았습니다.

화면은 1206×2622 컴프에 원본 332×720 영상을 contain했습니다. 배율은 1206÷332×100 = 363.253012%, 위아래 여백은 각각 3.289157px입니다. 원본 24fps·정상 속도·F171에서 소스 1초 시작을 유지했습니다. 실제 저장 startTime의 약 0.000008초 반올림 차이는 타임라인 기록에 명시했습니다.

사용자가 `iPhone17.SCREEN` 재질 연결을 완료한 뒤, F182와 F219의 다른 영상 내용 및 저장·재열기 후 렌더를 확인했습니다. Computer Use 절차상 반복 실패한 메뉴 조작은 중단하고 사용자 연결로 진행했으며, 회색 화면이나 평면 오버레이를 완료로 처리하지 않았습니다.

추가 요청에 따라 `SCREEN_iPhone17_VIDEO_CONTAIN` 내부에 `RECORDING_RED_DOT_MASK`를 만들었습니다. 중심 (385,94), 반지름 26px, Feather 2px의 검정 원형 마스크로 녹화 붉은 점만 가렸습니다. F182/F219에서 마스크 바깥 반경 32px 이후 픽셀 변화는 0, 검사 영역의 밝은 빨강 픽셀은 0입니다. 원본 MP4는 변경하지 않았습니다.

### 07 Operations, / refined

F220–222 도트를 가로 리본으로 늘린 뒤, F222–228 차콜 면으로 덮고 넓은 면들을 F234까지 정렬했습니다. Operations,는 F228–232, refined는 F230–234에 진입합니다. 읽기 구간 F234–250에서 전경은 고정되고, 배경 OPERATIONS 상·하단은 각각 −24/+18px/F로 이동합니다.

설치된 Adobe 프리셋 3종은 실제 적용 성공 로그를 남겼고, 기본 긴 키프레임을 제거해 지정 시간으로 조절했습니다. refined는 Pretendard Black에 faux italic을 사용했으며, 비활성 프리셋 애니메이터의 Opacity를 쓸 수 없어 레이어 Opacity로 구현했습니다. aftr wordReveal은 지정 속성에서 출발한 네이티브 이식·조정이며 원형 그대로의 Offset 애니메이션은 아닙니다. 상세는 프리셋 기록에 있습니다.

### 08 전체 확대 오버레이와 즉시 정지

07씬 컨테이너는 Position (1200,512), Scale 100%로 고정했습니다. 그 위에서 **배경·마스크·레일·문구를 모두 포함한 08씬 전체**가 F250–252에 나타나고 F252–260에 600→100%로 복원됩니다. 07씬 썸네일, 별도 셔터, 카드 프레임은 만들지 않았습니다.

실제 역산된 레일 셀은 y101–401이므로, 지시서가 허용한 재계산에 따라 Anchor를 초기안 (210,205)에서 **(210,251)**로 조정했습니다. 시작 Position (1200,512), 도착 Position=Anchor, 같은 5차 q를 적용합니다. 확대되는 첫 셀은 아이보리이며 크기 420×300을 6배 확대한 2520×1800으로 화면을 덮습니다. 가이드 PNG 확대가 아닌 네이티브 벡터입니다.

새 오버레이/레일 컴프에는 Shutter 180°, Phase 0°, Samples 64 / Adaptive 256을 적용했습니다. 기존 마스터 전역 120° / −60°는 그대로입니다. F252/F260은 선명하고 중간 구간은 모션블러가 생깁니다. Phase 0은 F279 첫 홀드 프레임에 정지 이전 블러가 남지 않게 하기 위한 범위 내 조정입니다.

양쪽 레일은 F262부터 반대 방향으로 이동하며 총 이동량은 5×14 + 6×36 + 6×60 = 646px입니다. F279에서 둘 다 즉시 정지하고 Bets는 F279–284, auto-blocked는 F281–287에 나타납니다. 완성 결과 F287–315는 28프레임, 28÷30 = 0.933333초 유지됩니다.

## Remaining risks

- 아이폰 원본 332×720의 작은 글자 해상도 한계가 있습니다. 모델 물리 카메라 섬은 원본 상태 섬 경계와 일부 겹치며, 요청한 붉은 점만 가렸습니다. 업스케일·UI 재제작은 하지 않았습니다.
- 07씬 읽기 구간과 08씬 속도감은 기술 검사만으로 사용자 승인을 대신할 수 없습니다. 특히 08씬의 최종 모션 승인은 남아 있습니다.
- AEP는 기존 로컬 소스 경로를 참조합니다. 다른 컴퓨터용 Collect Files 패키지는 이번 범위가 아닙니다.
- 보호된 3D 프레임은 위와 같은 극소 픽셀 차이가 있어 비트 단위 동일성은 보장하지 않습니다. 전체 표현식 전수 검사도 제공 가능한 도구 범위의 한계가 있습니다.
