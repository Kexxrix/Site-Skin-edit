# 제작 검토 기록

## 의도
CC Lime B 구조를 보존한 추가 시안에서 기존 고급 카지노 사진을 미래 도시의 포인트 보관소·초대 패스·리워드 로봇으로 전환한다. 네 개 진입점은 버튼 전체 사진과 편집 가능한 글자가 겹치는 구조로 바꾼다.

## 관찰과 수정
- 첫 생성 포인트 장면은 재질·도시·라임 조명이 현재 배경과 연결되고 좌측 글자 공간을 확보했다. 이 결과를 나머지 생성의 재질 참조로 사용했다.
- 회원 이벤트 인물 장면은 도구가 출력 단계에서 거절하여 결과 파일이 없었다. 인물이 없는 초대 패스와 입구 장면으로 전환해 역할을 유지했다.
- 첫 Figma 전체 렌더에서는 흰 화살표가 밝은 라임 버튼 위에서 약했다. 새 복제본의 기존 벡터 선 색을 #07110B로 바꿨고 형태는 유지했다.
- 최종 실제 크기 바로가기에서 카지노·슬롯·축구·농구 주체와 한글 제목이 각각 읽히는 것을 확인했다.
- 세 혜택의 중심 주체가 오른쪽에 있고 제목/설명은 왼쪽에 배치되어 서로 가리지 않는다. 측면 미리보기는 이미지별 우측 주체를 기준으로 크롭했다.
- 기존 A/B, 기존 마스터와 새 화면 하위 영역의 해시 보존을 확인했다.

## 결과와 한계
기술 검사와 실제 배치 시각 검수를 통과하여 에이전트가 7개를 선택하고 Figma 비교 시안에 적용했다. 사용자 최종 승인으로 간주하지 않는다. 실제 서비스 동작·반응형·채택·배포는 별도다.
