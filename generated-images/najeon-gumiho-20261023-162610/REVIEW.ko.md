# 자개 구미호 · NACRE NOIR 검토 기록

## 목적
24 기본형의 구성과 간격을 유지한 추가 스킨. 검은 옻칠과 실제 조개껍질 조각을 상감한 듯한 무지갯빛 자개 공예품을 표현한다. 털·글리터 코팅·무지개 플라스틱 같은 여우로 만들지 않는다.

## 제작과 관찰
- 기본 화면은 기존 제우스 스킨의 구조를 복제했다. 생성 참조 화면은 배치와 가독성 맥락에만 사용했고, 제우스·그리스 건축·기존 남색/금색 분위기는 상속하지 않았다.
- 산수·구름·국화·초승달 자개 문양의 배경을 먼저 생성하고, 그 재질을 구미호와 헤더에 연결했다.
- 최초 구미호는 꼬리 끝이 여덟 개로 읽혔다. 기존 파일을 보존하고 오른쪽 아래에 별도 꼬리를 추가한 수정본을 생성했다. 수정본에서 왼쪽 네 개·가운데 한 개·오른쪽 네 개의 꼬리 끝을 확인했다.
- 캐릭터 파일은 RGBA이며 배경 알파가 실제 존재한다. 모서리 하나는 alpha 1/255의 극미량 잔여값이 있으나 실제 어두운 페이지 배치에서 사각 배경은 보이지 않는다.
- 배너 세 장은 보관함과 토큰, 병풍과 초대함, 진주 구슬을 놓는 의식으로 구분했다. 금액·지급 조건은 새로 만들지 않았다.
- 바로가기 네 장은 룰렛, 슬롯 릴, 축구 달리기, 농구 도약으로 구별했다.
- 첫 전체 화면에서 메뉴 글자와 파트너 로고 뒤의 자개 문양이 과했다. 이미지 자체는 유지하고 배경 및 UI 텍스처의 농도를 낮춰 실제 표시 크기에서 다시 확인했다.
- 메뉴에 추가한 선이 라벨의 위치/폭을 바꾸어 기본 행의 추가 선을 제거하고 FILL/HUG 치수를 갱신했다. 최종 구조 검증에서 차이 0건으로 확인했다.

## 최종 확인
- 원래 화면과 다른 기존 캔버스 작업물 보존.
- 주요 레이아웃 1920 × 1829.2, 메인 gap 16, 콘텐츠 타이틀 gap 8 유지.
- 원래 컴포넌트 인스턴스 91개의 연결 유지. 이전 제우스 전용 색상 변수 참조 0개.
- 독립 스킨 색상 토큰 43개. 이미지·텍스트·오버레이·마스크는 별도 편집 가능 레이어.
- 전체 화면과 상단/캐릭터의 실제 표시 크기 캡처를 검토했다. 얼굴·자개 조각·라벨과 진입 버튼을 확인했다.
- 장식 캐릭터는 기존 크기를 유지한 채 얼굴이 보이도록 63px 왼쪽으로 옮겼다. 배너 마스크만 새 구미호에 맞춰 수정했다.
- 이미지 파일 형식/읽기/크기와 이동 전후 해시를 확인했다. 원본 이미지에 리사이즈·포맷 변경·압축을 적용하지 않았다.

## 상태
내장 image_gen 생성 11회 성공, 최종 시안용 10장 선택·적용, 최초 캐릭터 후보 1장 제외·보존. 사용자 최종 승인 대기. Figma 시안이며 실제 웹 코드에는 적용하지 않았다.

상세 경로·프롬프트·참조 해시·노드·검수 결과는 run.json, qa/verification.json을 따른다.
