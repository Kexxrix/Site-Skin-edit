# 슬롯 3D 이미지 검토

- 원본 10장: 각각 독립된 3:4 PNG, 1086×1448, 읽기 검증 및 이동 전후 SHA-256 일치.
- 생성 방식: Codex 내장 이미지 생성, 카드 사용 맥락과 제우스의 3D 질감을 실제 이미지 참조로 사용.
- 게임사별 캐릭터·상징 소품을 작은 카드에서도 식별할 수 있음. 원본 일부 장식은 상단 경계에 닿지만 얼굴과 중심 소품은 보존됨.
- 최종 Figma 카드 10종과 데스크톱/390px 모바일 화면을 시각 확인. 로고와 문구는 별도 편집 레이어로 유지.
- 샴페인 페이지의 6개 화면 × 슬롯 카드 10개 = 60개 이미지 적용. 기존 BIT365·ALDEBARAN 페이지와 컴포넌트 마스터는 변경 없음.
- 공식 대표작·인기작 소개에 근거해 선정. 모든 게임사의 최신 전역 인지도 1위를 입증한 순위는 아님.
- Figma 렌더 뒤 768px/390px 전체 프레임 높이가 최초 조회보다 26px 증가했고 일부 비대상 인스턴스 지문이 달라짐. 해당 노드 속성에 직접 쓰기를 수행하지 않았으며 정확한 재계산 원인은 미확인. 렌더 결함은 발견되지 않음.
- 사용자 최종 미감 승인 상태는 아직 미확인. 적용 완료와 승인 상태를 분리해 기록.
