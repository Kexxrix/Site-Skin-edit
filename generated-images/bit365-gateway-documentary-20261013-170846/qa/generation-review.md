# 카테고리 이미지 4장 — 현장감 제작 검수
## 요청과 실행
- 요청: 라이브 카지노, 슬롯, 스포츠, 인플레이에 들어갈 독립 이미지 4장. 기존 CG/판타지 느낌을 줄이고 현장감 강화.
- 화면 참조는 아래 4개 카드의 비율과 하단 왼쪽 제목 위치에만 사용. 원본 CGI 콘텐츠나 상단 배너를 복제하지 않음.
- 각 컷은 실제 촬영 사진이 아닌, 현장 사진의 인상을 목표로 생성한 가상 장면.
## 장면에서 확인한 목적
- 라이브 카지노: 이용자 시점 전경, 딜러의 실제 카드 배분 행동, 테이블/칩/카드 슈, 따뜻한 실내 분위기.
- 슬롯: 사람 크기에 맞는 직립 머신과 좌석, 버튼을 이용하는 사람, 원근감 있는 머신 열.
- 스포츠: 가까운 두 선수와 하나의 공, 잔디·유니폼 질감, 경기 동작.
- 인플레이: 관중석 시점의 진행 중인 경기, 전경 관중 반응, 전체 경기장과 영상 전광판. 스포츠 근접 컷과 역할 구분.
- 공통 사진 품질과 자연스러운 실내/경기장 조명은 유지하되 하나의 색으로 고정하지 않음.
## 사용자 피드백과 수정
- 최초 라이브 카지노의 인물이 나이 들어 보이고 의상이 예쁘지 않다는 피드백.
- 얼굴 참조를 추가해 젊고 부드러운 인상과 포니테일로 수정하고, 회색 조끼/셔츠를 네이비 새틴 드레스와 아이보리 스카프로 변경.
- 카드 배분 동작, 공간과 카메라 구도는 유지. 수정본이 선택 후보이며 최초 출력은 qa/not-selected에 별도로 보존하고 해시 일치를 확인.
## 배치 및 기술 검수
- 독립 선택 PNG 4장, 모두 디코딩/해시 검사 통과. 생성 출력 총5장, 수정으로 대체된 후보1장, 실패0장.
- 실제 치수: 라이브 카지노 수정본2048x768, 나머지1942x809. 원본 픽셀 크기나 비율을 후처리로 강제하지 않음.
- QA에서만 342x142로 표시. 라이브 카지노의 중앙 표시 크롭에서 딜러 얼굴/손/카드/테이블이 남는지 확인.
- 브라우저 카드4개, 이미지8개 정상 로드, 깨진 이미지0개, 제목 넘침0개.
- 제목과 하단 음영은 검수용 HTML 오버레이이며 생성 원본에 추가 합성하지 않음.
- 실제 카드·테이블·머신·유니폼에는 자연스러운 소품 표기/숫자/기호가 있음. 따라서 텍스트가 전혀 없는 이미지라고 주장하지 않음.
## 한계와 상태
- 슬롯 UI의 작은 문자는 생성된 표현이며 실제 게임 인터페이스를 검증/재현한 것이 아님. 카드 표시 크기에서는 작지만 확대 용도로 사용할 때 정리가 필요할 수 있음.
- 스포츠 유니폼에 작은 브랜드 형태의 기호가 남아 있어 완전한 무브랜드 출력이라고 주장하지 않음. 실제 팀/선수/장소를 재현했다고 주장하지 않음.
- 사진 인상/카드 배치에 대한 제작자 검수 통과와 사용자 최종 만족·승인·사이트 채택은 별도.
- 이전 이미지, 참조 원본, 사이트/Figma 파일은 수정하지 않음.
