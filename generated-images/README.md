# 생성 이미지 보관함

이 프로젝트와 하위 프로젝트의 새 생성 이미지를 작업별로 관리합니다. 사용자가 다른 출력 위치를 명시한 작업은 해당 지시를 따릅니다.

```text
generated-images/
  <topic>-<yyyyMMdd-HHmmss>/
    results/    생성 이미지
    prompts/    실제 사용한 프롬프트
    run.json    출력 경로, 참조, 검수 및 선택 상태
    qa/         필요한 검수 자료
```

실제 생성 작업이 시작될 때 실행 폴더를 만듭니다. 새 파일은 기존 파일을 덮어쓰지 않는 이름으로 저장하며, 기본 Codex 생성 폴더에서 이동한 경우 SHA-256 일치, 읽기 가능 여부, 실제 형식과 크기를 확인합니다. 생성 성공과 사용자 승인·사이트 채택은 구분해서 기록합니다.

기존 `D:/WebDL` 이미지와 이전 생성물은 별도 이동 요청이 있기 전까지 원래 위치에 둡니다.
