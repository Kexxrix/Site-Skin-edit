## 변경 내용

기존 Together Pink · 24 기본형 고정 · 1920 화면에 오리지널 3D 마스코트와 어울리는 판타지 환경을 생성하여 적용했다. 사용자가 든 플랫폼 게임 캐릭터 예시는 통통한 비율·친근한 실루엣·3D 렌더링의 방향으로 반영했다.

- 마스코트: 핑크 별귀 드래곤 토끼, 크림색 얼굴과 배, 민트색 별 장식, 큰 눈과 운동화, 환영하는 손짓.
- 배경: 짙은 핑크 지형과 곡선 다리, 진주광 구체. 중앙은 어두운 여백.
- 이미지와 캐릭터를 별도 레이어로 분리했다. UI를 이미지에 합치거나 기존 인스턴스를 분리하지 않았다.

## 실제 파일과 생성 방식

Built-in image_gen을 2회 사용했다. 배경과 캐릭터를 각각 독립 생성했고, 일관된 광원·팔레트를 텍스트로 지정했다. 생성 도구에 기존 화면을 첨부하지 않았으며, 제작 전 실제 Figma 화면을 열람해 노출 영역과 색·크기를 확인했다.

| 용도 | 실제 파일 | 실제 형식·크기 | 프롬프트 |
|---|---|---|---|
| 배경 | [together-pink-fantasy-background-v1.png](results/together-pink-fantasy-background-v1.png) | PNG RGB 1289 × 1220 | [background.txt](prompts/background.txt) |
| 마스코트 | [together-pink-star-mascot-v1.png](results/together-pink-star-mascot-v1.png) | PNG RGBA 1086 × 1448 | [mascot.txt](prompts/mascot.txt) |

캐릭터의 알파 최솟값 0, 최댓값 255, 완전 투명 픽셀 892170개를 확인했다. 두 이미지 원본을 추가 크롭·리사이즈·재압축하지 않았다. 이번 성공 출력만 프로젝트로 이동했고 전후 SHA-256 일치와 이미지 파일 읽기를 확인했다. [검증 기록](qa/asset-moves.json).

## Figma 적용

| 레이어 | 노드 ID | 위치·크기 | 표시 |
|---|---|---|---|
| Generated 3D fantasy background | 905:7502 | x0 y0 / 1920 × 1819.199951 | FILL, 이미지 불투명도 80%, 양방향 STRETCH |
| Original 3D star mascot | 905:7503 | x2 y1090 / 260 × 340 | FIT, 불투명도 100%, 비율 유지 |

둘 다 ABSOLUTE 배치와 잠금을 사용하여 원본 오토레이아웃 흐름에 영향을 주지 않는다. 마스코트는 사이드바 하단 여백과 전경 지형에 배치했다. 메뉴·TITAN 문구·스포츠 카드·사진·버튼·파트너 로고에 겹치지 않는다.

캐릭터는 y1090부터 놓여 있으므로 최초 높이 1080 화면에서는 보이지 않는다. 현재 검증 대상은 스크롤 내용을 포함한 Figma 전체 페이지다. 추후 웹 구현에서 첫 화면 노출이나 고정 배치가 필요하면 별도 판단해야 하며 이번 작업에서는 웹 동작을 구현하지 않았다.
