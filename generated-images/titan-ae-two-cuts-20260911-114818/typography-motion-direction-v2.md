# TITAN 영문 타이포 — 구조 완성과 모션 강화 방향 v2

작성: 2026-09-11. 현재 사용자가 정한 제작 방향을 기록한 계획 문서다. 진행 중인 첫 3초 테스트의 AEP나 렌더를 수정한 기록이 아니다.

## 현재 확정한 우선순위

1. **지금의 영문 타이포 구조를 먼저 완성한다.** 문구의 역할, 강조 관계, 줄 구성, 정착했을 때의 구도를 기준으로 삼는다.
2. **영문판의 시각적 완성도와 모션의 표현력을 최우선으로 한다.** 한국어판 제작을 필수 후속 작업으로 가정하지 않는다.
3. 한국어는 나중에 선택할 수 있는 가능성이다. 이를 이유로 지금 쓸 수 있는 영문 모션을 과도하게 줄이지 않는다.
4. 명시적으로 제외한 것은 **글자 하나씩 순차 등장**과 **글자 모양 자체의 변형**이다.
5. 그 밖의 타이포 액션과 효과는 장면의 목적에 맞게 폭넓게 사용한다. 모든 컷에 같은 효과를 반복하거나 모든 효과를 한꺼번에 겹치는 것을 목표로 삼지 않는다.

## 구조를 유지한다는 뜻

읽는 정착 상태의 문구, 크기·굵기 위계, 공통 기준선, 문구 간 관계를 유지한다. 진입·강조·퇴장 중에는 전체 단어·문구의 위치, 균일 크기, 각도, 자간, 투명도, 색과 효과를 적극적으로 변화시킬 수 있다.

첫 두 컷의 정착 기준은 [기존 모션 지시서](motion-instructions.md)와 [컷 01](results/01-meet-titan.png), [컷 02](results/02-built-in-house.png)다. 참조 그림의 래스터 얼룩을 복제하지 않고 실제 텍스트·도형으로 제작한다. 영문 전체 영상의 새 타임라인이나 전체 제작 범위를 이 문서에서 추가로 확정하지 않는다.

## 활용할 모션과 효과

| 유형 | 계획하는 표현 | 유지할 기준 |
|---|---|---|
| 이동과 강한 정지 | 단어·문구 전체의 상하·좌우·대각 진입, 속도 변화가 확실한 이동, 짧게 감속하며 자리 잡기 | 움직임이 끝나면 기준선과 최종 위치에 정확히 정착 |
| 균일 확대·축소 | 중요한 단어의 빠른 확대, 작은 단발성 오버슈트 후 정착. 예: 96→103→100%는 후속 시험의 출발값 | 가로·세로에 같은 배율 적용. 최종 글자 크기 위계 유지 |
| 전체 회전 | 단어·문구 전체를 약간 기울였다 바로 세우거나 회전과 이동을 연결 | 글자 윤곽은 그대로 두고 레이어 전체를 회전 |
| 자간 모션 | 모든 글자를 동시에 보이게 한 상태에서 자간을 펼쳤다가 모으기 | 글자별 등장 지연 없이, 마지막 자간은 정착 기준으로 복귀 |
| 가림과 등장 | 단어 전체가 위아래로 이동하며 매트 경계를 통과하는 방식, 문구 블록 간 앞뒤 가림 | 수평으로 한 글자씩 읽히게 만드는 순차 노출은 제외 |
| 속도 효과 | 이동 중 짧은 방향성 블러, 필요할 때 문구 전체의 짧은 잔상 | 정착하면 선명하게. 잔상은 읽는 화면과 다음 컷에 남기지 않음 |
| 색·빛 강조 | 핵심 단어의 주황 강조, 전체 단어의 짧은 밝기·광택·glow 강조 후 기본 상태 복귀 | 글자 형태와 판독성 유지. 반복 점멸은 기본안에 넣지 않음 |
| 레이어 조합 | 여러 단어·문구의 진입 시간 차이, 블록 단위 교차·겹침·정렬 | 이미 전달한 문맥과 마지막 완성 문장이 명확하게 읽힘 |
| 그래픽과 전환 | 타이포의 정착에 밑줄·선·점의 동작을 맞추고, 퇴장 방향을 배경 와이프와 연결 | 단어·도형·배경의 동작이 하나의 장면으로 연결됨 |

위 목록은 활용 범위다. 실제 효과 조합과 세기는 첫 결과를 본 뒤 선택한다. 현재 설치된 AE와 MCP에서 해당 속성을 구현하고 원하는 렌더가 나오는지는 각 보강안의 실행 때 확인한다.

## 제외하는 표현

- 타자기처럼 글자 하나씩 등장하거나 글자마다 다른 지연으로 나타나는 효과.
- 글자의 윤곽을 늘이거나 구부리거나 녹이는 모핑, 세로·가로를 다르게 늘이는 squash/stretch.
- 문자 자체를 다른 문자로 바꾸는 scramble/character-offset 효과.
- 글자 조각을 분해·재조립해 윤곽 자체를 바꾸는 연출.
- 가림 방향 때문에 결과적으로 글자가 왼쪽부터 한 글자씩 등장하는 효과.

단어별 시간차 등장은 사용할 수 있다. 전체 단어의 이동·균일 스케일·회전, 모든 글자가 동시에 보이는 자간 모션은 글자 모양 변형으로 취급하지 않는다.

## 첫 두 컷에서 검토할 조합

### 컷 01 — Meet TITAN

- Meet가 먼저 자리를 잡아 도입 문맥을 만든다.
- TITAN은 전체 단어의 빠른 진입과 균일 스케일 정착으로 더 강하게 등장한다. 작은 전체 회전 또는 자간 수렴을 추가 후보로 둔다.
- 원호와 점의 움직임을 TITAN이 정착하는 순간에 맞춰 힘을 모은다.
- 첫 컷 전체가 정착한 뒤 읽는 상태를 확보하고 다음 배경으로 넘긴다.

### 컷 02 — Core systems / Built in-house

- Core systems는 문맥 역할이므로 정착 후 유지한다.
- Built는 가장 강한 액션을 맡는다. 전체 단어가 짧게 치고 들어오고, 정착과 함께 밑줄이 이어지게 한다. 단발성 균일 스케일 강조 또는 짧은 블러를 조합 후보로 둔다.
- in-house는 옆에서 들어와 같은 기준선에 맞물리도록 한다. Built의 진입을 그대로 반복하기보다 방향과 속도 리듬을 달리한다.
- 완성된 문장은 모두 선명하게 유지한다. 강조 효과가 끝난 뒤에도 남는 잔상이나 앞 컷 문구는 제거한다.

이는 후속 보강 계획이며 기존 F00–F89 지시를 이미 변경했다는 뜻이 아니다. 첫 테스트를 확인한 뒤 보강본의 타이밍·강도·전체 길이를 구체적으로 정한다.

## 나중의 문구 변경을 위한 최소 기준

영문 모션을 제한하는 별도 다국어 시스템은 만들지 않는다. 다음 기본 편집 가능성만 유지한다.

- 실제 문구를 네이티브 Text Layer로 보존한다.
- 단어·문구의 의미 역할이 알아보이도록 레이어를 구분한다.
- 효과용 복제본은 원문과의 관계를 유지해 나중에 복제본만 옛 문구로 남지 않게 한다.
- 영문 글자 개수나 특정 글자 인덱스에 의존하는 구현을 기본으로 삼지 않는다.
- 별도 언어판이 필요해지면 그때 실제 문구·폰트·배치·마스크·읽는 시간을 맞춘다. 한국어 변경을 반드시 수행한다거나 수정 없이 교체된다고 약속하지 않는다.

AE는 텍스트 전체의 레이어 변환과 텍스트 애니메이터·선택자 방식 등을 제공한다. 실제 구현에서 이번에 제외한 지연을 둔 글자별 등장과, 모든 글자가 동시에 보이는 효과를 구분한다. [Adobe 텍스트 애니메이션 안내](https://helpx.adobe.com/after-effects/desktop/animating-text/text-animation/animating-text.html)

## 다음 판단 순서

1. 진행 중인 첫 영문 3초 결과를 실제 재생해 정착 구도와 기본 동작을 확인한다.
2. 약한 지점에 맞춰 위 효과 중 필요한 조합을 선택한다. 첫 보강에서는 기존 결과와 차이를 판단할 수 있도록 변경 항목을 명시한다.
3. 보강본에서 더 힘 있는 액션이 생겼는지, 읽는 시간·타이포 위계·컷 연결이 유지되는지 비교한다.
4. 선택한 모션의 원칙을 이후 영문 컷에 적용한다. 한국어판 여부는 별도 결정 사항으로 남긴다.

현재 상태: 계획 문서 작성. AE 수정·영상 렌더·이미지 생성·다른 작업으로의 지시 전달은 실행하지 않았다.
