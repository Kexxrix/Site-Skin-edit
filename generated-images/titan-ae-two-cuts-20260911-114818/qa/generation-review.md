# 두 컷 생성 및 검수 기록

날짜: 2026-09-11. 현재 사용자 요청은 전체 영상이 아닌 첫 두 컷의 AE 테스트에 필요한 이미지 2장, 모션 지시서, MCP 사전조사다. 이후 지시로 16:9 대신 원래 히어로 화면비를 적용했다.

## 생성

- Codex 내장 이미지 생성 사용, 순차 2회 호출, 2회 성공.
- 01은 첨부 이미지 없이 새로 생성했다. 기존 Grok 테스트 첫 두 컷의 문구·색·단순 도형 방향을 프롬프트로 구체화했다.
- 02는 이번 01의 저장 PNG만 첨부했다. 역할은 깔끔한 스타일과 여백의 참조이며, 01의 문구·원호·점을 남기는 지시가 아니다.
- 실제 프롬프트는 [01](../prompts/01-meet-titan.txt), [02](../prompts/02-built-in-house.txt)에 보관했다.
- 출력 두 파일을 기본 생성 경로에서 이번 results로 이동했다. 대상은 프로젝트 안의 신규 폴더이며 기존 이름 충돌이 없었다.
- 이동 전후 SHA-256 일치, PNG 형식과 읽기 가능 여부를 검사했다. [원경로와 최종 경로 기록](saved-outputs.jsonl).
- 두 파일 모두 1920×819. 목표 75:32의 높이 반올림 오차 0.2px이며 크롭·리사이즈·형식 변경은 하지 않았다.

## 이미지별 실제 확인

| 이미지 | 확인 결과 | AE 재작성 시 주의 |
|---|---|---|
| 01-meet-titan.png | Meet TITAN 철자 정확. Meet가 작고 가벼워 위계가 구분됨. 원호·점이 글자와 충돌하지 않음. 잘림 없음. | TITAN이 다소 굵어 보임. 이미지에서 실제 폰트나 weight는 확정할 수 없으므로 Pretendard-SemiBold를 사용. |
| 02-built-in-house.png | Core systems와 Built in-house 철자 정확. 두 줄 위계, Built 강조색, 아래 문구의 공통 기준선 확인. 밑줄이 글자에 닿지 않음. | in-house를 Pretendard-Medium으로 명시. 래스터의 미세한 얼룩·톤 변화를 AE에 복제하지 않음. |

주 작업자와 별도 검토자가 두 파일을 직접 확인했다. 큰 구성 결함은 발견하지 못했다. 이번 결과는 구도 가이드로 사용 가능하다는 검수이며, 사용자 최종 승인 또는 사이트 채택을 의미하지 않는다.

## 검증된 것과 남은 것

확인: 이미지 2장, 문구, 가로 구도, 비율 반올림, 파일 해시·형식·읽기, MCP catalog와 기존 Hello World의 구현 경로.

아직 미확인: 이 두 컷의 실제 AE 글자 경계, 키프레임과 와이프 재생, 최종 3초 영상, 사이트 내 표시. 이 작업에서는 AE 프로젝트·현재 사이트·이전 생성물을 변경하지 않았다.

현재 수량: 시도 2, 생성 성공 2, 생성 실패 0, 기술·시각 검수 통과 가이드 2, 재생성 0, 보류/거절 출력 0, 사용자 승인 0, 사이트 채택 0, AE 실행 0, 영상 생성·렌더 0.

후속 개선은 먼저 가이드 2장을 AE의 정확한 텍스트·도형으로 옮겨 정착 화면을 비교한 다음, 문서의 프레임 타이밍을 적용하는 순서다. 이 방법의 새 컷 재현 품질은 아직 시험하지 않았다.
