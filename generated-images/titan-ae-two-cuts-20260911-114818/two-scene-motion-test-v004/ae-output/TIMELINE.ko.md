## review-01 이후 사용자 요청 반영

- 첫 씬의 iPhone 합성을 껐습니다. 소스 GLB, 이전 컴포지션, 이전 검토본은 삭제하지 않았습니다.
- 회전 방향·각도: review-01의 Y −30° / Z −3° → review-02의 Y +35° / Z 0°. 스케치처럼 오른쪽 모서리가 가까워지는 방향입니다.
- 후퇴: F174–214 → F174–204. 최종 부모 X 0 → −10으로 조정해 화면 안 노출량을 늘렸습니다.
- 회전 시작: F174 → F180. 정면으로 접촉하고 후퇴하기 시작한 뒤 회전합니다.
- 글자, 원호, 도트, 둘째 씬 기존 레터링, 190px 밀림과 문구 복귀 시점은 유지했습니다.
- 위 기기 X 값은 AE 네이티브 3D 부모의 좌표 단위이며, 화면의 픽셀 좌표와 구분합니다. 정면 상태에서는 15단위가 약 150px에 해당합니다.

## 편집 지점

- 문구 밀림량: 주 컴포지션 `C02_TYPE_RECOIL_CTRL` → Effects → `Text Push px`.
- 이벤트 시간: 주 컴포지션의 이름 있는 마커. 기기 프리컴프는 이 주 컴포지션의 마커 시간을 읽습니다.
- 기기 이동/회전: `TITAN_DEVICE_iPad_VIDEO_v004_R02`(485) → `DEVICE_iPad_VIEW` → Position / Y Rotation expression.
- `DEVICE_iPad10_MODEL`은 실제 ThreeDModelLayer입니다. 모델 정립 X=90°, 균일 scale=66%는 유지했습니다. 외부 GLB를 수정하지 않았습니다.
- 화면 영상: `SCREEN_iPad10_HADES_VIDEO_v004`(389). 원본 24fps 영상을 30fps 컴포지션에서 재생하며 속도·루프·소스 해석은 바꾸지 않았습니다.
- `revise-review02.mjs`는 실행 이력의 일부입니다. 이미 만들어진 현재 사본에 무조건 재실행하지 말고, 위 편집 지점에서 필요한 값만 수정하십시오.
