## 목적과 작업 경계

사용자가 선택한 토이 레이싱 파크 콘셉트를 기존24 기반 고정 레이아웃에 새 시안으로 제작했다. 최신 Together Pink를 복제하고 원본은 보존했다. 같은 페이지에서 비교할 수 있도록 오른쪽 x8580/y220에 배치했다.

24 기본형의 카드 크기·여백·간격·글꼴·문구·버튼 위치를 유지한다. 테마 색상·배경·헤더·캐릭터·배너3개·바로가기4개만 새 콘셉트로 바꾼다. 웹 구현·배포는 범위 밖이다. 기존 공용 컴포넌트를 변경하거나 인스턴스를 분리하지 않았다.

## 이미지 설계와 실제 결과

- 마스코트: 코발트 여우, 아이보리 얼굴·꼬리 끝, 노란 고글·레이싱 수트. 투명 배경 독립 파일.
- 배경: 미니어처 트랙이 가장자리와 하단을 감싸는 어두운 블루 파크.
- 헤더: 피트 레인 차고의 넓은 파노라마, 실제1920×88 중앙 크롭 검수.
- 페이백: 왼쪽 여우가 차고 작업대에서 지갑에 토큰을 넣는 장면.
- 회원 이벤트: 오른쪽 여우가 노을의 트랙 시상대에서 트로피를 드는 넓은 장면.
- 데일리: 선물 속 장난감 자동차를 여는 장면을 위에서 내려다보는 구도.
- 카지노: 카드가 보이는 클럽하우스 테이블.
- 슬롯: 커다란 슬롯 머신과 레버를 당기는 여우.
- 스포츠: 밝은 야외 잔디 경기장에서 오른쪽으로 슈팅.
- 인플레이: 밤의 실내 목재 코트에서 낮은 카메라로 잡은 레이업.

마스코트 원본의 실제 출력은 털 표현을 포함한3D 캐릭터다. 처음 프롬프트의 비닐 토이 재질보다 부드러운 재질로 나왔으며, 이후7개 장면에는 실제 생성된 캐릭터를 참조해 얼굴·의상·재질의 일관성을 맞췄다. 첫3개는 신규 생성, 이후7개는 마스코트와 배경을 서로 다른 역할로 첨부해 독립 생성했다. 콜라주를 분할한 결과가 아니다.

주관적 디자인 판단: 코발트 패널과 노란 버튼, 여우 레이서 및 트랙 소품으로 기존 핑크 테마와 구별된다. 세 배너의 장소·행동·카메라가 다르며, 축구와 농구도 서로 다른 공간과 시점으로 표현된다.

## 관찰과 수정

첫 전체 화면에서 하단 트랙의 노란 난간이 파트너 로고와 경쟁했고, 선택 메뉴의 흰 글자가 노란 바탕에서 약했다. qa/first.png 확인 후 배경 불투명도를55%에서25%, 헤더 이미지65%에서40%로 낮췄다. 선택 메뉴 글자는 짙은 남색, 사이드 분류 제목은 흰색으로 바꿨다. 섹션바 오른쪽 전체보기는 흰색으로 대비를 맞췄다. 노란 CTA의 글자·화살표도 짙은 남색이다.

qa/final.png와 실제 표시 크롭을 검수했다. 얼굴·지갑·선물·카드·레버·공·후프가 보이고, 한국어 제목·CTA 판독을 확인했다. 일부 장면의 귀 끝과 주변 소품은 이미지 경계에서 잘리지만 얼굴과 핵심 동작은 보존된다. 좌측 대형 마스코트는 기존과 같은 영역에서 일부가 프레임 밖으로 나가는 구성이다.
