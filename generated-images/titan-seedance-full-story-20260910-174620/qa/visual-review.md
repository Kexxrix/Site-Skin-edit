# 시각 검수: TITAN 16:9 이미지 8장

검수 대상은 생성 도구의 실제 출력 이미지이며, 시도 8장에서 수정 재생성 없이 8장을 에이전트 선택했다. 사용자 최종 승인·영상 채택과 구분한다.

| 이미지 | 확인한 내용 | 남은 제한 |
| --- | --- | --- |
| 01 | MEET / TITAN 정확, 검정 글자 가림 없음, 자연스러운 상하 스튜디오 | 은색 금속판의 장식적 연장부는 프레임 밖으로 이어짐 |
| 02 | CORE SYSTEMS / BUILT IN-HOUSE 정확, 두 사람의 시선·손·모니터 관계가 읽힘, 주요 얼굴·손 보존 | 작은 코드 내용은 실제 시스템 증거가 아님 |
| 03 | 같은 생성 인물의 사진 패널, 별도 기기 두 개, 정확한 문구, 16:9 안의 얼굴과 기기 | 사진 패널 위쪽은 프레임 경계에 가까움. 추가 2.34:1 크롭에서는 기기 하단 가장자리 잘림 가능 |
| 04 | 정확한 CORE 두 줄, CAT VILLAGE 태블릿과 스포츠북 폰 구분, 두 기기 전체 보임 | 작은 UI 글자는 원본과 다름 |
| 05 | 정확한 CONTROLS 두 줄, 신호가 오른쪽 아래 잠금 선택에 닿음, 다른 셀은 밝게 유지 | 정지 상태에서 인과를 암시하며 실제 잠금 동작은 영상에서 확인해야 함 |
| 06 | 정확한 PARTNER 두 줄, 하단 카드 이동 상태와 세 도착 묶음, 글자와 카드 분리 | 실제 카드 정렬 모션은 미검증 |
| 07 | 하이픈·앰퍼샌드 포함 정확한 PARTNER 두 줄, 정렬된 기록, 송금·새 금액 없음 | 실제 영상의 긴 문구 판독 시간은 미검증 |
| 08 | TITAN / SOLUTION 정확, MEET 제거, 01과 연결되는 TITAN·공간·금속판 | 정지 이미지의 시각적 앵커 일치이며 프레임 단위 루프 성공은 아님 |

전 이미지에서 명백한 검정 레터박스·필러박스·삽입된 초광폭 띠가 없고, 주요 문구·얼굴·기기는 16:9 프레임 안에서 확인된다. 제품의 작은 UI 문자열은 정확한 실제 화면 전달용 자료로 사용할 수 없다는 한계를 함께 기록한다.

검토자는 실제 01·02·03·04·05·07·08을 별도로 확인했고 재생성이 필요한 큰 실사용 결함을 발견하지 못했다고 보고했다. 06은 주 작업자가 생성 결과를 직접 검수했다. 기술 검증은 [verification.json](verification.json)과 별도다.
