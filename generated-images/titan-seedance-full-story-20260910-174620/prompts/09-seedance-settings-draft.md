# TITAN 전체 영상 — Seedance 설정·첨부 안내 초안

작성일: 2026-09-10  
상태: **DRAFT — 실제 이미지 8장의 최종 구성·품질을 확인하기 전 작성한 초안**

이 초안을 작성한 시점에는 완성·검수된 참조 8장 세트를 확인하지 않았다. 아래 첨부 번호는 예정된 이야기 순서이며, 실제 파일과 번호를 확인한 뒤 사용한다. 이 문서를 작성하면서 이미지 업로드·영상 생성·결제는 실행하지 않았다. 이미지 제작 완료, 영상 생성 성공, 사용자 채택을 뜻하지 않는다.

## 최신 화면 조건

기존 콘티의 21:9 설정보다 **이미지와 영상 모두 자연스러운 16:9**라는 최신 지시를 우선한다.

- 배경은 16:9 전체 프레임의 가장자리까지 자연스럽게 이어진다.
- 상하 블랙 레터박스, 좌우 필러박스, 테두리, 16:9 안에 넣은 초광폭 화면은 사용하지 않는다.
- 주요 문구·얼굴·태블릿·휴대폰은 해당 장면의 주 노출 구간에서 가능한 한 온전히 보인다.
- 중요한 대상은 대략 화면 높이의 15–85% 안쪽에 두고 좌우에도 여유를 둔다. 이 기준은 구성 여유를 뜻하며 위아래를 비우거나 검정으로 채우라는 의미가 아니다.
- 카메라 이동과 기기 회전은 작게 사용하고, 과도한 줌으로 글자·얼굴·기기가 잘리지 않게 한다.

## 연출·메시지 확인

- 02→03→04는 같은 `CORE SYSTEMS / BUILT IN-HOUSE` 메시지 안의 연속 상태다. 인물은 사진 패널 안에 남아 뒤로 빠지고, 독립된 기기가 전경으로 나온다. 사람 몸이 기기로 변형되는 전환은 쓰지 않는다.
- CAT VILLAGE는 태블릿의 카지노·슬롯 화면, COBALT는 별도의 휴대폰 스포츠북 화면으로 구분한다. 제공된 COBALT 화면을 새로 검증한 네이티브 모바일 UI라고 설명하지 않는다.
- 05의 급변 신호·잠금은 실제 제품 화면과 구분되는 설명용 제어 그래픽이다. 다른 항목은 계속 움직여 해당 선택만 차단됐음을 전달한다.
- 06→07은 같은 긴 두 줄을 유지한다. 파트너 수익금의 자동 계산·백오피스 기록을 표현하며, 송금·지급 완료·새 수익 수치를 추가하지 않는다.
- 장면마다 배경·재질·배치에 변화를 주되 02·03의 인물과 공간, 03·04의 기기, 06·07의 문구와 기록 구조, 01·08의 TITAN 배치는 연결한다.
- 이번 전체 영상에는 Grok의 개별 6초 클립용 초반 완전 가림 규칙이나 낱글자 낙하·자석 복귀 실험을 적용하지 않는다.
- 루프는 TITAN의 크기·위치뿐 아니라 배경 밝기·조명·금속판의 움직임까지 연결한다. 약 10.4–11.8초의 브랜드 판독 뒤, 마지막 약 0.2초부터 SOLUTION 퇴장과 다음 MEET 등장으로 이어지는 경계를 설계한다.

## 시간과 검증 상태

합계: `1.5 + 1.3 + 0.3 + 1.2 + 2.2 + 0.7 + 2.8 + 2.0 = 12.0초`.

- CORE 메시지 배정: `4.3 - 1.5 = 2.8초`.
- PARTNER 메시지 배정: `10.0 - 6.5 = 3.5초`. 등장 움직임이 포함되므로 전부를 정지 판독 시간으로 세지 않는다.
- 위 시간은 생성 목표다. 8개 이미지와 정확히 일치하는 프레임·시각 또는 원샷 성공을 보장하지 않는다.
- 실제 영상 생성 후 길이, 16:9·레터박스 부재, 주요 대상의 크롭, 정확한 문구, 두 제품의 구분, 제어·기록 의미, 실제 판독 구간, 루프 경계를 확인해야 한다.
- **현재 완료 범위는 프롬프트·설정 안내 초안 작성과 정적 검사까지다. 실제 영상은 업로드·생성·검수하지 않았다.**
