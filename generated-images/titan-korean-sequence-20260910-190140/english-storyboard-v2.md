# TITAN — English storyboard v2

상태: **영문 화면 문구와 타이포·모션 콘티 수정안. 이미지 생성 중지.**
최신 요청에 따라 화면에 표시할 문구를 영어로 바꾸고, 크기·굵기·정렬·움직임의 강약을 다시 설계합니다. 아래 영문 문구는 영상 속 추가 카피이며 설명은 한국어로 작성합니다.

- 시간: 직전에 승인된 원본 템포의 **20초 / 16비트** 유지. 16비트는 16번의 독립적인 전체 화면 교체를 뜻하지 않습니다.
- 출력 계획: **16:9, 무음, 풀블리드, 자연스러운 루프.**
- 흐름: 핵심 시스템 직접 개발 → CAT VILLAGE 태블릿 → 스포츠북 휴대폰 → 운영 제어 두 사례 → 파트너 수익금 계산·기록 → TITAN SOLUTION.
- 기기: **받침대 없는 기기 단독 부유**. 검은 패널·단상·테이블·쇼룸 바닥을 두지 않습니다.
- 이 문서는 생성 프롬프트 제출이나 생성 실행 기록이 아닙니다. 영문 이미지·영상은 아직 만들지 않았습니다.

## 수정 판단

현재 결과의 큰 글자와 두꺼운 획은 모델의 한글 능력만으로 설명할 수 없습니다. 기존 [01 프롬프트](./prompts/01-intro.txt)는 extremely bold, [07 프롬프트](./prompts/07-operations.txt)는 두 줄의 동일한 큰 크기·굵기와 enormous title, [10 프롬프트](./prompts/10-limit-change.txt)는 one huge라는 지시를 직접 포함합니다. 앞 장의 굵은 서체를 계속 참조한 것도 같은 인상을 반복시키는 요인이었습니다.

이번 수정은 **영문 교체와 함께 타이포 지시 자체를 변경**합니다. 영어가 한글보다 안정적인지, Seedance 2.5가 이번 구성을 정확히 재현할지는 이 결과로 검증되지 않았습니다. Dreamina의 Seedance 2.5 가이드도 움직임 중 상세 타이포를 다시 그릴 때 텍스트·로고가 불안정해질 수 있다고 설명하며, 안정된 참조·정면 배치·읽는 구간 확보를 권합니다. [공식 가이드](https://dreamina.capcut.com/seedance/seedance-2-5-prompt)

## 타이포와 화면 설계

하나의 현대적인 산세리프 계열을 기본으로 쓰되 보통 굵기, 중간 굵기, Bold, 제한된 Italic을 구분합니다. 서로 무관한 서체를 매 장면 바꾸지는 않습니다.

| 역할 | 크기·굵기 목표 | 적용 |
| --- | --- | --- |
| 문맥·설명 | 글자 높이 약 3.5–4.5% H, Regular 또는 Medium | Casino & slots, 운영 조건, In the back office |
| 일반 메시지·제품명 | 약 6–8% H, Medium 또는 Semibold | Core systems, CAT VILLAGE, Sportsbook, Partner earnings |
| 짧은 강조어 | 약 10–12% H, Bold 또는 Semibold | Built, Recorded |
| 최종 브랜드 | 두 줄 모두 약 12–13% H, 같은 Bold | TITAN / SOLUTION |

H는 전체 16:9 영상 높이입니다. 수치는 제작 시 판단할 상대적인 배치 목표이며 실제 생성 모델의 픽셀·폰트 굵기 제어를 보증하지 않습니다. 두꺼운 글자로 빈 곳을 채우기보다 기기·도형·빈 공간이 함께 화면의 비중을 나눕니다.

- 일반 문구는 **Title case 또는 문장형**을 사용합니다. 브랜드 CAT VILLAGE, TITAN, SOLUTION은 대문자를 유지합니다.
- 제품명과 설명의 글자 높이는 대략 2:1로 구분합니다. 설명까지 최대 굵기로 만들지 않습니다.
- 문맥 문구가 있는 장면은 작은 조건과 중간 크기 결과를 함께 읽게 구성합니다.
- 중앙, 왼쪽 정렬, 오른쪽 정렬, 단어 결합, 기록 누적을 이야기 역할에 맞게 배정합니다.
- 글자는 읽는 동안 정면·고정 상태를 유지합니다. 움직이는 도형과 고정된 문구가 동시에 존재하는 구간을 둡니다.
- 주요 글자와 기기는 중앙 약 70% 높이 안에 들어가도록 설계합니다. 기존 사이트의 약 2.34:1 영역에 적용할 때는 별도 화면 검수가 필요합니다.

## 읽기 시간과 연결 원칙

짧은 0.7–0.9초 비트에는 한 번의 단어 등장 또는 상태 변화만 배정합니다. 02–04, 08–09, 10–11, 12–13, 14–15의 문구 누적은 기존 문맥을 다시 읽는 부담을 줄입니다. 새로 나타나는 문구에는 별도의 판독 시간이 필요합니다. 특히 Bets auto-blocked와 Auto-calculated는 각각 1.2초 안에서 등장과 판독이 이루어져야 하므로 짧은 입장 뒤 정면으로 멈추는 구간을 우선합니다. 실제 영상에서 빠르게 느껴지면 해당 전환을 줄이고 읽는 구간을 늘려야 합니다.

- 02–04: Core systems → Built → In-house, 총 2.5초 안에서 한 문장으로 완성.
- 05·06: 제품당 1.9초. 입장 뒤 약 1초 정도 기기와 화면의 인상을 읽는 자세를 목표로 함.
- 08–09: Sudden odds shift라는 조건을 총 1.9초간 유지하면서 자동 차단 추가.
- 10–11: Limit changes라는 조건을 총 2.2초간 유지하면서 다음 라운드 적용 추가.
- 12–13: Partner earnings를 총 2.5초간 유지하면서 자동 계산 추가.
- 14–15: In the back office를 총 2.5초간 유지하면서 Recorded가 도착점이 됨.
- 16: 2.3초 중 브랜드가 읽히는 정지 구간을 확보하고 마지막 약 0.2–0.3초를 루프 연결에 사용.

위 시간은 편집 의도이며 실제 읽기·움직임·프레임 연결은 생성 영상에서 검증해야 합니다. 16장의 정지 참조를 넣는 것만으로 16개의 정확한 시간 키프레임이 고정되지는 않습니다. 각 장면의 카메라·동작·끝 상태를 구분해서 지시한다는 접근은 [Higgsfield의 장면별 프롬프트 가이드](https://higgsfield.ai/blog/seedance-2-5-prompting-guide)를 참고했습니다.

## 의미와 참조 범위

- Core systems. Built in-house.: 스포츠북·벤더 API·사용자/파트너/백오피스 등 핵심 시스템 직접 개발이라는 [원래 명세](../../titan_promotion/docs/briefs/hero-media-brief.md)의 범위입니다. Everything 또는 100%를 추가하지 않습니다.
- Sudden odds shift는 방향을 제한하지 않는 배당 급변입니다. Odds surge는 상승으로 의미를 좁힐 수 있어 사용하지 않습니다.
- Effective next round는 한도 변경의 적용 시점을 보존합니다.
- Auto-calculated → Recorded는 자동 계산과 백오피스 기록입니다. Paid, Transferred, Payout complete처럼 실제 지급이 끝났다는 문구를 추가하지 않습니다.
- CAT VILLAGE는 카지노·슬롯 태블릿, 스포츠북은 별도 휴대폰입니다. 스포츠북 선택 참조는 COBALT의 데스크톱 경기 목록 상세 크롭을 사용한 목업이며, 네이티브 모바일 UI로 검증된 화면이 아닙니다.
- 기존 한글 이미지의 참조 역할은 제품 정체성·색 흐름 확인에 한정합니다. 영문판의 크기·굵기·구도는 이 콘티가 새 기준입니다. 기존 큰 한글 블록을 영문 서체 기준으로 계승하지 않습니다.

## 현재 작업 상태

기존 한국어 결과는 [results](./results/)에 01–10번까지 저장돼 있습니다. 이들은 영어로 바뀐 이미지가 아니며 사용자 승인·영상 채택 상태도 아닙니다.

- 기존 한국어 생성 시도 14회, 도구 출력 14장.
- 현재 results 후보 10장.
- 2장은 내부 시각 검수 보정 전 결과로 qa/rejected에 보관.
- 2장은 받침대 제거 요청으로 교체된 결과로 qa/superseded에 보관.
- 11–16 한국어 이미지 생성은 중지. 영문 이미지 생성 0장, 영상 생성 0회.
- 영문 콘티의 시각 효과·모델 재현성·실제 루프는 미검증.

원본 이미지, 기존 프롬프트, 사이트 코드와 원본 제작 의뢰서는 변경하지 않습니다.
