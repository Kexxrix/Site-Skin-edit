# TITAN 한국어 시퀀스 — 장면·모션 설계 초안

> 최신 상태: 한국어 이미지는 01–10번에서 생성 중지되었습니다. 현재 수정안은 [English storyboard v2](./english-storyboard-v2.md)입니다. 아래 11–16 PNG는 생성되지 않은 이전 계획이며, 한국어 문구·타이포 지시를 새 생성에 적용하지 않습니다. 기존 한국어 제작 과정을 보존하기 위한 문서입니다.

이 문서는 승인된 **약 20초 / 16장면 순서**와 현재 [이미지용 프롬프트](E:/codexwork/Site-Skin-edit/generated-images/titan-korean-sequence-20260910-190140/prompts/), 최신 기기 단독 부유 및 슬라이더·저장 프레임 간소화 수정의 의도를 정리합니다. 이미지의 완성 상태를 확인했다는 기록이 아닙니다. 아래 PNG 링크는 각 프롬프트의 동일 basename에서 정한 **최종 결과 예정 경로**이며, 링크만으로 파일 존재·생성 완료·시각 합격·사용자 승인·사이트 채택을 판단하지 않습니다.

영상 생성, 실제 타이포 움직임, UI 보존, 읽기 시간, 전체 루프는 **미검증**입니다. 이미지 파일·최종 선택 상태는 생성 담당자가 별도로 확인해야 합니다. 이 문서와 영상 초안은 사이트 또는 영상 생성 설정을 변경하지 않습니다.

## 시간과 참조의 해석

- 바깥 구간은 승인된 0.00–20.00초 표를 그대로 사용합니다. 그 안의 입장·읽기·퇴장 분할은 이번 초안의 편집 목표입니다.
- 초 단위 지시는 목표 타이밍입니다. 생성 결과의 정확한 프레임·컷 위치를 보증하지 않습니다.
- 16개 참조는 장면별 카피·구도·색·재질·도형의 역할을 지정합니다. 16장을 첨부하는 것만으로 해당 시각의 강제 키프레임이 설정되는 것은 아닙니다.
- 이미지 순서와 플랫폼의 실제 참조 라벨을 확인한 뒤 영상 초안의 @Image1–@Image16 대응을 맞춥니다. 파일명이나 프롬프트 텍스트만 입력해도 로컬 이미지가 첨부된 것으로 취급하지 않습니다.
- 이 작업은 20초 전체 이야기의 무음 루프입니다. 장면마다 같은 정지 이미지를 확대하는 슬라이드쇼나, 모든 장면을 같은 퇴장·재등장 동작으로 처리하는 구성으로 만들지 않습니다.
- 출력은 **16:9 풀블리드**입니다. 배경이 영상의 위아래 끝까지 이어져야 하며 레터박스·검은 막대·액자 테두리는 넣지 않습니다.

기본 서체는 굵고 선명한 기하학적 한국어 고딕입니다. 한글은 완성된 음절 블록과 단어·줄 단위로 움직이며 자모·획·파편으로 분해하지 않습니다. 읽기 상태에서는 정면·평면의 깨끗한 글자를 유지합니다. 한글 돌출 입체 글자, 글자 액화·재질 변형, 읽기를 방해하는 모션 블러를 쓰지 않습니다. 입장과 퇴장에는 온전한 단어의 짧은 이동·작은 반동·화면 평면 안의 회전·그룹 마스크를 사용할 수 있습니다.

07·10은 얇은 선과 원형 손잡이의 간결한 부유 슬라이더로 통일합니다. 10의 간소화는 설계 의도이며 실제 결과를 검증했다는 뜻이 아닙니다. 14·15는 카드가 모이는 영역을 나타내는 **얇은 중공 라운드 저장 프레임 그래픽**과 기록 카드만 사용합니다. 실제 기기의 거치대·받침대나 부피가 큰 장식을 추가하지 않습니다.

## 입장·읽기·퇴장 목표

읽기 구간은 **글자의 안정된 판독 상태**를 뜻합니다. 주변 도형의 작고 통제된 움직임까지 모두 멈추는 것은 아닙니다. 도형과 기기는 이 구간에서 주요 카피를 가리지 않아야 합니다.

### 01 — 만나보세요

- **입장 0.00–0.20초:** 완성된 단어 전체가 짧게 올라오며 정착합니다. 구체는 가장자리에서 부드럽게 회전합니다.
- **읽기 0.20–1.15초, 0.95초 목표:** 글자는 정면에 고정하고 구체만 느리게 움직입니다.
- **퇴장·이어 붙이기 1.15–1.30초:** 단어 전체가 같은 방향으로 짧게 빠지고 차콜 배경으로 전환합니다.
- **다음 장면 연결:** 오렌지 구체의 위치·속도를 02의 작은 구체로 연결합니다.

### 02 — 핵심 시스템

- **입장 1.30–1.47초:** 핵심과 시스템을 온전한 단어 단위로 짧게 시차를 두어 붙입니다.
- **읽기 1.47–2.05초, 0.58초 목표:** 한 줄 전체를 읽히는 상태로 유지합니다.
- **퇴장·이어 붙이기 2.05–2.20초:** 완성된 문구를 한 그룹으로 짧게 이동시켜 교체합니다.
- **다음 장면 연결:** 중앙 글자 기준점과 구체·주변 경로를 03에 유지합니다.

### 03 — 직접

- **입장 2.20–2.40초:** 직접 전체를 화면 평면 안에서 작게 회전시켜 정면으로 정착합니다. 자모나 개별 획은 분리하지 않습니다.
- **읽기 2.40–2.95초, 0.55초 목표:** 두 음절을 선명한 정면 상태로 유지합니다.
- **퇴장·이어 붙이기 2.95–3.10초:** 단어 전체를 짧게 교체합니다.
- **다음 장면 연결:** 04는 같은 기준점·시각 크기를 사용하고 개발로만 바뀝니다.

### 04 — 개발

- **입장 3.10–3.26초:** 개발 전체가 작은 크기 반동 한 번으로 붙고 정착합니다.
- **읽기 3.26–3.68초, 0.42초 목표:** 현재 단어 개발만 보여 직접 다음 개발이라는 순서를 완성합니다.
- **퇴장·이어 붙이기 3.68–3.80초:** 글자를 정리하고 배경을 아이보리로 전환합니다.
- **다음 장면 연결:** 오렌지 구체를 05 제품 구도의 주변 악센트로 이어 갑니다. 태블릿으로 글자를 변형하지 않습니다.

### 05 — CAT VILLAGE / 카지노·슬롯 플랫폼

- **입장 3.80–4.02초:** 왼쪽 제목과 단독 부유 태블릿이 짧은 이동으로 들어옵니다. 태블릿은 정면에 가까운 약한 3/4 각도에 정착하며 기기를 지지하는 별도 조형물은 두지 않습니다.
- **읽기 4.02–5.47초, 1.45초 목표:** 태블릿 화면을 고정된 텍스처로 유지하고 전체 기기를 읽히게 합니다. 기기 자체에만 매우 작은 움직임을 허용합니다.
- **퇴장·이어 붙이기 5.47–5.70초:** 태블릿을 하나의 완전한 물체로 옆으로 빼고 제목을 교체합니다.
- **다음 장면 연결:** 같은 아이보리 모션그래픽 공간을 유지하며 06의 완전한 단독 부유 휴대폰이 들어옵니다. 태블릿을 휴대폰으로 녹이거나 UI를 변형하지 않습니다.

### 06 — 스포츠북

- **입장 5.70–5.92초:** 제목과 단독 부유하는 전체 휴대폰이 들어와 정면에 가까운 약한 3/4 각도로 정착합니다. 기기를 지지하는 별도 조형물은 두지 않습니다.
- **읽기 5.92–7.37초, 1.45초 목표:** 기존 COBALT 크롭의 경기·배당 행을 화면 텍스처로 유지합니다. 새 모바일 탐색 UI나 가짜 터치·스크롤 반응을 만들지 않습니다.
- **퇴장·이어 붙이기 7.37–7.60초:** 휴대폰과 제목을 그룹별로 짧게 정리하며 차콜 장면으로 전환합니다.
- **다음 장면 연결:** 제품 소개 다음에 운영 제어를 둡니다. 실제 스포츠북 UI의 값이 바뀌었다는 시연은 만들지 않습니다.

### 07 — 운영까지 / 세밀하게

- **입장 7.60–7.78초:** 두 줄 전체가 짧은 시차로 들어오며 오렌지 원형 손잡이가 얇은 흰색 선을 따라 한 번 부드럽게 이동합니다.
