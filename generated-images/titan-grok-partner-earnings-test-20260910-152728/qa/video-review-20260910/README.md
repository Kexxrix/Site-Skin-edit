## 이후 추가된 필수 규칙과의 관계

사용자가 정한 [타이탄용 Grok 필수 제작 규칙](../../../../.agents/skills/theme-image-pipeline/references/titan-solution-brief.md)은 **초반 완전 퇴장 또는 전면 가림 → 후반 재등장 → 판독**이다. 이 규칙은 위 비교 프롬프트를 작성한 뒤 추가됐다. 따라서 이번 결과를 해당 기법을 정확히 지시한 시험의 실패라고 소급 판정하지 않는다.

A의 본문 영역 전체 145프레임에서는 중앙 제목이 완전히 사라지는 프레임을 찾지 못했다. B의 확인 샘플에서도 없었다. 두 결과 모두 새 규칙을 만족하는 편집 시작점을 확보한 사례로 채택하지 않는다.

## 편집 활용 후보

- **약 3~5.75초:** 대체로 읽히는 제목과 도형 움직임을 함께 쓸 수 있는 후보. 중간의 RECORDED 가림을 수용해야 하며, 깨끗한 등장 모션이나 연속 무가림 구간으로 설명하지 않는다.
- **A 약 4.8~5.75초, B 약 4.75~5.75초:** 가림이 상대적으로 적고 문구가 읽히는 약 1초의 짧은 후보. 마지막 6초 프레임에서는 링이 최종 D 일부를 가리므로 끝까지 무조건 쓰지 않는다.
- 실제 컷·속도 조절·12초 편집은 하지 않았다. 짧은 후보를 늘렸을 때의 움직임과 읽을 시간도 아직 검증하지 않았다. 기존 원본이나 후보를 최종 채택한 상태가 아니다.
