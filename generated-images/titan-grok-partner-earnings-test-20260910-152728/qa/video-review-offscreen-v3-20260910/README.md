2. **요소 묶음별 분리:** 타이틀의 경로를 고정한 상태에서 비텍스트 도형 묶음만 다른 경계에서 들어오게 해 독립 제어 여부를 확인한다.
3. **개별 요소와 이미지:** 앞의 조건을 확인한 뒤 리본·링·패널별 진입 경계, 이어 제품·인물 이미지의 진입 경계와 각도를 시험한다. 이 타이포 영상에는 제품·인물 이미지 레이어가 없어 이미지 방향 제어를 검증했다고 기록할 수 없다.

각 시험에서는 화면 기준 왼쪽/오른쪽/위/아래, 들어오는 경계, 움직이는 방향, 도착 위치를 구분한다. 한 번에 여러 요소의 방향·속도·회전·디자인을 함께 바꾸지 않는다. 반복 결과에서 방향 재현 여부와 글자·이미지 형태 보존을 따로 평가한다. 이번 사용자 승인으로 모든 방향을 정밀 제어할 수 있다고 단정하지 않는다.
