## 남은 차이

- 시작 화면 유지 조건을 뒤늦게 확인했다. 0초 프레임에는 원래 이미지가 있으나 0.25초에 이미 왼쪽부터 가림이 진행된다. V2 프롬프트 자체가 0초부터 검정 가림을 시작하도록 썼으며, 완성된 첫 화면을 잠깐 보여 준 뒤 전환하라는 사용자 의도를 충분히 반영하지 못했다. 앞선 검수도 이 유지 구간을 놓쳤다. 이후 사용자는 암전 대신 실제 요소의 화면 밖 퇴장·복귀를 요청했다. 시작 직후 암전과 글자 모션 불안정의 인과관계는 확인되지 않았다.
- 재등장이 요청한 단일 타이틀 블록의 짧은 상승 이동으로 구현되지 않았다. 특히 [3.5초](frames/sample-015.png)와 [3.75초](frames/sample-016.png)의 하단 중복은 분명하다.

- [6초](frames/sample-025.png)에는 리본도 문구 왼쪽 뒤까지 확장된다. 주변 그래픽과 글자 영역을 완전히 분리한 결과는 아니다.
- 완전 검정이 오래 유지되고 문구 정착도 늦어졌다. 따라서 후반 약 4초를 모두 완성된 판독 구간으로 계산하지 않는다.
