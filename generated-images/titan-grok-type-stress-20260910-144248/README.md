# TITAN SOLUTION — C 고강도 모션 시험

2026-09-10. 현재 상태: 사용자가 제공한 C 영상 2개 검토 완료. [실제 결과·편집 후보·다음 개선 방향](qa/video-review-20260910/README.md)에 텍스트와 배경의 강한 움직임 및 후반 문구 회복을 기록했다. 사용자는 수정과 컷 편집 후 활용 가능하다고 평가했다. 아래는 최초 C 시험 준비 시점의 계획이며, 최종 영상 선택·편집·사이트 적용은 아직 수행하지 않았다.

## 현재 요청과 변경점

사용자는 TITAN SOLUTION으로 문구를 늘리고 텍스트와 배경 요소를 더 빠르고 과격하게 움직여 표현 범위를 시험하도록 요청했다. 기존 영문 표기를 이어받아 TITAN과 SOLUTION을 두 줄로 배치했다. 글자는 5+8=13개다. 두 줄 배치는 서로 반대 방향의 이동을 구분하기 위한 이번 시험의 설계 선택이다.

[A 결과 검토](../titan-grok-type-test-20260910-130048/qa/video-review-20260910/README.md)에서 관찰한 화면 밖 이동·배경 움직임은 이번 C에서는 일부 의도적으로 허용한다. A의 고정 조건을 그대로 적용해 C의 의도된 가림·블러·퇴장을 실패로 분류하지 않는다. 읽힐 때의 철자와 마지막 재조립은 계속 확인한다.

| 항목 | 이전 A | 이번 C 요청 |
| --- | --- | --- |
| 문구 | TITAN 한 단어 | TITAN / SOLUTION 두 줄 |
| 주된 동작 | 단어 전체가 한 글자 폭만 좌우 이동 | 두 단어의 반대 방향 급가속·퇴장·복귀 후 글자 분리·재조립 |
| 배경 | 고정 | 리본의 휘두르기·가로지르기, 링의 회전·궤도 이동, 유리 패널의 전진·회전 |
| 움직임 강도 | 짧은 이동, 약 3초 뒤 정지 | 약 5초까지 강한 이동·급격한 방향 전환, 마지막 약 1초 정착 |
| 허용 표현 | 문구 전체 노출·형태·간격 고정 | 일시적 가림·중첩·화면 이탈·모션 블러·글자 분리 |
| 유지할 조건 | 정확한 글자·간격 | 읽을 수 있는 구간과 마지막 정착 시 정확한 TITAN / SOLUTION 회복 |

문구 길이·텍스트 동작·배경 동작을 함께 강화하는 한계 탐색이다. 단일 변수 비교가 아니므로 결과가 나빠져도 한 요인만 원인이라고 단정하지 않는다. 필요하면 다음 시험에서 글자 분리, 배경 강도, 속도 중 하나를 줄여 원인을 분리한다. 이번 기록 자체는 C의 성공을 입증하지 않는다.

## 입력과 사용 방법

[새 시작 이미지](results/01-titan-solution-start.png)를 Grok에 첨부하고 [C 영상 프롬프트](prompts/02-grok-c-aggressive.txt)를 사용한다. 영상 길이는 이번 사용자 환경에 맞춘 6초이며, 입력의 넓은 비율을 유지한다. 출력 길이·비율·타이밍은 MP4를 받은 뒤 확인한다. 실제 초 단위 실행을 보장하는 키프레임 지시가 아니라 자연어 목표다.

시작 이미지에 제목이 이미 보이므로 즉시 기존 문구를 움직이도록 했다. 빈 화면에서 생성되는 제목으로 지시하지 않았다. 카메라는 중앙을 유지하고, 텍스트와 도형 자체의 동작으로 강도를 높이도록 설계했다. 새 영상이나 최종 컷 편집·사이트 적용은 수행하지 않았다.

## 시작 이미지의 확인 결과

- [기존 입력](../titan-grok-type-test-20260910-130048/results/01-titan-type-start.png)을 실제로 보고 참조 첨부해 Codex 내장 이미지 생성으로 수정했다.
- [실제 이미지 프롬프트](prompts/01-start-image.txt): 중앙 문구를 두 줄로 변경하고 배경 리본·링·패널과 표현 스타일을 이어받음.
- 육안 확인: TITAN 5글자와 SOLUTION 8글자 정확, 두 줄 분리, 문구 전체 노출, 배경 요소가 문구를 가리지 않음.
- PNG / RGB / 1915×821px / 1,231,213 bytes. Pillow 완전 디코드 성공.
- 실제 비율은 1915÷821≈2.33252로 약 21:9. 참조는 1916×821px였으며 너비가 1px 달라 정확한 픽셀 크기 보존은 아니다. 리사이즈·크롭으로 수정하지 않았다.
- 이동 전후 SHA-256: 8B4708CEB0F6A480AA00E71A0D40A144489BFFB7078285C403D5B5332DCDFBCE, 일치.
- 생성 시도 1 / 성공 1 / 실패 0 / 건너뜀 0 / 정지 입력 검수 통과 1 / 사용자 승인 0 / 거절 0.
- 최종 아트디렉션이나 Grok 모션 검증의 통과가 아니라 이번 실험용 입력 선별이다. 원래 결과와 영상은 보존했다.

## C 영상이 오면 확인할 내용

1. 텍스트와 배경이 둘 다 빠르고 크게 움직이는가. 화면 전체 확대나 빛 변화만으로 움직임을 대신하지 않았는가.
2. 잠시 가리거나 화면 밖으로 나간 뒤 문구가 돌아오는가.
3. 글자 분리·중첩 중의 의도된 비가독 구간과, 정렬된 상태에서 발생하는 오탈자·중복·누락을 구분한다.
4. 마지막 약 1초에 TITAN / SOLUTION이 두 줄로 완전히 회복되어 읽히는가. 정확한 초 경계보다 실제 회복 여부와 사용할 구간을 먼저 기록한다.
5. 빠른 동작과 읽히는 순간을 포함하는 연속 2~3초 편집 후보가 있는가. 전체 6초의 완성도와 부분 활용 가능성을 별도로 기록한다.
6. 원본 재생/프레임 검사 범위, 실제 모델·옵션이 확인되는 범위, MP4 메타데이터·해시·추천 in/out 구간을 남긴다. 글자 오탈자를 '과격한 효과'라는 이유로 합격 처리하지 않는다.
