# 배경 이미지 검토

- 역할: 기존 고정 레이아웃에 사용할 배경 소재 2장.
- 사용한 참조: 직전 검수를 통과한 각 시안의 전체 화면. 팔레트·배경 노출 위치 참고용이며, UI 재생성 요청이 아니다.
- 한지: 종이 섬유와 먹 번짐이 실제 보이는 여백·헤더에 나타남. 왼쪽 대나무는 사이드바 아래에서 드러나고 중앙 콘텐츠를 가리지 않음.
- 바이오: 젤 막의 광택·굴절이 좌우 여백과 상단에 드러남. 주요 텍스트가 놓인 패널은 원래 불투명도를 유지해 가독성을 확보함.
- 두 생성물 모두 배경만 포함하며 문자·인물·UI가 없음.
- 목적 검수: 두 배경이 각 테마의 재질을 전달하고, 실제 화면에서 노출되는 영역에 효과가 나타나는 것을 확인함.
- 수정: 재생성/추가 크롭/리사이즈/압축 없음.
- 구조 검수: 배경 외 콘텐츠 해시 2/2 일치. 보호 노드 54/54 일치.
- 범위: 실제 1920px Figma 화면 확인. 2x/4K 출력과 실제 웹 성능·반응형은 미검수.
- 상태: generated=true, qa_pass=true, selected_by_agent=true, applied_to_figma=true, accepted_by_user=false, site_adopted=false.
