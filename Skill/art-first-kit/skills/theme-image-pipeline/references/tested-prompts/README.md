# 실제 제출 프롬프트 보관

이 파일들은 역사적 원문이며 실패 조건도 포함한다. 번호대로 무조건 실행하지 않는다. 신규 작업은 [현재 변수형 템플릿](../person-prompts.md)과 [인물 공정](../character-workflow.md)을 따른다.

- 01: 정면 얼굴·상체 참조. 체형 정보를 읽을 수 있도록 만든 입력.
- 02: 머리 없는 의상 참조. 샘플에 없던 하의와 신발의 보완 디자인을 포함한 사례.
- 03~07: 초기 전신·몸통/시선·스쿼트·무릎 앉기. 인물 비례와 자세에 usable 사례가 있었으나 상체가 슬림해졌고 좌우·고개·시선·바닥 위치 오차가 있었다. 이 프롬프트의 참조 역할 배정은 현행 기준으로 그대로 재사용하지 않는다.
- 08~09: 전신·무릎 앉기 상체 체형 보정. 얼굴·상체 참조의 체형 권한과 의상 디자인 권한을 분리한 뒤 사용자가 사용 가능으로 확인한 경로.
- 10: 몸통 7:30, 얼굴·눈 6시의 웹 비교 샘플. 원하는 몸통 방향이 나왔지만 정확한 회전각 보장은 아니다.
- 11: 10과 같은 문구·참조 순서로 Codex 내장 도구에서 만든 한 장 비교. 이번 샘플의 육안 품질이 유사했고 사용자가 향후 내장 생성으로 전환하기로 결정했다.

01~09는 2026-09-08 전신/볼륨 실험 원문, 10~11은 2026-09-09 시계 좌표/내장 비교 원문이다. 파일 내용은 유지했고 [index.json](index.json)에 해시를 기록했다. 재배포 패키지에는 개인 인물·의상 사진을 포함하지 않는다. 같은 원문이라도 새 참조와 실행 문맥에서 결과는 달라질 수 있다.
