## 로컬 실행

이 폴더에서 다음 명령을 실행한 뒤 브라우저에서 [로컬 사이트](http://127.0.0.1:8000/#home)를 엽니다.

```sh
python -m http.server 8000 --bind 127.0.0.1 --directory site
```
