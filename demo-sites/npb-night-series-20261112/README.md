# NPB NIGHT SERIES

[사이트 열기](https://npb-night-series.kexxadrix.chatgpt.site/#home)

일본 프로야구 12개 구단 스킨을 지원하는 1920×1080 데스크톱 데모입니다. 하단 메뉴에서 추천게임, 라이브카지노, 슬롯게임, 공지를 전환할 수 있습니다.

## 로컬 실행

이 폴더에서 다음 명령을 실행한 뒤 [로컬 사이트](http://127.0.0.1:8000/#home)를 엽니다.

```sh
python -m http.server 8000 --bind 127.0.0.1 --directory site
```
