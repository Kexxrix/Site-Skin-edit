## 사용자 확정 수치와 구현 판단 구분

- 확정: 오버레이 #000000/40%, 아이콘 20px, 종목명 14px, 경기 수 12px, 고정 1920 레이아웃.
- 파일에서 실측: 영상 1920×62 / 14.536초 / 357,956 bytes, CASINO 200×116, SLOT 97×116.
- 정확한 사용자 지정이 없는 값: 종목바 상단 여백, 버튼 좌우 패딩/내부 gap, 로고 판 불투명도/사선 길이.
- CSS 예시의 8px/8px/4px는 구현 시작값이다. 이미지 배율로 수치를 단정하지 말고 현재 결과와 참조의 관계를 맞춘다.
- 헤더 범위는 제공 영상 높이 및 바로 앞 합의에 따라 62px 메뉴 행이다. 공지사항 줄에는 영상을 확장하지 않는다.
- 배너 40%는 오른쪽 배너에만 적용한다. 좌측 사진이나 헤더의 일괄 밝기 조정은 요청되지 않았다.

## 유지 범위

WOG는 더 이상 디자인 참조로 사용하지 않는다. 기존 중앙 구조, 내부 카드, 1px 마켓 강조선, 텍스트 정렬, 모드별 스크롤, 경기 전 카드와 배당/선택 데이터는 그대로 유지한다. R10에 대한 사전 전체 QA를 재개하지 않는다. ALDEBARAN 승인 후 다른 사이트에 적용하는 순서는 유지하며 이번에 이식하지 않는다.
