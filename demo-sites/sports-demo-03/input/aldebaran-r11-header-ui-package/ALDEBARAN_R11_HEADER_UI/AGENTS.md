# ALDEBARAN R11 — 현지 운영 문서에 병합할 적용 지침

- 대상은 sports-demo-03의 ALDEBARAN이다. R10 완료 후 사용자 직접 확인 상태와 이후 직접 수정사항을 기준으로 한다. 과거 commit으로 reset하지 않는다.
- 이 패키지는 현지 네 운영 문서의 추가/수정 사항이다. 기존 결정과 이력은 보존한다. 이전 지시와 충돌하면 DECISIONS.md의 R11 대체 규칙을 적용한다.
- 지정한 네 UI 변경만 수행한다. 최신 DOM/CSS와 현재 배포 절차를 확인해 최소 범위로 적용한다. 파일명이 같더라도 최신 이미지의 SHA-256으로 새 파일을 구분한다.
- 종목 버튼 폭 고정/최소폭/균등 분배/세 자리 배지 폭 예약 규칙은 제거한다. 버튼 높이, 글자 크기, 현재 폰트/굵기/선택 표현은 유지한다.
- 상단 간격 수정은 중앙 종목바의 불필요한 여백에 한정한다. header/notice/좌우 레일 높이, 중앙의 두 스크롤 구조를 바꾸지 않는다. transform이나 음수 margin으로 겹침을 만드는 방식 대신 해당 padding/margin을 수정한다.
- 우측 배너 오버레이는 배경 이미지 위, 텍스트 아래에 한 번만 그린다. opacity/filter를 배너 전체에 적용하지 않는다. 이 40% 값은 헤더 영상이나 좌측 사진 버튼에 적용하지 않는다.
- 헤더 영상은 하나의 장식 레이어다. 로고 영역에 별도 영상을 복제하지 않는다. 메뉴 링크와 로고를 영상에 합성하거나 클릭 위에 영상이 덮이게 하지 않는다.
- 사용자 원본 PNG/WebM은 그대로 복사한다. 이번 작업에서 재생성·재인코딩·색보정·글자 덧씌우기는 하지 않는다. 기존 이미지와 로고를 확대 스크린샷에서 잘라 자산으로 만들지 않는다.
- 현재 설치된 도구와 프로젝트의 필수 규칙만 사용한다. 새 플러그인/라이브러리, 별도 QA/Jev, 광범위 리팩터링, WOG/Figma 재접속, MERCURY/SIRIUS 수정은 하지 않는다.

## 확인 및 완료 범위

- 기존 build 1회. build에 포함되지 않은 프로젝트 필수 타입 검사가 있을 때만 기존 방식으로 추가한다. 실패 시 관련 원인만 수정하고 재실행한다.
- 1920 고정 화면, 브라우저 100%에서 변경 부위를 짧게 확인한다. 기존 슬롯/카지노 버튼의 클릭 의미, 종목 필터와 국내/해외 모드 스크롤을 보존했는지 대표 동작만 확인한다.
- 경기 수 0/7/32/128은 레이아웃 확인용이다. 임시 로컬 fixture나 미리보기에서만 비교하고 운영 데이터에 이 숫자를 쓰지 않는다. 새로운 테스트 스위트를 작성하지 않는다.
- 영상 재생·반복·무음·메뉴 클릭 확인은 정지 캡처와 별도로 한다. 오디오 트랙이 있으므로 muted 설정을 빠뜨리지 않는다. 기존 reduced-motion 대응이 있으면 존중한다.
- 기존 배포 절차로 동일 사이트에 반영한다. 공개 GitHub 백업 동기화와 다른 프로젝트 변경은 별도 지시가 있을 때 한다.
- 완료 보고에 실제 수정/검증 범위와 미확인 사항을 구분한다. 기존 R10을 전부 재검수하거나 사용자 확인 전에 다음 작업을 시작하지 않는다.
