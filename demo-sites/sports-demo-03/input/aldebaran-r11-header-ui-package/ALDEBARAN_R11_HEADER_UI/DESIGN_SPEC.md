# ALDEBARAN R11 — 구현 사양

현재 승인된 무광 차콜/주황/흰색 컨셉과 레이아웃을 사용한다. 고정 수치로 확정된 값과 아래의 구현 시작값을 구분한다. 스크린샷은 확대율이 다르므로 그림 픽셀을 CSS 치수로 환산하지 않는다.

## R11-01 — 우측 안내 배너 배경만 어둡게

| 순서 | 대상 제목 | 유지할 배경 |
| --- | --- | --- |
| 1 | 텔레그램 고객센터 | img_banner_01.png |
| 2 | 텔레그램 공식채널 | img_banner_03.png |
| 3 | ALDEBARAN 이용안내 | img_banner_04.png |
| 4 | 실시간 중계 안내 | img_banner_05.png |
| 5 | 스포츠 라인업 | img_banner_06.png |
| 6 | 미성년자 이용불가 | img_banner_07.png |

- 확정값: #000000, 불투명도 40%. CSS로 rgba(0, 0, 0, 0.4)를 이미지 바로 위에 한 겹 적용한다. opacity 0.4인 전체 버튼을 만드는 의미가 아니다.
- 아래에서 위로 배경 이미지 → 검정 오버레이 → 기존 제목/설명 순서다. 제목/설명에는 오버레이가 덮이지 않으며 색과 밝기를 유지한다.
- 다중 background의 첫 번째 linear-gradient 또는 이미지 전용 가상 요소 중 현재 구조에 맞는 하나만 사용한다. 이미 어둡게 하는 레이어가 있다면 중복시키지 말고 유효한 오버레이가 40%가 되도록 정리한다.
- 기존 외곽 약 306×61px, radius 4px, 위치/간격/클릭 영역, 글자 크기와 중앙 정렬을 유지한다. 현재 높이가 기존 비율에 따라 소수점이면 반올림해 레일을 재배치하지 않는다.
- 원본 PNG는 수정하지 않는다. 패키지에는 이미 적용된 배너 6개를 다시 넣지 않았다. 기존 파일을 그대로 사용한다.
- references/banner-darkening.png는 배경 밝기 참고다. 스크린샷에 글자가 없다고 실제 제목/설명을 삭제하지 않는다.
- 좌측 CASINO/SLOT 이미지, 헤더 영상, 다른 패널은 이 40% 오버레이의 대상이 아니다.

## R11-02 — 종목 선택 바 위치와 내용에 맞는 폭

### 상단 정렬

- references/sports-bar-alignment.png의 빨간 수평 기준선 쪽으로 종목 버튼 행의 상단 간격을 줄인다. 현재 버튼 위에 생긴 과한 공백을 수정하는 요청이다.
- 현지 중앙 종목바/부모의 padding-top, margin-top, align-items로 생긴 여백을 확인한 뒤 최소한의 규칙만 수정한다. 중앙 종목 버튼 행이 참조의 상단 기준에 놓이게 한다.
- 이미지에는 정확한 CSS 여백 수치가 없으므로 임의 수치를 사용자 확정값으로 기록하지 않는다. 현재 header/notice/좌우 레일의 좌표를 이동시켜 맞추지 않는다.
- 버튼 자체 높이는 유지한다. 종목바의 과한 상단 여백을 줄여 경기 목록이 자연스럽게 이어지게 하되, 아래 카드 프레임과 내부 간격, 스크롤 주체를 바꾸지 않는다.

### 버튼 및 경기 수 배지

references/sports-tab-compact.png의 오른쪽이 목표다. 왼쪽의 넓은 빈 공간과 숫자 한 자리에 남는 과한 배지 폭을 줄인다.

| 요소 | 적용 규칙 |
| --- | --- |
| 아이콘 | 20×20 CSS px, 기존 아이콘 자산 유지 |
| 종목명 | 14 CSS px, 현재 폰트·굵기 유지 |
| 경기 수 | 12 CSS px, 현재 폰트·굵기 유지 |
| 버튼 높이 | 현지 현재 값 유지, 새 높이로 재설계하지 않음 |
| 버튼 폭 | 내용 너비 + 일정한 내부 간격 + 같은 좌우 패딩 |
| 버튼 좌우 패딩 | 동일하고 현재보다 작게, 종목/선택 상태와 무관하게 같은 값 |
| 배지 폭 | 숫자 실제 폭 + 작은 동일 좌우 패딩, 한 자리/두 자리/세 자리마다 자연스럽게 변화 |
| 배지 높이 | 현재 값 유지, 숫자 세로 중앙 정렬 |
| 종목별 폭 | 전체·축구·아이스하키 등 내용에 따라 달라짐 |

- 기존 종목별 고정 width/min-width, flex: 1, space-between으로 생긴 불균형, 수량 min-width: 3ch 등 불필요한 예약 폭을 제거한다. 아이콘/이름/수량을 실제 내용 크기의 한 줄 inline-flex로 배치한다.
- 한 자리 수량 0/7에 세 자리 공간을 예약하지 않는다. 128처럼 세 자리로 늘어나면 배지와 버튼 전체가 함께 늘어난다. 줄바꿈/말줄임/숫자 잘림을 만들지 않는다.
- 외곽 폭 유지보다 이번 content-fit 지시가 우선이다. 모든 버튼을 아이스하키 최대 폭으로 통일하지 않는다.
- 시작값 제안: 버튼 좌우 padding 8px, 내부 gap 8px, 배지 좌우 padding 4px. 이 세 값은 사용자 지정이 아닌 구현 제안이다. 현재 값이 이미 더 작으면 늘리지 말고, 참조의 균형과 기존 높이에 맞춰 최소 조정 후 최종값을 기록한다.
- 버튼 간 기존 간격, 선택 테두리·색, ALL 표현, 글자 크기, 세로 중앙 정렬은 유지한다. 선택 테두리 때문에 좌우 패딩이 달라지지 않게 box-sizing과 border 공간을 일관되게 유지한다.
- 런타임 DOM 측정/ResizeObserver나 글자 수별 폭 계산은 필요하지 않다. 현재 flex 레이아웃과 콘텐츠 기반 크기로 구현한다.
- 국내형·해외형에 공통 적용한다. 좌측 레일 종목 목록이나 다른 버튼까지 전역 축소하지 않는다. 실제 경기 수/필터/데이터를 변경하지 않는다.

## R11-03 — 헤더 영상과 로고

### 영상 적용 범위

- 원본 assets/header/bg_header_0.webm: 1920×62px, 14.536초, VP9, Opus 오디오 포함. 원본 전체를 메뉴 헤더 한 줄의 배경으로 사용한다.
- 1920 고정 캔버스의 현재 62px 메뉴 행에 맞춘다. 영상 때문에 헤더를 98px나 더 큰 높이로 늘리지 않는다. 아래 공지사항 줄은 기존 그대로다.
- 원본 비율은 현재 메뉴 행과 같으므로 1:1 표시가 기준이다. 임의 확대/크롭, repeat 타일, 좌우 늘이기 왜곡을 하지 않는다.
- 하나의 video를 메뉴 헤더 안에 absolute/inset:0으로 놓는다. 일반 문서 흐름의 높이와 기존 메뉴 grid는 유지한다. 로고 영역에도 이 동일한 영상이 이어져 보여야 한다.
- autoplay + muted + loop + playsinline을 적용한다. HTML 예시:

```html
<video class="header-background" autoplay muted loop playsinline
       preload="metadata" aria-hidden="true" tabindex="-1">
  <source src="/media/aldebaran/bg_header_0.webm" type="video/webm">
</video>
```

React에서는 autoPlay/playsInline 등 해당 JSX 속성으로 매핑한다. controls는 표시하지 않는다. pointer-events: none으로 메뉴 클릭/키보드 탐색을 방해하지 않는다. 오디오 트랙이 있어도 소리가 나면 안 된다.

- 기존 헤더 배경색을 로딩/재생 실패 시 바탕으로 남긴다. 영상 실패로 로고·메뉴가 사라지거나 레이아웃이 변하지 않게 한다. 기존 reduced-motion 처리가 있다면 정적인 바탕 표시로 이어간다.
- 새 영상 엔진/라이브러리·재인코딩·자동 속도 변경·추가 이펙트를 넣지 않는다. 자동 재생 실패 시 무한 재시도나 동적 메뉴 이동을 추가하지 않는다.

### 로고 영역 — 참조 이미지 위쪽이 목표

- references/header-logo-treatment.png 위쪽이 목표, 아래쪽은 기존 불투명 회색판 비교다. 로고 크기를 확대 스크린샷의 픽셀 수로 복제하지 않는다.
- 현재 선명한 원본 레터링 로고를 영상 위의 독립 이미지로 유지한다. 로고를 영상에 구워 넣거나 저해상도 참조에서 잘라 쓰지 않는다. 엠블럼은 추가하지 않는다.
- 불투명 회색 로고 판을 영상이 비치는 어두운 반투명 사선판으로 바꾼다. 기존 오른쪽 사선 방향을 유지한다. 불투명도 정확한 수치는 지정되지 않았으므로 참조처럼 배경 움직임이 보이는 정도로 조정한다.
- 로고 오른쪽 N과 사선이 겹치지 않도록 사선판 오른쪽 범위에 여유를 확보한다. 판의 사선은 장식 레이어에만 clip-path를 적용하고 로고 본체나 메뉴 컨테이너를 함께 자르지 않는다.
- 현재 얇은 주황색 하단선은 유지하되 판의 왼쪽 끝에서 사선판의 아래쪽 꼭짓점까지 이어지게 한다. 사선 아래로 선이 계속 뻗거나 N을 침범하지 않게 한다.
- 로고는 기존 위치/표시 크기를 기준으로 정렬한다. 필요한 변경은 판의 범위·투명도·선 끝점이며, 메뉴 열 전체를 밀거나 헤더 높이를 바꾸지 않는다.
- 레이어 순서는 영상 → 반투명 사선판/하단선 → 로고·메뉴다. 사선판을 두 겹으로 중복하거나 헤더 전체에 배너용 40% 오버레이를 넣지 않는다.
- 국내형/해외형 선택의 주황 텍스트·밑줄, 다른 메뉴의 흰색·동작 없음, hover 미적용 상태는 유지한다. 새로운 active 이미지나 메뉴 애니메이션은 추가하지 않는다.

## R11-04 — 좌측 이미지 최신본 교체

| 대상 | 이번 업로드 원래 이름 | ZIP 안 파일 | 원본 크기 |
| --- | --- | --- | --- |
| CASINO | btn_image_casino(1).png | assets/left-rail/btn_image_casino.png | 200×116px |
| SLOT | btn_image_slot(1).png | assets/left-rail/btn_image_slot.png | 97×116px |

- 위 최신본으로 R10 사진을 통째로 교체한다. 최신 글자는 이전 입체 금속 글자보다 간결한 표현이며 이미 이미지에 포함되어 있다. 이름이 같다는 이유로 R10 파일을 재사용하지 않는다.
- 별도 CASINO/SLOT HTML 텍스트, 검은 라벨 바, 글자용 가상 요소를 추가하지 않는다. alt/aria-label은 유지한다.
- 버튼 외곽 크기·좌우 비율·간격·radius·클릭 동작은 유지한다. 전체 이미지가 보여야 하며 contain/중앙 정렬을 사용한다.
- SLOT 원본은 97×116이다. 현지 버튼 외곽이 98×116이어도 1px 차이 때문에 원본을 자르거나 98px로 재저장하지 않는다.
- 이 두 이미지에 우측 배너용 40% 오버레이를 추가하지 않는다. 새 이미지와 레터링을 그대로 표시한다.

## 짧은 완료 확인

1. 우측 배너 6개에 정확히 한 겹의 검정 40% 레이어가 있고 제목/설명은 밝기와 중앙 정렬을 유지한다.
2. 종목바 상단 공백이 줄고 좌우 패딩이 같다. 아이스하키/축구, 0/7/32/128에서 내용에 따라 폭이 변하며 20/14/12px와 버튼 높이는 유지된다.
3. 메뉴 헤더 한 줄에서 영상이 재생·반복되며 무음이다. 로고가 선명하고 사선/밑줄이 N과 겹치지 않는다. 공지와 메뉴 기능은 그대로다.
4. 좌측 두 이미지가 최신 SHA의 파일이며 글자가 한 번만 보이고 전체가 잘리지 않는다.
5. 국내형 두 열 공동 스크롤 / 해외형 두 영역 독립 스크롤, 기존 내부 카드와 배당/슬립 동작이 유지된다.

확인용 숫자와 임시 스타일은 운영 데이터에 남기지 않는다. 기존 build와 이 한정 확인 후 같은 사이트에 반영하고 결과를 보고한다.
