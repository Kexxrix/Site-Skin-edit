# ALDEBARAN R6 — 결정 변경분

현지 문서의 다음 번호로 병합한다.

| 변경 | 기준 |
| --- | --- |
| 배당 두 자리 | 최신 피드백. R5의 세 자리 배당 표시 허용을 대체 |
| 예정 경기 VS | 최신 피드백. 현재 스포츠 화면의 스코어/LIVE 표시를 대체 |
| 팀명 확대와 좌우 엠블럼 | 기존 R5의 작은 팀명/홈 표식 위주 표현을 대체 |
| 로고 잘림 최소 수정 | 원인 미확인. 승인 원본과 실제 CSS를 비교해 해당 부분만 수정 |
| 헤더 시각 효과 보류 | 선택·hover의 신규 디자인은 이번 작업에서 제외 |
| GNB 두 항목만 동작 | 국내형/해외형만 선택. 나머지 메뉴의 표시 자체는 유지 |
| 해외형 현 구조 유지 | 경기 목록/상세 마켓, 각각 독립 스크롤 |
| 국내형2열 카드/공동 스크롤 | 상세 마켓 없이 동일 카드 UI 재사용. 전체 중앙은 실제 scroller 하나 |
| 공통 데이터/슬립 유지 | 중복 경기 복제, 모드별 선택ID 분리, 금액 초기화 방지 |
| 타 사이트 적용 대기 | ALDEBARAN 규격 승인 이후 기존 브랜드 콘셉트를 유지하며 별도 이식 |

팀명15px/엠블럼28px/VS영역56px는 구현 시작값이다. 국내형 초기 상단 종목바1개, 행 우선 경기 배치, 모드별 위치 복원은 사용자 지시를 구체화한 구현 선택이며, 참조 사이트에서 새로 검증한 사실이라는 뜻이 아니다.
