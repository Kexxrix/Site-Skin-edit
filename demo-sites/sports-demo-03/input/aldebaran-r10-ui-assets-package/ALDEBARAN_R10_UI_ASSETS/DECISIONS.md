# ALDEBARAN R10 결정 변경분

- D10-01: 나머지 안내 배너 5개는 사용자 제공 원본 배경을 적용한다. 제목/설명은 기존 텍스트를 유지하고 별도 아이콘은 이미지로 대체한다. 첫 img_banner_01.png를 다시 만들지 않는다.
- D10-02: 카지노/슬롯은 사용자가 완성 이미지를 제공했다. R9의 ‘사진 위 HTML 라벨 유지’는 이 두 버튼에서 종료하고 별도 화면 라벨을 제거한다. 향후 별도 글자 이미지를 만들자는 과거 계획보다 이번 완성본이 우선한다.
- D10-03: 사용자가 Figma 표기 의미를 확인한 뒤 종목명 14px/경기 수 12px로 확정했다. 아이콘은 20×20px다. 처음 말한 pt를 CSS pt로 구현하지 않는다.
- D10-04: 가변 폭 버튼의 현재 모습은 수용됐다. 종목마다 다른 현재 폭과 높이를 보존하고 내부 요소만 작게 한다. 가장 긴 버튼 폭으로 통일하는 안은 채택되지 않았다.
- D10-05: 중앙 전체의 바깥 보드 배경/외곽선만 제거한다. 사용자는 두 차례 내부 카드 프레임 유지 의사를 명시했다. 초기 ‘내부 중첩 프레임 정리’ 해석은 철회한다. 레이아웃과 스크롤은 그대로다.
- D10-06: 세부 베팅 섹션의 주황색 왼쪽 선은 유지하되 1px로 줄인다. 전체 주황 강조 제거/일괄 변경이 아니다.
- D10-07: 안내 배너 6개에서 제목/서브텍스트 간격을 줄이고 두 줄을 하나의 묶음으로 세로 중앙에 맞춘다. 가로는 기존 왼쪽 정렬을 유지한다. 폰트 크기는 별도 변경 지시가 없다.
- D10-08: WOG 추가 참조는 종료 상태다. ALDEBARAN의 현재 컨셉과 레이아웃을 완성한 후 다른 두 사이트를 다루며, 이번 패키지에서는 이식하지 않는다.
- D10-09: 배당/주력 핸디캡 라인 개선은 이번 UI 요청으로 승인된 작업이 아니므로 포함하지 않는다. 현지 R9 배당 자료와 선택 ID를 보존한다.
- D10-10: 숫자로 미지정된 배너 텍스트 간격의 2px 제안과 종목 텍스트 line-height 예시는 구현 시작값이다. 사용자 확정 수치인 것처럼 보고하지 않는다.
