# ALDEBARAN R10 적용 지침 — 현지 운영 문서에 병합

- 대상은 sports-demo-03의 ALDEBARAN이다. 사용자 최신 피드백과 이후 직접 수정사항을 우선한다.
- 최신 현지 앱에서 시작한다. 알려진 PUBLIC v9 commit은 출처 식별용이며 reset 대상이 아니다. 과거 GitHub 공개 백업 v6로 대체하지 않는다.
- 현재 네 운영 문서에 이번 변경분을 병합하고 기존 결정/완료 이력을 보존한다. 이 ZIP의 문서는 전체 원문 교체본이 아니다.
- 지정한 6개 UI 변경만 수행한다. 현재 헤더·폰트 파일·스포츠 아이콘 원본·팀 로고·카드 배경 motif·경기/배당 자료와 선택/저장 동작은 보존한다.
- 중앙 바깥 보드 제거는 시각 표현의 변경이다. 레이아웃 DOM, 폭/높이, 패딩, overflow, 스크롤 주체를 제거하지 않는다. 내부 카드까지 투명하게 만드는 전역 selector를 사용하지 않는다.
- 종목 버튼의 글자/아이콘 축소는 외곽 버튼 크기 축소를 의미하지 않는다. 바뀌기 전 종목별 외곽 치수를 한 번 기록하고 CSS의 필요한 최소폭/크기 값으로 보존한다. 여섯 버튼을 가장 긴 버튼 폭으로 통일하지 않는다.
- 사용자 제공 PNG를 그대로 사용한다. 재생성·재색상·그림자 합성·글자 덧씌우기를 하지 않는다. 슬롯 원본은 97×116px이며 임의로 98px 파일로 다시 저장하지 않는다.
- 이미지는 접근 가능한 이름을 유지한다. CASINO/SLOT의 화면 텍스트만 없애고 기존 링크/버튼의 의미와 클릭 동작은 보존한다.
- 현재 설치된 디자인 지침이 필요하면 typeset/layout의 해당 부분만 참고할 수 있다. 이를 이유로 설치하거나 bolder/layout/typeset/harden/polish 전부를 실행하지 않는다.
- 새 의존성, 플러그인, 별도 QA/Jev, 이미지 생성, 광범위 리팩터링, 다른 사이트 수정은 범위 밖이다.

## 한정 확인과 완료

- 기존 build 1회. 프로젝트 필수 gate인 타입 검사가 build에 포함되지 않는 경우에만 기존 방식으로 추가한다. 실패 시 해당 원인만 수정한다.
- 1920×1080, 브라우저 100% 기준으로 변경 부위와 두 모드의 스크롤을 짧게 확인한다. 로컬 결과가 충분하면 공개에서 같은 정밀 검사를 반복하지 않는다.
- 사진 글자의 잘림/중복, 배너 6개의 글자 위치, 종목 버튼 외곽 크기, 중앙 내부 프레임 보존, 1px 강조선을 확인한다. 전 사이트 미감 감사나 새 회귀 스위트는 만들지 않는다.
- 기존 사이트의 같은 주소에 반영한다. 실제 인증·충전·환전·베팅 제출은 하지 않는다. 공개 GitHub 백업 동기화는 별도 요청을 따른다.
- 변경/확인/미확인 사항을 구분해 짧게 보고한다. 사용자가 이번 화면을 확인하기 전 자동 다음 작업을 시작하지 않는다.
