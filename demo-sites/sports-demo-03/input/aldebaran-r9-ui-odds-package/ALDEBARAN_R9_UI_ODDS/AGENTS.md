# ALDEBARAN R9 적용 지침 — 현지 운영 문서에 병합

## 작업 대상과 우선순위

- 대상은 sports-demo-03의 ALDEBARAN만이다. 사용자 최신 피드백 → 최신 현지 변경 → 이 패키지의 구현 사양 순으로 적용한다.
- 알려진 배포 기준은 PUBLIC v8, 소스 `4759aae04293e80c9dc3c60658ab97297118dbb0`이다. 이후 현지 변경이 있으면 보존한다. 기준 commit으로 reset하지 않는다.
- GitHub 공개 백업은 v6이므로 기존 앱 대체용으로 사용하지 않는다.
- WOG 디자인 재참조를 종료한다. 과거 WOG 관련 파일명은 이번에 일괄 변경할 필요가 없다.
- 기존 운영 네 문서 AGENTS/STATE/DESIGN_SPEC/DECISIONS에 관련 변경을 병합한다. 패키지의 같은 이름 파일은 변경분이며 원문을 덮어쓰는 배포 파일이 아니다.
- 사용자 직접 수정, 승인 아이콘 원본, 팀 엠블럼, 일반 아이콘과 카드 배경 아이콘의 분리, ALL 아이콘, 토글 수정은 보존한다.

## 작업 방식

- 필요한 UI와 데이터 경로만 변경한다. 일반적인 전체 리팩터링, 새 UI 프레임워크, 플러그인, 폰트 설치, 이미지 생성, 별도 배당 서버는 추가하지 않는다.
- 디자인 지침이 이미 설치돼 있다면 종목바는 layout, 라벨/가독성은 typeset, 긴 이름/숫자/배당 일관성은 harden의 해당 지침만 참고할 수 있다. 다섯 명령을 순서대로 전부 실행하거나 전체 polish를 시작하지 않는다. 스킬 부재를 설치 사유로 만들지 않는다.
- 지금 필요한 모습과 실제 화면 판단을 우선한다. 수치만 맞추기 위해 글자를 줄이거나 버튼을 찌그러뜨리지 않는다.
- 선택 ID와 저장 내역을 보존한다. 배당 데이터 갱신 시 새 선택의 출처/버전을 명확히 하고 과거 영수증을 소급 재계산하지 않는다.
- 합성 배당을 실시간 제공사 배당이라고 표시하지 않는다. 데이터 출처 구분은 데이터/운영 기록에 두며 화면에 긴 기술 설명을 추가하지 않는다.

## 완료 방식

- 기존 build 1회. 실제 변경 때문에 필요한 경우에만 추가 타입 검사 등을 실행하며 같은 검증을 중복하지 않는다.
- 해외형 독립 스크롤, 국내형 공동 스크롤, 필터, 선택/해제/슬립 연동 등 변경에 닿은 동작을 짧게 확인한다. 인증·충전·출금·실제 베팅 제출은 수행하지 않는다.
- 배당 자료는 한 번의 데이터 검증으로 가격 범위/소수 자리/라인 순서/양쪽 화면 일치 여부를 확인한다. 별도 QA 스레드나 Jev를 실행하지 않는다.
- 현지 기존 배포 절차로 ALDEBARAN만 반영하고 사용자에게 결과를 보여준다. 디자인 최종 승인은 사용자가 한다.
- 별도 요청 없이 MERCURY/SIRIUS 및 공개 GitHub 백업을 갱신하지 않는다. 기존 Sites 배포에 필요한 소스 작업과 공개 백업 동기화를 혼동하지 않는다.
