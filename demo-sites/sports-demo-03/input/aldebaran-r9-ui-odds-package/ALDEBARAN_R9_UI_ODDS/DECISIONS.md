# ALDEBARAN R9 결정 기록 — 기존 이력에 추가

## 사용자 확정 사항

- WOG의 새 디자인 참조 종료. 현재 프레임 위에서 ALDEBARAN을 완성한 후 MERCURY/SIRIUS 이식을 검토한다.
- 공지 행 유틸리티는 실제 사용할 수 있는 것처럼 밝게 표시한다.
- GNB 미반영 수정(흰색 비활성 항목, 로고 오른쪽 여유, hover 없음)을 이번에 함께 전달한다.
- 종목 선택바는 얇은 가로 형태. 버튼 폭은 이름 길이에 따라 자동 확장하는 안을 먼저 적용하고 실제 화면으로 재판단한다.
- 숫자 영역은 앞선 제안대로 세 자리 최소 폭을 확보한다. 높이·패딩·간격은 통일한다.
- CASINO/SLOT 검은 라벨 바 제거. 지금은 텍스트만, 나중에는 사용자가 제공한 라벨 이미지로 교체 가능한 구조.
- 첫 텔레그램 고객센터 배너의 텍스트 유지, 별도 아이콘 제거, 제공한 img_banner_01.png를 배경으로 사용. 아래 공식채널 배너는 유지.
- 배당 수치가 데모처럼 보이는 원인을 확인하고 현실적인 표현 방법을 작업지시에 포함한다.
- 별도 QA 스레드 단계를 추가하지 않고 구현 결과를 사용자가 보고 판단한다.

## 구현을 위해 채택한 판단 — 사용자 지정값과 구분

- 공통 종목바는 중앙1226px 상단 행에 배치한다. 샘플832px을609px 영역에 강제 축소하지 않고 기존 두 열의 가로 규격을 보존하기 위한 판단이다.
- 공통 행 상하8px 여백, 로고 장식 간격12~16px은 시작값이며 해당 부분을 보고 맞춘다.
- 배당은 이번 작업의 범위와 비용을 고려해 고정 합성 스냅샷을 사용한다. 실시간 API 도입은 포함하지 않는다. 현재61경기와 안정적인 ID에 연결하며 모델/출처를 기록한다.
- 첨부 축구 가격 예제는 수학적 일관성을 설명하는 합성 자료이다. 실제 팀 전력을 판정한 데이터가 아니다. 다른 종목이나 모든 경기에 복제 적용하지 않는다.

## 다음 단계로 남겨둔 사항

- 동일 고정 폭 버튼으로 변경할지 여부는 실제 구현을 본 뒤 결정한다.
- CASINO/SLOT 라벨 이미지, 두 번째 텔레그램 배경, 다른 추가 배너는 별도 제공/지시 후 적용한다.
- MERCURY/SIRIUS 이식과 공개 GitHub 백업 동기화는 별도 작업이다.
- 최종 미감 승인, 전체 서비스 QA, 실제 배당 제공사 연동은 이번 완료 범위가 아니다.
