# ALDEBARAN R13 적용 지침 — 운영 문서에 변경분 병합

이번 구현 범위는 정확히 두 건이다.

1. 경기 카드의 노란 추가베팅 버튼: 숫자와 화살표의 표현 및 내부 간격.
2. 좌측 레일 ‘최신 인기 게임’ 제목 앞 LIVE 칩: 배경과 글자 색상.

- sports-demo-03의 최신 현지 소스에서 최소 수정한다. PUBLIC v13 이전으로 reset하거나 과거 패키지의 전체 CSS를 재적용하지 않는다.
- 현재 AGENTS/STATE/DESIGN_SPEC/DECISIONS를 보존하고 이 패키지의 변경분만 병합한다.
- 추가베팅 버튼의 현재 클래스는 공개 DOM에서 `ab5-market-open`으로 확인했다. 구현 시 최신 소스에서 해당 컴포넌트와 규칙을 먼저 확인한다.
- 숫자 span과 전용 SVG만 기존 버튼 내부에 넣는다. 기존 버튼의 조건부 렌더링, 동적 마켓 수, 접근성 이름, 핸들러, 키보드 경로는 보존한다.
- 참조 화면의 숫자 8을 하드코딩하지 않는다. 배당/실제 마켓 수/데이터/계산은 변경하지 않는다.
- 일반 경기 카드 클릭에서 추가베팅 버튼을 제외하는 현재 처리를 유지한다. SVG/path/span 클릭도 기존 버튼 클릭과 동일하게 동작해야 한다.
- 범용 ChevronRight 컴포넌트와 공용 SVG 규칙을 전역 수정하지 않는다. 전용 SVG의 크기와 stroke를 추가베팅 버튼 안에만 적용한다.
- 좌측 LIVE에는 대상 전용 클래스나 현지의 이미 분리된 선택자를 쓴다. 문자열 LIVE 전체나 공용 배지 토큰 전체를 일괄 치환하지 않는다.
- 이번 두 항목을 이유로 다른 치수·색상·프레임·헤더·배너·레이아웃을 추가 폴리싱하지 않는다.
- 새 플러그인/의존성/이미지 생성, WOG 재참조, 별도 QA/Jev, 전체 리팩터링, MERCURY/SIRIUS 이식은 수행하지 않는다.

## 한정 완료 확인

- 기존 로컬 미리보기, 1920 고정 화면, 브라우저 100%에서 숫자·화살표 균형과 좌측 LIVE 칩을 확인한다.
- SVG는 6×10px, viewBox도 6×10, computed stroke-width는 1.25px인지 확인한다. 전역 SVG CSS에 의해 다시 12px나 stroke 1.7px로 덮이지 않아야 한다.
- 한 자리와 두 자리 숫자에서 높이 24px, 내용 기반 폭, 가운데 정렬, 잘림 없음을 확인한다. 필요하면 임시 컴포넌트 미리보기만 사용하고 운영 데이터를 수정하지 않는다.
- 추가베팅 버튼의 숫자/화살표/여백 클릭과 기존 키보드 입력이 동일한 기존 동작으로 이어지는지만 짧게 확인한다. 베팅 제출이나 계정/결제 작업은 필요 없다.
- 국내형·해외형에서 같은 버튼을 공유한다면 두 화면의 외형을 확인하되 각 모드의 기존 기능은 유지한다.
- 기존 build 1회. 빌드에 포함되지 않은 필수 타입 검사는 현지 규칙에 따른다. 실패를 고치는 경우만 필요한 검사를 반복한다. 새 자동 테스트나 전체 회귀 검사를 만들지 않는다.
- 기존 배포 흐름으로 같은 주소에 반영한다. 최종 스크린샷, 실제 commit/배포 결과, 확인하지 못한 점을 짧게 보고한다. 검증 완료를 사용자 시각 승인으로 대신하지 않는다.
