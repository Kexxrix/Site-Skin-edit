# ALDEBARAN R13 결정 기록 — 기존 이력에 추가

2026-09-23

1. 사용자가 추가베팅 버튼의 작은 숫자/화살표 표현 개선안을 수락하고, 좌측 ‘최신 인기 게임’의 LIVE 칩도 노란색으로 바꾸도록 지정했다. 이번 구현은 이 두 항목으로 한정한다.
2. 현재 화살표는 SVG이므로 벡터 전환이 원인 해결책은 아니다. 범용 24×24 도형의 축소를 버튼 전용 6×10 SVG로 교체한다.
3. 숫자는 기존 11px 크기에 700 굵기를 사용하고, 숫자 span/아이콘 중앙 정렬과 gap 3px, 좌우 padding 5px를 적용한다. 버튼은 높이 24px/라운드 5px/내용 기반 폭을 유지한다.
4. 색은 기존 노랑 #F1B000과 짙은 전경 #171717을 사용한다. 좌측 LIVE에는 색상만 적용한다.
5. PUBLIC v13 이후 현재 상태가 출발점이다. R12 문서의 VS 주황색, 예전 추가베팅 54px 고정 폭 등의 폐기된 규칙을 복원하지 않는다.
6. 위 수치는 이번 구현 기준이며 실제 수정 후 시각 승인 완료를 뜻하지 않는다. 앱 수정과 검증/배포 결과는 구현 담당자가 기록한다.
