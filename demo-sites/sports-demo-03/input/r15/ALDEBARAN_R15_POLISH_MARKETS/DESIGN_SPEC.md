# ALDEBARAN R15 — 통합 적용 사양

## R15-01. 베팅하기 버튼

대상은 우측 베팅슬립 하단의 ‘베팅하기’ 버튼 한 종류다. 기존 활성 배경을 #F1B000, 텍스트와 티켓 아이콘을 #171717로 바꾼다. 기존 폭·높이·라운드·패딩·라벨 중앙 정렬·폰트 규격을 유지한다.

기본/hover/pressed의 현재 동작을 살리고 주황색 잔상이 남는 상태만 같은 노랑 계열로 조정한다. 비활성 상태의 구분·커서·클릭 차단은 보존한다. 노란색이 되었다는 이유로 미선택 상태의 제출이 활성화되면 안 된다. 충전·환전·고객센터·마켓 선택의 주황색은 유지한다.

## R15-02. 실제 경기 수와 탭 수

| 종목 | 목표 실제 경기 수 |
| --- | ---: |
| 축구 | 32 |
| 농구 | 6 |
| 야구 | 16 |
| 배구 | 0 |
| 아이스하키 | 7 |
| 전체 | 61 |

현재 캡처의 합은 32+6+0+0+7=45다. 전체 61을 유지하기 위해 부족한 61−45=16을 야구에 배정한다. 따라서 32+6+16+0+7=61이다. 이것은 화면/데이터 배분을 위한 적용값이며 현재 실제 경기 일정에서 수집한 수량이 아니다.

같은 활성 fixture 목록에서 전체·종목·리그 수를 집계한다. 전체 목록에 종목 탭에 없는 숨은 NFL 등이 남지 않아야 한다. 종목 카운터가 검색에 반응하는 기존 정책이 있다면 전체와 종목 모두 동일한 필터를 적용한다. 검색 전 기본 상태의 합은 61이다.

야구 16개는 야구 팀/리그/시간/엠블럼 매핑과 야구용 마켓을 가진 데모 fixture로 구성한다. 기존 32/6/7의 정상 경기와 ID는 최대한 보존한다. 없는 로고는 현재 대체 표시 정책을 사용하고 다른 종목의 로고를 잘못 붙이지 않는다. 새 팀 로고나 이미지를 생성하지 않는다.

배구 탭은 0을 유지하고 클릭하면 ‘경기 없음’을 표시한다. 다른 종목 경기나 이전 상세가 배구 결과처럼 남으면 안 된다. 해외형에서 빈 종목 선택 시 경기 목록과 상세를 일관된 빈 상태로 처리한다. 다른 종목으로 돌아오면 기존 정상 선택 또는 첫 유효 경기로 복원한다. 슬립의 유효 선택을 종목 전환만으로 삭제하지 않는다.

이전 NFL fixture를 제거할 경우 저장된 슬립·선택 경기에서 삭제된 ID만 정리한다. 같은 ID를 야구로 재사용해 과거 미식축구 선택이 야구 선택으로 바뀌지 않게 한다.

## R15-03. 우측 계정 패널

최종 기준은 references/05-account-panel-target.png다. 앞선 ‘세로’라는 표현은 첨부한 최종 형태에 따라 해석한다. 전체 버튼 배열은 **3열×2행**, 개별 버튼 내부는 **아이콘 왼쪽·글자 오른쪽**이다.

| 줄 | 왼쪽 | 가운데 | 오른쪽 |
| --- | --- | --- | --- |
| 첫 줄 | 충전 | 환전 | 페이백 |
| 둘째 줄 | 쪽지 | 고객센터 | 베팅내역 |

6개 버튼은 균등 폭·같은 높이이며, 내부 묶음을 가로·세로 중앙 정렬한다. 아래 수치는 현지 CSS 실측값이 아닌 이번 구현 시작값이다.

| 항목 | 적용 시작값 |
| --- | --- |
| 높이 | 38px |
| 버튼 간격 | 4px |
| 아이콘과 텍스트 간격 | 6px |
| 아이콘 | 기존 아이콘 사용, 약 18px |
| 버튼 배경 | #353535 |
| 아이콘 | 기존 주황 #FF641F |
| 텍스트 | 기존 밝은 글자 #F5F4F4 및 현재 웨이트 |
| 라운드 | 현재 규격 보존 |

현재 폰트에서 clipping이 생기는 경우 필요한 최소 치수만 조정하고 최종 값을 보고한다. 계정 패널 폭과 외곽 디자인을 키워 해결하지 않는다. 좌측 메뉴 자체나 다른 아이콘 체계는 바꾸지 않는다.

‘금일 적중’은 이 패널의 표시 요소에서 제거한다. 데이터/API/베팅 이력 기능까지 삭제하는 지시가 아니다.

‘보유머니’와 ‘보너스 전환’은 각각 독립된 채움/테두리/그림자 박스를 없애고 계정 패널 위의 행으로 정리한다. 보유머니는 이름 왼쪽·현재 금액과 단위 오른쪽, 보너스 전환은 이름 왼쪽·기존 전환 버튼 오른쪽이다. 보유머니 아래에 약한 구분선 1개를 둔다. 잔액의 기존 주황 강조와 숫자 포맷을 유지한다. 금액을 1,000,000으로 하드코딩하지 않는다.

상단 LV·이름·정보수정, 계정 외곽 박스와 내부 여백은 현재 상태를 유지한다. 전환/충전/환전/페이백/쪽지/고객센터/내역의 기존 데모 동작을 연결한다.

## R15-04. 중앙 일반 텍스트 웨이트

범위는 중앙의 **리그·경기 카드 목록과 오른쪽 상세 마켓**이다. 리그/팀명/날짜·시간/VS/상세 경기 제목/상세 필터/마켓 제목/라인 수/선택지 이름/회색 핸디캡·총점 기준값을 현재 값에서 한 단계 가볍게 한다.

아래 두 종류는 삭제하지 않으며 웨이트도 보존한다.

- 실제 배당 숫자: 기본 청녹색뿐 아니라 선택/비활성 상태에서 색이 달라지는 같은 의미의 배당 값.
- 추가마켓 `8+`, `12+`, `100+` 등 숫자+ 라벨 전체.

색상만 보고 대상을 찾지 말고 의미에 해당하는 요소/클래스로 구분한다. `218.5`, `홈 −3.5` 같은 기준값은 배당이 아니므로 감량 대상이다. 신규 마켓의 구간/선수명/기준값에도 같은 규칙을 적용한다.

| 변경 전 | 변경 후 예시 |
| --- | --- |
| 900 | 800 |
| 800 | 700 |
| 700 | 600 |
| 600 | 500 |
| 500 | 400 |
| 400 | 300 |

실제 로드된 폰트가 지원하는 다음 낮은 단계로 매핑한다. 지원하지 않는 굵기를 선언한 뒤 완료로 보고하지 않는다. 최저 지원 굵기라 더 낮출 수 없는 요소는 유지하고 예외를 보고한다. 부모/자식 규칙을 합쳐 두 단계 낮추지 않으며 `font-weight: lighter`나 전체를 같은 숫자로 덮어쓰는 방식을 피한다.

글자 크기·색·줄높이·간격·위치·사용 폰트를 바꾸지 않는다. 헤더/GNB/좌우 레일/상단 종목바는 이번 중앙 웨이트 범위에 포함하지 않는다. 우측 계정 패널 버튼은 R15-03의 별도 사양을 따른다.

## R15-05. 실제 마켓 확장과 경기별 차이

resources/market-catalog.json은 115개 재사용 계열, resources/market-generation-plan.json은 적용 순서와 종목별 생성 조건이다. 공식 출처와 개별 종류는 resources/market-research.ko.md를 참고한다. 조사를 다시 처음부터 반복하지 말고 실제 구현에 부족한 명단/규칙만 필요한 범위에서 확인한다.

### 제공 범위

경기/팀/구간 마켓을 먼저 충분히 구현하고, 지원 가능한 코너·카드·기록을 추가하며, 확인된 선수 명단이 있는 경기는 선수 마켓까지 이번 작업 안에서 확장한다. 임의 선수·잘못된 소속으로 채우지 않는다. 선수 확보가 어렵더라도 앞 단계의 종목별 마켓 확장을 완료한다.

| 종목 | 경기·팀·구간 중심의 풍부한 경기 목표 | 선수 데이터 포함 확장 목표 |
| --- | ---: | ---: |
| 축구 | 55–100 | 100–220 |
| 농구 | 60–110 | 150–300 |
| 야구 | 45–90 | 100–200 |
| 아이스하키 | 40–85 | 80–160 |

이 범위는 설계 목표이고 실제 사이트 평균이나 경기별 할당량이 아니다. 모든 경기에 같은 세트를 넣지 않는다. 프리시즌/친선·부족한 지원 조건에 따른 소규모 프로필은 허용한다. 주요 정상 경기에서도 기존 10개 수준을 그대로 유지한 채 숫자만 올리는 것은 미완료다. 지원 가능한 범위를 최대한 구현한 후 실제 최소/중앙값/최대와 제외 이유를 보고한다.

축구 68개 설계 예시의 합은 3+10+13+5+10+10+8+6+3=68이다. 이는 팀·구간만으로 충분히 확장할 수 있다는 예시이며 경기마다 이 구성을 그대로 복제하라는 지시가 아니다.

### 집계 정의

N은 상세에서 제공하는 고유 활성 **개별 마켓 수**다. 미리보기 기본 마켓도 한 번만 포함한다. 하나의 질문에 대한 선택지를 여러 마켓으로 세지 않는다.

- 핸디캡 5라인 × 각 2선택지 = 5마켓 / 10선택지.
- 정확한 스코어 20선택지 = 1마켓.
- 선수 6명의 독립 득점 O/U = 6마켓 / 12선택지.

아코디언/탭/미리보기 중복·빈 항목·렌더러 미지원 유형·유효 배당 없는 항목·동일 조건 별칭은 제외한다. DNB와 동일 범위의 아시안 0, 첫 이닝 득점 유무와 0.5 O/U 등은 중복 제거한다. 스코프·조건이 다르면 별도 마켓으로 구분한다.

집계는 상세의 전체 마켓 배열에서 하고 UI 필터·아코디언 접힘·가상 렌더링 여부에 영향받지 않아야 한다. N+와 상세의 소스가 다르면 안 된다. 접근성 이름은 기존 팀명을 보존하면서 ‘전체 마켓 N개 보기’를 설명한다. 0개 버튼 처리와 국내형의 기존 진입 동작은 현재 정책을 보존한다.

### 현실적인 구성

종목, 경기 형식, 통계 지원, 확인된 로스터, 선발투수·골리, 프로필에 따라 유형·구간·라인 수·선수 수를 다르게 한다. 같은 종목에서 숫자가 우연히 같을 수는 있다. 고의로 모든 숫자를 고유하게 만들 필요는 없다.

기존 합성 배당 모델을 재사용/확장하고 한 경기의 기본 결과·핸디캡·총점·팀 총점은 일관된 모델에서 생성한다. 반대 선택지, 대체 라인 난도, 팀 기준값의 방향과 합리성을 확인한다. 프레임마다 난수를 새로 뽑거나 관련 선택지의 배당을 무조건 곱하지 않는다. 지원하지 못하는 타입은 노출/집계에서 제외하고 이유를 기록한다.

축구는 정규/추가시간과 연장·진출을 구별한다. 농구는 리그의 하프/쿼터와 마켓별 연장 범위를 명시한다. 야구는 첫 5이닝과 단일 5회, 초·말, 2방향 환불/3방향 무승부를 구별한다. 하키는 정규 60분/연장·슛아웃 포함, 1~3피리어드, 팀 점수와 선수 기록을 구별한다. 모든 종목에 축구나 농구의 구간 라벨을 재사용하지 않는다.

시즌 우승/장기 선수상/진행 상태가 필요한 다음 타석·다음 공격 등 인플레이 전용 항목은 프리매치 한 경기의 수량에 섞지 않는다. SGP의 모든 조합도 마켓 수에 포함하지 않는다.

### 화면과 동작

왼쪽 카드의 현재 대표 배당 구성·행 수·내부 프레임을 보존하고, 오른쪽 상세 내용을 확장한다. 해외형의 기존 경기 선택과 독립 스크롤을 유지한다. 국내형에 새 상세 패널을 추가하지 않는다. 공용 데이터 확장이 국내형에도 적용되면 현재 모드의 표현/동작 범위 안에서 일관되게 반영한다.

기존 전체/승무패/핸디캡/언더·오버/기타를 유지한다. 승패는 승무패 계열, 코너·카드·선수 등 특수 마켓은 기타 안에서 이름 있는 그룹으로 묶을 수 있다. 상세 분류는 생성 타입에서 명시적으로 매핑해 누락되지 않게 한다.

2방향/3방향/예·아니오/정확한 스코어/선수 목록 렌더러를 필요한 범위에서 확장한다. 한 유형의 여러 라인은 한 카드로 묶고, 다수 선택지는 현재 상세 폭 안에서 읽을 수 있는 규칙적 배열을 사용한다. 마켓마다 외곽선을 겹겹이 추가하지 않는다. 기존 접힘 상태 정책을 우선 유지하고 큰 신규 그룹은 접힘으로 시작할 수 있다. 새 탭 체계·검색·모바일 라우트는 요구하지 않는다.

N+는 기존 높이 24px·라운드 5px·12px/700 단일 텍스트·내용 기반 폭을 유지한다. 99+→100+에서도 기준선·중앙·우측 위치가 맞아야 한다. 화살표나 별도 + 아이콘을 복원하지 않는다.

클릭·키보드·선택 해제·슬립 연결을 실제 확인한다. 시장/구간/선수/기준값 정보가 슬립에 표현되고, 목록 미리보기와 상세의 동일 선택은 같은 ID로 동기화되어야 한다. 현재 선택 경기와 상세 제목이 어긋나지 않아야 한다.
