## 보존할 기존 결과

- 고정 1920 레이아웃. 해외형 경기 목록/상세 마켓은 각각 스크롤, 국내형 두 경기 열은 함께 스크롤.
- 종목 선택 버튼은 내용 기반 가변 폭. 아이콘 20px, 종목명 14px, 경기 수 12px. 한 자리 경기 수에 세 자리 폭을 예약하지 않는다.
- 1920×62 헤더 WebM, 원본 워드마크, 반투명 사선판 및 주황 하단선. 공지사항 줄과 메뉴 선택/비활성 동작.
- 오른쪽 안내 배너 6개의 검정 40% 배경 오버레이와 텍스트 세로 중앙 정렬.
- 최신 CASINO/SLOT 이미지와 별도 HTML 라벨 제거 상태.
- 경기 전 VS 표시, 팀명/엠블럼, 배당 소수점 두 자리, 현재 경기/배당/선택 ID와 슬립/저장 동작.
- 내부 경기 카드·마켓 카드 프레임과 마켓 제목 왼쪽 1px 주황선.
