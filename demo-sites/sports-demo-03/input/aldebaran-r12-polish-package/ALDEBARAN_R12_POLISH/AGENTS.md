# ALDEBARAN R12 적용 지침 — 현지 운영 문서에 병합

- 대상은 sports-demo-03의 ALDEBARAN이다. R11 완료 후 최신 현지 소스 및 사용자 수정이 기준이다. 이전 공개 버전이나 commit으로 reset하지 않는다.
- 네 운영 문서에 변경분을 병합하고 기존 기록을 보존한다. 이 패키지의 문서를 전체 교체본으로 사용하지 않는다.
- 이번 폴리싱은 배색과 중앙 영역 표현 4건이다. 무관한 치수·타이포그래피·버튼 동작·이미지를 새로 디자인하지 않는다.
- 색상은 선택자/데이터의 의미에 따라 적용한다. 화면에 나온 숫자나 '.number' 같은 광범위 클래스 전체를 청록색으로 만들지 않는다.
- 통화, 경기 수, 시간, 팀명, 핸디캡 기준값, 마켓 수와 실제 decimal odds를 구분한다. 새 색상을 이유로 가격 계산/데이터를 수정하지 않는다.
- 색상 토큰은 ALDEBARAN 범위 안에 둔다. 다른 사이트 테마까지 영향을 주는 전역 토큰을 교체하지 않는다.
- 중앙 전체를 감싸는 옛 큰 보드를 되살리지 않는다. 종목바, 좌측 목록 면, 우측 마켓 외곽선이라는 지정된 역할에만 적용한다.
- 프레임 변경 시 실제 grid 폭, padding, 스크롤 주체, sticky/flex 제약과 클릭 영역을 보존한다. 내부 카드 프레임을 제거하는 전역 border/background 초기화를 하지 않는다.
- 현재 원본 자산을 그대로 사용한다. 이번 ZIP에는 참조 이미지 5장만 있으며 새로운 프로덕션 이미지나 영상을 만들 필요가 없다.
- 새 플러그인/의존성, 이미지 생성, 별도 QA/Jev, 전체 자동 polish, 다른 사이트 이식은 하지 않는다. WOG 참조는 종료된 상태다.

## 완료 확인

- 기존 build 1회. build에 포함되지 않은 필수 타입 검사는 현지 프로젝트 규칙에 따라 수행한다. 실패할 때만 필요한 수정과 재실행을 한다.
- 1920 고정 화면, 브라우저 100%에서 네 변경 부위만 확인한다. 동일한 정밀 검사를 로컬/공개에서 반복하거나 새 회귀 스위트를 만들지 않는다.
- 실제 배당과 기준값의 색 구분, 노란 칩/추가베팅 버튼, 종목바의 배경/하단선, 좌측 8px 배경 면, 우측 연속 외곽선을 확인한다.
- 경기 선택과 추가베팅 이동, 마켓 접기/필터, 국내/해외 스크롤의 대표 동작을 짧게 확인한다. 일반/선택 배당 상태에서 글자 가독성과 선택 표시를 확인한다.
- 실제 결제·계정 생성·베팅 제출 없이 기존 동작 보존을 확인한다.
- 기존 배포 흐름으로 같은 ALDEBARAN 주소에 반영한 후 실제 완료 사항과 미확인 사항을 구분해 보고한다.
