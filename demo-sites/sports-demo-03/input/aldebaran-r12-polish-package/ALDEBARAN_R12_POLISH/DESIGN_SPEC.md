# ALDEBARAN R12 — 확정 폴리싱 사양

목표는 무광 차콜/주황 컨셉 안에서 정보 역할별 색을 나누고, 왼쪽 경기 목록과 오른쪽 마켓이 서로 다른 영역으로 읽히게 하는 것이다. 현재 레이아웃과 밀도는 유지한다.

## 참조 우선순위

1. 이번 사용자 설명과 아래 확정 사양.
2. palette-approved.png의 배색, sports-toolbar.png / match-list-surface.png의 영역 표현.
3. market-outline-overview.png와 market-outline-detail.png의 오른쪽 프레임 구성.

오른쪽 참조에는 아직 주황색 배당/기준값이 남아 있다. 구성만 참조하고 색은 최종 규칙으로 바꾼다. 초기 민트 NEW 칩 시안과 배당/기준값을 모두 청록으로 만든 이전 시안은 이번 최종안이 아니다. 참조 이미지의 편집 도구 UI, 잘린 화면, 확대된 글자 크기를 구현하지 않는다.

## R12-01 — 배색

아래 HEX는 사용자 PNG에서 확인한 픽셀값을 구현 토큰으로 채택한 것이다. Figma 원본 스타일이나 공개 사이트 CSS를 측정했다는 뜻은 아니다.

| 역할 | 적용값 | 대상 |
| --- | --- | --- |
| 브랜드/선택 | #FF641F | 기존 주요 버튼·선택 테두리/밑줄·VS·마켓 강조선 |
| 실제 배당 | #50DCD9 | 일반 상태 배당 숫자: 1.56, 2.48, 1.89 등 |
| 작은 보조 강조 | #F1B000 | NEW/LIVE 칩, 카드의 추가베팅 숫자·화살표 버튼 배경 |
| 보조 강조 위 글자 | 기존 짙은 글자 토큰, 없으면 #141515 | 노란 배경 위 NEW/LIVE·숫자·화살표 |
| 핸디캡/득점 기준값 | #B7B7B7 | 홈 -3.5, -4.5, 218.5, 54.5 등 |

- 청록색은 실제 배당 가격에만 적용한다. 같은 값이 경기 카드와 우측 상세 마켓에 나타나면 일반 상태에서 같은 색으로 보인다.
- 승패뿐 아니라 핸디캡·언더/오버·홀짝·쿼터·팀 득점 등 모든 상세 마켓의 실제 배당에도 적용한다. 숫자의 크기나 소수점 유무로 역할을 추측하지 말고 데이터 필드/구성 요소로 구분한다.
- 홈 -3.5와 218.5 같은 기준값은 가격이 아니다. 밝은 회색으로 표시하며 기준값 라벨도 기존 중립색 계열을 유지한다. 청록색 적용 때문에 기준값을 218.50으로 바꾸지 않는다.
- 배당은 기존 두 자리 표기를 유지한다. 값/정밀도/배당 계산/마켓 수/경기 수를 이 시안의 예시 숫자로 교체하지 않는다.
- 노랑은 면으로 표시한다. NEW/LIVE와 추가베팅 버튼의 현재 크기·모서리·문구·숫자·화살표·클릭 동작을 유지하며 배경과 전경색만 바꾼다. 초기 제안인 청록 테두리형 추가베팅 버튼은 사용하지 않는다.
- LIVE는 기존 헤더 칩의 표시다. 경기 전 카드에 라이브 상태나 스코어를 추가하라는 의미가 아니다. 반응하지 않던 헤더 메뉴를 클릭 가능하게 만들지 않는다.
- 주황색 선택 표현은 계속 유지한다. 일반 상태 배당은 청록으로 통일하되, 선택된 배당 버튼의 기존 주황 배경과 대비되는 전경색은 보존한다. 청록 글자를 주황 면에 강제해 읽기 어렵게 만들지 않는다.
- 잔액·합계·날짜·리그 경기 수·종목 배지·팀명 등 모든 숫자/글자에 전역 재색상을 하지 않는다. 이번 가격 색상 대상은 중앙 경기 카드와 상세 마켓이다.
- 새로운 발광/그라데이션/맥동 애니메이션이나 hover를 추가하지 않는다.

## R12-02 — 상단 종목 선택 바

- 현재 중앙 종목 선택 바의 전체 가로 영역에 #191919 배경을 적용한다.
- 아래 경기 영역과 맞닿는 하단에 #383838, 1 CSS px 구분선을 한 줄 적용한다. 1px는 첨부처럼 얇게 구현하기 위한 지정값이다.
- 선/배경은 중앙 콘텐츠 폭에 맞춰 끊김 없이 이어지며 좌우 레일 위로 확장하지 않는다. 그림의 1240px 폭은 잘라낸 이미지 크기이며 새 레이아웃 수치가 아니다.
- 종목바 높이·버튼 좌표·간격·가변 폭·현재 상단 정렬을 유지한다. border 추가 때문에 바의 높이가 늘어나면 안 된다. 기존 선을 재사용하거나 inset/장식 레이어로 한 줄만 그린다.
- 선택 주황 테두리, 경기 수 배지 색, 아이콘 20px/종목명 14px/수량 12px와 실제 경기 수를 유지한다.
- 사방을 둘러싼 새로운 카드 외곽선을 더하지 않는다. 이번에는 약한 배경과 하단선으로만 분리한다.

## R12-03 — 왼쪽 경기 목록의 배경 면

- 대상은 중앙 왼쪽의 리그 제목과 베팅카드들을 포함한 경기 목록 영역이다. 사이트 맨 왼쪽 퀵메뉴 레일을 뜻하지 않는다.
- 종목바와 같은 #191919 배경을 쓰고 코너 라운드를 정확히 8 CSS px로 한다.
- 목록을 묶는 큰 영역에 별도 외곽선/그림자를 더하지 않는다. 현재 페이지 배경과의 약한 명도 차이로 구분한다.
- 기존 목록 영역을 감싸는 한 단계에 적용한다. 리그마다 또는 카드마다 새 래퍼와 외곽선을 연달아 추가하지 않는다. 기존 리그/카드 구조는 그대로 이용한다.
- 리그 제목, 리그 아래 구분선, 개별 카드 배경과 프레임, 선택 경기 주황 테두리, 사진 motif, 팀명/엠블럼, 배당 버튼은 유지한다.
- 내부 카드까지 투명하게 만들거나 선택 표시를 제거하지 않는다. 이번 8px는 목록 영역의 모서리이며 모든 버튼/카드 모서리를 8px로 통일하는 값이 아니다.
- 기존 목록 폭·여백·높이와 스크롤 주체를 보존한다. 배경과 라운드를 위해 scroll wrapper를 없애거나 추가 스크롤을 만들지 않는다.

## R12-04 — 오른쪽 마켓을 하나의 세트로 묶기

- 대상은 중앙 오른쪽 상세 마켓이다. 계정/베팅슬립이 있는 맨 오른쪽 레일이 아니다.
- 공통 바탕은 transparent로 유지한다. 아래 페이지 배경이 보이고, 내부 마켓 사이 빈 공간에도 새로운 면색을 채우지 않는다.
- 경기명/시작 시간 헤더, 마켓 필터, 아래 상세 마켓 목록 전체를 한 겹의 연속된 외곽선으로 감싼다.
- 외곽선: #383838, 1 CSS px. 넓은 회색 면이나 추가 세로 separator를 더하는 방식이 아니다.
- 외곽의 둥근 윗모서리는 현재 경기 헤더 곡률에 맞춘다. 현지 기준이 없을 때 8px를 시작값으로 사용할 수 있지만, 우측 radius는 사용자 확정 수치가 아니다.
- 경기명/시간의 기존 회색 헤더 면, 필터 영역의 기존 배경과 하단 구분선, 내부 마켓 카드의 제목/몸통 배경과 프레임은 유지한다. '페이스 없음'은 이 전체 세트의 큰 바탕을 뜻한다.
- 승패/핸디캡/언더오버 등 개별 마켓 제목의 1px 주황 강조선과 펼침/접힘 동작은 유지한다.
- 경기 헤더/필터에 이미 외곽선 일부가 있다면 공통 프레임과 접합부를 정리해 두 줄로 겹치지 않게 한다. 한 개의 세트가 아니라 별도 패널 여러 개처럼 보이지 않게 연결한다.
- 프레임은 기존 우측 공통 컨테이너에서 처리한다. border 공간 때문에 내용 폭이 줄거나 팀명이 새로 잘리지 않게 한다. box sizing/기존 border 공간 또는 장식 레이어를 활용하고 주변 레이아웃을 밀지 않는다.
- 기존 스크롤, sticky 여부, header/filter 위치 관계를 유지한다. 프레임을 넣기 위해 두 스크롤을 하나로 합치거나 각 카드에 스크롤을 만들지 않는다.

## 모드별 적용

| 모드 | 적용 |
| --- | --- |
| 해외형 | 종목바 아래 경기 목록은 배경 면, 상세 마켓은 투명 바탕+외곽선. 두 영역 독립 스크롤 유지 |
| 국내형 | 공통 배색과 종목바 적용. 두 열을 포함한 공동 경기 목록 영역에 동일한 목록 배경 원칙을 적용하고 공동 스크롤 유지. 상세 마켓 영역은 만들지 않음 |

왼쪽 목록/오른쪽 마켓을 다시 하나의 큰 바깥 보드로 감싸지 않는다. 중앙 전체의 기존 투명 바탕은 유지하고 역할별 컨테이너만 표현한다.

## 필요한 확인만 수행

1. 두 모드의 일반 배당이 청록이고 기준값은 회색이다. 선택 표시와 숫자 데이터는 그대로다.
2. 헤더 NEW/LIVE와 추가베팅 버튼이 노랑/짙은 전경으로 표시된다.
3. 종목바가 약한 배경과 한 줄 하단선으로 구분되며 기존 버튼 좌표/가변 폭이 유지된다.
4. 왼쪽 목록 면의 radius가 8px이고 새 외곽선은 없다. 내부 경기 카드의 프레임/선택 표시는 보존된다.
5. 오른쪽은 큰 바탕이 투명하고 헤더부터 마켓 전체를 한 겹의 외곽선이 묶는다. 내부 카드 배경과 구분선은 유지된다.
6. 해외형 두 스크롤/국내형 공동 스크롤 및 대표 선택·추가베팅·접기 동작을 확인한다.

사용자 시안에 맞춘 한정 폴리싱이다. build 및 위 확인 후 같은 사이트에 반영하고 사용자 검토를 기다린다.
