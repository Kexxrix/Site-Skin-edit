# ALDEBARAN R12 결정 기록

## 배색 확정 과정

- 최초 청록/민트 보조색 제안 이후 사용자가 노랑 NEW/LIVE·추가베팅, 청록 배당 시안을 제시했다.
- 이후 핸디캡/득점 기준값을 회색으로 바꾼 시안을 제시하고, 그 배색으로 적용하도록 지시했다.
- 따라서 최종안은 주황(브랜드/선택), 청록(실제 배당), 노랑(작은 칩/추가베팅 면), 회색(기준값)이다. 최초 제안 #4CC9B0이나 민트 칩으로 되돌리지 않는다.
- 청록 #50DCD9, 노랑 #F1B000, 회색 #B7B7B7은 최신 PNG에서 확인한 색이다. 문서에 명시한 토큰으로 구현하되 출처가 Figma/CSS 실측이라고 주장하지 않는다.

## 이전 규칙의 적용 범위 수정

| 대상 | R12 결정 | 이전 규칙과 관계 |
| --- | --- | --- |
| 중앙 전체 큰 바깥 보드 | 투명 유지 | R10/R11 유지 |
| 종목 선택 바 | #191919 면 + 얇은 하단선 | 이 공통 바에 한정해 배경/하단선 추가 |
| 중앙 경기 목록 | #191919 면, radius 8px, 큰 외곽선 없음 | 목록 영역에 한정해 면색 추가 |
| 중앙 상세 마켓 | 큰 바탕 투명, 전체 한 겹 외곽선 | 우측 세트의 경계를 추가 |
| 내부 리그/경기/마켓 카드 | 기존 프레임 유지 | 이전 보존 규칙 유지 |
| 모드별 스크롤/배당 데이터 | 그대로 유지 | 디자인 변경을 동작/데이터 변경으로 확대하지 않음 |

## 수치와 범위

- 왼쪽 영역 radius 8px는 사용자 명시값이다.
- 얇은 구분선/우측 외곽선은 1 CSS px로 구현한다. 이는 첨부의 표현을 위한 구현값이다.
- 우측 외곽 radius는 기존 헤더와 연결되게 유지한다. 미정일 때의 8px는 제안값이며 사용자 명시값이 아니다.
- 오른쪽 참조 이미지의 주황 가격은 최종 배색 지시보다 우선하지 않는다.
- 스크린샷의 확대율과 크롭 크기를 기준으로 폰트/레이아웃/전체 폭을 확대하지 않는다.
- 패키지에는 최종안에 필요한 참조 5장만 넣고, 혼동을 줄 수 있는 이전 민트 칩/모든 숫자 청록 시안은 제외했다.

WOG 참조 종료, ALDEBARAN 완성 후 다른 두 사이트에 순차 적용이라는 진행 방향은 유지한다. 이번 범위에 다른 사이트 작업은 없다.
