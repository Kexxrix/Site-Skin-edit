1. 시안의 역할별 배색 적용
   - 주황 #FF641F: 기존 주요 버튼, 선택 표시, VS 등 브랜드 강조 유지.
   - 청록 #50DCD9: 중앙 경기 카드와 우측 마켓의 일반 상태 실제 배당 숫자.
   - 노랑 #F1B000: NEW/LIVE 칩 및 추가베팅 버튼의 면, 내부 글자/화살표는 짙은 색.
   - 회색 #B7B7B7: 홈 -3.5, 218.5 등 핸디캡/득점 기준값.
   - 전체 숫자를 일괄 변경하지 말고 데이터의 역할로 구분합니다. 배당 값/표시 자리수는 변경하지 않습니다.

2. 중앙 종목 선택 바
   - 약한 차콜 #191919 배경과 하단 #383838 / 1px 구분선으로 독립된 가로 영역을 만듭니다.
   - 기존 버튼 높이/가변 폭/간격/정렬/20·14·12px 규격과 선택 동작은 유지합니다.

3. 좌측 경기 목록
   - 리그 제목과 베팅카드를 포함한 목록 영역에 종목바와 같은 #191919 배경을 적용합니다.
   - 모서리 8px. 큰 영역의 외곽선 없이 명도 차이로 우측 마켓과 구분합니다.
   - 내부 경기 카드 프레임, 리그 구분선, 선택 경기의 주황 표시와 내용은 유지합니다.

4. 우측 상세 마켓
   - 전체 바탕은 투명하게 유지합니다.
   - 경기명/시간 → 마켓 필터 → 전체 마켓 목록을 #383838 / 1px 외곽선 한 겹으로 묶습니다.
   - 내부 마켓 카드의 배경과 프레임, 제목 영역, 1px 주황 강조선은 유지합니다.
   - 참조에 남은 주황 배당/기준값은 복사하지 말고 1번의 최종 배색으로 통일합니다.
