# ALDEBARAN R5 — 준비 상태와 인계

## 확인된 현재 상태

- 외부 구현자가 R4 중앙 두 열과 헤더 수정까지 배포했다. 사용자는 첫 구현을 확인했다.
- 축구만 노출/독립 스크롤 수정안 준비 중 사용자가 중단시켰으며, 그 중단된 안의 새 파일/사이트 수정은 없었다.
- 이후 WOG 해외형 스포츠를 직접 열어 공개 CSS와 DOM을 확인했다. 로그인 뒤 해외형 화면 접근 및 왼쪽 목록/오른쪽 마켓의 독립 스크롤을 확인했다. 오른쪽 scrollTop 462일 때 왼쪽은 0이었다.
- 현재 사용자는 세 사이트가 실제 제품처럼 보이지 않는다는 피드백에 따라 WOG의 전체 배치/요소/치수를 ALDEBARAN 스타일로 이식하도록 승인했다.
- 본 패키지는 작업 지시 자료다. 실제 Windows 소스/빌드/배포 결과는 포함하지 않는다. R5는 지시 패키지 번호이며 공개 버전 번호가 아니다.

## 근거의 범위

| 자료 | 의미 |
| --- | --- |
| reference/wog-user-wide.png | 사용자 제공 전체 배치 참조, 실제 PNG 1916×941 |
| reference/components.csv | 현재 1363×936 렌더의 요소별 적용 치수/서체/간격 |
| reference/geometry-rules.css | 필요한 데스크톱 치수 CSS의 발췌, 구현용으로 직접 import하지 않음 |
| implementation/layout-contract.json | 데스크톱 CSS를 1920에 적용해 계산한 목표 |
| DESIGN_SPEC | 출처 측정값 + 테마 변환 + 상호작용을 합친 실행 명세 |

전체 WOG 소스나 API를 확보한 것은 아니다. 숨겨진 회원 기능의 내부 동작, 결제/베팅 실행, 모든 hover/팝업은 조사하지 않았다. 공개 DOM/CSS와 사용자 제공 넓은 화면이 레이아웃 근거다. 기준 요소 중 현재 DOM에는 데이터가 없어 보이지 않은 상태는 로컬 데이터 계약으로 보완한다.

## 구현 순서

1. 최신 ALDEBARAN 소스와 네 운영 문서를 읽고 기존 상태/자산/호스팅을 유지한다.
2. 1920 shell, 62+36 header, 320/1244/320 본문 그리드와 중앙 독립 scroller부터 교체한다.
3. 헤더·공지·양쪽 레일을 ui-inventory 순서로 구성하고 명시 치수를 적용한다.
4. 카드에 기본 배당 3줄, 상세에 필터/마켓 아코디언을 연결한다. 팀/리그/시간/상태/스코어/배당/추가 마켓 수를 같은 데이터에서 읽는다.
5. 액션/슬립/금액/목록 필터/검색을 연결한다. 기존 배너/사진/폰트를 우선 재사용한다.
6. 아래 짧은 구현 확인 후 기존 ALDEBARAN 주소에 배포하고 현지 STATE에 실제 결과를 기록한다.

## 구현 담당의 짧은 확인 — 별도 QA 단계가 아님

- 기존 빌드/타입 검사 한 번. 빌드에 포함된 검사 중복 금지.
- 1920×1080 초기 화면 한 장: 10개 메뉴/공지 우측 5개 버튼/좌우320/중앙 두609/카드36px/상세34px 및 실제 사진·아이콘 확인.
- 오른쪽만 내려 왼쪽 선택 경기 위치 유지 확인. 이후 왼쪽만 내려 오른쪽 위치 유지 확인. 상단 종목탭·선택경기제목·마켓탭 고정 확인.
- 경기 전환 한 번 → 오른쪽 제목/마켓 변경. 왼쪽 배당 하나 선택 → 오른쪽 동일 선택/슬립 표시 → 해제. 실제 베팅 제출 없음.
- 리그와 마켓 아코디언 각 한 번, 검색 한 번, 새 퀵메뉴/안내 메뉴의 실제 내용 있는 연결 한 번 확인.
- 나머지 전체 미감은 사용자 판단. 고치지 못한 항목을 숨기지 말고 짧게 보고한다.

commit/deployment ID, 실제 수정 파일, 실제 확인한 범위만 현지 기록에 추가한다.
