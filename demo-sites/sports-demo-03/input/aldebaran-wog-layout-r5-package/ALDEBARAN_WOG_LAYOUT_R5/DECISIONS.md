# ALDEBARAN R5 — 결정 추가분

현지 DECISIONS의 다음 번호로 병합한다.

| 결정 | 이유 |
| --- | --- |
| WOG 해외형의 전체 구조 이식 | 실제 제품처럼 보이지 않는다는 사용자 피드백에 대한 새 방향 |
| 기존 헤더/레일/중앙 너비도 변경 | 중앙만 바꾸거나 과거 프레임을 고수하면 레퍼런스의 밀도와 비율이 재현되지 않음 |
| 1920 고정, 반응형 미구현 | 사용자 명시 요구. 1363 관측 폭은 레퍼런스 분석용일 뿐 |
| 좌우 레일 320, 중앙1244, 중앙 내부609/8/609 | WOG의 외곽 8/열간격10/중앙패딩8/테두리1에서 계산 |
| 헤더62 + 공지36, 10개 메뉴 | 확인한 WOG 구성/수치 유지 |
| 중앙 기본은 경기 목록 + 상세 마켓 | 최신 WOG 해외형 배치를 우선. 과거 큰 축구 트래커/축구만 노출안은 현재 기본 화면에서 대체 |
| 재질은 ALDEBARAN 그대로 | 무광 차콜, 플랫 버튼, 오렌지/흰색. 레퍼런스의 골드/실버/흰 패널은 미이식 |
| 숫자/사용자 정보는 ALDEBARAN 데이터 | WOG 로그인 계정·잔액·실시간 수치를 데모 데이터로 복제하지 않음 |
| 헤더 메뉴와 서비스 요소의 작동 범위 | 동일한 UI 역할을 기존 기능 또는 구체적인 데모 내용으로 연결; 실제 거래 백엔드 신설 아님 |
| 독립 스크롤 + 상단 컨트롤 고정 | 선택 경기의 문맥을 유지하며 상세 마켓 탐색 |
| 구현 확인만 수행 | 별도 QA/Jev/polish로 시간 늘리지 않고 공개 화면 사용자 피드백으로 진행 |

1920 목표 치수는 CSS에서 계산한 값이다. 이 환경에서 1920 viewport로 직접 캡처·실측했다는 뜻이 아니다. 제공 PNG는 1916×941이며 그 차이를 확대/축소로 보정해 소스인 것처럼 표시하지 않는다.
