# ALDEBARAN — HEADER R3 준비 상태

## 배경과 현재 상태

- 사용자는 ALDEBARAN의 차콜·주황 배색을 수용했다.
- R2 비대칭 헤더는 구현되었으나 사용자가 전체 균형과 본문 정렬을 수정 요청했다.
- 사용자 요구는 엠블럼 제거, 작은 중앙 레터링, 왼쪽 레일 끝에 맞춘 전체 높이 세로선, 얇은 공지, 중앙 폭 안의 메뉴, 같은 메뉴 줄로 내린 오른쪽 계정 버튼이다.
- 이 패키지는 위 요구를 합친 구현 입력이다. 실제 앱 소스 수정·앱 빌드·공개 배포는 이 패키지 작성 과정에서 수행하지 않았다.
- 최신 commit / deployment / project ID는 현지 운영 문서에서 확인한다. 이 패키지의 과거 정보로 대체하지 않는다.

## 실행 순서

1. 현지 최신 문서·헤더 소스·본문 셸 값을 확인한다. 레일 끝선은 내부 텍스트/버튼 끝이 아닌 레일의 외곽 경계를 기준으로 한다.
2. 기존 헤더의 브랜드 / 중앙 / 오른쪽 계정 구역을 본문 열에 맞춘다. 기존 폭·간격 변수를 재사용하고 아래 본문은 움직이지 않는다.
3. 엠블럼 제거, 레터링 축소·중앙 배치, 주황 세로선의 전체 높이 연결을 적용한다.
4. 계정 컨트롤을 아래 오른쪽으로 이동한다. 공지는 장식 없이 텍스트 한 줄로 줄이고 원래 클릭 동작은 유지한다.
5. 7개 메뉴를 중앙 가용 폭 안에서 재분배한다. 이전 flex 최소 폭과 padding 때문에 이벤트가 오른쪽으로 넘어가는 충돌을 제거한다.
6. 짧게 확인하고 기존 공개 주소로 배포한다. 같은 초기 화면 한 장에 전체 헤더와 양쪽 레일 상단이 보이게 보고한다.

## 필요한 확인만 수행

- 기존 프로젝트 통상 빌드/타입 검사.
- 1920px 셸에서 로고 크기, 왼쪽 세로선의 정렬·상하 접점, 얇은 공지, 메뉴/계정 분리 확인.
- 이벤트의 버튼·hover 면까지 중앙 영역에 포함되는지 확인. 로고나 메뉴를 잘라서 맞춘 상태는 완료가 아니다.
- 대표 메뉴 전환 후 실시간 스포츠로 복귀, 옮긴 공지·계정 버튼의 기존 연결 확인. 실제 인증/거래 제출은 하지 않는다.
- 같은 화면에서 본문 레일 위치와 빈 중앙 유지 확인. 슬립 전체·숨겨진 모든 상태를 다시 테스트하지 않는다.

별도 QA 보고서·Q번호 감사·Jev 실행·추가 자동화 테스트 파일은 요구하지 않는다. 공개 화면 확보가 막히면 같은 캡처를 장시간 반복하지 말고 한계를 간단히 보고한다.
