# ALDEBARAN — HEADER R3 정렬 명세

## 목표

사용자가 선택한 비대칭 2단 헤더를 유지하면서 본문의 세 열과 연결한다. 로고 영역과 메뉴 영역을 따로 임의의 폭으로 잡지 않는다. 이번 작업은 정렬과 공간 배분 수정이며 현재 수용된 차콜·주황·흰색 테마를 다시 디자인하는 단계가 아니다.

## 사용자 확정 요구

| 영역 | 요구 |
| --- | --- |
| 왼쪽 브랜드 | 엠블럼 제거, 원본 비율의 작은 레터링만 영역 중앙에 표시 |
| 브랜드 오른쪽 경계 | 왼쪽 레일의 오른쪽 외곽 끝선과 같은 x 좌표 |
| 주황 세로선 | 브랜드 경계에 놓고 헤더 위·아래 끝까지 연결 |
| 상단 공지 | 텍스트만 깔끔한 한 줄. 현재보다 낮은 행. 기존 공지 동작 유지 |
| 하단 메뉴 | 7개 모두 중앙 콘텐츠 가로 범위 안에 배치. 이벤트가 오른쪽 레일 영역을 침범하지 않음 |
| 하단 계정 | 로그인/회원가입을 메뉴와 같은 줄로 내려 오른쪽 레일 위에서 오른쪽 정렬 |
| 공간 배분 | 공지 행을 줄여 메뉴 행에 세로 여유 확보. 가로 메뉴 영역은 계정 영역과 분리되어 좁아짐 |

브랜드 영역은 계속 두 행 전체를 차지한다. 레터링을 페이지 전체 중앙으로 옮기는 의미가 아니다. 주황 세로선을 본문 아래까지 연장하지 않는다. 오른쪽 영역에 새 세로선이나 주황 테두리를 만들지 않는다.

## 본문과 공유할 기준

본문과 같은 고정 셸 안에서 다음 관계를 만족시킨다.

- 브랜드 오른쪽 경계 = 왼쪽 레일 오른쪽 경계.
- 메뉴 시작 = 중앙 콘텐츠 시작, 메뉴 끝 = 중앙 콘텐츠 끝. 기존 열 사이 간격은 유지한다.
- 계정 버튼 영역 시작/끝 = 오른쪽 레일 시작/끝. 버튼 묶음은 그 안에서 오른쪽 정렬한다.
- 헤더와 본문은 같은 외곽 여백·너비·열 간격을 따른다. viewport 전체를 기준으로 absolute/fixed 위치를 새로 잡지 않는다.
- 브랜드는 왼쪽 레일에 대응하는 폭에서 수평 중앙, 헤더 전체 높이에서 수직 중앙으로 둔다. 셸 바깥쪽 여백이 브랜드 배경에 포함되어도 그 여백 때문에 로고 중심이 치우치지 않도록 한다.

예제의 기존 프레임 대입값은 다음과 같다. **현지 최신 값이 다르면 최신 본문 값으로 연결하며 본문을 예제 숫자로 바꾸지 않는다.**

| 프레임 항목 | 예제 대입값 |
| --- | --- |
| 셸 폭 | 1920px |
| 좌우 외곽 여백 | 각각 12px |
| 왼쪽 레일 | 272px |
| 중앙 | 1280px |
| 오른쪽 레일 | 320px |
| 열 사이 간격 | 각각 12px |

계산: `12 + 272 + 12 + 1280 + 12 + 320 + 12 = 1920`.

셸 왼쪽을 0으로 하면 왼쪽 레일은 `12~284`, 중앙은 `296~1576`, 오른쪽 레일은 `1588~1908`이다. 따라서 예제의 주황선 오른쪽 경계는 `284`에 맞춘다. 브랜드 폭에 단순히 `272px`만 넣으면 외곽 여백 때문에 정렬이 어긋날 수 있다. 이는 좌표 설명 예제이며 공개 사이트를 이번 패키지에서 다시 측정한 결과는 아니다.

## 높이와 크기 — 조정 가능한 시작값

| 요소 | 시작값 | 의미 |
| --- | --- | --- |
| 전체 헤더 | 현재 총 높이 유지. 예제 104px | 높이를 더 늘리지 않음 |
| 공지 행 | 28px | 텍스트 한 줄과 작은 상하 여백 |
| 메뉴/계정 행 | 76px | `104 - 28 = 76` |
| 메뉴 버튼 높이 | 42px | 기존 높이를 유지하고 행 내부 여백 확보 |
| 계정 버튼 높이 | 38px | 현재 디자인 우선, 메뉴 행 중심선에 배치 |
| 레터링 폭 | 216px | 원본 1101×120 비율 유지 |
| 세로선 | 1px × 헤더 전체 높이 | 위아래 여백 없이 연결 |
| 메뉴 사이 간격 | 8px | 7개 메뉴를 가용 폭에 맞게 균등 분배 |

레터링 높이 계산: `216 × 120 ÷ 1101 ≈ 23.54px`. 예제 왼쪽 레일 폭 272px에서 좌우 여유는 `(272 - 216) ÷ 2 = 28px`씩이다. 이 수치들은 사용자가 확정한 픽셀값이 아니며 실제 폰트/여백을 보고 최소 조정한다.

메뉴 예제는 좌우 안쪽 여백 12px씩, 간격 8px 여섯 개를 둔다. 버튼 너비는 `(1280 - 24 - 48) ÷ 7 ≈ 172.57px`다. 기존의 min-width:136px/max-width:180px/flex 배치를 함께 남기지 않는다. 이벤트 버튼의 상자 전체가 메뉴 끝선 안에 들어와야 한다.

## 공지와 계정

- 공지는 NOTICE와 본문 텍스트만 남긴다. 현재 벨/화살표 장식은 공지 표현에서 제거하고 별도 배경 박스를 만들지 않는다.
- 본문이 길면 한 줄 말줄임한다. 텍스트는 기본 12px, line-height 18px를 시작값으로 하되 기존 폰트를 유지한다.
- 기존 공지 버튼/링크와 핸들러를 재사용한다. 시각적으로 단순해져도 클릭 기능은 제거하지 않는다.
- 공지 영역에는 로그인·회원가입을 남기지 않는다. 오른쪽 위에는 새 기능이나 채움용 장식을 추가하지 않는다.
- 기존 로그인/회원가입 순서, 컬러, 로그인 이후 표시 분기, 핸들러를 그대로 아래 오른쪽으로 이동한다.
- 공지와 메뉴 사이에 기존 중립 회색 구분선은 유지할 수 있다. 사용자 참고 이미지의 주황 가로선은 정렬 가이드이므로 실제 선으로 복제하지 않는다.

## 메뉴와 상태

순서 유지: 스포츠 / 실시간 스포츠 / E스포츠 / 카지노 / 슬롯 / 미니게임 / 이벤트.

현재 흰색 일반 텍스트, 주황 단색 선택 면·짙은 선택 글자, 작은 사각 라운드, 짧은 색상 hover를 유지한다. 메뉴 크기나 배경을 새 컨셉으로 변경하지 않는다. 선택할 때 크기/위치가 변하지 않게 한다. 모바일 메뉴, 슬라이딩 캡슐, 새 아이콘은 추가하지 않는다.

## 실제 소스 연결

제공 CSS는 `.aldebaran-site .ab-header3` 범위로 제한한다. 프레임 변수는 기존 본문 값에 연결한다. 제공 TSX를 통째로 도입하거나 현재 컴포넌트에 같은 구조를 적용하는 것 중 작은 변경을 선택한다. 기존 헤더·공지 중복 렌더, 오래된 46/58 행 값과 344px 브랜드 값, 헤더 높이 offset 충돌을 정리한다.

중앙은 계속 비어 있다. 레일 위치·디자인·배너를 바꾸거나 빈 중앙을 안내 텍스트/스켈레톤으로 채우지 않는다.
