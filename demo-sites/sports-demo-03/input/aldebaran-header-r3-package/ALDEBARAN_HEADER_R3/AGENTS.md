# ALDEBARAN — HEADER R3 작업 규칙

2026-09-21 · R2 헤더 균형 수정용 변경분

## 적용 우선순위

- 사용자 최신 피드백 > 본 패키지의 정렬 관계 > 구현 예제의 시작 치수.
- 실제 Windows 앱의 최신 네 운영 문서에 병합한다. 과거 실행 기록·배포 ID·사용자 수정은 보존한다.
- 운영 문서는 AGENTS / STATE / DESIGN_SPEC / DECISIONS 네 개를 유지한다.
- R2의 브랜드 폭 344px, 엠블럼+레터링, 짧은 세로선, 공지·계정 같은 줄, 오른쪽 전체 폭 메뉴 규칙은 이번 R3로 교체한다. 이전 지시와 중복 적용하지 않는다.

## 범위

- 현재 ALDEBARAN의 헤더만 수정한다. 본문의 왼쪽 레일 오른쪽 끝과 오른쪽 레일 시작점을 헤더 정렬 기준으로 사용한다.
- 본문 열을 헤더에 맞춰 움직이지 않는다. 같은 1920px 고정 셸, 외곽 여백, 열 너비, 열 사이 간격을 그대로 따른다.
- 레터링만 렌더하고 엠블럼 DOM은 헤더에서 제거한다. 원본 엠블럼 파일을 삭제하거나 다른 앱에서 제거하지 않는다.
- 현재 수용된 배색·버튼 표현·폰트·메뉴 순서·기능을 유지한다. 중앙 카드/트래커는 렌더하지 않는다.
- 이미지 재생성, 로고 편집, 외부 디자인 플러그인 사용은 하지 않는다.

## 구현

- 예제는 실제 앱에서 빌드되지 않은 연결 참고 파일이다. 더 작은 마크업/CSS 수정으로 요구를 충족할 수 있으면 현지 컴포넌트를 수정한다. 파일명 교체 자체가 목적이 아니다.
- 메뉴 상태, 로그인 상태 분기, 공지·브랜드·계정 이벤트는 기존 코드를 재사용한다. 별도 헤더 상태나 무동작 임시 버튼을 만들지 않는다.
- 정렬은 공통 CSS 값과 grid로 해결한다. 매 프레임 DOM 측정, resize listener, JS 좌표 보정, transform으로 눈대중 이동을 추가하지 않는다.
- R2 헤더 전용 규칙 중 충돌하는 부분을 교체한다. 새 CSS 뒤에 무조건 !important를 덧붙이는 방식은 피한다.
- 로그인·회원가입은 메뉴와 같은 줄의 오른쪽 레일 위에 둔다. 메뉴를 계정 영역 밑에 통과시키거나 overflow:hidden으로 잘라 숨기지 않는다.
- 설치된 Impeccable을 사용할 경우 layout 관련 지침만 필요한 부분에 참고한다. 재설치·전면 디자인 검사·자동 QA 연결은 하지 않는다.

## 완료 방식

- 구현자가 통상 빌드/타입 확인과 바뀐 헤더의 짧은 확인만 수행한다. 빌드에 포함된 타입 검사를 중복하지 않는다.
- 별도 QA 스레드·Jev·전체 상태 재감사·모바일 확대 작업은 실행하지 않는다.
- 기존 ALDEBARAN 공개 주소에 업데이트한다. MERCURY/SIRIUS는 수정·배포하지 않는다.
- 실제 변경 파일, 확인 범위, 배포 결과를 최신 STATE에 기록한다. 미확인 항목을 PASS로 보고하지 않는다.
- 디자인 판단은 공개 결과를 본 사용자에게 맡기고 다음 부위 작업으로 자동 확장하지 않는다.
