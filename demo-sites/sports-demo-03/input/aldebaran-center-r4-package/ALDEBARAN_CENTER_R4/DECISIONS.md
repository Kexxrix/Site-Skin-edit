# ALDEBARAN R4 — 결정 병합용 추가분

현지 최신 기록 뒤에 추가하고 현지 다음 번호를 사용한다. 과거의 중앙 비움은 이전 단계 완료 기록으로 남기되 현재 활성 지시에서는 아래 내용으로 대체한다.

| 항목 | 결정 / 근거 |
| --- | --- |
| 중앙 구현 시작 | 사용자 신규 승인. 이전 빈 중앙 규칙 해제 |
| 입력 방식 | 최신 첨부 레이아웃 이미지는 사용하지 않고 글로 명세 |
| 분할 | 기존 중앙 영역의 좌우를 동일 너비로 분할. 외부 양쪽 레일 유지 |
| 왼쪽 | 홈 로고–홈 이름–VS–원정 이름–원정 로고, 아래 기본 배당의 카드 목록 |
| 오른쪽 | 선택 경기 트래커 위, 세부 마켓 아래 |
| 트래커 참조 | 이전 Sportradar 공식 데모의 정보 구조 참고, ALDEBARAN 테마의 자체 데모 구현 |
| 데이터 연결 | 기존 경기/마켓/이미지/슬립 재사용, 선택 경기 ID와 배당 ID의 일관성 유지 |
| 축구 외 | 종목에 맞는 점수·상태·통계로 전환. 축구 필드 강제 재사용 금지 |
| 헤더 | R3.1 미반영 보정만 중앙 작업과 함께 반영 |
