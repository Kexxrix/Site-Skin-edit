# ALDEBARAN R4 — 중앙 첫 구현 준비

## 현재까지

- ALDEBARAN 프레임과 비대칭 헤더가 공개되어 있고 중앙은 이전 단계 지시에 따라 비어 있었다.
- 직전 공개 확인에서 헤더 총 높이104px, 공지28px, 하단76px, 중앙 콘텐츠 폭1280px을 확인했다.
- 헤더 R3.1 수정 자료는 전달되었다. 현지에서 반영되었는지는 작업 시작 시 최신 소스로 확인한다. 이미 반영된 보정은 다시 중복하지 않는다.
- 사용자는 중앙을 절반으로 나누어 왼쪽 베팅 카드 / 오른쪽 트래커와 세부 베팅을 함께 구현하도록 새로 지시했다.
- 최신 첨부 이미지는 구현 입력으로 사용하지 않았다. 작업 자료는 사용자 텍스트 요구를 구체화한 명세다.
- 이전 Sportradar 공식 데모를 다시 열어 확장 스코어보드·타임라인·필드·하단 탭이 보이는 상태를 확인했다. 참고 URL에 선택된 경기는 종료 상태였으며 생중계 동작을 검증한 것은 아니다.

## 실행 순서

1. 기존 데이터·현재 노출 조건·종목 필터·검색·슬립 추가 함수를 찾는다. 남아 있는 중앙 렌더 차단만 해제한다.
2. 중앙 두 열을 동일 너비로 만든다. 좌우 외부 레일과 헤더 그리드는 바꾸지 않는다.
3. 왼쪽 카드의 리그/상태/팀/점수/기본 배당을 연결한다. 초기 선택 경기의 카드와 우측 데이터가 일치하도록 한다.
4. 우측 축구 트래커의 점수·타임라인·필드·통계·탭을 구현한다. 타 종목은 종목에 맞는 점수/상태/통계 보기를 연결한다.
5. 트래커 아래 세부 마켓을 구성하고 기존 베팅슬립 함수에 연결한다. 좌우 중복 선택 ID를 통일한다.
6. 헤더 R3.1 미반영분을 합친다. 공개 초기 화면과 대표 동작만 확인한 뒤 같은 주소로 배포한다.

## 짧은 완료 확인

- 기존 빌드/타입 검사 한 번. 빌드에 포함된 검사는 중복 실행하지 않는다.
- 1920px 초기 화면 한 장에서 중앙 좌우 동등 폭, 카드 팀 행, 오른쪽 트래커 및 첫 세부 마켓이 보이는지 확인한다.
- 다른 경기 선택 한 번: 카드 강조·트래커·점수·세부 마켓이 같은 경기로 변하며 기존 슬립은 유지되는지 확인한다.
- 왼쪽 기본 배당 선택 한 번과 오른쪽 같은 배당의 상태 확인, 오른쪽 세부 배당 한 번을 기존 슬립에 연결한다. 실제 베팅 제출은 하지 않는다.
- 긴 팀명/0점/세 자리 점수에 대한 렌더를 구현 중 해당 데이터로 확인한다. 자료가 없다는 이유로 전체 경기 데이터 생성 작업을 새로 시작하지 않는다.
- 종목 또는 검색 한 번으로 목록과 선택 경기의 일치 확인. 빈 결과면 이전 경기 정보가 남지 않아야 한다.
- 더보기/맨 위로 이동은 기존 방식 재사용이며 불필요한 재검수는 하지 않는다.

전체 실제 스코어/배당 수집, 외부 실시간 피드, 실거래, 종목별 정교한 필드 애니메이션, 모바일은 이번 범위 밖이다.

## 구현 후 현지 기록

실제 수정 파일, 실제 재사용 데이터 범위, 트래커 구현 범위, 기본 확인 결과, commit/deployment ID와 공개 화면을 기록한다. 이 패키지 작성 시 실제 앱 빌드·배포는 미실행이다. 공개 버전 번호를 R4와 자동으로 같게 잡지 않는다.
