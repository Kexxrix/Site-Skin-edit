# ALDEBARAN R14 결정 기록 — 기존 이력에 추가

2026-09-23

1. R13 적용 후 사용자가 숫자와 화살표의 균형/정렬을 승인하지 않았다. R13의 전용 화살표 추가안을 이번 버튼에서 폐기한다.
2. 추가 마켓 존재와 상세 진입을 나타내는 버튼은 유지한다. 숫자 뒤 +를 붙인 단일 텍스트 방식으로 전환한다. 12px/700을 숫자와 기호에 동일하게 적용한다.
3. R13의 11px 숫자, 6×10 SVG, stroke 1.25px 및 숫자/SVG 간격 3px는 이번 버튼의 최종 사양에서 제외한다. 버튼 높이24/라운드5/내용 기반 폭/노랑과 짙은 전경은 이어간다.
4. 모바일 상세 진입은 버튼의 장기적 역할 설명이다. 이번 작업은 현재 1920 데스크톱 안에서 표시를 수정하며 모바일 개발은 포함하지 않는다.
5. 사용자가 제공한 Banner_01~06 원본을 우측 안내 배너에 의미별 순서로 연결한다. 기존 img_banner_01/03/04/05/06/07 번호와 혼동하지 않는다.
6. 사용자가 이번에 요청한 것은 이미지 교체다. 이전에 지정한 검정40% 오버레이, 문구와 텍스트 정렬, 박스 크기/라운드/기능은 유지한다. 새 어둡기 조정은 추가하지 않는다.
7. 사용자가 완료를 알린 좌측 최신 인기 게임 LIVE 노란색 변경은 보존한다. 이번 범위는 숫자+ 버튼과 배너 6장 교체의 두 건이다.
