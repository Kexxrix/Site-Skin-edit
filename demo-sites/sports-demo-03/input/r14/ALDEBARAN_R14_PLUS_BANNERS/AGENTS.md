# ALDEBARAN R14 적용 지침 — 기존 운영 문서에 병합

- 작업은 추가베팅 버튼의 숫자+ 표시와 우측 안내 배너 6장 교체, 두 항목으로 한정한다.
- sports-demo-03의 최신 현지 소스에서 최소 수정한다. R13 완료 이전으로 reset하거나 과거 패키지를 통째로 재적용하지 않는다.
- 기존 운영 문서를 보존하고 이 변경분만 병합한다.
- 추가베팅은 기존 버튼 요소/동적 개수/이벤트/접근성 이름을 유지한 채 내부 라벨과 관련 스타일만 수정한다.
- 숫자와 +는 하나의 문자열이다. 별도 SVG/아이콘/가상요소/상첨자/별도 span으로 +를 구성하지 않는다.
- 현재 표시 개수의 데이터 의미와 계산을 변경하지 않는다. +는 추가 마켓 진입을 나타내는 접미 기호이며 개수에 1을 더하거나 8 이상 등으로 다시 계산하는 지시가 아니다.
- 기존 aria-label의 팀명과 정확한 상세 마켓 개수 설명을 유지한다. 텍스트를 8+로 바꾸면서 접근성 이름을 8 이상으로 바꾸지 않는다.
- 숫자 라벨 클릭도 기존 추가베팅 동작으로 처리되게 한다. 상위 카드의 비버튼 클릭 분리 로직을 유지한다.
- 국내형/해외형이 같은 버튼을 공유하면 표시만 일관되게 적용하고 각 모드의 동작 차이를 보존한다.
- 화살표 전용 미사용 규칙만 정리한다. 다른 곳의 ChevronRight나 공용 SVG 스타일을 삭제/변경하지 않는다.
- 배너 원본 파일은 assets/banners에서 그대로 복사한다. 새 경로는 현지 공개 자산 구조에 맞게 연결하고 대소문자 및 여섯 역할을 확인한다.
- 기존 이미지 파일 번호는 01/03/04/05/06/07이고 새 파일 번호는 01~06이다. 숫자를 그대로 대입하지 말고 banner-map.json의 역할로 매핑한다.
- 배너의 기존 HTML 문구/텍스트 수직 중앙 정렬/간격/좌측 여백/라운드/크기/링크를 보존한다. 예전 아이콘을 복원하지 않는다.
- 기존 검정 40% 오버레이는 유지하되 두 번 적용하지 않는다. 이미지 파일을 편집하거나 텍스트까지 어둡게 만들지 않는다.
- 이번 패키지는 미래 모바일 버튼의 의미만 기록한다. 반응형 레이아웃/라우트/상세 페이지/새 이동 동작 구현은 범위가 아니다.
- WOG 재참조, 이미지 생성, 새 플러그인/의존성, 별도 QA/Jev, 다른 사이트 이식 및 GitHub 백업 동기화는 수행하지 않는다.

## 한정 확인 및 완료 보고

1. 1920/브라우저 100%의 기존 로컬 화면에서 8+, 12+ 등 한 자리·두 자리 숫자와 +의 균형, 라벨 전체 중앙, 잘림 여부를 눈으로 확인한다. 값만 확인하고 시각 검증 완료로 보고하지 않는다.
2. 운영 데이터를 바꾸지 않고 기존 데이터 또는 임시 컴포넌트 미리보기로 자릿수를 확인한다. 수치상 중앙과 실제 보이는 중앙의 차이가 있으면 버튼 라벨 전체를 대상으로 최소 조정하며 숫자와 +를 분리하지 않는다. 조정값과 이유를 보고한다.
3. 추가베팅 버튼의 기존 클릭/키보드 동작을 짧게 확인한다. 배당 토글/부모 카드 선택 처리를 새로 구현하지 않는다.
4. 배너 6장의 역할/파일 연결, 원본 비율, 텍스트 가독성, 기존 오버레이 한 겹을 확인한다. 헤더·좌측 CASINO/SLOT까지 자산 교체가 전파되지 않아야 한다.
5. 기존 build 1회, 빌드에 포함되지 않은 필수 타입 검사는 현지 규칙에 따른다. 실패 해결에 필요한 경우만 재실행한다. 새 회귀 테스트를 작성하지 않는다.
6. 기존 배포 흐름으로 같은 ALDEBARAN 주소에 반영하고 변경 부위 캡처, 실제 commit/배포 결과와 미확인 사항을 보고한다. 기술 검사 통과와 사용자 미감 승인을 구분한다.
