1. 추가베팅 버튼을 숫자+로 변경
   - 기존 화살표 SVG를 제거하고 8+, 12+처럼 숫자 바로 뒤에 +를 표시합니다.
   - 기존 동적 마켓 수와 +를 공백 없는 하나의 문자열, 하나의 span에 넣습니다.
   - 숫자와 + 모두 현재 폰트 / 12px / 굵기 700. 하나의 라벨 전체를 중앙 정렬합니다.
   - 버튼 높이 24px, 라운드 5px, 노랑 #F1B000, 전경 #171717, 우측 정렬 유지.
   - 좌우 패딩 각각 5px. 폭은 내용에 따라 증가하며 고정 폭으로 되돌리지 않습니다.
   - 기존 상세 마켓 열기/선택과 접근성 이름, 클릭/키보드 처리를 유지합니다.
   - 추가 마켓의 존재·개수와 상세 진입을 나타내는 버튼입니다. 지금은 데스크톱 동작만 유지합니다.
   - 향후 모바일에서 상세 베팅으로 이동할 의도는 기록하되 이번에 모바일 구현은 하지 않습니다.

   Banner_01.png → 텔레그램 고객센터
   Banner_02.png → 텔레그램 공식채널
   Banner_03.png → ALDEBARAN 이용안내

   Banner_05.png → 스포츠 라인업
   Banner_06.png → 미성년자 이용불가
   - assets/banners/의 원본 PNG를 그대로 사용합니다. 6장 모두 306×61px RGBA입니다.
   - 제목/서브텍스트/정렬/크기/라운드/동작은 현재 구현을 유지합니다.
   - 기존 검정 #000000 40% 오버레이는 이미지 위·텍스트 아래의 한 겹으로 유지합니다.
   - 원본 이미지에 오버레이를 굽거나 새로운 어둡기 필터를 추가하지 않습니다.
