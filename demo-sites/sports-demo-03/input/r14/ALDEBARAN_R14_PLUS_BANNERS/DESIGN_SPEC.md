# ALDEBARAN R14 — 상세 사양

## 1. 추가베팅 버튼: 숫자+

### 역할

버튼은 추가 마켓의 존재와 현재 마켓 개수를 알리면서 상세 베팅을 여는 진입점이다. 데스크톱에서 오른쪽에 상세 마켓이 이미 보이더라도 표시와 기존 클릭 동작을 유지한다. 향후 모바일에서는 같은 의미의 버튼을 상세 베팅 진입에 사용할 계획이며 이번에는 모바일 기능을 만들지 않는다.

### 표시와 치수

| 항목 | 이번 적용값 |
| --- | --- |
| 라벨 | 현재 개수 뒤에 ASCII +를 공백 없이 붙인 하나의 문자열: 8+, 12+ |
| 구조 | 버튼 안 하나의 span 또는 하나의 텍스트 노드. 별도 화살표 없음 |
| 폰트 | 현재 사용 중인 폰트 유지, 숫자와 + 모두 12px / 700 |
| line-height | 12px를 시작값으로 사용, 실제 화면에서 라벨 전체의 시각적 중앙 확인 |
| letter-spacing | 0 |
| 내부 정렬 | 라벨 전체 수평·수직 중앙. 요소 사이 gap은 0 |
| 버튼 높이 | 24px |
| 좌우 패딩 | 각각 5px |
| 라운드 | 5px |
| 배경 / 전경 | #F1B000 / #171717 |
| border | 현재 노랑 1px border 유지 |
| 폭 | 내용 기반. 자릿수 증가 시 자동 증가 |
| 위치 | 현재 카드 상단 우측 정렬 유지 |

숫자와 +에 서로 다른 글꼴·크기·굵기·위치 보정을 주지 않는다. +를 SVG나 가상요소로 바꾸거나 상첨자로 올리지 않는다. 라벨 전체를 동일한 텍스트 기준선으로 렌더링한다. 브라우저와 글꼴의 실제 결과는 100% 화면에서 확인해야 하며 이 문서의 수치만으로 시각 승인 완료를 주장하지 않는다.

기존 숫자 span을 재사용해 내용을 하나의 문자열로 바꾸거나 전용 label span으로 교체할 수 있다. 예전 __count의 11px 규칙과 __chevron의 크기/stroke/gap 규칙이 새 라벨에 남지 않도록 정리한다. 참고 CSS는 기존 ab5-market-open에만 병합한다.

현재 개수 n의 표시를 String(n) + '+'로 구성한다. 8이나 12를 하드코딩하지 않으며 계산식/마켓 목록/추가 개수 산정은 바꾸지 않는다. 기존 aria-label이 팀명과 상세 마켓 n개를 설명한다면 그대로 유지한다. 현재 노출 조건과 0개 처리도 보존한다.

버튼 전체 클릭과 키보드 동작을 유지한다. 해외형에서 해당 경기 상세를 표시하는 기존 처리와 국내형의 현재 동작을 그대로 사용한다. 별도의 모바일 전환이나 새 URL 라우트를 추가하지 않는다.

## 2. 우측 안내 배너 6장

기존 안내 배너의 배경 이미지만 아래 역할에 맞춰 교체한다. 제목 표기는 대상을 구분하기 위한 것으로 현재 HTML 문구를 다시 쓰라는 지시가 아니다.

| 화면 순서 | 대상 | 새 원본 | 이전 자산명 참고 |
| --- | --- | --- | --- |
| 1 | 텔레그램 고객센터 | Banner_01.png | img_banner_01.png |
| 2 | 텔레그램 공식채널 | Banner_02.png | img_banner_03.png |
| 3 | ALDEBARAN 이용안내 | Banner_03.png | img_banner_04.png |
| 4 | 실시간 중계 안내 | Banner_04.png | img_banner_05.png |
| 5 | 스포츠 라인업 | Banner_05.png | img_banner_06.png |
| 6 | 미성년자 이용불가 | Banner_06.png | img_banner_07.png |

새 원본은 모두 306×61px RGBA다. 파일명 대소문자를 그대로 취급한다. 이전 경로/이름은 역할 파악용 이력이며 현재 소스에서 실제 매핑을 확인한다.

- 현재 배너 박스의 폭/높이/4px 라운드/간격/클릭 영역을 유지한다. 원본 높이 61px라는 이유로 현재 CSS의 소수 px 치수를 임의로 반올림하지 않는다.
- 기존 background-size/object-fit 처리와 배치를 유지하며 이미지를 늘여 찌그러뜨리거나 내용 구성을 새로 크롭하지 않는다.
- 기존 제목과 서브텍스트, 주황색 제목/보조 글자 색, 좁힌 줄 간격과 두 줄 묶음의 세로 중앙 정렬을 유지한다.
- 기존 아이콘 삭제 상태를 유지한다. 새 PNG에는 HTML 텍스트를 굽지 않는다.
- 검정 #000000/40% 오버레이 지시는 변경되지 않았으므로 유지한다. 단 한 겹만 적용하며 텍스트는 그 위에 둔다.
- 레이어 순서: 새 배경 이미지 → 기존 40% 검정 오버레이 → 현재 제목/서브텍스트.
- 이미 어두운 새 원본에 별도 brightness/filter/두 번째 오버레이를 추가하지 않는다. 원본을 수정한 파생 PNG도 만들지 않는다.
- 현재 링크/클릭 핸들러와 접근성 이름은 유지한다. 장식용 배경 이미지 때문에 중복 접근성 텍스트를 추가하지 않는다.

assets/banners의 파일을 현지 공개 자산 폴더에 복사하고 기존 배너 데이터의 이미지 참조만 갱신한다. resources/banner-map.json의 권장 URL은 현지 경로가 맞는 경우에만 사용한다. 공유 자산 경로를 덮어써 다른 사이트에 영향을 주지 않는다.

## 완료 화면 기준

추가베팅 버튼은 8+·12+가 하나의 라벨로 보이고 숫자와 기호의 기준선/굵기가 일관되어야 한다. 버튼의 높이와 카드 내 위치는 유지한다.

우측 6개 배너는 역할별 새 그림으로 바뀌고 현재 문구가 위에서 읽혀야 한다. 헤더 영상·좌측 카지노/슬롯 이미지·완료된 LIVE 칩·그 외 중앙 UI는 현재 상태를 유지한다.
