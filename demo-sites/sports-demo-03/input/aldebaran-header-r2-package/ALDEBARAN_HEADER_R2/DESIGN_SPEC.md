# ALDEBARAN — 비대칭 헤더 1번 안

HEADER R2 · 2026-09-21

## 승인 방향

왼쪽 브랜드 영역이 헤더 두 행 높이를 차지한다. 오른쪽 위는 공지와 로그인/회원가입, 오른쪽 아래는 기존 주요 메뉴다. 차콜·주황·흰색과 제공 PNG를 유지하면서 **영역의 배치와 면의 차이**로 기존 두 브랜드와 구분한다.

현재 배색은 사용자 수용 상태다. 테마 HEX를 다시 선정하거나 전체 면의 밝기를 조정하지 않는다.

## 배치 시작값

| 영역 | 초기 크기/배치 |
| --- | --- |
| 헤더 전체 | 기존 셸 너비, 높이 104px |
| 왼쪽 브랜드 | 폭 344px, 두 행 전체 높이 |
| 오른쪽 상단 | 높이 46px, 공지 왼쪽/계정 버튼 오른쪽 |
| 오른쪽 하단 | 높이 58px, 7개 메뉴 가로 정렬 |
| 브랜드 안쪽 여백 | 좌우 20px |
| 엠블럼 / 타이포 간격 | 12px |
| 엠블럼 | 44×44px, contain |
| 타이포 | 폭 248px, 높이 auto |
| 오른쪽 가로 여백 | 24px |
| 메뉴 버튼 | 높이 42px, 간격 8px, 폭 136~180px 범위 |

계산: `46 + 58 = 104px`. 브랜드 안쪽 가로는 `20 + 44 + 12 + 248 + 20 = 344px`이다. 기존 셸이 1920px일 때 오른쪽 가용 폭은 `1920 - 344 = 1576px`이다. 타이포 높이는 `248×120÷1101 ≈ 27.03px`로 원본 비율을 유지한다.

치수는 구현 시작값이다. 폰트·기존 버튼을 연결해 생기는 실제 잘림을 해결하는 최소 조정은 가능하다. 브랜드 폭을 레일 폭에 전파하거나 헤더를 중앙 정렬 로고 형태로 바꾸지 않는다.

## 왼쪽 브랜드

- 기존 승인 엠블럼을 왼쪽, 타이포를 오른쪽에 놓고 전체 높이 가운데 정렬한다. 이미지를 세로로 쌓지 않는다.
- 브랜드 면은 현재 테마의 패널 회색을 이용해 나머지 헤더보다 살짝 구분한다. 별도 카드처럼 둥글게 감싸거나 외곽 패널을 추가하지 않는다.
- 오른쪽 경계에 폭 2px, 높이 약 56px의 짧은 주황 세로선을 넣는다. 이번 시작안은 사선 대신 수직선으로 정리한다.
- 로고 원본의 주황 그라데이션과 투명 영역을 보존한다. 그림자/금속 효과/컬러 필터/크롭/왜곡을 추가하지 않는다.
- 브랜드 링크의 기존 목적지와 핸들러를 유지한다. 접근성 이름은 ALDEBARAN 스포츠 홈을 사용할 수 있다.

## 오른쪽 상단

- 현재 별도 공지 줄의 NOTICE/본문/동작을 그대로 이동한다. 공지 버튼이 정상 클릭 영역을 갖도록 한다.
- 공지 내용이 길면 한 줄 말줄임으로 계정 버튼 영역을 보호한다. 공지 flex 영역은 min-width:0, 계정 영역은 줄어들지 않도록 한다.
- 로그인과 회원가입은 현재 순서와 동작을 유지하며 오른쪽 끝에 정렬한다. 로그인은 회색 면/흰 글자, 회원가입은 기존 주황 면/짙은 글자다.
- 이미 로그인된 상태에 다른 버튼이 표시되는 구조라면 그 기존 분기를 그대로 이동한다. 임의로 게스트 전용 구조로 고정하지 않는다.
- 기존 공지 행을 헤더 아래에서 제거한다. 화면에 같은 공지를 두 번 표시하지 않는다.

## 오른쪽 하단

기존 순서를 유지한다: **스포츠 / 실시간 스포츠 / E스포츠 / 카지노 / 슬롯 / 미니게임 / 이벤트**.

- 일반 메뉴는 배경이 거의 드러나지 않는 흰색 글자, 선택 메뉴는 주황색 단색 면과 짙은 글자다.
- 기본 본문 폰트를 유지하고 메뉴는 16px/굵게를 시작값으로 한다. 아이콘이 기존에 없다면 새 아이콘 세트를 추가하지 않는다.
- 메뉴 버튼은 작게 둥근 사각형(4px)을 사용한다. 전체 메뉴를 캡슐형 패널로 묶지 않는다.
- 메뉴 행 위에 중립 회색 1px 구분선을 둘 수 있다. 기존 활성 메뉴의 큰 외곽 테두리, 헤더 공통 주황 언더라인, 과거 골드 광택은 중복시키지 않는다.
- hover는 회색 면이 짧게 밝아지는 반응, 선택 항목 hover는 현재 주황의 밝은 변형을 사용한다. 약 140ms의 색상 전환을 시작값으로 한다.
- 선택 시 버튼 위치/폭/높이가 움직이지 않는다. 주황 선택 면이 메뉴 사이를 이동하는 애니메이션과 상시 광택은 이번 안에 넣지 않는다.
- 실제 선택 상태는 기존 앱 상태에 연결한다. 헤더 렌더만을 위한 별도 선택 상태를 만들지 않는다.

## 전체 프레임 연결

- 새 104px 헤더는 **기존 헤더 + 별도 공지 영역을 합쳐 대체**한다. 104px 아래에 예전 공지 높이를 더하지 않는다.
- 부모가 CSS grid이면 이전 두 개의 헤더 행을 하나로 정리한다. fixed/sticky + padding-top 구조라면 그 기존 방식 안에서 총 높이만 갱신한다. 실제 소스를 읽고 한 가지 방식으로 적용한다.
- 헤더 상수/변수를 기준으로 레일과 중앙의 가용 높이를 계산한다. 반복된 magic number를 서로 다르게 수정해 빈 띠나 겹침을 만들지 않는다.
- 좌/중앙/우의 가로 크기·순서·배너·내용은 유지한다. 중앙은 계속 비어 있다.
- 1920 고정 셸과 초과 폭에서의 중앙 정렬, 기존 스크롤 방식은 유지한다. 새 반응형 재배치나 전체 축소를 넣지 않는다.

## 코드 리소스

- `implementation/AldebaranHeaderR2.tsx`: 상태를 외부에서 전달받는 헤더 구조 예시. 기존 공지와 계정 버튼을 ReactNode로 전달해 재사용한다.
- `styles/aldebaran-header-r2.css`: 헤더 내부에만 적용되는 스타일. 기존 `--ab-*` 변수 우선, R1 색을 fallback으로 제공한다.
- `implementation/integration-map.json`: 상태·핸들러·부모 레이아웃 연결과 보존 범위.
- `assets/branding/`: 원본 PNG 2개. 현지 기존 파일과 같으면 재복사하지 않아도 된다.

예제 파일을 추가하는 것만으로 적용 완료가 아니다. 실제 앱에서 사용하고, 구 헤더 전용 스타일의 충돌 부분만 ALDEBARAN 안에서 정리한다. 예제 TSX는 현지 앱에서 빌드된 결과물이 아니다.
