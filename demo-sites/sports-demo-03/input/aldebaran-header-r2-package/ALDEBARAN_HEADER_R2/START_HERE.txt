- 현재 ALDEBARAN 앱과 운영 문서를 먼저 읽고 이어서 수정합니다. MERCURY를 다시 복제하거나 새 Sites 프로젝트를 만들지 않습니다.
- 기본 앱 경로는 E:/codexwork/Site-Skin-edit/demo-sites/sports-demo-03/site/입니다. 현지에서 실제 ALDEBARAN 경로와 기존 호스팅 연결을 확인하세요.
- 헤더 시작값은 전체 104px, 왼쪽 브랜드 폭 344px, 오른쪽 상단 46px/하단 58px입니다. 브랜드 폭은 헤더 안에서만 바꿉니다. 좌측 레일 폭을 늘리지 마세요.
- 기존 별도 공지 줄은 오른쪽 상단으로 이동합니다. 헤더 아래에 같은 공지 줄이나 빈 32px 공간을 남기지 마세요.
- 로고는 현재 승인된 엠블럼과 타이포 PNG를 그대로 사용합니다. 차콜/주황/흰색 배색은 사용자가 수용한 현재 테마를 유지합니다.
- 오른쪽 아래에 기존 7개 메뉴를 기존 순서로 배치합니다. 선택 메뉴는 주황색 단색 면과 짙은 글자, 일반 메뉴는 흰색 글자와 짧은 회색 hover로 구분합니다.
- 좌우 레일, 배너, 폰트, 데이터, 저장 키, 기존 기능, 빈 중앙은 보존합니다. 중앙 카드/트래커는 아직 구현하지 않습니다.

AGENTS.md → STATE.md → DESIGN_SPEC.md 순서로 읽고, 필요할 때 DECISIONS.md를 확인하세요. 네 문서는 현지 최신 운영 문서에 R2 변경분을 병합하는 입력입니다. 기존 R1 실제 완료·배포 기록은 보존하세요.
