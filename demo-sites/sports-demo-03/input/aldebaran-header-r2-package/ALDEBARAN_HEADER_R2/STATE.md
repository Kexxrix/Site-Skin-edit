# ALDEBARAN — HEADER R2 상태

## 시작 상태

- 사용자가 ALDEBARAN 1차 구현 완료를 알렸으며, 공개 주소는 https://aldebaran.kexxadrix.chatgpt.site/ 이다.
- 이 대화에서는 공개 첫 화면의 로고·차콜/주황 배색·빈 중앙과 DOM에 로드된 레일 구성을 가볍게 확인했다. 기능 전체 검수나 1920 전체 화면 감사를 수행한 것은 아니다.
- 사용자는 배색을 수용하고, 머큐리·시리우스와 구분되는 헤더의 **1번 비대칭 안**을 선택했다.
- 현재 패키지는 R2 구현 입력이다. R2 앱 수정·빌드·배포는 아직 실행하지 않았다. R1의 실제 commit/project/version/deployment 값은 현지 문서를 우선한다.

## 작업 위치

| 항목 | 값 |
| --- | --- |
| 기존 앱 기본 경로 | `E:/codexwork/Site-Skin-edit/demo-sites/sports-demo-03/site/` |
| 운영 문서 기본 위치 | `E:/codexwork/Site-Skin-edit/demo-sites/sports-demo-03/` |
| 업데이트할 공개 주소 | https://aldebaran.kexxadrix.chatgpt.site/ |
| 보존할 앱 | MERCURY / SIRIUS |
| 신규 자산 | 없음. 기존 승인 로고 원본 2개를 편의상 재포함 |

실제 앱 경로가 다르면 기존 ALDEBARAN 경로를 찾아 이어서 작업한다. 폴더 번호가 다르다는 이유로 신규 앱을 만들지 않는다.

## 실행 순서

1. 현지 ALDEBARAN의 최신 문서·소스·사용자 변경·호스팅 연결을 확인한다. R1을 다시 적용하지 않는다.
2. 기존 헤더와 공지 줄의 마크업, 부모 레이아웃의 행 높이/offset을 확인한다.
3. 왼쪽 브랜드 2행 병합, 오른쪽 상단 공지/계정, 오른쪽 하단 메뉴 구조로 바꾼다. 현재 공지 노드와 버튼 핸들러를 이동한다.
4. 현재 테마 변수를 연결하고 헤더 전용 스타일을 적용한다. 선택 메뉴는 주황 면, 비선택은 흰 글자로 표현한다.
5. 기존 아래 공지 행을 제거하고 앱 프레임의 헤더 높이를 한 곳에서 관리한다. 레일/중앙의 가용 높이는 새 헤더 높이만 반영한다. x축 배치와 너비는 유지한다.
6. 기본 확인 후 같은 ALDEBARAN 주소로 배포한다. 공개 최초 화면 1장과 결과를 기록한다.

## 짧은 확인

- 기존 프로젝트의 통상 빌드/타입 검사. 빌드에 포함된 검사를 불필요하게 중복하지 않는다.
- 1920 폭의 초기 화면: 왼쪽 로고가 2행 높이에 맞춰 중앙 정렬되고, 공지/계정과 7개 메뉴가 잘리지 않는지 확인한다.
- 공지 줄이 한 번만 보이는지, 헤더 아래에 이전 공지 높이가 남지 않는지 확인한다.
- 대표 메뉴를 한 번 변경하고 원래 실시간 스포츠로 돌아와 활성 상태와 기존 동작을 확인한다. 관련 없는 상태를 초기화하지 않는지 본다.
- 공지와 계정 버튼의 기존 연결이 유지되는지 필요한 대표 조작만 확인한다. 실제 인증/거래는 수행하지 않는다.
- 좌우 레일의 가로 위치와 빈 중앙이 유지되는지 같은 초기 화면에서 확인한다.
