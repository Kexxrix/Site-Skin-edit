# ALDEBARAN — HEADER R2 작업 규칙

2026-09-21 · 승인된 1번 비대칭 헤더 구현

## 문서 적용

- 현지 최신 ALDEBARAN의 네 운영 문서에 이번 변경분을 병합한다. 이 패키지로 기존 완료 기록·배포 식별자를 지우지 않는다.
- 운영 문서는 AGENTS / STATE / DESIGN_SPEC / DECISIONS 네 개를 유지한다.
- R1의 ‘MERCURY 헤더 배치 유지’는 이번 승인안에 한해 변경한다. R1의 차콜/주황 배색·자산·레일·빈 중앙 기준은 계속 유지한다.
- 사용자 최신 지시 > 승인된 R2 구성 > 아래 구현 시작값 순으로 적용한다. 104/344/46/58px 등은 초기 구현 치수이며 별도 사용자 시안 승인값은 아니다.

## 이번 범위

- 현재 ALDEBARAN에서 헤더와 기존 공지 줄만 재배치한다. MERCURY/SIRIUS 및 다른 앱은 수정하지 않는다.
- 왼쪽 브랜드가 두 행 전체 높이를 사용한다. 오른쪽 상단은 공지·로그인/회원가입, 하단은 기존 주요 메뉴다.
- 기존 공지는 이동한다. 화면 아래에 공지 사본이나 빈 높이 보정 공간을 남기지 않는다.
- 헤더 폭은 기존 고정 셸을 따른다. 헤더 브랜드 영역을 넓혀도 레일 폭·중앙 폭·컬럼 간격을 바꾸지 않는다.
- 중앙 카드/트래커/샘플 데이터를 렌더하지 않는다. 기존의 빈 중앙은 정상 상태다.

## 구현 방식

- 제공 CSS와 TSX는 현지 소스에 연결할 참조 코드다. 실제 상태/핸들러/라우팅을 읽고 필요한 부분만 적용한다.
- 메뉴 선택 상태는 기존 앱 상태를 한 곳에서 관리한다. 헤더 내부에 별도 active 상태를 만들지 않는다.
- 기존 공지·계정 버튼·브랜드 링크의 클릭 기능과 접근성 이름을 보존한다. 예제만 렌더하고 버튼이 무반응인 채 완료하지 않는다.
- 승인 PNG를 그대로 사용한다. 새 로고, 배경 이미지, 아이콘 생성·수정, 외부 이미지 플러그인 사용은 이번 범위에 없다.
- 설치된 폰트와 테마 변수를 재사용한다. 새로운 폰트/애니메이션/UI 라이브러리 설치나 전체 리팩터링은 하지 않는다.
- 2번 전체 주황 메뉴 띠, 3번 떠 있는 캡슐 메뉴 및 이동하는 선택 배경은 이번 안에 넣지 않는다. 짧은 색상 전환만 적용한다.
- 현재 레일·슬립·배너 스타일과 동작을 변경하지 않는다. 헤더 선택자를 별도로 제한한다.

## 확인과 배포

- 구현 담당이 통상 빌드/타입 확인과 변경한 헤더만 짧게 확인한다. QA 스레드·Jev·전 사이트 감사는 실행하지 않는다.
- 로그인 상태 전체, 베팅 계산 전체, 모바일, 숨겨진 모든 상태를 다시 검사하지 않는다. 변경 중 발견한 직접적인 오류만 수정한다.
- 기존 ALDEBARAN 호스팅 연결을 확인한 뒤 같은 주소로 업데이트한다. 새 프로젝트 등록 또는 MERCURY/SIRIUS 배포는 하지 않는다.
- 공개 초기 화면 1장, 실제 확인 범위, 변경 파일, 실제 배포 식별자를 STATE에 기록한다. 미확인을 PASS로 바꾸지 않는다.
- 디자인 최종 수용은 사용자에게 맡긴다. 이번 헤더 이후 작업으로 자동 확장하지 않는다.
