# ALDEBARAN — 노랑색 UI 정리 및 0경기 종목 추가

작성일: 2026-09-23

이 패키지는 다음 구현 작업을 위한 지시서와 사용자 제공 아이콘이다. 사이트 코드 수정이나 배포를 완료한 결과물이 아니다. 실제 포함 가능한 신규 종목 수는 대상 프로젝트의 1920 화면에서 확인해야 한다.

## 1. 작업 기준

- 대상 프로젝트: `E:/codexwork/Site-Skin-edit/demo-sites/sports-demo-03/`, 앱: `site/`.
- 현재 프로젝트의 코드와 운영 문서를 먼저 읽고 필요한 부분만 수정한다.
- 이번 범위는 아래 A~D 네 가지다. 이미 완료된 이전 폴리싱 작업을 다시 적용하거나 전체 테마를 교체하지 않는다.
- 노랑색 배경·선택 테두리: `#FCD73E`. 노랑색 배경 안의 글자·아이콘: `#171717`.
- 기존 1920 데스크톱 레이아웃, 글자 크기·굵기, 버튼 높이·간격을 기준으로 작업한다.

## A. LV / BET 칩

| 대상 | 배경 | 글자 |
| --- | --- | --- |
| 계정 정보의 LV 등급 칩 | #FCD73E | #171717 |
| 베팅 금액 제목 앞 BET 칩 | #FCD73E | #171717 |

- 게스트·회원 상태에서 같은 칩 규칙을 사용한다. 등급 값은 기존 데이터에 따른다.
- 기존 칩 크기, 모서리, 위치 및 중앙 정렬을 유지한다.
- 칩 바깥의 회원명, 베팅 금액 제목 등은 이 변경의 대상이 아니다.

## B. 베팅하기 버튼의 비활성 색상

- 활성·비활성 모두 배경 `#FCD73E`, 글자·아이콘 `#171717`을 사용한다.
- 비활성 상태를 어두운 노랑으로 만드는 이 버튼의 opacity/filter/별도 배경 규칙을 확인해 수정한다. 자식 요소나 상위 래퍼 때문에 색이 어두워지는 경우도 확인한다.
- 버튼의 disabled 상태, 클릭·키보드 실행 차단, 금액·선택·계정 검증 및 기존 안내는 유지한다. 색상을 유지하려고 disabled 속성을 제거하지 않는다.
- 비활성 버튼에는 실행 가능한 것처럼 보이는 hover/active 반응을 추가하지 않는다.
- 공통 disabled 스타일을 통째로 바꿔 다른 버튼에 영향을 주지 않는다.

## C. 상단 종목 탭의 선택 상태

- 선택된 탭의 외곽선: `#FCD73E`.
- 선택된 탭 내부 경기 수 박스: 배경 `#FCD73E`, 숫자 `#171717`.
- 탭의 회색 바탕, 종목명·아이콘의 기존 표현, 비선택 탭 표현은 유지한다.
- ‘전체’에만 고정하지 말고 선택되는 모든 종목에 같은 규칙을 적용한다. 0경기 종목도 선택 가능하며 동일한 선택 표현을 사용한다.
- 외곽선 두께와 버튼 치수가 선택 전후로 달라지지 않게 한다.

## D. 신규 종목 및 아이콘

### 순서와 파일 매핑

기존 종목 순서를 유지하고 마지막 종목 뒤에 아래 우선순위대로 추가한다.

| 우선순위 | 표시명 | 원본 파일 | 경기 수 |
| --- | --- | --- | ---: |
| 1 | 포뮬라1 | assets/image_Sports_Aldebaran-10.png | 0 |
| 2 | 복싱 | assets/image_Sports_Aldebaran-11.png | 0 |
| 3 | MMA | assets/image_Sports_Aldebaran-12.png | 0 |
| 4 | 모터스포츠 | assets/image_Sports_Aldebaran-13.png | 0 |
| 5 | 크리켓 | assets/image_Sports_Aldebaran-14.png | 0 |

- 다트는 이번 최종 추가 목록에 포함되지 않는다.
- 포뮬라1과 모터스포츠는 별도 종목으로 구분한다. 실제 ID 이름은 프로젝트 관례를 따른다.
- 모든 원본은 256×256 RGBA PNG다. 원본 파일명과 바이트를 보존해 동봉했다.
- 아이콘의 종횡비와 투명도를 유지한다. 기존 종목 아이콘과 같은 슬롯 안에서 표시하며 눈에 보이는 도형의 크기·무게·중심을 맞춘다. 특히 가로로 긴 포뮬라1과 세로로 긴 MMA를 같은 캔버스 크기만 보고 정렬하지 않는다.
- 기존 아이콘의 회색 톤·불투명도 처리 방식을 확인해 같은 방식으로 적용한다. 배경판, 프레임, 새 그림자나 장식은 추가하지 않는다.
- 새 아이콘을 생성하거나 기존 아이콘을 다른 그림으로 대체하지 않는다.

### 적용 위치

1. 중앙 콘텐츠 위의 상단 종목 탭.
2. 기존 레일의 ‘인기 스포츠 리스트’ 종목 목록.

대화에서 ‘우측 레일’이라는 표현이 있었으나, 직전 화면에서 해당 종목 목록은 좌측에 있었으며 마지막 합의에서는 이 기존 목록을 대상으로 정리했다. 실제 컴포넌트를 기준으로 수정하고 계정·베팅슬립 영역에 별도의 스포츠 목록을 신설하지 않는다.

### 폭 초과 처리

- 기준은 1920 CSS px 화면, 브라우저 100% 배율, 실제 앱 폰트가 적용된 상태다.
- 우선 다섯 종목을 모두 배치해 상단 탭 영역 안쪽의 사용 가능 폭과 탭 전체 폭을 측정한다. 외곽선, 내부 여백, 종목명, 숫자 박스 및 탭 사이 간격까지 포함한다.
- 영역 밖으로 넘치면 크리켓 → 모터스포츠 → MMA → 복싱 → 포뮬라1 순서로 뒤에서 하나씩 제외하고 다시 확인한다. 남는 공간에 맞는 우선순위의 연속된 목록을 확정한다.
- ‘아마 모터스포츠까지 들어갈 것’은 사용자 예상이며 확정값이 아니다. 크리켓을 처음부터 제외하거나 포함을 강제하지 않는다.
- 종목을 더 넣으려고 기존 버튼·폰트·간격을 축소하거나, 가로 스크롤·줄바꿈·말줄임·잘라내기로 넘침을 숨기지 않는다. 빈 공간이 조금 남아도 된다.
- 1920 기준으로 확정된 목록을 상단과 레일이 함께 사용하게 한다. 상단에서 제외된 종목은 레일에서도 제외한다. 사용하지 않은 원본 아이콘은 제공 리소스에 남겨둔다.
- 이 고정 화면 작업을 위해 별도 반응형 재설계나 복잡한 동적 숨김 시스템을 추가할 필요는 없다.

### 데이터 및 0경기 화면

- 신규 종목의 실제 경기 배열은 비어 있고 경기 수는 0이다. 표시 숫자만 0으로 바꾼 채 기존 경기를 재사용하지 않는다.
- 기존 종목 수: 축구 32, 농구 6, 야구 16, 배구 0, 아이스하키 7.
- 전체 합계: `32 + 6 + 16 + 0 + 7 = 61`. 신규 종목은 모두 0이므로 추가 전후 합계는 61이다.
- 탭과 레일에서 새 종목을 선택하면 같은 종목 필터가 적용된다. 중앙 경기 목록에 ‘등록된 경기가 없습니다.’를 표시한다.
- 0경기 종목을 선택했을 때 다른 종목의 이전 경기 카드나 상세 마켓이 그대로 남지 않도록 선택 경기 상태를 정리한다. 상세 마켓 영역은 기존 빈 상태 표현을 따른다.
- ‘전체’나 기존 종목으로 돌아가면 해당 경기 목록과 정상적인 경기 선택 동작이 복구된다.
- 종목 탐색만으로 기존 베팅슬립 선택이나 입력 금액을 삭제하지 않는다.
- 배구 0경기 동작과 가능한 한 기존 공통 빈 상태 로직을 재사용한다.
- 팀·선수 이미지, 가상 경기, 배당 데이터 및 신규 마켓 생성은 이번 범위에 없다.
