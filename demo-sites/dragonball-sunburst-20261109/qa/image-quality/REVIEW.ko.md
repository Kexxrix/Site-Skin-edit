# 추천게임 원화의 축소 표시 품질 수정

## 증상과 원인 확인

사용자가 추천게임 원화가 이전 토토로·ABURAYA보다 픽셀이 깨져 보인다고 보고했다. 실제 화면에서 머리카락·옷 주름·얼굴 경계에 점상/계단 현상이 보였다. 원본 PNG를 직접 열면 선이 정상이며, 브라우저에서도 원본 크기로 로드되고 있었다. CSS의 `image-rendering`은 `auto`였고 `pixelated` 설정은 없었다.

같은 원화를 같은 244×296 표시 크기로 독립 비교했다. 일반 IMG, GPU 합성용 transform, CSS 배경 표시에서는 증상이 남았고, Canvas 2D의 고품질 축소 보간에서는 개선됐다. 따라서 이번 환경에서는 원본 파일 손상보다 브라우저의 축소 샘플링 경로에 따른 현상으로 확인했다. 특정 GPU·드라이버 결함으로 단정하지 않는다. `sampling-comparison.png`의 위쪽 왼쪽은 고품질 Canvas, 중앙은 GPU 합성 IMG, 오른쪽은 CSS 배경이며 아래는 수정 전 카드다.

참고: CSS `image-rendering:auto`의 구체적인 스케일링 알고리즘은 브라우저가 선택한다. [W3C CSS Images](https://www.w3.org/TR/css-images-3/#the-image-rendering)

## 변경

- 런타임 변경 파일: `site/app.js` 하나.
- 추천게임 원화 15장에만 `imageSmoothingQuality='high'`로 그린 Canvas 표시를 추가했다. 카드의 원화 영역과 가운데 cover 크롭은 유지한다.
- 카드 내부 CSS 크기와 실제 화면 크기 중 큰 쪽에 기기 픽셀 배율을 곱해 버퍼 크기를 정한다. 모바일에서 너무 작은 버퍼를 다시 늘려 흐려지는 문제를 피한다.
- 이미지 로드와 창 크기 변경 때 필요한 경우만 다시 그린다. 매 프레임 재렌더하지 않는다.
- 원본 IMG는 그대로 유지한다. Canvas가 그려진 뒤 표시만 숨기며, Canvas 컨텍스트가 없으면 원본 표시가 유지된다. 미리보기는 기존 원본 경로를 사용한다.
- CSS·HTML·원본 이미지·프레임·제목·슬라이드 설정과 다른 사이트는 변경하지 않았다.

## 검증

| 항목 | 결과 |
|---|---|
| 1920×1080의 15장 원화 시각 검수 | 점상/계단 현상 개선 확인 |
| 1440×900 PC 시각 검수 | 정상, 렌더 버퍼 불일치 0 |
| 390×844 모바일 시각 검수 | 정상, 2열 유지, 가로 넘침 없음 |
| 기기 픽셀 배율 2의 구조 검사 | 15개 버퍼 각각 488×592, 불일치 0 |
| 연속 클릭·3페이지 순환 | 정상 |
| 추가 카드 클릭·미리보기·복귀 | 제목과 원본 이미지 경로 일치 |
| 다른 메뉴에서 홈 재진입 | 원화 Canvas 15개, 중복 없음 |
| 오류 화면·빈 화면·브라우저 경고/오류 | 없음 |
| `node --check site/app.js` | 통과 |
| 기존 파일 SHA-256 대조 | app.js 외 모두 동일 |

고밀도 검사 중 CDP 화면 캡처는 검수 환경의 타일/크기 불일치가 있어 시각 판정에 쓰지 않았고 해당 캡처를 제거했다. 고밀도 항목은 실제 DOM 크기·기기 배율·버퍼 치수 검사만 통과한 것으로 기록한다. 일반 PC와 모바일 시각 검수는 정상 뷰포트 API를 사용하는 독립 검수 탭에서 수행했다. 해당 임시 탭과 진단용 원화/Canvas는 정리했다.

## 증거와 남은 범위

- `before.png`: 수정 전 1920 화면.
- `final.png`: 최종 코드가 적용된 같은 페이지의 1920 화면.
- `after-1920-page-1.png`, `after-1920-page-3.png`: 나머지 10장의 표시. 최종 변경에서도 이 해상도의 버퍼는 동일하다.
- `after-1440.png`, `after-mobile.png`: 최종 PC·모바일 표시.
- `browser-checks.json`, `verification.json`, `before-file-hashes.json`: 검증과 보존 기록.

이번 확인은 로컬 Chromium/IAB 환경 기준이다. Safari·Firefox 및 실제 모바일 기기는 검수하지 않았다. 원본 이미지 재생성·변환·색 변경, Figma 변경, 공개 배포는 하지 않았다.
