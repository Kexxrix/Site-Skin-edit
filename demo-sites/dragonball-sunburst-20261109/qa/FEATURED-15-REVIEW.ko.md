## 결과

- 기존 5장 + 추가 10장 = 15장. 모두 서로 다른 원화. 5장 × 3페이지.
- 1920×1080에서 기존 첫 페이지의 카드 좌표는 x=274, 554, 834, 1114, 1394 / y=620이며 각각 252×304. 원래 배치 유지.
- 추가 10장의 제목·이미지·프레임 매핑, `object-fit:cover`, 244×296 원화 창과 42px 모서리를 확인. 1440×900 화면의 0.75배 실측 원화 창은 183×222.
- 첫 페이지 5장의 기존 원화·프레임·30px 모서리는 유지. 새 Figma 프레임은 기존 프레임과 다른 파일이므로 추가 카드에만 지정 파일 적용.
- 1920×1080과 1440×900에서 세 페이지를 실제 화면으로 확인. 추가 10장을 Figma 스크린샷과 비교해 인물·순서·크롭·제목·프레임 배치를 검수.
- 390×844에서 2열 표시, 마지막 카드까지 세로 스크롤, 다음 페이지 전환 확인. 이미지 누락과 문서 가로 넘침 없음.
- 15장 모두 클릭 → 제목/이미지 일치 → 로비 복귀 통과. 게임 선택 팝업도 15개 확인.
- 3→1 다음 이동, 1→3 이전 이동, 3페이지에서 더블클릭으로 2페이지 도착 및 전환 종료 확인.
- `prefers-reduced-motion: reduce` 설정에서 페이지 변경 및 슬라이드 상태 없음 확인. 임시 설정과 뷰포트 오버라이드는 복원.
- 이번 검수 시점 브라우저 경고·오류 0개.
- `node --check site/app.js` 통과.
- 파일 SHA-256 대조: 기존 런타임 185개 중 변경은 `app.js`·`app.css` 두 개뿐이며, 나머지 183개는 동일. 추가 PNG 11개는 실제 디코드·형식·크기 검사 통과.

## 범위와 한계

Figma 문서, 기존 원화, 다른 데모 사이트, 공지 내용과 서버 연동은 변경하지 않았다. 로컬 브라우저 검수이며 공개 배포나 실제 게임 연결은 포함하지 않는다. 모바일은 기존 데모의 배치 방식을 유지했고 별도 모바일 Figma 시안은 없다. Safari와 실제 모바일 기기 검수는 하지 않았다.
