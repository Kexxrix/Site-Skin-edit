# DragonBall Z Sunburst 구현 검수

검수일: 2026-11-09. 기준: 같은 폴더의 `figma-home.png`, `figma-live.png`, `figma-slots.png`, `figma-notice.png` 및 `../input/` Figma 코드.

## 구현과 파일

새 폴더에 `site/index.html`, `app.js`, `app.css`, `design.css`, `typography.css`, 화면 HTML 4개, 공지 HTML 24개, 이미지/SVG 136개, 로컬 폰트를 구성했다. 기존 토토로·ABURAYA 코드를 읽어 데모 동작 방식을 재사용했으며 기존 사이트 파일은 수정하지 않았다.

홈 추천게임 5개, 라이브 제공사 8개, 슬롯 제공사 14개, 공지 목록 4페이지와 상세 20개를 연결했다. 추천 좌우 버튼은 Figma에 포함된 5개 게임 순서를 회전한다. Figma 밖의 추가 이미지는 이 구현에 넣지 않았다.

## 검수 중 수정

1. 슬롯 제공사 로고의 Figma 레이어 이름이 라이브와 달라 발생하던 전환 오류를 슬롯의 실제 레이어 이름으로 수정했다.
2. JILI·PLAYACE와 왼쪽 화살표의 음수 CSS 너비를 양수 너비+좌우 반전으로 재현했다. 슬롯 캐릭터 표시와 공지 뒤로가기 화살표를 확인했다.
3. 투명 이미지 래퍼의 사각형 box-shadow를 알파 외곽을 따르는 drop-shadow로 변경했다.
4. 모바일 서비스 메뉴와 하단 메뉴의 축소 비율에 실제 사용 가능한 문서 너비를 사용했다.

## 유지 및 범위

- Figma 원본, 이미지 원본, 제공사 로고, 기존 토토로·ABURAYA 파일과 서버 유지.
- 로그인·입출금·문의는 로컬 화면 확인용 데모. 실제 회원·결제·게임 서버 연결 없음.
- 모바일은 기존 데모의 반응형 방식으로 구현했으며 별도 모바일 Figma 시안과 비교한 것은 아니다.
- 인앱 Chromium에서 검수했다. 실제 iOS/Android 기기 및 Safari/Firefox 검수는 수행하지 않았다.
- 공개 배포, GitHub 업로드, 사용자 미감 승인은 별도 상태다.
