## 구성

- `input/`: Figma 원본 코드·메타데이터, 다운로드 주소와 자산 해시, 변환 스크립트

- `qa/`: Figma 기준 화면, 실제 브라우저 화면, 자산·공지 검증 결과

화면 전환·고정 메뉴·게임 미리보기·계정/입출금/문의 데모는 기존 토토로·ABURAYA 데모 구조를 재사용했다. 계정은 페이지 메모리에서만 유지되며 입력값은 저장·전송되지 않는다. 실제 게임·결제·회원 서버는 연결되어 있지 않다.

1920×1080에서 Figma 부모 배치를 유지하고, 다른 데스크톱 비율은 배경을 뷰포트 전체에 표시한다. 760px 이하에서는 카드 2열·고정 하단 메뉴로 재배치한다. 별도 모바일 Figma 시안은 제공되지 않아 기존 데모의 모바일 방식을 적용했다.

Figma 원본의 좌우 반전 이미지가 코드에 음수 너비로 출력되는 부분은 CSS의 양수 너비와 `scale:-1 1`로 재현했다. 이미지 파일 자체는 변경하지 않았다. 프레임 그림자는 투명 알파 외곽을 따르도록 `drop-shadow`로 처리했다.

`input/compile-design.cjs`는 기존 작업공간의 esbuild·React·Tailwind를 빌드 시에만 사용한다. `site/` 배포·실행에는 이 도구가 필요 없다. 임시 Figma 자산 URL을 런타임에서 사용하지 않는다.

현재 상태: 로컬 구현·기술/브라우저 검수 완료. 사용자 미감 승인·공개 배포·GitHub 업로드는 이번 작업에 포함하지 않았다. 기존 토토로·ABURAYA 사이트와 Figma 원본은 유지했다.
