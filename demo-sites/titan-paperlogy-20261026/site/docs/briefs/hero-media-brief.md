# TITAN SOLUTION 첫 화면 미디어 제작 의뢰서

첫 화면의 왼쪽 임시 영상과 오른쪽 사진을 타이탄에 맞는 리소스로 제작합니다. **그래픽팀에서 제작해 전달할 결과물은 완성된 동영상 1개와 사진 3~4장입니다.**

- **동영상 1개:** 왼쪽에 들어갈 약 15초 길이의 완성된 루프 영상입니다.
- **사진 3~4장:** 오른쪽에 들어갈 개별 정지 이미지입니다.

전달받은 사진을 약 5초 간격으로 디졸브하는 작업은 **프로그램팀에서 코드로 처리합니다.** 그래픽팀은 사진이 순차적으로 교체된다는 점을 참고해 구도와 톤을 맞춰 주세요.

이 문서는 전달할 메시지와 전체 방향을 공유하기 위한 기준입니다. 아래 문구, 장면 순서, 시간 배분, 연출 예시는 더 좋은 비주얼과 자연스러운 흐름을 위해 그래픽팀에서 조정해 주세요. 구체적인 디자인과 모션은 그래픽팀의 판단을 존중합니다.

## 1. 목적과 보는 사람

새로운 솔루션을 찾는 신규 사업자와 기존 운영사가 첫 화면에서 다음 인상을 받는 것이 목표입니다.

> 직접 만든 제품이 있고, 실제 운영을 깊이 이해하며, 함께 사업을 이어갈 역량이 있는 팀.

왼쪽 영상은 타이탄의 핵심 강점과 제품의 완성도를 짧게 보여줍니다. 오른쪽 사진은 역동적인 개발 조직, 적극적인 지원, 기술력, 파트너의 경제적 성공을 느끼게 합니다.

현재 영상 위에는 이미 `250개+ 누적 서비스 런칭 업체`, `10년+ 베팅 서비스 개발·운영`, `24시간 운영·기술 지원`이 표시됩니다. 영상에서는 이 숫자를 반복하기보다 제품과 운영 역량을 보여주는 데 집중합니다.

## 2. 전체 분위기와 공통 기준

- **최우선 레퍼런스:** [Dizora Home의 첫 화면](https://kits.roxthemes.com/dizora/template-kit/home/?storefront=envato-elements)
- **모션 참고:** 현재 프로젝트에 임시로 삽입된 [소개 영상](https://www.youtube.com/watch?v=-jokuknAtu8)
- 어두운 배경, 큰 타이포그래피, 발광하는 도형, 부드러운 움직임을 기본 인상으로 참고합니다.
- 타이탄의 **주황색은 유지**합니다. 현재 사이트의 주황색은 `#FA871F`이며, 배경과 보조 색상은 영상에 맞게 조정할 수 있습니다.
- 로고는 아직 확정되지 않았습니다. 브랜드가 필요한 장면에는 **TITAN SOLUTION을 타이포그래피로 표현**합니다.
- 주요 메시지는 **한국어**로 작성합니다.
- 왼쪽 영상이 시선을 이끌고, 오른쪽 사진은 분위기를 보완하도록 구성합니다.

## 3. 왼쪽 메인 영상

### 기본 방향

- 전체 길이는 **약 15초**입니다.
- 소리 없이도 의미가 전달되는 **무음 중심 영상**으로 구성합니다.
- 마지막 장면에서 첫 장면으로 자연스럽게 이어지는 루프를 만듭니다. 배경·도형·기기 목업의 움직임이 연결되면 좋겠습니다.
- 한 장면에서 읽어야 하는 문구는 짧게 정리하고, 각 메시지가 눈에 들어올 시간을 확보합니다.
- 중간부터 보더라도 장면의 의미가 이해되도록 구성합니다.

### 전달할 세 가지 메시지

아래 순서를 출발점으로 삼되, 장면 연결과 비주얼에 맞춰 순서와 표현을 바꿀 수 있습니다. 문구를 그대로 사용하는 것보다 핵심 의미가 전달되는 것이 중요합니다.

| 메시지 | 문구 초안 | 전달할 실제 내용 |
| --- | --- | --- |
| 핵심 시스템 직접 개발 | **핵심 시스템, 직접 개발.** | 스포츠북, 벤더 API, 사용자·파트너·백오피스 등 서비스의 핵심 시스템을 직접 개발하는 팀입니다. |
| 실전에서 다듬은 운영 제어 | **실전에서 다듬은 운영 제어.** | 배당 급변 시 자동 베팅 차단, 다음 라운드부터 적용되는 베팅 한도 변경 등 현장의 요구를 반영한 기능을 갖추고 있습니다. |
| 파트너 수익금 자동 정산 | **파트너 수익금, 자동 정산.** | 정산일에 복잡한 파트너 수익금을 자동 계산하고, 분배할 금액을 백오피스에 기록합니다. |

정산 장면의 시각적 도착점은 **계산 결과가 정리되어 기록되는 상태**입니다. 이 기능의 범위에 맞춰 표현해 주세요.

### 제품 티징: CAT VILLAGE 태블릿 + 스포츠북 휴대폰

**CAT VILLAGE는 태블릿에서, 스포츠북은 휴대폰에서 실행 중인 모습으로 보여주세요. 두 제품을 별도의 두 기기 목업으로 구성합니다.**

CAT VILLAGE는 카지노·슬롯 샘플이며 스포츠북이 없습니다. 스포츠북에는 별도의 스포츠북 샘플 화면을 사용합니다. 두 제품의 화면과 기기 구분이 영상에서도 명확하게 드러나도록 해주세요.

기기 목업을 사용하는 이유는 제품 화면을 더 정돈되고 입체적인 형태로 보여주기 위해서입니다. 타이탄의 좋은 화면을 잠깐 보고 실제 데모가 궁금해지는 정도의 티징을 기대합니다.

- **CAT VILLAGE — 태블릿 목업:** 캐릭터를 중심으로 브랜드·게임 콘텐츠의 매력이 드러나는 화면을 활용합니다. 태블릿의 넓은 화면에서 캐릭터와 일러스트가 잘 보이고, 실제 서비스가 실행 중인 느낌을 줍니다.
- **스포츠북 — 휴대폰 목업:** 별도 스포츠북 샘플의 모바일 경기 목록·배당 등 스포츠 베팅 화면임을 알아볼 수 있는 구도를 활용합니다. 휴대폰에서 실행 중인 느낌을 줍니다.
- 각 목업에는 해당 기기의 화면 비율에 맞는 실제 UI를 사용해 글자·캐릭터·UI 비율이 자연스럽게 보이도록 합니다.
- 태블릿과 휴대폰이 함께 등장하거나, 각각 순차적으로 등장하거나, 타이포그래피와 함께 배치되는 등 구체적인 방식은 자유롭게 제안할 수 있습니다. 함께 배치할 때도 두 제품은 각자의 기기 안에 표시합니다.
- 기기의 각도·조명·크기와 화면 전환은 제품이 잘 보이는 수준으로 조절합니다. 짧은 시간에도 화면의 인상이 남는 것이 중요합니다.

### 흐름 예시

고정 콘티가 아니라 약 15초를 구성하는 참고안입니다. 제품 티징 장면을 먼저 보여주거나 두 목업을 함께 배치하는 방식도 가능합니다.

| 대략적인 구간 | 중심 내용 | 가능한 연출 |
| --- | --- | --- |
| 0~5초 | 직접 개발 + CAT VILLAGE 티징 | 주황색 도형이나 타이포그래피와 함께 캐릭터 중심의 캣빌리지 태블릿 목업 등장 |
| 5~10초 | 실전 운영 제어 + 스포츠북 티징 | 별도의 스포츠북 휴대폰 목업이 등장하고, 그래픽 요소로 변화에 대응하는 제어감을 표현 |
| 10~15초 | 파트너 수익금 자동 정산 + 루프 연결 | 여러 요소가 정리되어 결과로 모이는 모션 후 첫 장면의 형태·움직임으로 자연스럽게 복귀 |

파트너 정산 설명은 화면을 복잡하게 채우기보다, 복잡한 일이 정리되는 인상을 간결한 그래픽으로 표현하면 좋겠습니다.

## 4. 오른쪽 사진

### 기본 방향

**개별 사진 3~4장을 제작합니다.** 사진 자체의 구도와 내용으로 생동감을 만들어 주세요. 아래 네 가지 인상을 각각 한 장으로 구성하는 4장 안을 기본으로 보되, 잘 어울리는 주제를 묶어 3장으로 정리할 수도 있습니다.

| 전달할 인상 | 사진 방향 예시 |
| --- | --- |
| **역동적인 개발팀** | 모니터와 자료를 함께 보며 적극적으로 토론하거나 문제를 해결하는 개발자들. 집중력과 협업의 에너지가 느껴지는 장면. |
| **적극적인 CS팀** | 문의를 살피고 신속하게 대응하며 팀원과 소통하는 모습. 상대의 문제에 집중하는 태도와 전문성이 느껴지는 장면. |
| **탁월한 기술력** | 정교한 작업 환경, 시스템을 분석하는 집중된 모습, 기술적 디테일이 보이는 장면. 개발팀 사진과 구도·거리감을 달리해 기술의 깊이를 표현. |
| **파트너의 경제적 성공** | 운영사·영업 파트너가 사업 성과를 확인하거나 확장 계획을 논의하는 모습. 자신감, 성장, 사업이 잘 운영되는 인상을 표현. |

소재 선정과 촬영·연출 방식은 그래픽팀에서 제안해 주세요. 팀·기술·성공은 전달하려는 이미지이며, 구체적인 수익 수치나 새로운 실적 문구를 덧붙일 필요는 없습니다.

### 사진 구도와 톤

- 좁은 세로 프레임에서도 인물·손·기기 등 장면의 중심이 명확하게 보이도록 구성합니다.
- 사진별 구도와 장면에는 변화를 주되, 색온도와 전체적인 밝기를 맞춰 하나의 시퀀스로 느껴지게 합니다.
- 어두운 페이지에서 사진 영역이 적당히 밝게 드러나도록 하고, 사진 교체 때 밝기가 갑자기 뛰지 않도록 합니다.
- 오른쪽은 사진 중심으로 구성하고, 별도의 설명 문구는 필수로 넣지 않습니다.

## 5. 실제 페이지에서 보이는 구도

현재 페이지는 다음과 같은 틀을 사용합니다. 아래 치수는 화면 구도를 판단하기 위한 참고값입니다.

| 구분 | 현재 표시 형태 | 구도에서 고려할 점 |
| --- | --- | --- |
| 넓은 PC 화면 | 왼쪽 약 938×400px, 오른쪽 약 313×400px | 왼쪽은 약 2.34:1의 넓은 가로형, 오른쪽은 약 3:4의 세로형입니다. |
| 창 너비가 줄어든 화면 | 두 영역의 가로세로 비율이 달라짐 | 문구와 목업, 사진의 주요 피사체가 잘리지 않도록 여유를 확보합니다. |
| 모바일 | 왼쪽 영상만 표시, 오른쪽 사진은 숨김 | 핵심 메시지는 왼쪽에서 모두 전달되어야 합니다. 작은 화면에서도 문구와 제품 티징을 알아볼 수 있게 구성합니다. |

PC 영상의 단순 축소·크롭만으로 모바일 구도가 어색해질 경우, 모바일에 맞는 장면 배치를 함께 검토합니다. 처음 대표 장면을 잡을 때부터 실제 페이지의 넓은 화면과 좁은 화면에 얹어보면 좋겠습니다.

현재 영역의 모서리는 둥글게 처리되어 있습니다. 문구나 중요한 UI를 화면 가장자리까지 붙이지 않고 여유 있게 배치해 주세요.

## 6. 작업에 참고할 화면

- **현재 페이지:** 전달받은 프로젝트의 첫 화면. 로컬 서버를 실행했다면 [localhost:3000](http://localhost:3000/)에서 확인할 수 있습니다.
- **CAT VILLAGE — 태블릿용:** [공개 데모](https://titan-solution-t01.pages.dev/)를 태블릿 화면 비율로 확인하고, 캐릭터와 일러스트가 돋보이는 카지노·슬롯 화면을 활용합니다.
- **모바일 스포츠북 후보:** [AURES](https://titan-solution-t02.pages.dev/), [COBALT](https://titan-solution-t03.pages.dev/), [LUMIÈRE](https://titan-solution-t04.pages.dev/). 실제 모바일 화면을 비교해 영상에서 가장 잘 보이는 샘플을 선택해 주세요. 특정 샘플을 확정한 것은 아닙니다.
- **최우선 디자인 레퍼런스:** [Dizora Home](https://kits.roxthemes.com/dizora/template-kit/home/?storefront=envato-elements)

전체적으로 **짧게 봐도 제품이 좋아 보이고, 뒤에 있는 팀과 운영 역량이 느껴지는 첫 화면**을 기대합니다. 세부 표현은 작업 화면을 함께 보며 자연스럽게 조정하겠습니다.
