## 추가 작업 — 헤더 로고

시각 기준: references/header-target.png.

- 로고 왼쪽의 원형 엠블럼을 제거하고 **MERCURY 워드마크만** 표시하세요. 기존 금빛 글자·장식·크기는 유지합니다.
- 엠블럼 제거 후 남은 워드마크의 보이는 영역이 **헤더 전체 폭의 가로 중앙**에 오도록 다시 정렬하세요. 우측 로그인 버튼 그룹의 폭 때문에 중앙이 밀리지 않게 합니다.
- 세로 위치는 현재보다 **4~6px 위로** 올리세요. -5px을 시작값으로 적용하고, 첨부 샘플처럼 육안으로 중앙에 보이는 위치로 맞추세요.
- 기존 로고 리소스를 재사용하세요. 엠블럼과 글자가 한 이미지에 있다면 워드마크 영역만 표시하되, 잘림이나 비율 변형이 없도록 하세요. 참고 스크린샷을 로고 이미지로 쓰지 않습니다.
- 헤더 높이·배경·메뉴·로그인 버튼·공지 라인은 그대로 유지합니다.
