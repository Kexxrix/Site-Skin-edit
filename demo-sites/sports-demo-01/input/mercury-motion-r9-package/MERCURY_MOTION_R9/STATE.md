MERCURY는 기존 3열 카드와 블랙·골드 디자인을 유지하며, 시리우스의 가로 경기 목록이나 남색 스킨을 복사하지 않습니다. 기존 실시간 스포츠/국내형 스포츠/인기경기의 최초6개·더보기6개를 유지하고 펼침과 접기에 같은 모션을 연결하세요. 중앙 영역을 한 화면 이상 내리면 우측 하단의 작은 버튼으로 중앙만 부드럽게 맨 위로 이동하게 하세요. 별도 검수 스레드는 사용하지 않습니다. 구현 중 기본 오류를 확인한 뒤 기존 MERCURY 공개사이트에 업데이트하고 URL·변경 요약·실제 배포 정보를 보고한 다음 사용자 피드백을 기다리세요. SIRIUS는 참고만 하며 수정하거나 재배포하지 마세요.

## 2. 더보기·접기 아코디언

- 실시간 스포츠 / 국내형 스포츠 / 인기경기 각각 최초6개, 더보기마다6개 추가를 유지한다. MERCURY는 3열 카드이므로 보통 두 줄씩 늘어난다. 잔여6개 미만이면 남은 경기만 표시한다.
- **카드 목록 영역의 높이가 펼쳐지고 접히는 애니메이션**을 적용한다. 승인된 SIRIUS의 속도·가감속을 재사용하되 MERCURY의 실제 카드 그리드 높이로 계산한다. 행높이·리그 구조를 시리우스 값으로 복사하지 않는다.
- 더보기 버튼은 해당 섹션 끝과 다음 섹션 사이 중앙에 둔다. 추가 노출분의 `접기`는 SIRIUS와 같은 의미로 최초6개까지 되돌린다. 모두 펼친 뒤에도 접기는 가능해야 한다.
- 이미 표시된 카드·고유 ID·선택을 유지하고 새6개만 아래에 드러나게 한다. 기존 카드를 다시 마운트하거나 전체를 처음부터 순차 등장시키지 않는다.
- 펼침 후 새 목록 끝으로 자동 이동하지 않는다. 읽던 위치를 유지한다. 접기에서는 제거되는 공간에 화면이나 초점이 남지 않도록 필요한 만큼만 보정한다.
- 한 섹션의 동작이 다른 섹션 확장 수·검색·종목 필터·슬립을 초기화하지 않게 한다. 검색/필터 결과가 바뀌면 현재 MERCURY의 규칙을 따른다.
- 연속 클릭에도 중복 경기·뜻하지 않은 여러 번 확장·잘림이 생기지 않게 SIRIUS의 중복 입력 처리를 함께 옮긴다. 모션 축소 설정도 같은 방식으로 처리한다.
- 새 구분선·카드 패널·로딩 연출을 추가하지 않는다. 기존 카드 모양과 간격은 유지한다.

## 3. 맨 위로 이동

- 대상은 MERCURY의 **실제 중앙 독립 스크롤 영역**이다. 전체 window 또는 좌우 레일 스크롤에 연결하지 않는다.
- 중앙 목록을 한 화면 이상 내려갔을 때 표시한다. 표시 조건·숨김·키보드 초점 처리는 승인된 SIRIUS 방식을 재사용한다.
- 중앙의 보이는 영역 **우측 하단, 오른쪽 레일 바로 왼쪽**에 놓는다. 카드와 함께 아래로 사라지지 않도록 중앙 바깥 틀에 고정한다.
- 클릭하면 현재 위치부터 중앙 최상단까지 부드럽게 올라가 끝에서 감속한다. 순간 이동으로 바꾸거나 먼 거리에서 지나치게 오래 이동하지 않는다. 승인된 SIRIUS의 시간·중단 처리·모션 축소 동작을 그대로 기준으로 삼는다.
- 검색/필터·더보기 확장 수·선택·슬립 금액과 좌우 레일의 스크롤 위치를 보존한다. 목록 초기화나 새로고침을 실행하지 않는다.
- 버튼의 크기·기능은 SIRIUS와 일관되게 하되 **표면·테두리·화살표 색은 MERCURY의 블랙·골드 계열**에 맞춘다. 남색 버튼을 가져오지 않는다. 간결한 작은 위 화살표와 `맨 위로` 접근성 이름을 사용한다.
- 배당·더보기·카드 조작이나 우측 슬립을 덮지 않게 한다. 필요한 최소 하단 여유만 허용한다. 기존 모달보다 위로 올라오지 않게 한다.

## 4. 유지할 범위

- MERCURY의 헤더, 로고 크기, 레일 순서/폭, 3열 경기 카드, 색감, 폰트, 이미지·배너는 유지한다.
- SIRIUS의 헤더 확대·계정 버튼·골드 텍스트·가로 경기 목록·추가 베팅 상세는 이번 이식 범위가 아니다.
- 현재 경기 데이터/ID/77경기 기준, 검색·종목·슬립·계산·계정 기능을 보존한다. 경기 수나 기존 현지 데이터가 더 최신이면 임의로 되돌리지 않는다.
- 기존 소스에 필요한 부분만 적용한다. 공유 모노레포·테마 엔진·새 애니메이션 라이브러리를 만드는 작업으로 확대하지 않는다.
- 새 이미지 리소스는 필요하지 않다. 사용자 요청 없는 이미지 생성·편집이나 플러그인 사용은 하지 않는다.

## 5. 구현 → 기본 확인 → 공개 반영

1. MERCURY 최신 상태와 배포 대상을 확인하고, SIRIUS의 승인된 두 기능 구현을 읽는다.
2. MERCURY 카드 그리드·중앙 스크롤 구조에 맞춰 필요한 동작만 적용한다.
3. 통상 빌드 후 더보기6→12→접기6, 중앙 한 화면 이후 맨 위로 이동, 기존 선택 유지 여부를 짧게 확인한다. 확인된 오류만 고친다.
4. **독립 QA/검수 스레드·WOG 감사·별도 PASS 보고·추가 승인 관문 없이** 기존 MERCURY에 공개 업데이트한다. R8 문서의 과거 독립 감사 요구는 이번 작업에 적용하지 않는다. 이 정책은 사용자 재개 지시 전까지 유지한다.
5. 공개 반영을 확인하고 기본 화면과 필요시 동작 증거를 남긴다. 실제 commit/버전/deployment ID, 변경 파일, 남은 문제를 현지 STATE에 간단히 기록한다.
6. 공개 URL과 변경 요약을 보고하고 사용자 피드백을 기다린다. SIRIUS 수정이나 다음 부위 작업으로 자동 진행하지 않는다.

통상적인 빌드/구현 중 오류 확인을 장시간 자체 감사로 확대하지 않는다. 예전 R8의 실시간 표현·이미지 출처·감사 미확인 사항은 기존 이력에 남기되 이번 모션 이식을 막는 새 완료 조건으로 삼지 않는다.
