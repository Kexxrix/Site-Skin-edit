문구와 배너 높이는 즉시 구현할 기본안이며 승인된 최종 시안은 아니다. 데모/체험/선택 연습/수집 고지를 넣지 않고 없는 혜택·지급 조건도 만들지 않는다. 버튼은 같은 이름의 기존 메뉴 동작을 재사용한다. 신규 사진1장만 제공됐다는 사실을 유지한다. 추가 사진이 꼭 필요하면 규격을 요청하되 가능한 적용을 먼저 끝낸다.

사진의 얼굴을 우측에 놓고 왼쪽 글자와 겹치지 않게 실제 크롭을 조절한다. CSS 프레임/DOM 문구/CTA/사진을 별도로 편집하며 이미지 한 장에 합성하지 않는다. 사이드바 폭은 그대로다. 좌측 먼저 적용하는 순서는 중간 검증이지 작업 종료 지점이 아니다.
