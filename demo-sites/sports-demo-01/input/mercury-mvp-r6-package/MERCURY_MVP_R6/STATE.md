## 4. 원인 확인과 정정

기획 문서 자체에서 잘못된 해석을 유도한 부분을 확인했다.

- R5의 `#12151A`, `#1B2027`, `#343B46` 등 기본 면/경계 값에는 푸른 기가 있었다. R6는 중립 면 토큰으로 교체했다.
- R5에는 ‘더 어두운 스코어/기준값 영역’ 및 기준값 ‘오목한 면’ 지시가 있었다. R6는 팀·점수·진행 상태의 같은 바닥면과 비클릭 정보의 평면 표시로 정정했다.
- R5는 엠블럼을 Left Panel 영역에서 설명하고 정확한 위치를 미확정으로 두었다. R6는 헤더 레터링 바로 왼쪽으로 확정하고 전용 사이드 패널 제거를 명시했다.
- 헤더 탭의 하단 경계와 헤더 공통 레일이 이중으로 구현될 여지가 있었다. R6 실행안은 탭 좌/상/우 윤곽 + 단일 공통 하단선이다.
- 감사 미실행은 전달 보고로 확인되지만, 구현자가 WOG를 복제해서 남색이 됐다는 원인은 확인되지 않았다. 이를 확정 사실로 기록하지 않는다.
