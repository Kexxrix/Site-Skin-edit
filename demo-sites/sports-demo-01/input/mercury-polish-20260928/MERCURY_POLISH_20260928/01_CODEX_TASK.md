| 순서 | 종목 | 경기 수 | 아이콘 |

- 숫자만 77에서 61로 덮어쓰지 않는다. 실제 경기 목록·검색·필터·리그별 합계가 같은 데이터에서 계산되도록 한다.
- 이 스포츠 화면의 미식축구 16경기는 대상 목록과 합계에서 제외한다. 테니스·E스포츠 종목 탭/행도 ALDEBARAN 구성에 맞춘다. 헤더와 퀵메뉴의 E스포츠 메뉴까지 삭제하는 작업은 아니다.
- 기존 원본 데이터나 과거 베팅내역을 파괴적으로 삭제할 필요는 없다. 현재 화면에 공급하는 경기 집합과 참조 관계를 올바르게 바꾼다.
- 신규 4종목과 배구는 경기 0, 선택 시 ‘등록된 경기가 없습니다’ 및 상세 패널의 경기 없음 상태가 연결되어야 한다. 임의 경기·선수·배당을 생성하지 않는다.
- 크리켓은 이번 대상에 포함하지 않는다. 1920px에서 모터스포츠까지 ALDEBARAN처럼 한 줄로 배치한다. 버튼 높이·글자 크기를 억지로 줄이거나 줄바꿈하여 맞추지 않는다.
- 종목 목록은 현재 구조상 **좌측 레일**에 있다. 우측 계정·슬립 레일에 새로운 종목 메뉴를 만들지 않는다.

## 2. 신규 아이콘 5개 적용

`assets/`에는 사용자 제공 PNG의 파일 바이트를 그대로 복사하고 이름만 명확하게 정리했다. 원본은 모두 256×256 RGBA이다. `reference-data/asset-manifest.json`에 원래 파일명·역할·SHA-256·알파 영역을 기록했다.

| 패키지 파일 | 원본 파일명 끝부분 | 대상 |
|---|---|---|
| `assets/mercury-sport-all.png` | `Layer-10.png` | 전체 / 트로피 |
| `assets/mercury-sport-formula1.png` | `Layer-11.png` | 포뮬라1 |
| `assets/mercury-sport-boxing.png` | `Layer-12.png` | 복싱 |
| `assets/mercury-sport-motorsport.png` | `Layer-13.png` | 모터스포츠 |
| `assets/mercury-sport-mma.png` | `Layer-14.png` | MMA |

- MERCURY 프로젝트의 기존 자산 규칙에 맞는 `public/` 하위 경로에 복사하고 모든 해당 표시 위치에 연결한다.
- 기존 흰색 트로피·임시 도형·ALDEBARAN의 흰색 신규 종목 아이콘을 이 파일로 교체한다.
- 원본 블랙·골드 재질, 비율, 투명도를 유지한다. 필터로 단색화하거나 이미지를 재생성하지 않는다.
- 아이콘 슬롯은 현행 구조의 상단 약 20px, 좌측 약 22px를 출발점으로 실제 ALDEBARAN 치수에 맞춘다. 숫자는 원본 이미지 크기와 혼동하지 않는다.
- PNG마다 투명 여백이 다르다. 특히 포뮬라1은 가로로 넓고, MMA는 세로형이다. 동일한 이미지 박스만 적용해 한쪽이 작거나 치우치지 않도록 실제 보이는 형태를 기준으로 중앙 정렬한다. 필요하면 아이콘별 래퍼 크기·내부 오프셋을 조정하되 원본 비율을 늘이거나 형태를 자르지 않는다.
- 상단/좌측 동일 종목은 같은 자산을 참조한다. 0경기 표현은 ALDEBARAN 동작에 맞추되 아이콘을 식별할 수 있어야 한다.


적용: 경기 카드의 배당 버튼, 상세 마켓 배당 버튼, +5,000부터 +1,000,000까지의 금액 추가 버튼. Figma 노드 243:379, 243:5743, 243:5914에서 확인했다. 일반 퀵메뉴·비선택 마켓 탭·계정 버튼까지 모두 그라데이션으로 바꾸지 않는다.

### 상태별 가독성 및 hover 수정

- Figma의 정지 화면에 없는 hover/focus/pressed 상태는 기존 동작을 유지하면서 같은 배색 안에서 처리한다. 새 색 테마를 추가하지 않는다.
- 확인된 결함: 선택한 배당에 마우스를 올리면 배경이 `#353535`로 바뀌고 글자는 `#171717`로 남아 읽기 어렵다.
- 선택된 배당은 골드 계열 배경과 어두운 팀명·배당 숫자를 유지한다. `selected + hover`에서 일반 회색 hover 규칙이 덮어쓰지 않도록 상태 우선순위를 수정한다. 목록·상세에 공통 적용한다.
- 골드 선택 상태 위에 청록 배당 숫자를 남기지 않는다. 미선택 상태로 돌아오면 청록 숫자를 복원한다.
- 비활성 베팅하기도 Figma처럼 골드 계열 형태를 유지한다. 불필요하게 전체 opacity를 낮춰 탁해지지 않게 하되, 실제 `disabled`와 클릭 차단·기존 안내 문구는 유지한다. 잠긴 배당은 별도의 잠금 상태를 유지한다.
- 라벨, N+, 아이콘+텍스트는 광학적으로 수직 중앙에 맞춘다. hover/focus로 크기·행 높이·위치가 흔들리지 않아야 한다.

## 4. 팀 이름 사이 스코어를 VS로 통일

- 국내형·해외형 스포츠 경기 카드의 두 팀 사이 중앙 슬롯에 `VS`를 표시한다.
- 기존 `1 : 1`, `6 : 3`, `5 : 1`, 종료 스코어, `- : -` 등의 조건부 출력은 이 카드 표시에서 제거한다.
- 중앙 슬롯의 폭·정렬·간격·글자 크기는 ALDEBARAN을 따른다. 두 팀 길이가 달라도 VS가 카드 중앙에서 이동하지 않게 한다.
- VS를 위해 실제 결과 데이터나 정산 기록을 변조하지 않는다. 변경은 카드의 표시 방식에 한정한다.
- 7회초·종료 등 이전 MERCURY 카드 부가 표시는 ALDEBARAN의 현재 일반 스포츠 카드 구성에 맞춰 정리한다. 현재 범위 밖의 인플레이·경기결과 페이지를 새로 만들거나 전역 스코어 기능을 제거하지 않는다.

## 5. 경기 목록·추가 마켓·기타 요소를 ALDEBARAN과 동기화

- 현지 ALDEBARAN 소스의 실제 경기/리그 데이터, 정렬, 마켓 생성·그룹화·필터 로직을 읽고 MERCURY에 맞게 이식한다. 공개 DOM 숫자를 수작업으로 복제하거나 새 임의 배당을 만들지 않는다.
- 종목별 61경기 구성, 리그 순서와 개수, 날짜·팀명·팀 로고·국가/리그 헤더의 표시 슬롯, 기본 배당, 최신 인기 게임 목록까지 같은 데이터 기준으로 연결한다.
- 상세 마켓은 기존 MERCURY의 3개만 남기지 않는다. ALDEBARAN의 확장 마켓, 종목별 차이, 라인 수, 그룹, 안내 문구, 탭 필터와 아코디언을 같은 수준으로 연결한다.
- 추가 마켓 버튼은 실제 경기별 마켓 수에 맞는 `N+`이다. 모든 경기를 3+, 10+ 또는 종목별 같은 값으로 고정하지 않는다. 숫자는 선택지 수·그룹 수와 혼동하지 않고 ALDEBARAN의 집계 정의를 그대로 사용한다.
- 2026-09-28 공개 화면 표본: 토론토 랩터스 80개, 토론토 메이플리프스 79개, 몬트리올 52개, 바이에른 뮌헨 111개. 이 수는 비교용 표본이며 하드코딩 값이 아니다. 당시 61개 카드의 VS와 서로 다른 N+ 표시를 확인했다.
- 목록/상세 같은 선택지의 가격·선택 ID·선택 상태가 일치해야 한다. 교체·해제·슬립 삭제·총 배당·예상 당첨금 계산까지 실제 연결한다.
- 이전 저장 슬립에 새 데이터와 맞지 않는 항목이 있으면 기존의 사용 불가/제거 흐름으로 처리한다. 계정·머니·과거 내역·저장소를 통째로 초기화하지 않는다.
- 레이아웃은 이미 이식한 헤더·좌우 레일·목록·상세·국내형 2열·독립 스크롤 구조를 유지한다. 폭/간격/높이/폰트 크기와 웨이트/숫자 및 라벨 정렬은 ALDEBARAN의 현재 대응 요소를 따른다.
- 브랜드 예외: MERCURY 로고·브랜드명·승인된 사진/배너·기존 골드 종목 아이콘 및 신규 5개 아이콘은 MERCURY를 유지한다. ALDEBARAN 로고·브랜드 문구·사진을 무조건 덮어쓰지 않는다. 제공되지 않은 장식 배경 이미지를 추가하지 않는다.
- ALDEBARAN 소스와 Figma는 읽기 전용 참조다. 수정·재배포하지 않는다.

## 6. 작업 순서

1. 현재 MERCURY 소스, 기존 운영 문서, ALDEBARAN 참조와 자산 경로를 확인한다. 기존 사용자 변경을 보존한다.
2. 종목 설정·경기 집합·마켓 로직을 맞추고 실제 집계값을 연결한다.
3. 신규 아이콘 5개를 복사·매핑하고 상단/좌측의 형태·정렬을 맞춘다.
4. Figma 배색·그라데이션을 기존 토큰과 컴포넌트에 적용한다.
5. 스코어 슬롯을 VS로 바꾸고 선택+hover 상태를 수정한다.
6. 아래 완료 조건을 확인한 후 기존 MERCURY 공개 주소에 반영한다. 결과는 기존 STATE와 통상 변경 보고에 남기고 다음 작업을 자동 시작하지 않는다.

## 7. 완료 조건

- 1920×1080 CSS viewport, 브라우저 100%, 폰트 로드 완료 상태에서 MERCURY 전체 화면을 확인한다. 브라우저 외곽 크기나 축소 캡처를 1920 검증으로 보고하지 않는다.
- 상단 10개 항목(전체 포함), 좌측 9개 종목 순서 일치. 전체 61 = 종목별 합계 = 실제 목록 경기 수. 미식축구 경기가 목록/검색/합계에 남지 않음.
- 신규 4종목과 배구 0경기 안내, 상세 패널 초기화 정상. 참조에서 가져온 61경기와 마켓 참조가 모두 유효함.
- 아이콘 5개 정상 로드, 원본 바이트/역할 매핑 일치, 검은 사각 배경·잘림·찌그러짐·치우침 없음.
- 카드 스코어 대신 VS, 첫 화면·필터 전환 후·국내형 모드에서도 동일.
- 골드/회색 그라데이션 방향과 위치가 Figma와 일치. 헤더는 단색, 일반 평면 버튼은 평면 유지.
- 라벨 주황/배당 청록/골드 강조는 이번 Figma 기준. 선택+hover에서 팀명과 배당이 분명히 읽힘.
- 축구·농구·야구·아이스하키 각 대표 경기에서 N+와 실제 상세 마켓 수가 일치하고, 탭 필터·아코디언·선택 연동 정상. N+와 마켓/그룹 수를 각자 다른 뜻으로 표시하지 않음.
- 배당 선택·교체·해제, 슬립 삭제, 금액 계산, 비활성 버튼, 독립 스크롤을 변경 범위에 맞게 점검한다. 최종 베팅 확정은 검수에서 실행하지 않는다.
- 기존 타입 검사/빌드를 통과하고 같은 공개 URL에서 핵심 변경을 재확인한다. 별도 새 테스트 체계나 무관한 리팩터링을 만들지 않는다.

## 패키지 읽는 법

- 이 문서가 작업 범위와 우선순위의 기준이다.
- `styles/mercury-figma-reference.css`: 확인된 색·그라데이션과 상태 처리 참조. 즉시 적용되는 완성 패치가 아니다.
- `reference-data/figma-style-facts.json`: Figma 읽기 결과의 색/그라데이션 근거.
- `reference-data/asset-manifest.json`: 5개 PNG의 역할과 원본 검증 정보.
- `reference-data/aldebaran-baseline.json`: 이번 공개 UI 확인의 종목 수·표본 기준. 전체 경기/마켓 원본 데이터 파일은 포함하지 않았으므로 현지 ALDEBARAN 소스에서 읽는다.
- 이 패키지 작성 단계에서는 실제 MERCURY 소스·Figma·배포를 변경하지 않았다.
