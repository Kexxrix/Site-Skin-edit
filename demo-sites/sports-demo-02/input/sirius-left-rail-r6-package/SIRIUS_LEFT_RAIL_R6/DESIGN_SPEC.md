# SIRIUS — R6 왼쪽 레일 구현 사양

문서 세트: **LEFT RAIL & THREE BANNERS R6 · 2026-09-18**

## 1. 방향과 고정 구조

머큐리의 작은 사각 제목 바·균일한 박스 버튼·촘촘한 종목 표현에서 벗어나, 시리우스의 남색과 샴페인 골드에 맞는 여백·둥근 입력창·정리된 타이포그래피를 적용한다. 새 장식보다 제목·버튼·목록의 형태 차이가 눈에 보이게 한다.

순서: **빠른 서비스 → 슬롯 배너 → 라이브 카지노 배너 → 이벤트 배너 → 경기 찾기 → 전체 스포츠/종목 목록 → 기존 나머지**.

- 레일 272px, 기존 중앙/우측 너비와 컬럼 간격 유지.
- 새 스타일은 왼쪽 루트 `.sirius-left-r6`에만 적용한다.
- 섹션 사이 14px, 배너끼리 10px를 시작값으로 한다. 빠른 서비스 패널과 검색/종목 패널은 별개의 묶음이다.
- 빠른 서비스·검색 패널은 얇은 남색 경계와 12px 반경, 낮은 표면 대비로 정리한다. 큰 금속 테두리나 반복 제목 바는 제거한다.
- 사진 배너의 프레임 반경은 8px. 검색창은 완전 캡슐형. 모든 것을 같은 캡슐 버튼으로 만들지는 않는다.

아래 수치는 디자인 구현 시작값이며 실제 폰트의 표시 크기에 따라 소폭 조정 가능하다. 폭·순서·배너 개수·기존 기능·다른 영역 보존은 확정 조건이다.

## L02. 빠른 서비스

- 제목 `빠른 서비스`는 16px/600, 오른쪽 `QUICK SERVICE`는 10px/500·자간 0.06em, 흐린 골드. 기존 꽉 찬 제목 바는 제거한다.
- 충전/환전은 같은 폭의 2열, 간격 8px, 높이 38px, 반경 7px, 한글 14px/600.
- 충전: 현재 헤더 회원가입 버튼과 같은 샴페인 골드 계열, 짙은 남색 글자. 환전: 헤더 로그인 계열의 깊은 남색 면·얇은 골드 경계·아이보리 글자.
- 고객센터는 그 아래 전체 폭 높이 36px의 낮은 대비 행으로 둔다. 아이콘과 글자는 왼쪽, 기존 이동 표시가 있으면 오른쪽. 큰 세 번째 골드 버튼으로 만들지 않는다.
- 기존 아이콘/핸들러/대화창을 재사용한다. 아이콘 슬롯 16–18px. 버튼 hover는 표면·테두리만 약하게 밝히며 120–160ms, 위치 이동과 계속 반짝이는 효과는 없다.
- 키보드 focus는 2px 골드 윤곽. 기존 비활성 상태가 있다면 유지한다.

## L03. 경기 찾기

- 제목 `경기 찾기`: 기존 Pretendard 계열 18px/600, 줄높이 24px, 자간 약 -0.02em. 새 한글 폰트를 받지 않는다. 글자 크기·굵기·여백으로 현재 머큐리와 차이를 만든다.
- 초기화는 제목 오른쪽의 작은 텍스트 버튼 12px. 기존 검색/필터 초기화 범위를 그대로 연결한다.
- 입력창은 높이 42px, `border-radius: 999px`, 남색 바탕 `#071127` 전후, 얇은 경계 `#344767` 전후. 제목 아래 간격 12px.
- 돋보기 16px, 왼쪽 여백 14px. 실제 입력 글자 14px/400–500. placeholder `팀 또는 리그 검색` 유지. focus 시 골드 경계와 약한 외곽선.
- 실제 검색과 연결된 input을 스타일 변경한다. 겉보기만 input인 div나 별도 중복 검색창을 만들지 않는다. 접근성 이름과 한글 입력 조합 처리는 기존 동작을 보존한다.
- 검색창/목록 위에 추가 영어 설명·광고 문구를 넣지 않는다.

## L04. 전체 스포츠와 종목

- 검색창 아래 12px 뒤에 목록 시작. `전체 스포츠`는 별도의 둥근 요약 행, 높이 44px, 반경 9px. 기존 트로피를 유지한다.
- 개별 종목은 높이 40px, 행 간격 3px, 반경 8px. 새로운 행 구분선은 넣지 않는다.
- 종목 이름 15px/500, 활성 항목 600. 아이콘 24×24px, 이름과 간격 10px, 기존 PNG 골드·알파 보존.
- 경기 수는 오른쪽 정렬, 고정 최소 폭 28px, 기존 DIN 17px/400로 표현한다. 전체 스포츠 숫자만 얇은 남색 캡슐 배경을 쓰고 흰 사각 배지는 제거한다. 경기 수와 종목 순서는 기존 데이터 그대로다.
- 기본: 투명 또는 낮은 대비 면, 텍스트 `#C3CCE0` 전후, 숫자 `#8D9FBF` 전후. 활성: 부드러운 남색 면, 약한 골드 경계, 이름·숫자 샴페인 골드. 기존 왼쪽 금색 막대와 흰 사각 숫자 배지 조합은 새 활성 표현으로 교체한다.
- 마우스 hover와 실제 선택 상태를 구별한다. 기존 필터 상태를 기준으로 active를 표시하고 `aria-pressed` 등 접근성 상태도 일치시킨다.
- 아이스하키/E스포츠, 두 자리·세 자리 경기 수가 들어가도 글자가 숫자 칸을 침범하지 않도록 한다. 종목 이름을 불필요하게 줄이지 않는다.
- 배당 DIN/공통 숫자 스타일은 건드리지 않고 **왼쪽 경기 수에 한정**해 동일 자산을 사용한다.

## B01. 사진 배너 3개

첨부 원본 6개는 모두 1672×941 PNG다. 사용할 3개는 아래와 같다. 한 배너에 한 장을 사용하며 콜라주로 합치지 않는다.

| 순서 | 용도 / 기존 연결 | 원본 파일 끝번호 | 패키지 | 상단 작은 영문 / 제목 / 보조 문구 |
| --- | --- | --- | --- | --- |
| 1 | 슬롯 메뉴 | (1) | assets/banners/slots.png | SIRIUS SLOTS / 슬롯 게임 / 새로운 즐거움을 만나보세요 |
| 2 | 카지노 메뉴 | (9) | assets/banners/casino.png | LIVE CASINO / 라이브 카지노 / 테이블의 열기를 가까이 |
| 3 | 이벤트 메뉴 | (4) | assets/banners/events.png | SIRIUS EVENTS / 이벤트 / 시리우스의 소식을 만나보세요 |

선정 이유: (1)은 슬롯 기계가 확실히 보이고, (9)는 카지노 테이블과 카드가 보여 메뉴 성격이 읽힌다. (4)는 녹색 의상으로 앞선 두 사진과 변화를 주는 일반 브랜드 배너다. 이벤트가 실제 진행 중이라는 별도 사실 주장은 넣지 않는다.

대안은 (5) 슬롯, (2) 카지노, (6) 일반 브랜드 이미지로 보관한다. 이번에는 위 지정 3장을 사용한다. 파일과 서비스 연결 키는 asset-map/banner-config JSON에 기록했다.

### 크기와 사진

- 배너 전체가 **16:9**. 폭 272px일 때 높이 `272 × 9 ÷ 16 = 153px`. border-box 기준이며 외부 캡션으로 높이를 추가하지 않는다.
- 사진은 전체 프레임을 채우는 `object-fit: cover; object-position: 50% 50%`. 원본 비율이 프레임과 거의 같으므로 불필요한 줌이나 강한 크롭은 하지 않는다.
- 얼굴을 크게 만들려고 원본을 늘리거나 좌우 반전하지 않는다. 사진 전체가 납작해지는 stretch도 금지한다.
- 인물의 얼굴은 상부에 있으므로 텍스트는 왼쪽 아래에 배치한다. 하단 55–60px 안에 짧은 세 줄로 구성하되 얼굴까지 올리지 않는다.
- 하단 가독성 그라데이션은 CSS 오버레이로 적용한다. 위는 거의 투명, 맨 아래는 깊은 남색 85–92% 수준으로 시작한다. 밝은 얼굴·카지노 조명이 사라지도록 사진 전체를 어둡게 하지 않는다.

### 문구와 클릭

- 패딩 14px. 영문 10px/600·골드, 제목 20px/600·화이트, 보조 문구 11px/400·연한 아이보리. 제목 줄높이 25px, 보조 줄높이 15px.
- `라이브 카지노`가 한 줄로 읽히도록 텍스트 영역을 잡는다. 더 긴 설명·슬로건·버튼을 추가해 공간을 채우지 않는다.
- **내부 CTA 버튼, 골드 사각 버튼, ‘바로가기’ 칩, 별도 화살표 버튼 없음.** 텍스트와 사진만 보인다.
- 배너 전체를 하나의 링크 또는 버튼으로 만든다. 현재 앱이 경로 이동이면 anchor/Link, 상태 전환이면 button을 쓰고 기존 메뉴 동작을 재사용한다. 중첩 버튼은 없다.
- 연결은 슬롯→현재 슬롯 메뉴, 카지노→현재 카지노 메뉴, 이벤트→현재 이벤트 메뉴. 실제 기존 대상/핸들러를 확인해 연결하고 임의의 `/slots`, `/casino`, `/events` 경로를 만들어 추정하지 않는다.
- 기존 메뉴가 안내 모달 방식이면 그 동작을 그대로 연결한다. 없는 신규 페이지를 구현하거나 빈 링크 `#`로 대체하지 않는다.
- hover 시 경계·사진 밝기의 아주 약한 변화만 허용한다. 패널 이동·확대·자동 순환은 없다. focus는 명확한 골드 윤곽.
- 접근성 이름은 `슬롯 게임 열기`, `라이브 카지노 열기`, `이벤트 열기`. 링크 이름에 포함된 의미를 장식 사진 alt로 중복 낭독시키지 않는다.

## B02. 세로 공간과 기존 기능

- 배너 3개의 총 높이는 `153 × 3 + 10 × 2 = 479px`다. 세 장을 배치하면 검색·종목이 아래로 내려가는 것이 예상된 결과다.
- 기존 왼쪽 레일 독립 스크롤을 유지한다. flex 컨테이너에서 배너가 153px보다 작게 눌리거나 마지막 종목이 잘리지 않게 한다. 레일 자체의 `min-height:0`/overflow 설정을 현지 구조에 맞춰 유지한다.
- 검색/목록에 별도 중첩 스크롤을 추가하지 않는다. 콘텐츠를 한 화면에 억지로 넣기 위해 16:9를 3:1로 바꾸거나 종목 행을 과도하게 줄이지 않는다.
- 배너 3개는 빠른 서비스와 검색 사이에 있다. 기존 슬롯 배너는 제거/교체해 중복을 없앤다. 하단에 대안 사진 3장을 추가하지 않는다.
- 다른 컬럼과 헤더를 밀어내지 않고 왼쪽 안에서만 콘텐츠 길이가 늘어난다. 오른쪽 베팅슬립은 수정하지 않는다.

## 참고 파일 연결과 확인

`implementation/sirius-left-rail-r6.css`의 클래스는 이 사양을 구현하기 위한 시작값이다. 기존 DOM에 대응 클래스를 붙이거나 규칙을 기존 왼쪽 선택자로 옮긴다. 전역 덮어쓰기와 불필요한 `!important` 누적은 피한다. `SiriusLeftBanners.tsx`는 메뉴 동작을 전달받는 참고 컴포넌트이며 브라우저/서버 환경에 맞게 기존 클라이언트 컴포넌트에서 사용한다.

구현 중 기존 충전/환전/고객센터, 검색·초기화·종목 필터, 배너 3개의 실제 연결과 얼굴·문구, 레일 마지막 항목까지의 스크롤만 짧게 확인한다. 통상 빌드 후 바로 기존 공개사이트를 갱신한다. 별도 검수 스레드·전수 QA는 만들지 않는다.
