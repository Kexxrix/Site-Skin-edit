# SIRIUS — R6 작업 공통 규칙

문서 세트: **LEFT RAIL & THREE BANNERS R6 · 2026-09-18**

## 실행 원칙

- 최신 사용자 지시 → R6 확정 범위 → 구현 시작값 → 충돌하지 않는 과거 규칙 순서다.
- AGENTS → STATE → DESIGN_SPEC 순서로 읽는다. DECISIONS는 결정 이력이다.
- 운영 문서는 이 네 MD만 관리한다. 별도 README/HANDOFF/QA 문서를 추가하지 않는다. 자산 매핑 JSON, CSS/TSX 참고 코드, 과거 기록 JSON은 허용한다.
- 현지 최신 SIRIUS 코드와 실제 배포 기록에서 이어 작업한다. 이 패키지의 구현 전 상태로 현지 완료 기록을 덮어쓰지 않는다.
- **이번 대상은 왼쪽 레일이다.** 빠른 서비스 버튼, 경기 찾기, 종목 목록의 표현을 변경하고 첨부 사진으로 배너 3개를 구성한다.
- R5의 ‘추가 배너 금지·기존 슬롯 배너 하나만 사용·좌측 전체 재설계 제외’는 이번 사용자 지시 범위에서 대체된다. 이 과거 제한 때문에 작업을 멈추거나 다시 승인을 요청하지 않는다.

- 기존 진행/구현 스레드를 사용한다. **사용자가 재개하기 전까지 별도 검수 스레드는 없다.** 통상 빌드와 변경 부분의 짧은 오류 확인 후 바로 기존 공개사이트에 반영하고 사용자 피드백을 받는다.

- MERCURY 소스·자산·문서·공개 배포는 변경하지 않는다.

## 작업 경계

- 왼쪽 레일 폭은 기존 272px를 유지한다. 중앙·오른쪽 폭과 배치, 헤더 134px·우주 배경·브랜드·메뉴는 유지한다.
- R5의 DIN 배당·골드 숫자·선택 상태·점수·아이콘, R4 마켓 간격·추가 베팅 우측 정렬, 승인된 아코디언·맨 위로 이동은 보존한다.
- 디자인 변경은 왼쪽 전용 클래스 아래에 둔다. 전역 button/input/.panel/.num/.photo-banner 규칙을 바꿔 오른쪽 레일이나 중앙까지 재디자인하지 않는다.
- 기존 기능과 상태를 이어 연결한다. 충전·환전·고객센터, 검색·초기화·종목 필터, 메뉴 이동을 새로 구현하거나 빈 클릭으로 대체하지 않는다.
- 첨부 원본 사진은 변경하지 않는다. HTML 텍스트와 CSS 배치·가독성 그라데이션으로 배너를 구성한다. 이미지 생성/외부 편집 플러그인/합성·얼굴 교체·좌우 반전·색보정은 실행하지 않는다.
- 배너는 정확히 3개이며 내부 버튼은 없다. 예전 슬롯 배너를 그대로 남겨 총 4개가 되지 않게 한다. 별도 캐러셀·자동 순환·새 페이지는 만들지 않는다.
- 전체 원본 6개 중 지정된 3개만 노출한다. 나머지 3개는 교체 후보이며 공개 앱에 복사할 필요가 없다.
- 기능을 설명하는 개발용 문구를 방문자 UI에 추가하지 않는다.

## 완료

최소 수정 → 통상 빌드·기본 동작 확인 → 기존 SIRIUS 공개 업데이트 → 실제 변경/배포 정보/남은 문제를 STATE에 짧게 기록 → 사용자 피드백 대기. 다음 오른쪽 레일 작업으로 자동 진행하지 않는다.
