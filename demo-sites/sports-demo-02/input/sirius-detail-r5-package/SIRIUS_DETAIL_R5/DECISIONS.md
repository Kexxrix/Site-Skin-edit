## 지속되는 기준

- D41/D42: 별도 검수 스레드 중단, 구현·기본 확인 후 공개 반영, 사용자 피드백. 재개 지시 전 유지한다.
- D44/D45: 더보기·맨 위로 및 리그/종목 접기 동작은 사용자 수용 상태로 보존한다.

- SIRIUS는 별도 프로젝트/공개 URL, 남색·화이트·골드와 중앙 가로 경기 목록을 유지한다. 로고·팀·리그·국기 변경은 이번 범위가 아니다.

## 원본·표시 데이터 구분

사용자는 실제 서비스처럼 보이는 정보 밀도를 위해 예시 점수를 허용했다. 이 허용을 실제 경기 피드 확보·실제 결과 검증으로 보고하지 않는다. 원본 경기·배당·계산·거래 로직은 유지하고, 화면용 점수와 필요한 표시 상태만 별도 관리한다. 화면에 데모/가상/개발 해설 문구를 노출하지 않는 기존 방향도 유지한다.

점수가0인 것은 누락이 아니다. 렌더마다 바뀌는 난수나 상세마다 다른 점수는 허용하지 않는다. 소수 세 자리 배당의 수치를 줄여 공간에 맞추지 않는다.

## 근거와 남은 범위

공개 DOM에서 스코어 din-condensed24px/400과 배당 Pretendard17px/800, 선택 배경 #FCE1A4→#D7B96C·글자#101A34를 관찰했다. 배당값의 부모 폭이 실제 숫자보다 좁은 현상도 관찰했다. 현지 소스 원인 확인과 수정은 구현 담당 작업이다.

신규 아이콘7개는 사용자 제공256px RGBA 원본이다. E스포츠 신규 파일은 제공되지 않았다. 배너 사진은 현지 기존 자산이며 새 사진이 아니다. 사용자 문구의 최종 의도는 여러 배너를 쌓을 수 있는 가로16:9로 해석했다.

R4 실제 배포 식별자/빌드 결과는 아직 별도 보고를 받지 않았다. R5는 이 기획 대화에서 파일을 준비한 단계이며 앱 구현·배포는 수행하지 않았다. R4 원문은 history/previous-records.json에 보존하고 이전 제한을 새 지시보다 우선하지 않는다.
