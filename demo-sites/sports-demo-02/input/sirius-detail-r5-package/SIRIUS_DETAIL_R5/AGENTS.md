- 최신 사용자 지시 > 이 R5 확정 범위 > 구현 시작값 > 충돌하지 않는 이전 규칙 순서다.

- 현지 최신 코드와 사용자 변경을 출발점으로 삼는다. 현지 문서의 실제 완료·배포 기록을 이 패키지의 실행 전 상태로 덮어쓰지 않는다.

- 최신 사용자는 화면에 실제 서비스 같은 정보가 채워지는 것을 최우선으로 강조했다. **이전 점수 임의 변경 금지 조항은 이번에 명시적으로 허용한 빈 점수용 표시 데이터에 한해 대체된다.** 이를 이유로 대시를 남기거나 다시 확인을 요청하지 않는다.

별도 검수 스레드는 사용자 재개 지시 전까지 사용하지 않는다. 구현 담당이 통상 빌드와 수정 부분의 짧은 오류 확인을 마치면 기존 SIRIUS에 바로 공개 반영한다. 사용자와 이 기획 대화에서 판단한다. 독립 QA·전수 감사·PASS 보고·WOG 비교·장시간 승인 절차를 만들지 않는다. 필요한 몇 가지 표시 사례는 구현 중 확인하고 별도 검수 단계로 확장하지 않는다.

기존 진행/구현 스레드를 이어 쓴다. 이 문서를 만든 대화에서 외부 Windows 스레드를 조작하거나 사이트를 배포했다고 기록하지 않는다.

## 보존 기준과 이번 예외

- 헤더134px와 제공 우주 배경, 중앙 브랜드·2단 메뉴·계정 버튼·탐색 패널은 유지한다.
- R4의 마켓 그룹 사이42px/내부4px, 추가 베팅56px·우측 끝 정렬을 우선 보존한다. 배당 넘침을 숨기기 위해 그룹 간격을 다시 좁히지 않는다.
- 사용자가 수용한 더보기·접기, 리그별·종목별 접기, 맨 위로 모션의 속도·곡선·상태 보존은 그대로 둔다.
- 기존 유효한 점수와 원본 경기/배당 데이터는 보존하고, 누락 점수만 별도 화면용 예시 자료로 보충한다. 표시용 상태 조정은 그 점수에 맞추되 베팅 가능 여부·정산·슬립 계산과 분리한다.
- 배당값을 반올림/삭제하거나 점수/배당에 말줄임을 적용해 맞추지 않는다. 팀명에만 기존 말줄임을 유지한다.
- 선택된 배당의 박스 그라데이션과 어두운 글자색은 유지한다. DIN 폰트는 선택/비선택 배당 숫자에 공통 적용한다.
- 첨부7종만 교체하고 E스포츠는 기존 아이콘을 유지한다. 팀·리그·국기·로고는 교체 대상이 아니다.
- 좌측 레일 폭은 유지한다. 기존 슬롯 배너 한 개를 이동·축소하며 중복 배너나 신규 배너 콘텐츠를 임의 추가하지 않는다.
- 방문자 화면에 데모·가상·예시·목업·개발 해설 문구를 넣지 않는다. 내부 문서/자료에는 점수가 화면용 예시임을 사실대로 남긴다.
- 새 이미지 생성, 외부 편집 플러그인, 원본 PNG 재색보정/트레이싱은 실행하지 않는다.
