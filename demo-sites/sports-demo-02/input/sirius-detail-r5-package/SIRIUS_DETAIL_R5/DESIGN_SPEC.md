# SIRIUS — R5 구현 사양

문서 세트: **SCORES, ODDS, ICONS & LEFT BANNER R5 · 2026-09-18**

## S01. 대시로 남은 점수 보충

사용자는 실제 운영 화면처럼 정보가 채워져 보이는 것을 우선하며, 빈 점수에 그럴듯한 임의 점수를 넣으라고 명시했다. 예정 경기에는 원래 점수가 없다는 설명으로 수정 없이 끝내지 않는다.

- 현지에서 점수 필드, null/undefined 처리, 예정 상태에 대한 렌더 조건을 확인한다. 실제 값이 있는데 숨긴 경우 그 연결을 먼저 고친다.
- 기존 유효한 점수는 보존한다. `0`은 정상 점수이며 falsy 검사로 누락 처리하지 않는다. 한쪽만 없는 경우 존재하는 쪽을 유지하며 자연스러운 짝을 보충한다.
- 양쪽 모두 비어 있으면 `assets/display-score-templates.json`의 종목별 자료를 기존 fixture ID와 연결해 고정한다. 고정 맵이나 안정적 ID 해시를 이용하며 렌더마다 Math.random을 실행하지 않는다.
- 기존77경기 목록과 상세에서 빈 점수가 남지 않도록 공통 표시 함수를 사용한다. 검색/필터/더보기/접기/새로고침/상세 복귀로 점수가 바뀌지 않아야 한다. 홈과 원정 순서도 동일하다.
- 숫자만 채워 `예정`과 진행 점수가 동시에 보이게 두지 않는다. 예시 점수를 보충한 경기의 화면용 상태/진행 표현도 같은 예시 레코드와 맞춘다. **표시 상태와 베팅 허용·마켓 잠금·정산 로직을 분리**하고 실제 데이터의 상태를 덮어써서 베팅 기능이 달라지게 하지 않는다.
- 원본 경기/배당 데이터는 보존한다. 화면용 자료를 명시적으로 구분하고 내부 문서에 출처를 남긴다. 실제 실시간 피드나 실제 경기 결과라고 보고하지 않는다. 방문자 화면에 개발 설명을 붙이지 않는다.
- 원본 시작일/시간을 새로 수집하거나 시간 경과에 맞춰 임의 갱신하는 기능, 점수 자동 증가, 실시간 피드 구축은 이번 범위가 아니다.
- 축구/하키는 골, 야구는 득점, 농구/미식축구는 점수, 배구/테니스는 세트 등 종목에 맞는 단위를 쓴다. 농구는112:108 같은 세 자리 예시도 포함한다. E스포츠는 실제 경기 데이터가 있을 때 해당 게임/시리즈 단위에 맞추며, 현재0경기를 새로 만들지 않는다.

현재 예시 JSON의 의미상 sport 키는 현지 enum에 매핑한다. 새 fixture ID를 만들거나 표시용 자료 때문에 전체 경기 수를 늘리지 않는다. 전체 목록에 같은1:0/0:0을 일괄 반복하지 않는다.

## O01. 배당 숫자에 기존 DIN 적용

- 현재 스코어의 `din-condensed` 폰트 등록과 자산을 재사용한다. 비슷한 폰트로 대체하거나 새 폰트 파일을 구하지 않는다.
- 숫자에만 적용한다. 홈/무/원정, 기준점 설명, 메뉴·팀명·금액 표시 등 한글 UI 전체를 DIN으로 바꾸지 않는다.
- 목록과 경기 상세의 같은 배당 컴포넌트에 적용하고 선택/비선택에서도 같은 폰트를 쓴다. 전역 `.num` 선택자로 잔액·카운터까지 바꾸지 않는다.
- 현재 스코어는24px/400, 배당은17px/800이다. 배당은 **20px/400 전후를 구현 시작값**으로 하고 46px 버튼 안의 시각적 중심·가독성에 맞춰 최소 조정한다. 기존800 굵기를 그대로 남겨 가짜 굵기를 만들지 않는다.
- 소수점과 숫자가 명확하게 보이고 값의 위치가 흔들리지 않게 한다. `white-space: nowrap`와 필요시 tabular numerals를 쓰되 실제 폰트의 렌더링을 확인한다.

## O02. 비선택 배당 숫자 골드

| 상태 | 숫자 | 박스와 라벨 |
| --- | --- | --- |
| 활성·비선택 | 현재 선택 박스에서 가져온 골드. 기본안 `#FCE1A4` | 남색 박스와 기존 홈/원정 라벨 유지 |
| 선택 | 현재 어두운 숫자색 `#101A34` 유지 | 현재 `#FCE1A4 → #D7B96C` 선택 그라데이션 유지 |
| 잠금/비활성 | 기존 비활성 대비·잠금 표현 유지 | 활성 배당처럼 밝은 골드로 강조하지 않음 |

사용자가 요청한 색상 변경 대상은 비선택 **배당 숫자**다. 선택 박스 재디자인이나 모든 텍스트의 골드화가 아니다. 새 금색을 발명하지 말고 현지 선택 색상 토큰을 재사용한다. 위 값은 공개 계산 스타일에서 확인한 기준이며 현지에 같은 토큰이 있으면 연결한다. 새 숫자 그라데이션 효과는 요청되지 않았다.

기존 hover/pressed/focus 표시를 유지하고 hover에서 숫자가 다시 흰색으로 돌아오지 않게 한다. 선택 해제 시 DIN 골드 숫자로 돌아와야 한다. 선택 상태의 색은 그대로 두되 O01의 폰트 변경은 공통으로 적용한다.

## O03. 소수 세 자리 배당과 세 자리 점수의 넘침 해결

사용자 두 번째 캡처의 핵심은 `2.125`처럼 **소수 셋째 자리까지 있는 배당값**이다. 정수 세 자리 스코어만 확인하고 이 문제를 놓치지 않는다.

- 3-way 승무패 그룹의 현재 버튼은 약80.66px, 라벨과 숫자는 한 줄이다. 숫자 부모만 좁아지고 안의 strong이 계속 넓으면 넘침이 남는다. DIN 적용 후 실제 글자·라벨·gap·padding·border 합계가 버튼 폭 안에 들어가게 한다.
- 숫자는 원문 그대로 모두 표시한다. `2.125 → 2.13` 반올림, 값 삭제, 숫자 말줄임, overflow:hidden으로 잘라 숨기기, CSS transform 압축으로 문제를 감추지 않는다.
- 숫자 칸이 글자보다 작게 줄어들지 않게 하고, 라벨/숫자 칸과 패딩을 해당 컴포넌트에서 조정한다. 한 줄·라벨 왼쪽/숫자 오른쪽의 현재 방식을 우선 유지한다. 공통 마켓 폭과42px 그룹 간격을 먼저 보존한다.
- 필요하면3-way에 한정해 좌우 패딩이나 내부 간격을 소폭 조정한다. 모든 배당 버튼을 늘리거나 마켓 그룹 간격을 다시 좁히지 않는다. 폰트 크기 조정은 가독성을 유지하는 범위로 제한한다.
- 원데이터의 정밀도와 슬립 계산을 바꾸지 않는다. DOM은 숫자를 문자열로 표시하더라도 기존 계산용 값과 대응한다.
- 스코어는 팀명 옆 현재40px 칸을 우선 유지하고112/108 같은 세 자리가 들어가는지 본다. 점수에 말줄임을 적용하지 않고 팀명이 길면 팀명만 말줄임한다. 스코어를 배당 옆으로 다시 밀지 않는다.

구현 중 확인할 대표 사례는3-way의2.125, 현지 데이터에서 가장 긴 배당값,2-way/잠금/선택 상태, 농구112:108이다. 필요한 로컬 표시 사례로 짧게 확인하고 공개 원본 배당을 테스트 값으로 바꾸지 않는다.

- 기존 아이콘 슬롯 크기를 우선 유지한다. 좌측은 현재24×24px이며 다른 위치는 기존 크기에 맞춘다. 공통 상자 안에서 `object-fit: contain`, 중앙 정렬, flex-shrink 방지를 적용하고 종목마다 높이/기준선이 들쭉날쭉하지 않게 한다.
- 테니스 라켓과 하키 스틱을 원형 마스크로 자르지 않는다. 원본 윤곽을 살리고 흰색/아이보리 사각 받침을 추가하지 않는다.
- 실제 미첨부 파일을 있다고 가정하거나 E스포츠 대체 이미지를 생성하지 않는다.

## L01. 빠른 서비스 아래의 가로 슬롯 배너

왼쪽 순서를 **빠른 서비스 → 슬롯 배너 → 경기 찾기/종목 목록 → 기존 나머지**로 바꾼다. 기존 하단 슬롯 배너를 이동하는 것으로, 같은 배너를 두 개 만들지 않는다.

- 레일 너비272px 유지. 배너 전체 프레임은16:9를 기준으로272×9÷16=153px. `aspect-ratio: 16 / 9`와 border-box 기준으로 설정한다. 기존272×240 고정 높이는 제거한다.
- “정사각형”보다 뒤에 명시한 “16:9 정도, 가로로 긴 비율, 향후 여러 개 배치”를 최종 배치 의도로 해석한다. 새 정사각형 배너를 만들지 않는다.
- 현재 `/banners/r8/mercury-slots-woman.png` 이미지를 재사용한다. 경로 이름만으로 머큐리 사이트를 수정하지 않는다. 이미지 교체나 새 사진 생성은 이번 범위가 아니다.
- 사진은 오른쪽 인물 얼굴이 텍스트/CTA에 가리지 않도록 배치한다. 왼쪽 카피, 오른쪽 인물이라는 현재 방향을 유지하며 새 프레임에 맞춰 CSS 크기·위치만 조정한다.
- 대표 CTA는 정확히 `슬롯 둘러보기`. 기존 슬롯 이동 동작을 이어 쓴다. 타이틀 `빛나는 밤, 새로운 즐거움.`과 브랜드 표기는153px 안에서 짧게 정리하고, 타이틀/CTA를 카드 바깥으로 빼서 총높이를 늘리지 않는다.
- 큰 하단 골드 버튼이 사진을 대부분 가리지 않게 카드 안에 간결하게 배치한다. 전체 배너를 링크로 만들 경우 기존 버튼과 중첩 인터랙티브 요소를 만들지 않는다. 접근성 이름과 키보드 작동을 유지한다.
- 기존 좌측 패널 사이 간격과 수평선을 유지한다. 향후 같은 크기 배너를 세로로 추가할 수 있는 단순 영역만 준비하며 캐러셀·편집기·추가 배너2개를 이번에 만들지 않는다.
- 경기 찾기/종목 목록이 아래로 이동해도 좌측 독립 스크롤과 검색/필터 기능은 유지한다. 우측 레일과 중앙 너비를 바꾸지 않는다.

## 실행 확인 범위

통상 빌드 후, 누락점수 보충/상세 일치,2.125의 전체 표시와 선택/해제 색,7종 아이콘의 매핑, 배너 위치·얼굴·슬롯 이동을 구현자가 짧게 확인한다. 별도 QA 스레드·전수 감사·긴 보고는 추가하지 않는다. 확인된 오류를 수정하고 기존 SIRIUS 공개사이트에 반영한 뒤 사용자 피드백을 받는다.
