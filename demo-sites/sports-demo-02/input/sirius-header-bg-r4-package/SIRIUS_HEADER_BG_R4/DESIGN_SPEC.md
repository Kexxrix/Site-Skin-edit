# SIRIUS — R4 구현 사양

문서 세트: **HEADER BACKGROUND & MARKET SPACING R4 · 2026-09-18**

## B01. 제공 이미지를 헤더 전체 배경으로

### 적용 범위

사용자 제공 `assets/header/BG_sirius_header.png`를 공통 헤더에 한 번만 적용한다. 상단 브랜드 줄과 하단 메뉴 줄을 가로질러 하나의 우주 배경이 이어져야 한다. 기존 심볼/레터링은 배경 위에 독립 이미지로 유지하고 텍스트·버튼도 기존 DOM을 유지한다.

- 전체 높이134px = 브랜드 줄84px + 메뉴 줄50px. 이미지 원본 높이199px에 맞추려고 헤더 높이를 늘리지 않는다.
- 기존 남색 헤더 그라데이션은 이미지로 대체하고 어두운 남색 fallback을 둔다.
- 브랜드 줄과 메뉴 줄의 배경은 투명하게 한다. 현재 메뉴 줄의 불투명 남색 면이 사진을 가리게 두지 않는다.
- 기존 얇은 줄 경계, 메뉴 활성 골드 텍스트·골드 선, 로그인/회원가입 스타일과 배치는 유지한다.
- 메뉴 탐색 패널과 모달은 현재 읽을 수 있는 독립 배경을 유지한다. 모든 헤더 자손을 일괄 투명 처리하지 않는다.

### 크기와 위치

기본값은 `background-size: cover; background-position: center center; background-repeat: no-repeat`다. 원본 비율을 유지하며 헤더 면을 채운다. 반복 타일, 강제 세로 압축, 헤더 높이 확대를 하지 않는다.

1920px 폭에서 이미지 높이199px와 헤더134px의 차이는199−134=65px다. 중앙 기준으로 상하 약32.5px씩 잘릴 수 있다. 이것은 표시 영역에서의 크롭이며 원본 PNG를 잘라 저장하는 작업이 아니다. 실제 공개 화면에서 우측 행성과 궤도 장식이 과도하게 잘리면 세로 background-position만 최소 조정하고 실제 적용값을 STATE에 남긴다. 이미지 전체를 보이게 하려고 메뉴 높이나 로고 위치를 변경하지 않는다.

현재 클래스와 권장 경로 기준 최소 예시:

```css
/* 기존 헤더 규칙에 병합. .topbar 크기와 overflow는 그대로 유지 */
.topbar {
  background-color: #060a2a;
  background-image: url('/assets/header/BG_sirius_header.png');
  background-size: cover;
  background-position: center center;
  background-repeat: no-repeat;
}
.topbar > .brand-row,
.topbar > .menu-row {
  background: transparent;
}
```

- 실제 DOM·경로가 다르면 현지 구조에 맞춰 같은 범위로 적용한다. 예시를 위해 전체 스타일을 재작성하지 않는다.
- 배경은 장식이므로 새 접근성 읽기 텍스트나 클릭 영역을 만들지 않는다. CSS background를 우선 사용한다.
- 별도 이미지 레이어를 사용할 사유가 있다면 해당 레이어만 `pointer-events: none`으로 두고 기존 버튼·팝업의 쌓임 순서를 유지한다.
- 공통 헤더에 `overflow: hidden`을 추가하지 않는다. 탐색 패널이 헤더 밖으로 열리는 현재 동작을 보존한다.
- 기본은 원본을 그대로 보여 준다. 일괄 brightness 필터·검은 덮개·블러·광택 애니메이션·새 반짝이 효과는 추가하지 않는다. 배경 조정이 필요하면 우선 위치로 해결하고 임의로 이미지를 재가공하지 않는다.

## N01. 추가 베팅 열과 세 마켓의 간격

참고: `references/additional-market-width-feedback.png`. 현재 문제는 추가 베팅에 넓은 폭이 남으면서 승무패/핸디캡/오버언더가 충분히 분리되지 않는 것이다.

1. 추가 베팅의 `+숫자`와 화살표를 한 묶음으로, 행 콘텐츠 우측 끝에 오른쪽 정렬한다. 기존의 작은 행 안쪽 여백은 유지한다.
2. 추가 베팅 열을 `+128`·화살표·필요한 클릭 여유가 들어가는 간결한 폭으로 줄인다. 가변 잔여 폭을 이 열에 몰아주지 않는다. 한 자리 수에서도 동일한 우측 기준선을 유지한다.
3. 회수한 폭을 **승무패–핸디캡**, **핸디캡–오버언더** 사이 두 간격에 배분한다. 그룹 내부 버튼 간격은 현재 작은 간격을 유지한다.
4. 배당 버튼의 폭·높이는 우선 유지한다. 확보한 폭이 버튼 늘리기나 행 좌우의 큰 빈 공간으로 다시 소모되지 않게 한다.
5. 제목 행과 경기 행의 공통 열 정의를 유지한다. 2-way 승패와3-way 승무패 모두 그룹 단위 정렬을 맞추고 `추가 베팅` 제목도 축소한 열 안에 배치한다.
6. 팀명과 점수의 거리·세 자리 점수 공간·긴 이름 말줄임은 현재 구현대로 유지한다.

새 구분선·마켓별 패널·배경 박스·장식은 추가하지 않는다. 기존 경기/리그 경계는 유지한다. 정확한 새 간격 픽셀은 실제 가용 폭에서 정하며 R3의16~20px 시작값을 목표치로 고집하지 않는다. 세 마켓이 세 묶음으로 분명히 보이는지가 사용자 피드백 기준이다.

추가 베팅의 경기별 고정 표시 수, 상세 연결, 복귀 시 검색·필터·펼침 상태·읽던 위치·슬립 보존은 그대로 유지한다. 추가 마켓 데이터나 가상 배당 생성은 이번 작업에 포함하지 않는다.

## 유지할 승인 동작

- 더보기 최초6개·추가6개와 접기 애니메이션.
- 리그별·종목별 접기/펼치기.
- 중앙 영역만 부드럽게 움직이는 맨 위로 이동과 현재 표시 조건.
- 현재 동작의 속도·곡선·상태 보존. 과거 문서의 제안 시간에 맞추려고 재조정하지 않는다.

## 간단한 완료 확인

구현자가 통상 빌드 후 이미지가 두 헤더 줄에 이어지는지, 메뉴/탐색/계정 버튼이 작동하는지, 축구3-way와 다른 종목2-way에서 열 정렬·추가 베팅 표시가 잘리지 않는지만 짧게 확인한다. 확인된 문제를 고쳐 배포한다. 별도 QA 스레드·전수 회귀·새 테스트 체계·미감 PASS 판정은 추가하지 않는다.
