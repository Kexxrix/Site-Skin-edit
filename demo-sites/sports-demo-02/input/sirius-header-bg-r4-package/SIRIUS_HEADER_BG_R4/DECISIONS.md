## 유지되는 사이트 기준

SIRIUS는 MERCURY와 별도 공개사이트다. 중앙 브랜드·2단 메뉴, 깊은 남색·화이트·골드, 리그별 가로 경기 목록을 유지한다. 심볼·레터링·금속 종목 PNG8개와 팀/리그/국기·기존 배너는 현지 승인 자산을 이어 쓴다. NHL 로고와 현재 팀명은 재작업하지 않는다.

스코어는 팀명과 같은 묶음, 마켓 그룹은 간격만으로 구분한다. 추가 베팅 표시 수는 경기별 고정 화면용 값이며 실제 데이터와 구분한다. 점수·시간·배당·잔액을 임의로 변경하지 않는다. 방문자에게 데모/목업/개발 해설을 노출하지 않는다.

## 이력과 근거

- R1/R2 완료 보고 및 R3 공개 관찰 기록은 이전 문서에 있다. R3의 정확한 배포 식별자와 현지 빌드 결과는 아직 별도 완료 기록을 받지 않았으므로 구현 담당의 현지 최신 기록을 따른다.
- 최근 공개 실측에서 헤더134px와 상단84px/메뉴50px를 확인했다. 메뉴 줄은 불투명 남색이어서 배경 이미지 적용 시 투명 처리할 필요가 있다.
- 제공 헤더 이미지1920×199px는 원본 그대로 패키지에 포함했다. 높이 차이에 따른 표시 크롭은 CSS에서 처리하며 PNG를 재생성하거나 재가공하지 않는다.
- 이번 문서 제작은 작업 지시와 리소스 정리다. 이 대화에서 실제 앱 수정이나 배포를 수행한 상태가 아니다.
- R4 직전 네 문서 원문은 `history/previous-records.json`에 보존한다. 그 안의 과거 실행 범위·시간/픽셀 시작값은 현재 지시보다 우선하지 않는다.

레일 재구성, 새 배너, 새로운 아이콘, 후속 사이트2개, 실시간 데이터 보강은 별도 후속 작업이다. R4 완료 후 사용자 피드백을 기다린다.
