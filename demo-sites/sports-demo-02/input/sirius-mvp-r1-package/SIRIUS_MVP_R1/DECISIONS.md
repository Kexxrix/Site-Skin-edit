## 확정 방향과 실행 기본안의 구별

고정1920 방향, 독립 스크롤, 지정 폰트 역할 등은 기존 기준을 이어받는다. 헤더68/공지32/열272·1280·320 같은 수치, 중앙 행88px·버튼38px, 새 색상 HEX, 로고 표시36/42px, 리그 그룹 접기와 공통 열 폭 등은 **실행 시작값**이다. 수치 자체의 고수가 완성도보다 우선하지 않는다. 사용자 확정 구조를 훼손하지 않는 범위에서 실제 렌더로 조정하고 중요한 변경만 STATE에 기록한다.

William Hill의 흰색 중앙 패널, bwin의 가로 리그 탭/우측 미디어/미니게임, 국내형 참고의 레이아웃 전환3종은 이번에 모두 채택하기로 확정된 요소가 아니다. 첫 구현은 **청색 연속 목록 + 기존3섹션 안의 리그 그룹**으로 정리한다. 원래 기능을 보존하며 중복 탐색 UI나 새 서비스를 추가하지 않는다.

참고 자료의 역할을 뒤섞지 않는다. WOG는 품질 비교, bwin은 중앙 구조, 국내형 화면은 마켓 열, William Hill은 색감이다. 감사자가 특정 사이트와 픽셀 단위로 같지 않다는 이유로 사용자 컨셉을 반려하지 않는다.

## 자산 확인 기록

패키지 작성 때 제공된 SIRIUS 두 PNG와 기존 종목8종의 파일을 직접 확인했다. 심볼640×640, 레터링1741×704이며 모두 RGBA/실제 투명도 채널을 가진다. 레터링 하단116px은 완전 투명하다. 패키지에는 원본 이미지 바이트를 변경하지 않은 사본과 매핑을 넣었다. 이 확인은 실제 헤더 적용과 화면 품질 검수가 완료됐다는 뜻이 아니다.

## 현재 구현 상태

이 문서 작성 시 SIRIUS의 새 프로젝트 등록·구현·독립 감사·배포는 아직 시작하지 않았다. MERCURY의 과거 기능 관찰이나 배포 성공을 SIRIUS의 PASS로 승계하지 않는다. 실제 실행 결과는 STATE에 갱신한다.
