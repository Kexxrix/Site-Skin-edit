## 3. 제안 수치와 미확정 후속 작업

상단56/하단44, 심볼32, 레터링 실제 높이34, 간격8, 활성선2px 및160~200ms, 스포츠 메뉴의 별도 펼침 버튼은 **실행 기본안**이다. 승인된 시안의 절대 픽셀 값이 아니다. 구조와 기능을 지키면서 실제 화면에 맞게 조정하고 변경 이유를 STATE에 적는다.

스크린샷 픽셀에서 얻은 색상 표는 시작 참고다. 모든 면을 같은 퍼센트로 어둡게 하거나 참고2의 미세 디테일을 복사하라는 지시가 아니다. 문자/골드/사진을 어둡게 하는 전역 필터는 방향에 맞지 않는다.

후속 후보: 좌측 빠른 서비스 아래 배너2개, 레일 패널의 순서·묶음·표현 변경, 오른쪽 계정/슬립/도움말의 구성 차별화. **이번 실행에는 포함하지 않는다.**

향후 두 사이트는 세로 내비게이션형과 독립 메뉴 바형 등 서로 다른 구조를 검토할 수 있다. 이는 디자인 계열을 겹치지 않게 하기 위한 후보이며 사이트 이름·팔레트·실행 사양을 확정한 것이 아니다. 시리우스에 미래 사이트용 설정 엔진/테마 시스템을 선행 개발하지 않는다.

## 4. 현재 완료의 의미

R1 첫 구현·공개 배포는 완료 보고와 이전 공개 관찰이 있다. 사용자 중앙 단계 수용도 기록했다. **R2는 지시서/자산 준비만 완료됐으며 구현·QA·공개 반영 결과는 아직 없다.** 구현자가 STATE에 실제 결과를 갱신한다. 공개 반영 후 미감 최종 수용과 다음 부위 착수는 사용자가 결정한다.
