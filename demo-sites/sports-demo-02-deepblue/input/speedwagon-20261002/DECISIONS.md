# 딥블루 변형 결정 기록 — 2026-10-02

사용자가 화이트 완성본을 유지한 채 기존 SIRIUS 딥블루 배색의 추가 앱을 요청했다. 따라서 기존 앱의 소스와 서버를 변경하지 않고 `sports-demo-02-deepblue/site` 및 빈 포트5293으로 분리했다.

첨부는 배색·브랜드 참조이고 배치는 최신 화이트 r02를 따른다. 사진들은 이미 어두운 장면/금색 제목과 별도 텍스트 레이어로 구성되어 유지했다. 금색 로고와 딥블루/금색 앱스트랙트 헤더는 기존 자산 담당이 실제로 생성한다.

기존 설치 의존성을 복사하여 설치 없이 실행한다. 스킨은 마지막 CSS import로 추가하고 원래 CSS의 치수·동작 선언은 보존한다. 독립 QA 요청은 부모가 기존 QA 담당에게 전달한다.
