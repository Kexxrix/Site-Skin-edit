# 고객센터·공지·출석 단색 흑연 후보 검수

- 작업 범위: action-support, action-notice, action-attendance 3종. 사이트 코드·서버·브라우저 작업 없음.
- 제작: 기본 image_gen만 사용하여 각 아이콘을 독립 PNG로 1회씩 생성. 참조는 Page의 완성 단색 충전 후보를 실제 ImageContent로 열람하고 num_last_images_to_include=1로 전달함.
- 참조 역할: 흑연 한 색상 계열, 정면 시점, 거의 평면의 낮은 입체감, 넓고 약한 명암. 화살표 형태는 상속하지 않음.
- 사용자 기준: 작은 크기에서 역할이 먼저 읽혀야 함. 서로 다른 두 색으로 부분을 분절하지 않음. 금속·장식·봉제·복잡한 질감 제외.
- 파일 처리: 도구의 embedded PNG base64를 refs/*-tool-payload.base64로 저장하고 원본 바이트를 results/*.png에 배타적 생성함. 원본 픽셀·알파 재색칠/정리 없음. 기존 파일 삭제·덮어쓰기 없음.

## 기술 확인

모두 PNG 실제 형식, 1254×1254 RGBA, 알파 범위 0..255, 네 모서리 알파 0을 확인했습니다. 바깥 경계 추가 검사에서는 고객센터 왼쪽 10픽셀과 출석 아래쪽 17픽셀에 alpha=1/255의 미세 잔여가 있었습니다. 공지 경계는 모두 0이며, 세 후보 모두 가장자리 alpha>8 픽셀은 0입니다. base64 해독 원본의 SHA-256과 저장된 PNG의 SHA-256이 일치합니다. 16/24/32px 출력은 원본을 LANCZOS로 축소한 독립 RGBA PNG입니다. qa/*-actual-16-24-32.png는 실제 픽셀 크기 검수표, qa/*-24px-nearest.png는 24px 표본을 nearest로 확대하여 픽셀 경계를 보는 보조 자료입니다.

밝은 배경 합성에서 흰색 외곽선·회색 배경 잔여·눈에 띄는 탈락 조각을 관찰하지 못했습니다. 경계의 alpha=1은 수치 검사에서만 확인한 잔여이며 실제 24px에서는 보이지 않았습니다. 원본 알파 정리 금지 지시에 따라 생성 원본을 고치지는 않았습니다. 완전 0인 경계가 필요한 엄격한 CSS mask용 기준은 고객센터·출석의 남은 검토 항목입니다. 더 정확한 전체 세트 시각적 크기 일관성은 부모의 통합 18종 검수에서 확인합니다.

- 기술 검수: 통과.
- 실제 16/24/32px 시각 검수: 완료, 24px 역할 전달 기준 통과.
- 선택 상태: 사용자 검토용 후보.
- 사용자 최종 승인: 아직 없음.

- 저장 직후 refs/*-generation.json의 visual_review=pending은 그 시점 기록이며, 이 검수 및 *-visual-review.json이 후속 확인 결과입니다.

기존 사용자 피드백을 분명한 제작 기준으로 적용했습니다. 새 과한 부품·질감을 넣지 않았고, 미세한 스타일 선택을 기다리며 작업을 멈추지 않았습니다.
