# 알데바란 v3 · 18종 완성 후보 세트

2026-10-06 재개 지시에 따라 남은 후보의 제작·정적 검수·로컬 보존을 완료했습니다. 사용자 최종 미감 승인과 실제 사이트 채택은 미확정입니다.

## 저장 구성

- results/: 원본18장, 각각 독립된1254×1254 투명RGBA PNG입니다. 원본 바이트·기존 파일을 덮어쓰지 않았습니다.
- exports/16,24,32,256/: 원본 전체 캔버스를 그대로 줄인 native 파생 PNG72장입니다.
- exports/aligned/16,24,32,256/: 기능8종의 투명 여백을 정렬한 권장 적용 준비 PNG와 같은 이름의 스포츠 파생본, 총72장입니다.
- 기능 파생본의 장축 여백은 명목상15%입니다. 알파32 이상 주 형태의 창을 찾고 가장자리 보호 여유2%를 둔 뒤 크기·캔버스만 정렬했습니다. 원본의색·재질·형태를 다시 그리거나 원본 알파값을 바꾸지 않았습니다. native 파생본도 함께 보존했습니다.
- 스포츠10종의 aligned 파일은 native 파생본과 바이트가 같습니다. 유지한 공·트로피·하키와 기존 F1·글러브의 모습은 그대로입니다.
- prompts/: 이번8종 실제 기본image_gen 프롬프트 및 재사용 충전·F1·복싱·MMA의 기존 제작 문구입니다.
- refs/: 복사·Page·도구출력·SHA-256·검수 참조 기록입니다. base64 전달 중간파일은 ZIP에서 제외합니다.
- qa/: 실제16/24/32px, 같은픽셀3배 확대, 전체 형태·알파 표와 검수 기록입니다.

## 전달 묶음

원본 총량은12761662bytes(약12.17MiB)이므로 원본을 줄이거나 재저장하지 않고8MiB 이하2개로 나눴습니다. 원본 묶음2개를 같은 빈폴더에 풀면 results/18장이 모입니다.

- ALDEBARAN-v3-source-part01.zip, ALDEBARAN-v3-source-part02.zip: 원본18장과 공통 실행/역할 기록입니다. 개별 원본의 Page/기존파일 해시를 유지했습니다.
- ALDEBARAN-v3-18-icons-apply.zip: 모든 크기별PNG, 역할표, 검수표, 프롬프트·기록입니다. 실제 사이트 연결 전 검토용이며 원본1254px 파일은 원본 묶음에 있습니다.
- package-index.json: 각 ZIP의 크기·SHA-256·항목·원본 분할 목록·검증 결과입니다.

각 원본과 파생 파일의 역할은 ROLE-MAP.ko.md와 run.json에 연결했습니다. Page 파일 업로드와 본문 삽입을 구분하며 Page 본문 정리는 부모 담당입니다. 사이트 코드·서버·배포·옛 브라우저 탭을 변경하지 않았습니다.
