TITAN SOLUTION — 웹사이트 프로젝트 인수인계
기준일: 2026-10-23 (한국 시간)

1. 이 전달본의 기준
현재 로컬에서 확인한 최신 titan_promotion 작업본입니다.
GitHub main에 아직 커밋·푸시하지 않은 히어로 코드, CSS, 이미지 및 영상을 포함합니다.
연결된 저장소: https://github.com/RickyJayPark/titan_promotion
GitHub main 확인 커밋: 7193c7b7314de9fea4151d95b1ecb90de2fd4d82
ZIP 전달 자체는 GitHub 업로드나 공개 배포를 의미하지 않습니다.

2. 실행 방법
검증에 사용한 도구: Node.js 24.14.0, pnpm 11.25.0.
pnpm이 없다면 Node.js 설치 후 터미널에서 다음 명령으로 준비할 수 있습니다.
  npm install -g pnpm@11.25.0

ZIP을 압축 해제한 뒤, package.json이 있는 titan_promotion 폴더에서 실행합니다.
  cd titan_promotion
  pnpm install --frozen-lockfile
  pnpm dev --hostname 127.0.0.1 --port 3000

브라우저 주소:
  http://127.0.0.1:3000/
서버를 실행한 터미널을 유지해야 페이지가 열립니다. 종료는 Ctrl+C입니다.
3000번 포트를 이미 사용 중이라면 --port 3001로 바꾸고 해당 주소로 접속합니다.
이 프로젝트는 HTML 파일을 더블클릭하는 방식으로 실행하지 않습니다.

배포용 빌드와 실행:
  pnpm build
  pnpm start --hostname 127.0.0.1 --port 3000

타입 검사:
  pnpm exec tsc --noEmit --incremental false
기존 next.config.mjs에 ignoreBuildErrors: true가 설정되어 있으므로
빌드 성공과 타입 검사 성공을 별도로 확인해야 합니다. 설정은 원본 그대로 보존했습니다.

4. 포함 범위
app, components, lib, public, docs 및 프로젝트 설정·pnpm 잠금 파일.
원본 프로젝트 파일 88개, 그중 public 이미지·영상 등 정적 파일 48개.
Git에 아직 등록하지 않은 로컬 파일도 포함했습니다.
프로젝트 파일의 바이트 수와 SHA-256은 handoff-manifest.json에 기록했습니다.
SHA256SUMS.txt는 전달본 내부 파일의 해시 목록입니다.

제외: node_modules, .next, .git, 로컬 도구 상태, 캐시 및 자동 생성 next-env.d.ts.
의존성은 설치 명령으로, Next.js 생성 파일은 실행·빌드 과정에서 다시 만들어집니다.
.git을 포함하지 않으므로 이 ZIP에 Git 커밋 이력은 들어 있지 않습니다.
다른 사이트 프로젝트와 프로젝트 폴더 밖의 AE 등 미디어 제작 원본은 포함하지 않았습니다.

5. 외부 의존과 기능 범위
의존성 설치 및 Google Fonts 준비에는 인터넷 연결이 필요합니다.
Pretendard는 기존 CDN CSS를 사용하며, 포트폴리오 데모 링크도 외부 주소입니다.
별도 API 키나 .env는 현재 페이지 실행에 요구되지 않습니다.
현재 상담 폼과 텔레그램은 연결 준비 상태인 검토용 화면입니다.
실제 상담 전송이나 서비스 연동 완료로 간주하지 마세요.

6. 검증 기록
verification.json을 확인하세요. 다른 작업자의 PC에서의 실행은 별도 확인이 필요합니다.
원본 로컬 프로젝트는 수정하지 않았고, 전달용 복사본에서 설치·실행 검증을 수행합니다.
