## Figma 작업 지시서 — 헤더·좌측 메뉴 3종 동시 비교

**목표: 블랙 메탈, 아르데코, 스포츠 중계형의 헤더·좌측 메뉴를 모두 제작한 뒤, 같은 전체 화면에서 원본과 나란히 비교한다.** 1안만 만든 상태에서 방향 선택을 요청하지 않는다. 3안의 헤더와 좌측 메뉴를 각각 재사용 가능한 컴포넌트/variant로 만들고, 페이지의 연결된 인스턴스를 교체하는 방식으로 작업한다. 세트 비교를 먼저 제시하되 헤더와 좌측 메뉴는 독립적으로 선택할 수 있어야 한다.

이 절은 2026년 10월 14일 요청한 **작업 지시서**이며 새 3종 디자인의 제작 완료나 실행 시작을 뜻하지 않는다. 기존 인계 계획에서 이번 비교의 범위를 구체화한 것으로, 아래 내용을 이번 작업에 우선 적용한다.

### 기준과 이번 작업 범위

- 기준 파일은 [블랙 골드 디자인](https://www.figma.com/design/PoUHKHsm9xOYavWBQ7uAGP/?node-id=140-552)과 [기존 컴포넌트 미리보기](https://www.figma.com/design/PoUHKHsm9xOYavWBQ7uAGP/?node-id=164-617)다. 작업을 시작할 때 현재 원본과 연결 상태를 읽고, 원본을 보존한 별도 비교 영역을 만든다.

- 10월 14일 12:26 KST 기록의 6프레임·21컴포넌트·274인스턴스·34변수는 당시 확인 수치다. 새 작업의 수량과 연결 상태는 작업 전후 실제 값으로 다시 보고한다.

- 이번에 바꾸는 부위는 사이트 헤더와 좌측 메뉴, 그 내부의 메뉴 항목·선택 표시·구분선·장식이다. 배너·본문 카드·스포츠 패널·푸터의 재디자인과 새 이미지 생성은 이번 범위에서 제외한다.

- 비교 화면은 모두 블랙 골드로 제작한다. 화이트 골드는 향후 색상 변수로 확장할 수 있도록 의미별 색상 역할을 정리하되, 이번에 화이트 골드 완성 화면을 추가 제작하지 않는다.

- 로고·메뉴 이름과 순서·아이콘의 의미·선택 항목·계정 상태·본문 이미지와 문구를 동일하게 유지한다. 메뉴를 삭제하거나 이름을 바꿔 공간 문제를 숨기지 않는다.

- 기준 프레임의 헤더 높이, 좌측 메뉴 폭, 본문 시작 위치, 주요 정렬선과 동일 화면 폭의 콘텐츠 배치를 공통으로 맞춘다. 재질·선·모서리·내부 강조와 여백으로 차이를 만들며, 외곽 크기 변경이 꼭 필요하면 이유와 영향을 따로 표시한다.

- 1920px에서는 스포츠가 위쪽, 1440px 이하에서는 아래쪽인 기존 의도된 배치를 유지한다. 원본 프레임과 기존 컴포넌트, 변수, 내비게이션 연결을 덮어쓰거나 삭제하지 않는다.

### 1안 블랙 메탈

**인상: 묵직한 검은 금속 패널과 절제된 금장.** 헤더 전체가 한 장의 연속된 금속판처럼 보이고, 좌측 메뉴는 차분한 바탕 위에서 현재 위치가 선명하게 드러나게 한다.

- 헤더: 검정·흑연 계열의 연속 패널에 얇은 골드 외곽선과 낮은 단차를 준다. 상단의 짧은 반사광, 가장자리 음영, 약한 수직 명도 변화로 금속감을 만들되 글자 뒤에 강한 빛이나 거친 텍스처를 놓지 않는다.

- 로고와 메뉴: 기존 정렬과 위치를 유지한다. 로고 주변의 금속 마감과 선택 탭의 얕은 명판으로 강조하고, 비선택 메뉴는 평평하게 정돈한다. 로그인 등 주요 버튼도 같은 금속 마감 규칙을 따른다.

- 좌측 메뉴: 무광 검정 레일을 바탕으로 그룹을 얇은 선과 여백으로 구분한다. 선택 항목만 골드 윤곽·작은 측면 표시·은은한 반사가 있는 금속 명판으로 표현한다. 아이콘과 텍스트는 명판 안에서도 기준 위치를 유지한다.

- 장식 규칙: 외곽과 선택 영역에 밀도를 집중한다. 모든 버튼을 두꺼운 액자나 돌출된 금속 덩어리로 만들지 않는다.

- 좁은 화면: 반사광과 단차를 줄여도 검은 패널·골드 엣지·선택 명판이라는 특징이 남아야 한다.

### 2안 아르데코

**인상: 대칭적인 금장 기하와 정돈된 고급스러움.** 선의 반복과 계단식 코너를 사용하되 메뉴를 읽는 공간은 충분히 비운다.

- 헤더: 로고 주변과 양 끝에 대칭적인 골드 기하 선, 계단식 코너, 얇은 이중선 장식을 배치한다. 장식은 메뉴 사이를 복잡하게 가르지 않으며 기존 로고·탭·계정 영역의 기능적 정렬은 그대로 둔다.

- 로고와 메뉴: 로고를 중심으로 장식의 균형을 맞춘다. 선택 탭에는 열린 모서리나 얇은 기하 프레임을 적용하고, 기본 글꼴과 읽기 쉬운 글자 크기를 유지한다. 화려함을 위해 자간을 과하게 벌리거나 메뉴를 작은 대문자 형태로 대체하지 않는다.

- 좌측 메뉴: 그룹 제목에 짧은 대칭 선과 작은 기하 포인트를 넣고, 그룹 구분선과 선택 항목의 코너 프레임에 같은 조형을 반복한다. 모든 항목에 장식을 복제하지 않고 제목·선택 상태에 집중한다.

- 재질과 색: 블랙 바탕과 절제된 골드 선을 중심으로, 1안보다 평면적이고 선명하게 구성한다. 장식선·본문·강조 색을 의미별 변수로 연결해 향후 아이보리·화이트 골드에서도 교체하기 쉬운 구조를 둔다.

- 좁은 화면: 양 끝 장식과 보조선을 먼저 간소화한다. 로고 주변의 짧은 기하 포인트와 선택 프레임으로 정체성을 유지하고, 글씨와 조작 영역을 줄여 장식을 살리지 않는다.

### 3안 스포츠 중계형

**인상: 방송 그래픽처럼 빠르고 또렷한 스포츠 화면.** 넓게 읽히는 탭, 방향감 있는 일부 사선, 강한 선택 표시로 생동감을 만든다.

- 헤더: 같은 높이와 정렬선 안에서 가로로 넓게 읽히는 탭 면을 만든다. 선택 탭이나 패널 양 끝의 일부에만 사선 마감을 쓰고, 헤더 하단에는 얇은 라이트 라인을 둔다. 탭마다 서로 다른 기울기나 두꺼운 외곽 효과를 넣지 않는다.

- 로고와 메뉴: 로고·상품 메뉴·계정의 구획을 명확히 한다. 선택 탭과 중요한 조작 버튼에 골드를 집중하고, 나머지는 흑연 면과 밝은 글씨로 정리한다. 사선 때문에 클릭 영역이나 텍스트 폭이 줄지 않게 한다.

- 좌측 메뉴: 수직 레일과 강한 선택 스트라이프를 연결하고, 종목 아이콘·숫자 배지의 정렬을 통일한다. 숫자 배지는 기존에 있는 값이나 명시된 샘플 값만 사용하며 실제 경기 수·상태처럼 보이는 새 정보를 임의로 만들지 않는다.

- 재질과 장식: 1안의 금속 반사보다 명확한 면 분할과 얇은 빛의 경계를 중심으로 한다. 골드 강조, 짧은 사선, 수직 스트라이프가 한 세트로 보이게 한다. 과도한 네온·발광·움직임은 넣지 않는다.

- 좁은 화면: 사선 장식의 양과 라이트 효과를 줄이고 선택 스트라이프·아이콘·짧은 탭 표시를 우선 유지한다. 메뉴 이름과 계정 진입은 계속 읽고 찾을 수 있어야 한다.

### 컴포넌트와 교체 구조

1. 먼저 기존 Header와 Sidebar의 원본, 중첩 컴포넌트, 디바이스별 variant와 노출 속성을 조사한다. 기존 명칭과 속성을 가능한 범위에서 재사용하고 원본 기본형으로 되돌아갈 경로를 보존한다.

2. 새 스타일의 논리적 구성은 **헤더 3종과 좌측 메뉴 3종**이다. 실제 COMPONENT·COMPONENT_SET·INSTANCE 수는 반응형과 중첩 구조에 따라 달라지므로 이 논리적 수량을 실제 노드 수로 보고하지 않는다.

3. 같은 역할의 변형은 호환 가능한 component set의 style variant로 정리한다. 별도 컴포넌트가 적합하면 instance swap으로 교체할 수 있게 한다. 예시 값은 Original, BlackMetal, ArtDeco, SportsBroadcast이며 실제 원본 이름에 맞춰 일관되게 정한다.

4. style과 device 또는 layout 속성을 분리한다. 기존 반응형 규칙과 선택 상태를 스타일 전환 때 잃지 않도록 한다. 페이지 조립부에서는 헤더 스타일과 좌측 메뉴 스타일을 각각 선택할 수 있게 노출한다.

5. 텍스트·아이콘·선택 상태의 역할, 레이어 이름·계층과 크기 규칙을 호환 가능하게 맞춘다. 새로운 장식은 콘텐츠와 구분된 레이어로 두어 문구를 가리거나 Auto Layout의 본문 폭을 밀어내지 않게 한다.

6. 비교 프레임은 재사용 원본에 연결된 인스턴스로 조립한다. 전체 화면을 이미지로 굳히거나 인스턴스를 detach한 복제본으로 제출하지 않는다. 전체 페이지가 이미 인스턴스인 경우에도 그 연결을 유지한다.

7. 동일한 시험 인스턴스에서 원본 → 1안 → 2안 → 3안 → 원본으로 실제 전환해 텍스트·아이콘·선택 표시와 관련 override가 보존되는지 확인한다. 헤더만 교체했을 때 좌측 메뉴와 본문, 메뉴만 교체했을 때 헤더와 본문이 유지되는지도 시험한다. 손실은 수정하거나 남은 제한으로 명시한다.

### 비교 보드와 반응형 산출물

- **1920px 메인 비교 보드:** 원본, 블랙 메탈, 아르데코, 스포츠 중계형을 한 보드에 나란히 배치한다. 모두 같은 프레임 폭·높이, 같은 스크롤 시작점, 같은 콘텐츠·선택 상태를 사용한다. 처음에는 각 스타일의 헤더와 좌측 메뉴를 같은 스타일의 한 세트로 맞춘다.

- 각 안에는 스타일 이름과 핵심 차이 한 줄을 프레임 바깥에 적는다. 전체 페이지의 인상을 비교하는 화면과 헤더·좌측 메뉴의 세부 마감을 확인하는 동일 배율 확대 영역을 제공한다.

- **390px 보조 비교:** 원본과 3안의 같은 첫 화면을 나란히 두어 로고·메뉴·계정 진입과 텍스트 가독성을 확인한다. 모바일에서 좌측 메뉴가 숨겨지는 기존 구조라면, 각 안의 메뉴 열린 상태도 별도 프레임으로 제공한다. 원본이 사용하는 모바일 표현을 먼저 확인하고 임의로 데스크톱 사이드바를 축소해 넣지 않는다.

- **1440px와 768px 구조 검수:** 각 스타일을 해당 기존 프레임에 연결해 헤더 줄바꿈, 메뉴 접힘과 노출, 본문 시작 위치, 장식의 잘림·겹침을 확인한다. 프레임 이름·링크와 결과를 남긴다.

- Auto Layout의 Hug·Fill·고정 크기, 최소 폭과 constraints를 확인하고, 긴 메뉴 이름 및 실제 전환 경계 부근의 중간 폭을 시험용 복제 인스턴스에서 확인한다. 테스트한 폭과 결과를 기록하며, 공정한 메인 비교 보드의 콘텐츠는 변경하지 않는다.

- 3세트 비교를 완성한 다음 헤더만·좌측 메뉴만 바꾸는 조합을 시험한다. 모든 혼합 조합을 완성 시안으로 추가하는 것은 필수 범위가 아니다.

### 진행 순서와 완료 기준

1. 원본 구조·변수·연결을 읽고 비교용 인스턴스와 공통 크기·콘텐츠를 준비한다.

2. 세 스타일의 헤더와 좌측 메뉴를 모두 같은 수준의 디테일로 제작한다. 1안에만 완성도를 집중하고 나머지를 색상만 바꾼 임시안으로 남기지 않는다.

3. 원본과 3세트를 1920px·390px 비교 화면에 적용하고 1440px·768px 구조와 개별 교체를 검수한다.

4. **3안 전체와 검수 결과를 함께 제출한 뒤** 사용자의 선호·수정 방향을 묻는다. 중간 진행 공유는 가능하지만 첫 1안을 보여주고 선택을 기다리며 나머지 제작을 멈추지 않는다. 실제 접근·권한 문제로 진행이 막히면 완료로 표시하지 말고 정확한 막힘을 보고한다.

5. 사용자가 선택하기 전에는 어느 안도 채택안으로 표시하지 않는다. 프론트엔드 구현은 최종 디자인 승인 후 별도로 진행한다.

- [ ] 원본 블랙 골드와 기존 컴포넌트가 보존되고, 새 3종 각각의 헤더·좌측 메뉴가 완성되어 있다.

- [ ] 원본 포함 1920px 4열 비교와 390px 보조 비교가 같은 콘텐츠·상태·뷰포트 조건으로 제공된다.
