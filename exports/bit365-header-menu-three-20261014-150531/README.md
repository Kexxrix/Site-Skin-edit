### 교체 방법

1. 비교 보드에서 한 화면의 최상위 INSTANCE를 선택합니다.
2. 오른쪽 속성에서 `Header style`과 `Sidebar style`을 각각 교체합니다.
3. 중첩 헤더/메뉴 인스턴스를 선택하면 `Style`과 `Viewport`를 따로 조정할 수 있습니다. 스타일을 바꿀 때 현재 화면의 Viewport를 유지하세요.
4. Style 값은 `Original / BlackMetal / ArtDeco / SportsBroadcast`입니다.
5. 모바일 `Menu open` Boolean으로 메뉴 표시를 조정할 수 있습니다. 메뉴 열린 비교 보드는 별도 `Menu shown` 모드를 사용합니다.
6. 기본형 복귀는 Original을 선택합니다. 원본 09/10 페이지를 수정할 필요가 없습니다.

새 COMPONENT 40개는 Header 12개, Sidebar 8개, NavigationItem 8개, AccountButton 8개, 페이지 조립 원본 4개입니다. 논리적인 신규 시안은 헤더 3종과 메뉴 3종이며, 디바이스·상태·기본형을 포함한 실제 노드 수와 다릅니다.

새 비교용 컬렉션에 `menuOpen` Boolean 1개와 `Interaction / Menu shown` 모드만 추가했습니다. 기존 의미별 색상 17개의 실제 해석 값과 scope, 현재 골드 6-stop 그라데이션은 동일합니다. 골드·금속 Paint Style과 얕은 단차 Effect Style은 새 비교 원본에서 사용합니다.

## Verification

- 정적 구조·렌더: 1920/1440/768/390px 4종 모두 같은 본문과 상태로 비교. 20개 전체 화면이 4개의 페이지 조립 COMPONENT에 연결되어 있으며 Header/Sidebar도 각 새 원본에 연결되어 있습니다.
- 본문 보존: 같은 폭의 본문 콘텐츠 해시가 모두 동일합니다. 1920 스포츠 상단, 1440px 이하 스포츠 하단 배치를 유지했습니다.
- 실제 swap: 동일한 시험 인스턴스에서 Original → BlackMetal → ArtDeco → SportsBroadcast → Original 전환. 메뉴 문구·아이콘·배지 표시 override와 선택 상태, 계정 문구·로고 이미지, 본문이 유지되었습니다.
- 독립 swap: 헤더만 교체했을 때 메뉴·본문, 메뉴만 교체했을 때 헤더·본문의 콘텐츠 해시가 유지되었습니다.
- 연결 전파: 새 BlackMetal 선택 메뉴의 원본 Label opacity를 잠시 0.913으로 바꾸었을 때 연결된 비교 인스턴스가 0.9129999876으로 반영되었습니다. 원본과 인스턴스를 1로 복원 확인했습니다.
- 실제 resize: 모든 헤더 스타일에서 Desktop 1439/1441px, Tablet 767/769px, Mobile 375/389/391px를 확인했습니다. 헤더의 표시된 조작 요소가 외곽을 넘지 않았습니다.
- 모바일 페이지 전체 resize: 원본+3안에서 375/389/391px. 헤더/본문/하단 메뉴/오버레이 너비가 화면 폭을 따르고 콘텐츠 해시가 유지되었습니다.
- 긴 이름: 신규 3안 메뉴를 160/210/298px에서 시험했습니다. 첫 렌더에서 말줄임이 적용되지 않는 문제를 수정해 최종 160px 캡처에서 한 줄 말줄임을 확인했습니다. 글자 크기 13px와 행 높이 44px를 유지합니다. 기존 기본형의 텍스트 동작은 보존했습니다.
- 장식 constraints: 모바일 메뉴의 선택 명판·코너·하단 선, 계정 버튼 코너, 세로 레일의 폭/높이 대응을 수정했습니다.
- 라이브 프로토타입: 3안 메뉴 열기 확인. ArtDeco에서 메뉴 내부 스크롤·배경 닫기·본문 스크롤과 헤더/하단 메뉴 고정을 확인했습니다. SportsBroadcast에서 수정한 공통 메뉴 아이콘 프레임으로 열기/닫기를 확인했습니다.
- 원본 보존: 09 페이지 2670개 노드 해시 `c47cd377`, 10 페이지 1016개 노드 해시 `a762a4bb`가 작업 전과 동일합니다. 검사 필드는 ID/이름/부모/유형/위치/크기/표시/채우기/선/문자입니다.
