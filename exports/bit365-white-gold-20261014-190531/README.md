## 변경 파일 / 위치

- Figma 새 페이지에 1920px 전체 화면 6종과 전용 사이드바·메뉴·헤더 컴포넌트를 생성.
- 이 폴더의 JSON 작업 기록, 최종 PNG, verification.json. 사이트 소스 파일 변경 없음.

## 변경 내용

WOG의 Raised / Inset / Tiles, ESPN의 Panel / Rail / Grid 형태를 유지하고 전체 화면의 배경, 헤더, 카드 바탕, 스포츠 영역, 텍스트, 선을 화이트·골드로 구성했다. 기존 메뉴의 크기, 폰트, 아이콘, 간격을 유지했다. TITAN SOLUSION은 박스 없이 텍스트로 유지했다.

전용 WhiteGold 색상 변수 40개와 스타일 18개, 컴포넌트 40개와 컴포넌트 세트 6개를 생성했다. 메뉴는 Style, State, Label, Icon, Badge 속성을 지원한다. 전체 Page/1920 인스턴스는 **Sidebar style** 속성으로 6종을 교체할 수 있다. 6개 비교 화면의 헤더와 본문은 동일한 화이트 전용 마스터를 공유한다. 본문의 기존 이미지·콘텐츠 구조는 재사용했으며 일부 하위 콘텐츠 인스턴스의 원본 구조는 기존 BlackGold 컴포넌트에 연결된 상태다.

회사 로고를 일괄 단색 처리했을 때 유색 바탕 내부의 문자가 사라지는 문제가 있어 최종본은 원본 로고 색을 유지했다. 파트너 영역만 흑연색의 대비 배경을 적용해 24개 로고를 3줄로 표시했다. 원본에서 숨겨져 있던 Playtech 로고는 화이트 복제본에서만 표시했다. 원본 PNG를 재확인했으며 Figma 이미지 해시는 동일했다. 헤더 로고는 원본 이미지의 투명 마스크를 활용해 골드로 표시했다.
