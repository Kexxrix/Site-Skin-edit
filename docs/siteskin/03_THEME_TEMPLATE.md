# SiteSkin 테마 정의 양식

문서 버전: **v0.1** · 작성일: **2026-09-09**  
연결: [안내](00_INDEX.md) · [공통 작업 규약](01_WORK_RULES.md) · [참고 분석](02_REFERENCE_AUDIT.md)

**상태: 양식과 작성 원칙은 제안. 실제 테마의 모든 값은 확인 필요.**  
이번 문서에서는 테마·세계관·색상·글꼴·생성 도구를 선택하지 않는다. 참고 사이트의 COBALT 색과 장면은 분석 사례이며 이 양식의 기본값이 아니다. `<입력>`을 실제 값으로 채우기 전에는 확정 명세로 사용하지 않는다.

### 참조 자료의 역할

참조가 많을 때에는 어떤 속성을 어느 자료에서 가져오는지 분리한다. 모든 이미지를 동등한 명령으로 섞지 않는다. 자료가 충돌하면 사용자가 정한 우선순위와 기능 보존 조건을 기록한다.

| 참조 ID | 실제 파일/URL·버전·해시 | 상태·권한 | 가져올 속성 | 가져오지 않을 속성 | 우선순위·적용 대상 |
|---|---|---|---|---|---|
| `<입력>` | `<입력>` | `<확인 필요>` | `<색/재질/조명/구도/형태/인물/타입 중 명시>` | `<입력>` | `<입력>` |

## 2. 디자인 DNA

**같은 DNA는 모든 요소에 같은 장식과 디테일을 넣는다는 의미가 아니다.** 히어로는 분위기와 시각적 집중도, 작은 아이콘은 식별성, 데이터·입력 영역은 가독성과 조작 정확성을 우선한다. 공통 인상을 전달하는 요소를 정하고 역할에 맞게 표현 강도를 조절한다.

```yaml
references: <참조 ID·파일/버전/해시·역할·우선순위>

```

정확한 픽셀 크기를 요구하지 않았다면 임의로 필수 크기를 설정하지 않는다. 양식의 `generation_spec`은 도구가 실제 지원하는지 확인한 뒤 작성한다. 원본 크기와 표시 크기가 다르면 두 비율과 크롭을 분리한다.

### 6.3 DNA와 명세 연결의 참고 예시

**제안 예시이며 생성 지시가 아니다.** [참고 분석서](02_REFERENCE_AUDIT.md)의 `REF-R003`은 원본과 표시 이미지 박스가 모두 1208×258이고 HTML 문구가 왼쪽에 있다. 이 사실을 참고해 실제 원본의 히어로를 조사할 때에는 DNA-05(조명)를 주체 위치에, DNA-09(이미지 규칙)를 문구 안전 영역에 연결할 수 있다. 실제 `SRC-R`의 크기·배치·테마 값은 별도로 측정한다.

반면 `REF-R019`는 941×1672 원본을 330×107 표시 창에 `cover`로 사용한다. 이를 근거로 모든 신규 배너를 세로 이미지로 만들지 않는다. 실제 적용 창, 주체 크롭, 공유 사용처를 먼저 정하고 지원 가능한 생성 비율을 선택한다.

## 10. 적용 시작 전 점검

- [ ] 고정 결과·수동 수정과 새 테마의 충돌 처리가 정해졌다.
- [ ] 도구 지원·비용·권한이 실제로 확인되었다.
