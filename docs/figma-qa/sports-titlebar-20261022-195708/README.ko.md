# 스포츠 타이틀 바 높이 수정

대상: Figma page25의 Together Pink 949:2268 및 Toy Racing Park 966:2789.
변경 인스턴스: 949:2293, 966:2853.

스포츠 타이틀 바는 스크롤 버튼이 숨겨져 있고 상하 패딩이0이라 높이가28px로 줄어들었다. 라이브 카지노와 슬롯 바는30px 버튼 및 상하4px 패딩으로38px였다.

수정: 스포츠 바의 상하 패딩을4px, 최소 높이를38px로 설정했다. HUG 오토레이아웃과 공용 컴포넌트 연결은 유지했다. 타이틀은 기존20px, 좌우 여백16px, 세로 위치5px로 중앙 정렬된다.

검증: 두 전체 프레임을 렌더링하고 comparison.png에서 실제 크기로 스포츠·라이브 카지노 바를 비교했다. 두 스포츠 바38px, 카드 간격8px, 메인 섹션 간격16px, 각 인스턴스91개 유지. 변경분10px에 따라 하단 콘텐츠와 전체 프레임 높이만10px 늘었다. 스포츠 카드 크기1592×228은 유지됐다. 다른 page25 시안 및 라벨의 전후 hash는 모두 동일하다.

변경하지 않음: 폰트·문구·색상·이미지·좌우 여백·스포츠 카드 크기·공용 원본 컴포넌트·24페이지 원본·웹 코드/배포.
남은 문제: 현재 Figma 검수 범위에서 발견하지 못함.
