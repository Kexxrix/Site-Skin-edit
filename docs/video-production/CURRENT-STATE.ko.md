## 기준 AEP의 변경 발견과 보존

기존 5.7초 결과 보고 당시 AEP는 846,343바이트, SHA-256 `fef5fff8170fcf67c925195a04f97acbbd0a930831f832538522821e866ac2a4`였습니다. 후속 지시서를 만들 때 같은 경로의 현재 파일은 846,583바이트, SHA-256 `7e44100ab29f9356942e9bace32e9dd3f7721280356319c64ed9a2383d9152f7`로 달랐습니다. 기존 MP4의 해시는 동일했습니다. AEP 바이트 차이만으로 원인이나 영상 변화 여부를 단정하지 않았습니다.

## 사용자 작업 방해 최소화
