## 비교 구성

각 방향에 실제 크기 3종 세트, 150% 확대 카드, 실제 1920px 전체 페이지를 배치했다.
전체 화면은 기존 BlackGold 기준이며 배너 외 헤더·사이드바·콘텐츠를 보존했다.
상단 요약 프레임 `742:3825`에서 5개 세트를 한눈에 비교한다.

## 편집 구조

- `94 · C 파생 · 고정 크기 5종 원본` (`749:589`): 15개 카드 원본.
- `90 · 공통 요소 · 화살표 / 바로가기 5종`: 버튼 컴포넌트 세트 `749:588`.
- Photo / Overlay / Copy / Entry button / Click target 분리.
- Title·Description은 텍스트 속성, Entry style은 인스턴스 스왑. 버튼 Label은 중첩 인스턴스에서 수정 가능.
- 텍스트 트림은 모두 NONE. 본문은 기존 문구를 보존하고 자연스러운 2행으로 정리.
- 반투명 채움은 알파 포함 색상 변수로 구성하여 원본과 인스턴스에서 동일하게 표시.
- 카드 전체와 바로가기의 목적지는 동일하다는 디자인 계약을 표기했다. 실제 웹 이동 기능이나 Figma 목적지 연결은 이번 비교 작업에 포함하지 않았다.
