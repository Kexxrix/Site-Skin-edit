# 대담한 타이포·정보 띠 · 배너 탐색

[23번 비교 페이지](https://www.figma.com/design/PoUHKHsm9xOYavWBQ7uAGP?node-id=772-579)

사용자가 공유한 「GoldFlow 추가 타이포·정보띠 레퍼런스」의 구성 원리를 바탕으로 6개 방향을 제작했다.
참고 이미지는 구조 검토에만 사용했으며 Figma에 복제·삽입하지 않았다.

## 결과

- **23 · 대담한 타이포 · 정보 띠 · 배너 탐색** / 페이지 `771:552`.
- 신규 카드 **6방향 × 3종 = 18개**, 연결 인스턴스 **72개**.
- 각 방향에 실제 크기 세트, 개별 150% 확대, 전체 1920px 페이지를 구성했다.
- 기존 골드 릴리프 3종의 연결 인스턴스를 별도 비교 기준으로 함께 배치했다.
- 기존 **522.67 × 256px / R6**, 3열 간격 12px 유지.
- 현재 사진 3종·크롭만 사용. 이미지 생성·인물 교체·새 금액·지급 조건 추가 없음.
- 텍스트·사진·오버레이·마스크·클릭 요소가 분리된 편집 가능한 원본이다.
- 현재는 비교 시안이며 **최종 채택·웹 적용 없음**.

| 안 | 핵심 변화 | 장점 / 제한 |
| --- | --- | --- |
| 01 교차 타이포 | 대형 산세리프 + 이탤릭 세리프 영문을 엇갈리게 배치, 한글 목적은 하단 | 타이포와 사진의 비중이 비슷함. 긴 설명은 생략 |
| 02 초대형 한글 포스터 | 72px 두 줄 한글 제목, 버튼 박스 없이 전체 카드 진입 | 목적이 빠르게 읽힘. 상세 설명은 목적지에서 제공하는 구성 |
| 03 인물 뒤 윤곽선 | 168px 영문 윤곽선이 사진을 가로지르고 인물이 그 앞에 위치 | 깊이 표현이 강함. 사진 교체 시 인물·소품 실루엣 조정 필요 |
| 04 사진을 담은 글자 | 96px 영문 글자의 내부에 동일 원본 사진 노출 | 사진과 글자의 관계를 직접 바꿈. 한글 목적과 영문 그래픽을 분리 |
| 05 전체 폭 정보 띠 | 사진을 가로지르는 아이보리 띠에 한글 목적·화살표 배치 | 정보가 선명함. 사진 일부가 띠 뒤에 놓임 |
| 06 세로 정보 패널 | 사진 양옆을 남기는 종이색 세로 패널에 메타·제목·설명·링크 | 정보 위계를 세로 편집. 패널 비중이 큼 |

추천은 **02**(목적 전달)와 **05**(정보와 사진의 균형)이며 최종 선택은 하지 않았다.

## 구성·편집

- 원본 섹션: `771:574`. 현재 노드 ID는 `final-state.json`에 기록했다.
- 카드 이름은 `P23/Bold/번호-방향/목적` 형식이다.
- 한글 제목은 Title, 본문은 Description, 링크 문구는 Entry label 속성으로 편집한다.
- 영문 그래픽은 Display 속성. 04는 같은 문구를 마스크와 윤곽선에 함께 반영한다.
- 03은 기존 원본 사진을 한 번 더 겹치고 편집 가능한 벡터 실루엣으로 마스킹했다. 이미지 교체 시 이 실루엣도 맞춰야 한다.
- 04는 텍스트를 알파 마스크로 사용한다. 사진을 글자로 평탄화한 비트맵이 아니다.
- 05는 얼굴·봉투·선물을 고려해 페이백 y134, 이벤트 y130, 데일리 y204에 48px 높이의 띠를 배치했다.
- 모든 안은 카드 전체와 시각적 진입점(화살표·밑줄·정보 띠)이 같은 목적지로 이동하는 디자인 계약이다. 실제 웹 이동 및 프로토타입 목적지는 연결하지 않았다.

## 보존·검증

- 골드 릴리프 원본 3개의 시각 속성 해시가 작업 전과 일치.
- 기존 21번 4개 화면의 해시가 작업 전과 일치.
- 기존 22번의 모든 최상위 원본·비교 영역 유지.
- 18개 카드의 규격·R6·이미지·크롭·목적 문구·본문 단어·트림 NONE·텍스트 경계·스타일 연결 검사 통과.
- 6개 전체 페이지의 1592×256 배너, 간격 12px, Main gap 16px, 헤더·주변 콘텐츠 보존 검사 통과.
- 03의 실루엣 마스크 3개, 04의 텍스트 마스크 3개 및 연결 인스턴스 72개 확인.
- 실제 크기 세트와 전체 페이지의 제목 가독성, 얼굴·핵심 소품 노출, 글자 잘림, 페이지 조화를 시각 검수했다.
- 검증 범위는 Figma 1920px. 모바일·웹 동작은 검증하지 않았다.

`verification.json`은 검사 결과, `final-state.json`은 현재 노드 ID다.
`qa/01-native.png`, `04-native.png`는 최초 통과 후 변경되지 않았다.
나머지는 `-final.png`가 최신 통과 화면이다.
