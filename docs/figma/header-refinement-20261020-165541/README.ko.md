# 21 · 헤더 디테일

[Figma 수정 전후 비교](https://www.figma.com/design/PoUHKHsm9xOYavWBQ7uAGP?node-id=693-6096)

문서의 01 헤더 항목만 적용했다. 19번의 일반형·동영상형 다크/화이트 화면을 복사하고 헤더 컨트롤 높이를 44px에서 36px로 줄였다. 구체적인 픽셀값은 지정되지 않아 로고 높이(37.375px)에 가까운 36px를 선택했다.

- 헤더 88px, 로고 184 × 37.375px, 공지 830 × 28px 유지.
- 서비스 묶음 376 × 36px, 계정 버튼 90/90/126 × 36px, R6.
- 공통 세로 중심 Y44. 글자·아이콘의 기존 광학 보정 +0.5px 유지.
- 텍스트 14px 및 line-height 20px, 서비스 아이콘 16px 유지. 텍스트 트림 없음.
- 우측 여백 51px, 공지 x277, 서비스 묶음 x1139, 계정 묶음 x1547 유지.
- 21번 전용 Header 2종, QuickLinks 2종, AccountButton 6종을 생성했다. 다른 구성요소는 기존 원본 연결을 유지했다.
- Header/control-height = 36 변수를 새 전용 컬렉션에서 관리한다.

## 검증

verification.json에 네 화면 본문 렌더 속성 해시 일치, 기존 19번 화면과 20번 헤더 원본 보존, 인스턴스 연결 및 높이·너비·정렬 검증을 기록했다. qa/에는 헤더 원래 크기 및 비교·전체 화면 검수 결과를 보관했다.

기존 페이지, 카드 이미지, 사이드바, 웹 코드는 변경하지 않았다. Figma 디자인 검증이며 웹 반영은 이번 범위에 없다.
