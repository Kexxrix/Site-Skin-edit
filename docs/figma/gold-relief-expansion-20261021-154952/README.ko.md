## 편집·비교 구성

- 원본 컴포넌트: `749:589` 섹션.
- 제목·본문·버튼 텍스트에 공통 텍스트 스타일 연결, 제목 그림자는 방향별 효과 스타일.
- Photo / Overlay / Copy / Entry button / Click target 레이어 분리.
- Title·Description 속성과 Entry style 스왑 유지. 버튼 Label은 공유 텍스트 속성에 연결.
- 모든 텍스트 트림 NONE. 목적별 버튼 문구가 실제 렌더에 반영되는 것을 확인했다.
- 원본 포함 5종 각각 실제 크기 3개 세트, 150% 확대, 전체 1920px 화면을 제공한다.
- 버튼 또는 카드 전체가 같은 목적지로 이동하는 디자인 계약이며 실제 웹·프로토타입 목적지 연결은 이번 작업 범위에 없다.

## 검증

`verification.json`에 최종 구조 검사, `final-state.json`에 현재 노드 ID를 기록했다.

- 골드 릴리프 원본 3개: 작업 전후 시각 속성 해시 일치.
- 기존 21번 4개 화면: 작업 전후 해시 일치.
- 신규 카드 12개: 규격·이미지·크롭·본문·트림·텍스트 경계·라벨·컴포넌트 속성 검사 통과.
- 총 원본 카드 15개 / 연결 인스턴스 60개 / 버튼 변형 5개.
- 4개 신규 전체 페이지: 배너 높이 256px, 간격 12px, Main gap 16px, 헤더·주변 콘텐츠 유지.
- 04 페이지의 일부 로고 y값에서 원본 대비 0.0005px 차이가 발생했다. 복제 좌표 정밀도 차이이며 0.001px 허용오차 내로 확인했다. 재배치나 콘텐츠 변경은 하지 않았다.
- 최종 카드와 비교 화면에서 제목·본문·버튼 잘림 없이 얼굴과 주요 장면이 보이는 것을 검수했다.
- 스타일 연결 후 28개 텍스트의 시각 속성 해시가 연결 전과 동일했다.

최종 시각 자료: `qa/00-summary-final.png`, `03-native-final.png`, `04-native-final.png`, `02-full-page-final.png`.
`-final`이 없는 캡처는 버튼 라벨 연결 보정 전 중간 검수다.
검증 범위는 Figma 1920px이며 모바일 반응형 및 웹 적용은 하지 않았다.
