# 혜택 배너 5방향 비교

[Figma 한눈에 비교](https://www.figma.com/design/PoUHKHsm9xOYavWBQ7uAGP?node-id=742-3825)

현재 21번에 사용된 페이백 포인트·회원 이벤트·데일리 리워드 사진만 사용했다. 새 이미지 생성, 인물 변경, 금액·지급 조건 추가는 없다. 기존 21번 화면은 보존했다.

## 비교 구성

- 개별 편집 가능한 원본 15개.
- 원래 표시 크기의 3개 카드 세트 5개.
- 카드별 125% 또는 150% 확대 인스턴스 15개.
- 배너 높이와 주변 콘텐츠를 확인하는 1920px BlackGold 페이지 5개.
- 모든 방향을 함께 보는 요약 보드.
- 사진, 오버레이, 타이포그래피, 장식, 클릭 타깃 레이어 분리. Title/Description/Entry label 컴포넌트 속성과 재사용 스타일·토큰을 제공한다.
- 카드 전체 클릭을 전제로 화살표·밑줄 링크를 사용한다. 실제 서비스 목적지는 최종 방향 선택 후 연결한다.

| 안 | 언어 | 묶음 높이 | 판단 |
|---|---|---:|---|
| A 에디토리얼 | 사진과 밝은 캡션, 세리프 제목 | 340px | 균형 추천. 사진을 가리지 않고 정보가 안정적으로 읽힘. |
| B 와이드 챕터 | 큰 가로 행 3개, 디렉터리 | 672px | 설명과 목적 구분이 명확하지만 아래 콘텐츠가 많이 내려감. |
| C 시네마 포스터 | 인물 확대, 큰 타이포, 사진 위 정보 | 384px | 시각적 강조 후보. 대비와 보조 문구의 축소를 관리해야 함. |
| D 베네핏 티켓 | 사진 창, 종이 면, 절취선 | 216px | 밀도가 좋고 정보를 읽기 쉬우나 사진 비중이 작음. |
| E 포커스 스테이지 | 큰 페이백 + 작은 두 배너 | 436px | 중심 구도가 강하지만 페이백 우선이라는 서비스 위계 확인 필요. |

## 검증과 상태

현재 이미지 해시 3종 재사용, 15개 개별 원본, 5개 실제 페이지와 확대 화면 연결, 텍스트 경계와 트림 해제, 기존 네 화면 렌더 속성 보존을 확인했다. 1:1 배너와 전체 페이지를 렌더 검수했다. 포스터형 이벤트 카피가 봉투를 가리던 부분과 중복 화살표, 비교 보드 설명의 배경 대비를 수정했다.

모두 **미채택**이다. 화이트 스킨·모바일·실제 웹 연결은 이번 비교 범위에 포함하지 않는다. 상세 ID와 확인 결과는 final-state.json / verification.json을 참조한다.
