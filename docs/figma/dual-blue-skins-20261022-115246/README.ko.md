두 화면 모두 1920×1819.2이며 기존 24페이지의 고정 레이아웃을 유지했다. 참고는 사용자가 첨부한 두 스크린샷이다. 원 사이트 CSS·폰트의 직접 복제를 주장하지 않는다.

## 각각 반영한 특징

### Royal Cobalt

첫 번째 참고의 검정 바탕, 짙고 선명한 로열 블루, 흰 글자, 얕은 그라데이션 버튼을 반영했다.

- 페이지 #08090c / 패널 #14161b의 중립적인 블랙.
- 섹션 바 #3150be→#1b2b75.
- 버튼 #3155c7→#1e2e79와 흰 레이블.
- 배너 한글은 밝은 시안 블루, 인물 뒤 영문 윤곽은 코발트.
- 숫자의 따뜻한 노란색 포인트 유지.
- 장식보다 블랙·블루 대비와 얕은 버튼 입체감이 중심.

### Frost Azure

두 번째 참고의 푸른 네이비 패널, 밝은 아이스 블루, 얼음 테두리와 눈 표현을 반영했다.

- 페이지 #07121c / 패널 #102633의 푸른 네이비.
- 밝은 바 #9ed8f7 계열, 버튼 #b8e6ff→#5ba9d2와 어두운 레이블.
- 패널과 카드에 흰색·아이스 블루·짙은 블루가 이어지는 그라데이션 테두리와 안쪽 하이라이트.
- 배너 타이포는 밝은 얼음색과 약한 푸른 광택.
- 숫자도 밝은 아이스 블루로 구분.
- 헤더의 정적인 눈 결정·작은 광점·이중 얼음 라인과 배너/게이트웨이의 크리스털 모서리를 편집 가능한 Figma 벡터로 추가했다.

Frost의 장식은 원본 UI와 별도의 절대 배치 레이어 2개로 분리했다. 두 장식 레이어와 하위 도형 총 46개이며, 사진이나 인물은 생성·교체하지 않았다. 선택 방해를 줄이도록 장식 레이어만 잠갔고 잠금을 해제해 편집할 수 있다. 웹으로 이식할 때 장식에는 pointer-events:none을 적용하면 된다. 눈 표현은 정적인 디자인이며 애니메이션을 추가하지 않았다.

참고 화면의 캐릭터·로고·혜택 문구를 새 사이트 콘텐츠로 복사하지 않았다. 기존 ALDEBARAN 로고·사진·메뉴·문구는 보존했다.

## 공통 유지 사항

- Main content gap 16.
- 사이드바 제목 좌우 12px, 메인 제목 좌우 16px.
- 표시 스크롤 버튼 30×30px, 상하 4px, 바 높이 38px.
- 스크롤 버튼은 각 시안의 블루 계열로 연결.
- 카드 비율·코너·배치·텍스트 크기·인물 마스크 유지.
- 원본 인스턴스를 detach하지 않았다.
- 두 스킨은 각각 독립된 색상 변수·텍스트 스타일·효과 스타일을 사용한다.

## 파일 및 상태

01-create-foundations-and-clones.js에서 각 스킨의 독립 토큰·스타일과 복제 화면을 만들고, 별도 호출의 02-apply-complete-skins.js에서 모든 중첩 인스턴스를 포함해 스타일을 적용했다. 03-verify.js는 최종 읽기 전용 검증이다. baseline.json·foundation-state.json·skin-state.json·final-state.json에 근거와 ID를 보관했다.

Figma 제작·구조 검증·1920 화면 시각 검수 완료. 사용자 채택은 미정이다. 기존 원본과 스킨을 교체하지 않았다. 웹 코드·서버·배포는 변경하지 않았으며 새로운 모바일 동작이나 웹 기능을 검증한 결과는 아니다.
