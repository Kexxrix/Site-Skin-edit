## 디자인

### White Gallery

백색과 옅은 회색 표면, 검정 타이포, 평평한 버튼, 가는 구분선을 적용했다. 사진 위 진입 버튼은 흰색으로 처리해 클릭 경계가 보이게 했다. 파트너 로고는 원래 색과 이미지를 유지하면서 읽히도록 검정 패널에 배치했다.

### Hanji Ink

미색 한지 표면, native NOISE 종이 질감, 먹색 워시·대나무·섬유 도형, 주홍색 포인트를 적용했다. 명조체는 고정폭 섹션 제목과 게임 카드명에 적용했다. 배너 제목에 명조체를 적용했을 때 원본 텍스트 상자보다 1px 넓어지는 문제가 있어, 배너 제목은 원래 서체·수치로 복원했다. 고정 레이아웃을 우선한 선택이다.

### Bio Membrane

짙은 녹색 바탕, 연두색 버튼과 수치, 막을 연상시키는 곡선·세포 도형, 반투명 느낌의 그라데이션과 내부 광택을 적용했다. 유기적인 도형은 원래 사각 카드·버튼 밖의 배경 표현이며, 카드의 위치·크기·R6는 그대로다.

## 편집성 및 보존

- 소스의 인스턴스를 복제했으며 detach하지 않았다.
- 스킨별 독립 변수 45개와 텍스트/효과 스타일을 적용했다.
- 기존 이미지 파일, 이미지 해시, 크롭·변환·형상을 유지했다.
- 밝은 두 스킨에서는 로고와 사이드바 아이콘 15개씩의 표시 필터만 어둡게 조정했다. 한지 선택 행의 입금 아이콘은 밝게 처리했다.
- 바이오테크에서는 밝은 선택 행의 입금 아이콘 1개의 표시 필터만 어둡게 조정했다.
- 사진·인물·게임/팀/파트너 이미지를 교체하거나 새로 생성하지 않았다.
- 한지·바이오 장식은 별도 잠긴 native Figma 프레임 안의 벡터/도형이며 수정 가능하다.

## 수정 과정에서 확인한 사항

- 테두리를 추가하면 원래 테두리가 없던 사이드 메뉴에서 내부 요소가 1px 이동했다. 원본처럼 해당 테두리를 제거해 모든 기하 차이를 0으로 복원했다.
- 한지 배너 명조 제목의 직접 width 조정은 해당 중첩 인스턴스에서 원하는 폭을 유지하지 못했다. 원래 배너 서체로 복원하고, 명조는 고정 컨테이너의 제목에 적용했다. 미사용 배너 명조 스타일은 이번 작업에서 생성한 정확한 ID로 제거했다.
- NOISE 효과의 문서에 있는 blendMode 필드는 현재 도구에서 검증 오류가 나므로 제외했다. 이 시도의 변경은 커밋되지 않았고, 도구가 안전한 재시도를 허용한 후 수정했다.
