## 변경 범위

- 기존 인물 뒤 윤곽선 3개 원본(`771:650`, `771:663`, `771:676`)과 사진 글자 3개 원본(`771:690`, `771:701`, `771:712`)의 ID와 기존 인스턴스 연결을 유지하고 수정했다.
- 기본안 2세트에 계열별 3세트씩 추가했다. **신규 6세트 / 18개 원본**, 유지 원본을 포함하면 **8세트 / 24개 원본**이다. 각 세트는 페이백 포인트·회원 이벤트·데일리 리워드로 구성한다.
- 폐기한 방향: 교차 타이포, 초대형 한글 포스터, 전체 폭 정보 띠, 세로 정보 패널. 해당 비교 보드·요약 행·원본 12개를 제거했다. 삭제 전 소비 인스턴스가 모두 23번 페이지 내부임을 확인했다. 이후 미사용이 확인된 공통 화살표 배지도 제거했다.
- 21·22번 기존 디자인은 수정하지 않았다. 금액이나 지급 조건 등 새로운 혜택 정보는 추가하지 않았다. 새로운 이미지 생성, 인물 교체, 원본 이미지 파일 수정은 없다.

## 편집 및 구현 정보

- 카드: **522.67 × 256px / R6**. 세트: **1592 × 256px**, 카드 간격 **12px**.
- A계열 윤곽선은 좌측 정렬된 고정 폭 상자가 아니라 실제 글자의 자간을 조정하여 카드 폭 약 **92~93%**를 채우고 가운데에 맞췄다. 가로 변형으로 폰트를 늘리지 않았다.
- 모든 텍스트의 `leadingTrim`은 **NONE**이다. 한글 제목은 28/34, 26/32, 두 행 26/32, 캡션 20/28의 역할별 스타일을 사용한다. 제목과 진입 문구의 컴포넌트 텍스트 속성 연결을 유지했다.
- 바로가기는 금색 채움·분할형·넓은 바형으로 구성하고 기존 화살표 벡터 인스턴스를 사용한다. 버튼 내부는 Auto Layout, 이미지 위의 캡션과 버튼은 원본 카드 컨테이너 내부의 absolute 레이어다.
- 원본 사진, 가독성 오버레이, 영문/한글 타이포, 인물 실루엣, 글자 마스크, 바로가기, 전체 카드 클릭 영역이 별도 레이어다. 사진 글자의 내부 사진에만 노출·대비 조정을 적용했으며 기본 사진의 이미지 해시와 크롭은 그대로다.
- 원본 마스크는 편집 가능한 텍스트·벡터다. 이미지 교체 시 인물 실루엣을 새 사진에 맞춰 조정해야 한다.
- 카드 전체와 금색 바로가기는 같은 목적지로 이동하는 의도다. 이번 산출물은 Figma 디자인 비교이며 프로토타입 링크나 실제 웹 동작을 구현한 결과는 아니다.

- 원본 24개 모두 규격·R6·기존 사진 해시·크롭 보존, 목적과 바로가기 문구, 텍스트 속성, 스타일 연결, 트림 NONE, 카드 밖 텍스트 없음 확인.

- 전체 페이지 8개 모두 1920px 폭, 메인 간격16, 배너 간격12, 배너 영역1592×256 확인. 헤더와 배너 이외 콘텐츠가 원본과 동일함을 구조 비교했다.
- 21번 기준 화면 4개와 22번 골드 릴리프 원본 3개의 렌더 구조 해시가 이전 기록과 일치했다.
- 실제 크기의 8세트, 1920 페이지 A1/B1/B3, B3 150% 확대, 전체 요약을 Figma 렌더로 직접 검수했다. 최종 스타일 연결 후 전체 요약과 A1/B3 실제 크기를 재확인했다.
- 첫 렌더에서 새 캡션·버튼이 Auto Layout 흐름으로 이동한 문제를 발견하여 absolute 위치를 복구했다. B2 사진 글자의 중심 배치를 좌측 이미지 영역으로 옮겨 얼굴 겹침을 줄였다. 마지막 구조 검수에서 스타일 연결이 해제된 텍스트를 공통·역할별 스타일에 다시 연결했다.

## 파일

- `prior-state.json`, `discovery.json`: 작업 전 구조와 삭제 대상 사용 범위.
- `01-refine-masters.js`: 카드 정리·신규 변형·폐기 범위 실행 기록.
- `02-compose.js`: 기존 두 비교 보드 유지 및 신규 비교 보드 6개 추가.
- `03-position-fix.js`: 실제 렌더에서 확인한 위치 문제 수정.
- `04-audit.js`: 구조·원본·이미지·연결 검증.
- `05-relink-text-styles.js`: 정밀 조정 후 텍스트 스타일 최종 연결.
- `build-state.json`, `composition-state.json`, `final-state.json`: 생성·변경·삭제 ID와 최종 노드 매핑. 스크립트는 실행 이력이며 재실행용 명령이 아니다.

- `qa/`: 초기 렌더와 수정 후 렌더. `*-native-final.png`, `00-summary-final.png`, `A1-native-style-final.png`, `B3-native-style-final.png`이 마지막 카드/요약 검수 자료다. 전체 페이지는 `*-full-page.png`에 있다.

## 미변경 및 남은 사항

기존 이미지·기존 페이지·웹 코드·사이트 배포는 변경하지 않았다. 이전 전역 토큰 및 스타일 정의는 보존했다. 현재 검수에서 남은 배치 결함은 발견하지 못했다. 반응형 웹, hover/focus, 실제 이동, 마스크 렌더 방식은 선택 후 별도 구현 범위다.
