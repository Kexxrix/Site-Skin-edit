## 범위

24페이지의 고정 레이아웃을 복제해 블랙·레드·실버 테마 한 개를 추가했다. 기존 골드·CC Lime·HT Gold·ZXC Navy Cyan은 보존했다. 새 사진·인물·혜택 문구를 만들지 않았고, 원본 컴포넌트를 변경하거나 인스턴스를 분리하지 않았다.

## 스크린샷에서 채택한 표현

- 블랙 페이지 #080808, 차콜 패널 #141414와 #202020.
- 짙은 크림슨 #a31e24와 #711015의 제목 바·버튼.
- 밝은 레드 #db3a42 테두리·포인트.
- 레드 버튼에 1px 안쪽 밝기/암부 효과로 약한 입체감.
- 배너 한글 제목에 흰색·실버 그라데이션과 작은 어두운 그림자.
- 배너 뒤 영문 윤곽은 붉은색, 사진·인물 마스크는 원본 유지.
- 사이드바 아이콘 14개와 게이트웨이 타이틀 이미지 4개는 원본 imageHash를 유지하고 Figma의 비파괴 채도 필터로 실버 톤 적용. 게이트웨이의 사진 레이어에는 필터를 적용하지 않았다.
- 숫자에는 참고 화면의 보조 노란색 분위기를 반영한 #f4cd6a 사용.
- 레이아웃은 변경하지 않고 헤더 아래 2px 붉은 구분선 및 기존 섹션 헤딩 3개의 레드 채움 적용.
- 원래 사이트의 로고·문구·광고·메뉴 구조를 복사하지 않고 기존 서비스 콘텐츠에 테마만 적용했다.

## 검증

기계 점검은 final-state.json, 점검 스크립트는 03-verify.js에 기록했다.

- 기존 노드 629개 대응, 컨테이너 위치·크기·간격·padding·radius·clip 차이 0건.
- Main content gap 16 유지.
- 94개 인스턴스의 원본 컴포넌트 연결 동일.
- 기존 이미지 100개 imageHash·크롭·변환 동일.
- 정밀 인물 마스크 3개 벡터 경로 및 변환 동일.
- 문구 변경 0건.
- 기존 화면 4개와 원본 컴포넌트 44개, 총 48개 보존 스냅숏 동일.
- 표시 텍스트 151개, 실제 폰트 7종 load 성공. Missing font·text trim·미연결 텍스트 스타일 0건.
- Black 웨이트를 적용한 배너 제목 2개는 자연 폭만 150→149px. 카드와 부모 배치에는 변화 없음.

전체 페이지·배너·사이드바를 실제 렌더로 확인했다. 헤더 무기명 회원가입 문구가 어둡게 보여 흰색으로 조정하고, 작은 레드 아이콘의 대비도 보정한 뒤 전체 페이지를 재확인했다. 최종 통과 이미지: qa/final-full-page.png. qa/full-page.png는 대비 수정 전 기록이다. 배너·사이드바는 이후 변경이 없어 qa/banners.png, qa/sidebar.png가 현재 상태다.

## 파일

- 01-create-skin.js: 원본 보존 확인 후 새 스킨 제작. 재실행 시 같은 이름이 있으면 중단.
- 02-header-legibility.js: 헤더 대비 보정.
- 03-verify.js: 읽기 전용 구조·연결·원본 보존 검증.
- baseline.json / skin-state.json / final-state.json: 전후 근거와 ID.
- reference/user-reference.png: 사용자 원본을 보존하고 복사한 참고 이미지.
- qa/: 실제 Figma 렌더 검수 자료.

## 상태 및 제한

제작·구조 검증·1920 화면 시각 검수 완료. 사용자 채택은 미정이다. 웹 코드·서버·배포는 변경하지 않았다. 새로운 모바일 레이아웃이나 실제 사이트 동작 검증을 뜻하지 않는다. 참고 화면의 정확한 폰트 및 CSS는 확인되지 않아 기존 검증된 Pretendard JP와 Bebas Neue를 사용했다.
