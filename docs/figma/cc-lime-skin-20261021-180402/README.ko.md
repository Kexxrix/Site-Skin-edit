## 변경

24페이지의 원본 오른쪽에 한 화면을 추가했다. 검정 바탕, 라임 포인트, 건메탈 그라데이션과 음영을 적용했다. 헤더, 공지, 회원 액션, 사이드바, A0 배너의 타이포와 CTA, 스포츠 배당 및 게임 카드 정보 영역을 함께 조정했다.

참고 사이트의 컴포지션은 복사하지 않았다. 기존의 1920×1819.2, 헤더 88, 메인 Gap 16, 타이틀/본문 간격, 카드 크기/비율/코너, 사이드바 Icon 22px, 배너 이미지와 인물 마스크, 콘텐츠 순서 및 문구를 유지했다. 문자 자체의 자연 폭은 글꼴 변경으로 달라지며, HUG/FILL 안에서 흐른다. 실제 패널/컨테이너/아이콘의 기하 차이는 0건이다.

주 글꼴 S-CoreDream은 현재 Figma 사용 가능 목록에 없었다. 참고 사이트의 보조 글꼴이자 Figma에서 확인된 Noto Sans KR을 사용했다. A0 영문 윤곽선의 Bebas Neue는 유지했다. 한글 타이틀은 기존 폭 안에서 26.5px로 맞췄다. 스포츠 배당은 항목마다 크기가 달라지지 않도록 원본 역할별 크기(배당 14px 등)를 일괄 유지했다. 텍스트 트림은 사용하지 않았다.
