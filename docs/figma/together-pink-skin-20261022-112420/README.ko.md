## 새 스킨

현재 GGR Crimson의 수정된 고정 레이아웃을 복제했다. 기존 사진·마스크·문구·메뉴 구조를 유지하고 블랙 배경, 밝은 핑크 제목 바, 핑크 버튼·테두리·배너 타이포를 적용했다. 참고 이미지의 캐릭터·로고·혜택 수치를 추가하지 않았다. 새 이미지를 생성하지 않았다.

큰 제목 바와 작은 버튼은 명도를 구분했다. 제목 바는 #da5f9e 중심, 흰색 글자가 있는 작은 버튼은 #bd4b82→#a94174의 짙은 핑크를 사용한다. 사이드바의 작은 제목과 메인의 전체보기에는 어두운 글자를 사용했다. 배너 한글 제목은 연한 핑크 그라데이션이며, 기존 인물 뒤 영문 윤곽은 핑크로 연결했다.

전용 색상 컬렉션 VariableCollectionId:850:3570, 변수 43개, 텍스트 스타일 19개, 효과 스타일 4개를 만들었다. 원본 GGR 변수·스타일을 변경하지 않고 새 컬렉션으로 연결했다. 원본 컴포넌트 연결은 유지했다.

## 후속 지시 — 컬러 섹션 바의 스크롤 버튼

Together Pink 및 GGR Crimson의 라이브 카지노·슬롯 로비, 총 4개 섹션 바에 있는 8개 버튼을 수정했다.

- 버튼: 38×38 → 30×30px.
- 버튼 배경: 해당 스킨의 accentDark 색상. Pink #b34d80 / Red #711015.
- 밝은 같은 계열 테두리와 기존 얕은 안쪽 효과.
- 섹션 바 위·아래 padding 4px / 좌·우 16px.
- 섹션 바 높이 38px 유지.
- 원본 화살표 벡터와 24px 아이콘 프레임 유지, 흰색으로 표시.
- 버튼을 아이콘 24px + 좌우/상하 padding 3px의 HUG auto-layout으로 구성.

직접 size/벡터 rescale은 중첩 인스턴스에서 제한되어, 원본 아이콘을 보존하고 auto-layout으로 최종 30px 크기를 확보했다. 중간에 증가한 바 높이는 최종 38px로 복구했으며 전체 화면 높이도 원래대로 유지했다. 표시되지 않는 스포츠 섹션의 화살표와 채움 없는 다른 테마는 변경하지 않았다.
