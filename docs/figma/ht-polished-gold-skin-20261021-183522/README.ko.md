## 변경

참고 사이트의 차콜 바탕과 강한 반사광을 가진 금색 컨트롤을 24번 기본형에 적용했다.

- 기존 크기를 그대로 사용한 금속 골드 회원 액션·배너 CTA·스포츠 카운트
- 기존 24px 섹션 타이틀 프레임을 사용한 사이드바 골드 카테고리 바
- 차콜 메뉴 행, 골드 선택 행, 회색/금속 테두리
- 골드 다중 그라데이션과 음영을 가진 A0 타이틀, 인물 뒤 영문 윤곽선
- 검정 수직 그라데이션 헤더, 음각 공지 바
- 스포츠 카드와 게임 카드의 금속 테두리·짙은 패널

버튼의 표면은 실제 사이트에서 읽은 #E5A834 → #F4E7A3 → #E5A834 → #F4E7A3 → #E5A834 그라데이션과 안쪽 브론즈/밝은 금색 음영을 바탕으로 만들었다. 참고 사이트의 #1A1A1A 배경, #2A2A2A 메뉴, #484848 테두리를 사용했다. 기존 R6 등 코너 형상은 유지했다.

헤더의 기존 골드 흐름 배경과 읽기 보조 페이드는 새 화면에서만 숨겼다. 참고 사이트처럼 검정 헤더의 표면 자체로 분위기를 냈다. 별도 이미지 생성이나 외부 이미지 복사는 하지 않았다.

## 글꼴

참고 사이트의 GmarketSansMedium은 현재 Figma 글꼴 목록에 없었다. 확인된 Pretendard JP를 사용하고, 배너 타이틀 Black, 콘텐츠 제목 ExtraBold, 메뉴 SemiBold 등 웨이트를 조정했다. 영문 Bebas Neue는 유지했다. 글꼴 크기는 원본 역할별 크기를 유지했고 trim은 사용하지 않았다.

카테고리 바의 글자에 8px 문단 들여쓰기를 적용했다. 두 배너 제목의 자연 폭은 웨이트 변경으로 1px 감소했다. 컨테이너·카드·아이콘의 위치나 크기는 바뀌지 않았다.

## 변경하지 않은 범위와 한계

골드 기본형, 성공 판정된 CC Lime, 다른 Figma 페이지, 공용 원본, 웹 소스·서버·배포를 변경하지 않았다. 이번 결과는 1920 Figma 시안이다. 실제 웹의 반응형·호버·스크롤 동작과 다른 해상도는 검증하지 않았다.

공유 레이아웃과 스킨 전용 변수/스타일의 인스턴스 오버라이드로 구성했다. 모든 테마가 한 스위치로 자동 전환되는 완성형 웹 스킨 엔진을 구현한 것은 아니다.

## 후속 수정 — 사이드바 아웃라인

사용자가 좌우 테두리 잘림을 지적한 뒤, 메뉴 13개와 카테고리 바 4개를 INSIDE stroke + strokesIncludedInLayout=false로 수정했다. 스크롤 clipping을 유지하면서 모든 요소의 크기·위치 차이 0건을 확인했다. 최신 결과와 검수 이미지는 [후속 수정 기록](../ht-sidebar-outline-fix-20261021-184746/README.ko.md)에 있다. 이 폴더의 최초 제작 스크린샷은 수정 전 이력이다.
