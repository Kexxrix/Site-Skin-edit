# 선택 배너 두 방향 — A0 마스크 / B2 포토 워드 업그레이드

[Figma 비교 페이지](https://www.figma.com/design/PoUHKHsm9xOYavWBQ7uAGP?node-id=772-579)  
페이지 `771:552`: **23 · 선택 배너 · 정밀 마스크 / 포토 워드**

## 변경

사용자가 첨부한 A0와 B2 두 세트만 유지했다. 각 세트의 페이백 포인트·회원 이벤트·데일리 리워드 원본 3개와 기존 인스턴스 연결은 그대로다. 새 방향이나 새 이미지는 만들지 않았다.

**A0 — 정밀 인물 마스크**

- 300%로 확대한 기존 사진에 맞춰 인물별 벡터 실루엣을 다시 추적했다.
- 페이백: 헤어 볼륨과 컬, 어깨, 팔, 팔걸이에 걸친 손과 몸의 오목한 경계를 세분화했다.
- 회원 이벤트: 상단에서 잘린 머리, 좌측 컬과 레이스 어깨·팔, 손과 봉투 경계를 다시 잡았다.
- 데일리 리워드: 실제 머리와 어깨 폭으로 좁히고, 선물 상자·리본·손을 별도 서브패스로 포함했다. 두 서브패스는 같은 NONZERO 벡터 알파 마스크로 합성된다.
- 기존 와이드 윤곽선 타이포, 한글 제목, 금색 바로가기, 오버레이는 유지했다. 마스크는 편집 가능한 네이티브 벡터이며 사진 자체를 수정한 결과가 아니다.

**B2 — 아웃라인 없는 포토 워드**

- 사진 글자의 중복 외곽선 텍스트 레이어 3개와 사용하지 않는 Display 2 속성을 제거했다.
- 글자 폭을 줄이면서 글꼴 모양을 가로로 변형하지 않았다. Anton 82px / 행높이94, 역할별 자간을 적용했다. 기존은 88px / 행높이100이다.
- 폭 변화는 다음과 같다. 감소율은 `(이전 폭 - 현재 폭) / 이전 폭 × 100`으로 계산했다.

| 목적 | 이전 | 현재 | 감소율 |
|---|---:|---:|---:|
| 페이백 | 294px | 264px | 10.20% |
| 회원 이벤트 | 292px | 263px | 9.93% |
| 데일리 리워드 | 293px | 263px | 10.24% |

- 기본 사진과 인물은 그대로다. 외곽선 없이 사진 글자가 읽히도록 글자 내부 사진에만 노출·그림자 보정을 적용했다.
- 상단 한글 제목과 하단 금색 바로가기의 위치·크기는 바꾸지 않았다.

## 정리 범위

- 23번 페이지의 A1, A2, A3, B0, B1, B3를 폐기했다. 전용 원본 18개, 비교 섹션 6개, 요약 행 6개와 원본 설명 라벨 6개를 제거했다.
- 삭제 전에 해당 원본들의 사용 인스턴스가 모두 23번 페이지 안에 있음을 확인했다.
- 이 페이지에 복사돼 있던 골드 릴리프 참조 프레임을 제거했다. 22번 원본은 보존했다.
- 검수용 300% 사진·경계 프레임은 PNG 증거를 저장한 뒤 캔버스에서 제거했다.
- 최종 원본 6개, 연결 인스턴스 24개, 실제 크기 세트 2개, 150% 확대 세트 2개, 1920 전체 페이지 2개, 통합 요약을 남겼다.

## 검증

`verification.json`의 `allPassed: true`.

- 6개 카드가 522.67×256 / R6이며, 세트는1592×256 / 간격12다.
- 각 원본의 연결 인스턴스 4개씩 총24개를 확인했다. 마스터 ID와 기존 연결을 유지했다.
- 기본 사진 해시·크롭, 목적 문구, 제목·바로가기 텍스트 속성, 스타일 연결, 트림 NONE, 텍스트 범위를 검증했다.
- A0 세 개 모두 새 벡터를 가진 ALPHA 마스크다. B2 세 개 모두 중복 외곽선 레이어가 없고 사진 마스크 텍스트에 stroke가 없다.
- 한글 제목의 x/y·크기와 금색 버튼의 x/y·너비·높이가 수정 전과 동일하다.
- 두 전체 페이지 모두 배너 외 헤더·콘텐츠 구조가 기존 기준과 같다. 메인 간격16 유지.
- 21번 기준 화면4개와 22번 골드 릴리프 원본3개의 렌더 구조 해시가 이전 검증 기록과 일치했다.
- 마스크 수정 전·후 300% 사진 경계, 최종 실제 크기 두 세트, A0 150% 확대, 두 전체 페이지와 최종 요약을 Figma 렌더로 직접 확인했다. 사진 경계와 타이포 겹침이 개선된 것을 시각적으로 확인했으며, 픽셀 단위 자동 매팅 정확도를 측정한 것은 아니다.

## 파일과 미변경 범위

- `discovery.json`: 작업 전 구조, 마스크 경로, 폐기 원본의 사용 범위.
- `contours-300px.json`: 기존 사진을 300%로 확대한 좌표계에서 작성한 세 실루엣.
- `01-upgrade.js`, `02-consolidate.js`: 업그레이드와 정리 실행 기록.
- `03-audit.js`, `verification.json`: 구조·범위·보존 확인. audit의 `cfg`, `before`, `removedIds`는 해당 실행 기록에서 제공한다.
- `upgrade-state.json`, `final-state.json`: 새 벡터, 유지 원본, 연결 화면, 삭제 노드 ID.
- `qa/`: 마스크 전·후 및 최종 카드·전체 페이지 렌더.

21·22번 기존 디자인, 원본 이미지 파일, 카드 규격, 한글 제목, 금색 버튼, 웹 코드·배포는 변경하지 않았다. 최종 적용 대상으로 채택한 것은 아니다. 현재 검수에서 남은 배치 결함은 발견하지 못했으며, 이미지 교체 시에는 마스크 재조정이 필요하다.
