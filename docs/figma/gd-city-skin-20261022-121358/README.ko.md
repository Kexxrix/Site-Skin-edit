- 상태: 편집 가능한 비교 시안 제작 및 Figma 검수 완료. 사용자 최종 승인·실서비스 채택은 미확정.

## 접근 및 디자인 근거

Chrome에서 공개 홈 화면과 하단을 실제 열람했다. 텍스트 추출용 웹 도구에서는 실패했으나 Chrome에서는 로그인 없이 디자인을 확인했다. 로그인·회원가입·베팅은 진행하지 않았다.

관찰한 요소는 차콜·검정 표면, 은색 메탈 타이포와 테두리, 붉은 구분선, 일부 금색 포인트, 고딕 도시 야경이다. 사이트의 홍보 수치·회원 조건·사업자 주장은 복사하지 않았다.

배경은 실제 페이지 BODY에서 확인한 `https://gd330904.com/home-bg.png`를 원본 그대로 보관·업로드했다. 별도 이미지 생성이나 인물 교체는 없었다. 공개 열람 가능 여부와 실서비스 배포에 필요한 이미지 사용 권한은 별개이며, 사용 권한은 검증하지 않았다.

## 변경

- Together Pink의 기존 연결된 화면을 복제하고 독립 색상 변수 45개, 텍스트 스타일 19개, 효과 스타일 6개로 재연결했다.
- 메인 배너 한글 제목과 진입 버튼에 은색 메탈 그라데이션을 적용했다.
- 차콜 버튼·패널, 은색 카드 림, 붉은 섹션 구분선과 선택 포인트를 적용했다.
- 헤더 무기명 가입에는 금색 포인트를 남겼다. 기존 버튼 크기와 위치는 그대로다.
- 야경은 별도 잠긴 배경 레이어 `875:5378`에 배치했다. 배경 알파 커버를 0.58로 조정하고, 파트너 영역 `875:5377`에 별도 어두운 그라데이션을 적용해 로고 가독성을 보강했다.
- 기존 원본 화면 8개, 공유 마스터 44개, 모든 사진·마스크·카피·인스턴스 연결을 보존했다.

## 파일

- `baseline.json`: 작업 직전 원본/마스터 스냅샷 및 소스 스타일
- `00-discover.js`: 읽기 전용 조사
- `01-create-foundations-and-clone.js`: 독립 토큰·스타일 및 연결 복제
- `02-apply-skin.js`: 전체 하위 노드 스킨 적용
- `03-background-alpha.js`: 알파 전용 변수 보정
- `04-contrast-refinement.js`: 최종 배경·파트너 가독성 보강
- `05-verify.js`, `final-state.json`: 최종 보존/구조 검증
- `foundation-state.json`, `skin-state.json`: 생성/변경 ID 명세
- `reference/`: 참조 화면 및 원본 배경
- `qa/`: 초기 렌더와 최종 렌더
- `run.json`: 출처, 상태, 해시, 경계

스크립트는 이미 실행한 기록이며 그대로 중복 실행할 용도가 아니다. 새 스킨 생성 스크립트에는 이름·위치·원본 변경 검사가 있다.

## 변경하지 않은 범위 및 한계

- 기존 8개 스킨, 브랜드 로고, 기본 레이아웃, 사진/인물/마스크, 텍스트 내용, 공유 마스터를 수정하지 않았다.
- 웹 코드, 로컬 서버, 배포, 서비스 기능은 변경하지 않았다.
- 이번 검증은 1920px Figma 시안과 기존 자동 레이아웃 보존 기준이다. 실제 웹의 반응형 동작이나 서비스 기능 검증 결과가 아니다.
- 신규 발견된 Figma 구조/연결/가독성 문제는 최종 검수에서 없었다.
