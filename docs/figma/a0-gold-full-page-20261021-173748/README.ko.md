# A0 금색 그라데이션 — 새 전체 페이지

[Figma 전체 화면](https://www.figma.com/design/PoUHKHsm9xOYavWBQ7uAGP?node-id=795-1331)

- 페이지: **24 · A0 정밀 마스크 · 골드 그라데이션 · 1920** (`795:1330`)
- 전체 화면: `795:1331`, **1920 × 1819.2px**, 페이지 안에 전체 화면 하나만 배치했다.
- 기준: 23번 A0 전체 화면 `772:2777`과 사용자가 현재 수정한 A0 원본 3개. 이전 기록의 단색 표현을 다시 적용하지 않았다.

## 적용 내용

사용자가 원본에 넣은 한글 제목·금색 버튼의 그라데이션 페인트, 스톱 위치, 변환과 그림자를 그대로 사용했다. A0의 인물별 정밀 마스크와 사진, 윤곽선 영문 타이포도 유지했다.

새 배너 인스턴스는 원본 `771:650`(페이백), `771:663`(회원 이벤트), `771:676`(데일리 리워드)에 연결된다. 원본을 분리하거나 복제하지 않았다. 헤더·사이드바·콘텐츠 바로가기·스포츠 카드·라이브 카지노·슬롯·파트너 영역은 기존 전체 화면의 구조와 연결을 그대로 복사했다.

전체 메인 간격16, 배너 영역1592×256, 배너 간격12, 카드522.67×256 / R6를 유지했다. 새 페이지의 캔버스 배경도 기존 비교 페이지와 동일하게 맞췄다.

## 확인

- 원본과 복사 화면의 렌더 구조가 0.001px 허용 오차 안에서 동일했다.
- 세 배너의 제목·버튼 페인트가 현재 원본과 일치하고 모두 선형 그라데이션을 포함한다.
- 세 배너의 네이티브 인물 마스크가 유지됐다.
- 전체 화면의 중첩 포함 인스턴스94개에서 연결 끊김0개를 확인했다.
- 기존 23번의 원본 섹션·가이드·요약·A0·B2 비교 섹션5개의 렌더 구조 해시가 작업 전과 일치했다.
- 전체 화면과 실제 크기 배너를 Figma 렌더로 확인했다. 처음 새 페이지의 기본 캔버스 배경이 밝게 표시돼 기존과 동일한 배경으로 맞춘 뒤 전체 화면을 다시 확인했다.
- `final-state.json`의 `allPassed: true`, `visualQA.checked: true`.

## 파일 및 범위

- `discovery.json`: 현재 사용자 그라데이션, 컴포넌트·변수·스타일과 기존 화면의 보존 기준.
- `01-create-page.js`: 새 페이지 생성 및 복사·연결 검증 실행 기록. `cfg`는 discovery의 baseline을 제공했다.
- `02-page-background.js`: 새 페이지 캔버스 배경 일치 처리.
- `final-state.json`: 생성된 노드, 원본 연결과 검증 결과.
- `qa/full-page-final.png`, `qa/banner-detail.png`: 마지막 시각 검수. `qa/full-page.png`는 캔버스 배경 조정 전 기록이다.

기존 페이지·이미지·컴포넌트 원본·B2 비교안은 변경하지 않았다. 웹 코드나 사이트 배포는 이번 작업 범위가 아니다. 현재 검수에서 남은 결함은 발견하지 못했다.
