# PELAGIA · Paperlogy 적용

## 범위와 결과

Figma의 `PELAGIA · 해파리 여왕 · 24 기본형 고정 · 1920` 프레임(`1039:4364`) 안의 편집 가능한 텍스트 163개에만 Paperlogy를 적용했습니다. 기존 글자를 수정하거나 공유 컴포넌트의 마스터를 변경하지 않았습니다. 원래 인스턴스 연결 91개를 유지했습니다.

확인: https://www.figma.com/design/PoUHKHsm9xOYavWBQ7uAGP/?node-id=1039-4364

## 폰트 사용과 조정

- 400 `4 Regular`: 26개
- 500 `5 Medium`: 3개
- 600 `6 SemiBold`: 17개
- 700 `7 Bold`: 104개
- 800 `8 ExtraBold`: 7개
- 900 `9 Black`: 6개

헤더 문구는 12~13px로 맞추고 행 높이는 유지했습니다. 상단 프로모션의 큰 영문은 Paperlogy Black으로 교체하면서 기존 폭 안에서 PAYBACK 94.7px, EVENTS 113.8px, REWARD 97.7px로 조정했습니다. 기존 가운데 기준과 184px 행 높이를 유지하고 자간을 0.5px로 정리했습니다. 나머지 텍스트는 기존 크기와 행간으로 들어가는 것을 확인했습니다.

로고·파트너 로고와 바로가기 이미지에 포함된 래스터 글자는 이미지 원본을 유지했습니다. 배경·사진·마스크·패널·테두리·버튼 재질을 바꾸지 않았습니다.

## Figma 폰트 등록

Windows의 설치 폰트는 확인했으나 MCP에서 사용할 수 없어, [Figma 공식 안내](https://help.figma.com/hc/en-us/articles/360039956894-Add-a-font-to-Figma)의 계정 업로드 경로를 사용했습니다. 사용자는 폰트 업로드 권리 확인 및 Figma 플랫폼 저장·사용 허용에 대해 `동의하고 업로드 진행`이라고 답했습니다. 이 화면에 필요한 TTF 6개 굵기만 사용자 계정에 업로드했습니다. 계정의 폰트 목록에는 등록되지만 다른 화면의 서체를 변경하지는 않습니다. 원본 파일과 프로젝트 TTF·WOFF2 자산은 그대로 보존했습니다.

## 검증

- 원래 1920×1829.2 프레임 크기·위치와 모든 기록된 주요 컨테이너의 크기·위치·패딩·간격 동일. Main Gap 16과 기존 섹션 간격 유지.
- 텍스트 163/163 Paperlogy 확인. 필요한 6개 face 명시 로딩 성공, 로딩 후 missing font 0건.
- 실제 새 폰트로 각 텍스트의 자연 크기를 측정하여 텍스트 박스 넘침 0건 확인.
- 공통 컴포넌트 마스터와 다른 최상위 노드 21개를 변경 전 속성 해시와 비교해 동일함을 확인.
- 인스턴스 91개 연결 변화 0건. 텍스트 내용 변경 0건.
- Figma에서 실제 폭 1920px로 렌더해 전체와 헤더·배너·배당표·게임 카드 문구를 확인했습니다.

헤드리스 검수의 첫 missing font 표본은 해당 실행에서 명시 로딩하기 전에 읽어 참값으로 나왔습니다. 모든 사용 face의 로딩을 먼저 마친 별도 검사에서는 missing font 0건이며 이를 최종 결과로 기록합니다. 캔버스의 폰트 교체를 다시 수행한 것은 아닙니다.

증거: `baseline.json`, `text-baseline.json`, `text-changes.json`, `verification.json`, `before.png`, `after.png`.

## 적용 경계

이 결과는 지정된 Figma 화면에 대한 적용입니다. 웹 CSS·앱 소스·전역 기본 폰트·다른 페이지·운영 배포는 변경하지 않았습니다.
