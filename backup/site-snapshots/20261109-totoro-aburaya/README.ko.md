# TOTORO WORLD · ABURAYA GitHub 업로드

2026-11-09 사용자 요청에 따라 두 로컬 구현을 기존 저장소에 추가한다.

- TOTORO WORLD: `demo-sites/totoro-world-20261102/site/`
- ABURAYA: `demo-sites/aburaya-20261102/site/`
- 각 `site/` 폴더를 웹 루트로 제공하면 된다. `npm start`로 로컬 실행하고 `npm run check`로 JavaScript 구문을 확인한다. 설치·빌드 단계는 없다.
- 소스, 이미지, 투명 WebM 영상, 폰트·라이선스, Figma 입력 참조 및 파비콘을 함께 보관한다. 원본·이전 영상 파일을 삭제하지 않았다.
- 파비콘은 기존 도토리·등불 이미지를 비율·색·알파를 유지하여 변환했다. 각 사이트에 ICO(16/32/48), PNG(16/32/48/512), Apple 아이콘(180)이 있다.
- `source-files.json`에 업로드 파일별 바이트 수·SHA-256을 기록했다. 사본은 원본과 모두 일치했다.
- `qa/verification.json`: 두 사이트 구문 검사, 파비콘 HTTP 200·바이트 일치, 정적 자산 참조 검사, 원본 보존 검사. `qa/browser-checks.json` 및 두 화면 캡처: 실제 브라우저 표시·파비콘 연결 확인.
- 파비콘 12개 생성 성공, 실패 0. ICO 프레임과 대응 PNG의 RGBA 픽셀 일치.
- 본 작업의 브라우저 검수 범위는 파비콘과 홈 화면이다. 기존 영상 호버·게임 데모 동작은 수정하지 않았으며, 기존 검수 범위를 이번에 다시 전체 수행한 것으로 취급하지 않는다.
- 공개 웹사이트 배포, 실제 회원·결제·게임 서버 통합 및 사용자 최종 시각 승인은 별도다.
