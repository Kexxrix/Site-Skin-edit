# DragonBall Z 현재 상태 업로드 · 2026-11-10

사용자 요청 시점의 `demo-sites/dragonball-sunburst-20261109/` 전체 276개 파일을 바이트 변경 없이 보관한다. 사이트 코드, 이미지, 로컬 폰트, 라이브카지노 WebM 8개, 입력 자료와 기존 검수 기록을 포함한다.

현재 사이트에는 추천게임 15장, 슬롯 카드 호버 경계 수정, 라이브카지노 스틸/호버 영상, 하단 메뉴 반투명 배경과 아이콘 중앙 정렬이 포함되어 있다. 정적 실행 루트는 해당 폴더의 `site/`다.

`source-files.json`은 원본 경로, 저장소 경로, 크기, SHA-256과 Git blob SHA-1을 기록한다. 복사본과 원본의 SHA-256을 대조했고 `node --check site/app.js`를 통과했다. 이번 작업은 기존에 수행한 화면 검수를 재사용하며 새로운 디자인 변경이나 공개 사이트 배포를 수행하지 않는다.

원본 README와 검수 문서는 작성 당시 상태 그대로 보존했으므로 과거의 "GitHub 업로드 미포함" 문구는 본 스냅샷 이전 이력이다. 사용자 미감 승인과 공개 사이트 배포는 GitHub 업로드와 별개다.
