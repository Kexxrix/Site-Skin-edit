# 백업 범위와 검증 기록

이 체크아웃은 진행 중인 `E:/codexwork/Site-Skin-edit`의 디스크 파일을 읽어 별도 위치에 복사한 자료입니다. 원래 작업 폴더의 Git 상태·AE 메모리·소스 미디어는 백업 과정에서 변경하지 않습니다. 새 이력 문서는 원래 작업의 `docs/video-production`과 루트 README에 작성했습니다.

| 파일 | 의미 |
| --- | --- |
| `source-files.json` | 원본 경로, 저장소 경로, 파일별 수집 시점·바이트·SHA-256, 복사 전후 원본 안정성 |
| `external-references.json` | 외부 로컬 미디어 참조와 복사본·동일 해시 파일·이동 기록 대응 |
| `summary.json` | 수집 파일·용량·종류·외부 경로 상태와 제외 범위 |
| `content-scan.json` | 파일명·텍스트·ZIP 내부의 강한 자격증명 패턴 검사 범위와 결과 |
| `document-validation.json` | 신규 문서 UTF-8 및 실제 내부 링크 검사 |
| `provenance.json` | 백업 목적·원래 Git 상태·원본 변경 경계·진행 중 출력의 취급 |
| `repository-files.json` | 이 파일 자신을 제외한 저장소 일반 파일의 바이트·SHA-256 목록 |

`source-files.json`은 수집한 원본 파일의 명세이고, `repository-files.json`은 여기에 백업 메타데이터를 더한 저장소 명세입니다. 후자는 자기 자신의 해시를 포함할 수 없어 자신만 제외합니다. Git 커밋은 그 파일까지 포함합니다. 업로드 검증은 별도 새 clone에서 원본 체크아웃과 전체 추적 파일의 SHA-256을 직접 대조합니다.

원래 `titan_promotion`은 독립 Git 저장소입니다. 이번 백업은 해당 작업 파일을 일반 파일로 포함하며 `.git`, Git 이력, `node_modules`, `.next` 및 캐시는 제외합니다. 수정·추적되지 않은 사용자 작업 파일도 현재 디스크 내용대로 보존합니다. 원래 저장소에 commit·reset·clean·pull을 실행하지 않습니다.

`.gitattributes`의 `* -text`와 체크아웃의 `core.autocrlf=false`를 사용해 텍스트·로그의 줄바꿈도 바이트 그대로 보관합니다. 이를 애플리케이션의 새로운 코딩 규약으로 적용한 것은 아닙니다.

외부 원본은 복사만 하며, 내부 동일 해시 파일이 있으면 경로 매핑으로 연결합니다. 이전 도구 출력 경로가 없더라도 같은 실행 JSON에 기록된 파일 해시가 실제 보관본과 일치하면 이동 이력으로 기록합니다. `[###].png` 같은 AE 출력 문자열은 실제 파일명이 아니라 시퀀스 템플릿이므로 보고서에 명시된 실제 frames 폴더를 연결합니다.

제작을 멈추지 않으므로 전체 폴더가 단일 시각에 고정된 원자적 스냅샷은 아닙니다. 현재 작업 중 AEP·로그·검수 프레임이 포함될 수 있습니다. 모든 포함 파일은 복사하는 동안 원본이 변하지 않았음을 확인하지만, 이후 변경·미저장 AE 메모리까지 포함됐다고 주장하지 않습니다. 완성 여부는 버전별 결과·검증·사용자 판정 문서로 결정합니다.
